# SFD (Smithfield Foods, Inc.) 財務狀況全面拆解報告

作為資深美股分析師，針對 **Smithfield Foods (SFD)** 的財務數據及母公司 **萬洲國際 (WH Group, 0288.HK)** 揭露之最新營運實況（註：SFD 目前為萬洲國際全資子公司，其美股代碼已下市，以下分析結合提供之數據與最新產業動態），進行深度解析。

---

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**：
    根據數據，SFD 的 **Sales Q/Q 為 -3.78%**，反映出全球豬肉價格波動及終端需求疲軟。過去 3-5 年，營收成長主要受商品價格（豬價）驅動而非銷量大幅擴張。最新季度營收下滑，主因是美國生豬養殖產能過剩導致價格承壓，以及通膨環境下消費者對肉類支出的結構性調整。
*   **獲利能力與利潤率**：
    *   **毛利率 (Gross Margin)**：**13.44%**。在食品加工業屬於中規中矩，顯示其受上游飼料成本（玉米、大豆）影響極大。
    *   **營業利益率 (Oper. Margin)**：**8.56%**。
    *   **純益率 (Profit Margin)**：**6.85%**。
    值得注意的是，**EPS Q/Q 成長達 25.76%**，在營收下滑的情況下利潤反增，顯示公司正處於「效率驅動型」轉型，透過關閉低效工廠（如 2023-2024 年間關閉多處美國加工廠）及優化供應鏈來擠壓利潤。
*   **費用控制**：
    S&A（銷售與管理費用）控制尚稱穩定。由於產品屬大宗商品性質，研發費用佔比較低，獲利關鍵在於規模經濟與垂直整合（從養殖到加工）的成本對沖。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**：
    *   **P/B 為 1.24**，顯示市場對其資產估值接近帳面價值，溢價不高。
    *   **存貨與應收帳款**：食品業存貨周轉至關重要。目前數據未顯示明顯堆積，但需關注生豬價格波動對存貨價值的潛在減損風險。
*   **負債與償債能力**：
    *   **流動性**：**流動比率 (Current Ratio) 2.56**，**速動比率 (Quick Ratio) 1.34**。這是一個非常健康的信號，顯示公司有充足的短期資產覆蓋債務，短期違約風險極低。
    *   **長期風險**：**Debt/Eq 為 0.34**，**LT Debt/Eq 為 0.25**。負債率極低，這在資本密集型的肉類加工業中表現優異，顯示公司財務策略趨於保守，具備極強的抗風險能力。
*   **無形資產與商譽**：
    作為老牌食品巨頭，商譽主要來自過去的併購。目前獲利尚能支撐，短期內無重大減損跡象。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF) 與盈餘品質**：
    **P/C (股價現金流比) 為 6.42**，顯示公司產生現金的能力強勁。EPS 雖有波動，但現金流相對穩定，盈餘品質良好。
*   **自由現金流 (FCF)**：
    **P/FCF 為 10.96**。換算 FCF Yield 約為 9.1%，這在成熟產業中非常具吸引力。公司產生的現金足以支付其 **5.38% 的股息**。
*   **資本配置 (Capital Allocation)**：
    SFD 近年的資金主要投向：
    1.  **產能優化**：關閉高成本養殖場，轉向高附加值的包裝肉品（Packaged Meats）。
    2.  **股息發放**：5.38% 的殖利率顯示其作為現金牛的屬性。
    3.  **償債**：持續降低槓桿，這從 0.34 的低 Debt/Eq 可以得到印證。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **杜邦分析 (DuPont Analysis)**：
    *   **ROE (15.9%)** = 純益率 (6.85%) × 資產周轉率 (約 1.3-1.5) × 財務槓桿 (約 1.6)。
    *   分析顯示，SFD 的 ROE 並非靠高槓桿堆疊，而是來自於合理的資產周轉與利潤率。
*   **效率指標**：
    **ROI (12.13%)** 高於其資本成本（估計 WACC 約 7-8%），說明公司仍在創造經濟價值（Economic Value Added）。

**最終結論：**
1.  **整體評級**：**穩健**
2.  **核心摘要**：SFD 目前處於產業週期底部回升階段。雖然營收受豬價壓制微跌，但透過嚴格的成本控制與產能重組，獲利能力（EPS）逆勢成長。其極低的負債率（D/E 0.34）與強勁的現金流產生能力，使其在面對經濟衰退或商品價格波動時具備極高的安全邊際。
3.  **關鍵監測指標**：
    *   **包裝肉類利潤率 (Packaged Meats Margin)**：觀察是否能抵銷生豬養殖端的虧損。
    *   **自由現金流收益率 (FCF Yield)**：確認 5.38% 的高股息是否具備長期持續性。
    *   **飼料成本趨勢 (Corn/Soybean Prices)**：直接影響毛利率的關鍵外部變數。
