# Fiserv, Inc. (FI) 財務報表深度分析報告

**註：** Fiserv 已於 2023 年將股票代碼由 **FISV** 更改為 **FI**。以下分析基於 2023 年年報（10-K）及 2024 年前三季（最新為 Q3 10-Q）之官方數據。

---

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**：
    Fiserv 展現了強勁且穩定的有機增長。2023 全年營收達 190.9 億美元（年增 8%），2024 年 Q3 單季營收為 52.1 億美元（年增 7%）。
    *   **成長來源**：主要由 **Merchant Solutions (商戶解決方案)** 驅動，特別是 **Clover** 平台（Q3 交易量增長 15%）。成長模式已從過去的併購驅動轉向「有機成長 + 增值服務（如支付處理與軟體整合）」。
*   **獲利能力與利潤率**：
    *   **毛利率 (Gross Margin)**：維持在 60% 左右的高水準，顯示其在金融科技基礎設施的壟斷地位。
    *   **營業利益率 (Operating Margin)**：2024 Q3 GAAP 營業利益率提升至 28.4%（去年同期為 20.1%），調整後（Adjusted）營業利益率更達到 40.2%。這反映了與 First Data 合併後的規模經濟效益持續釋放。
*   **費用控制**：
    銷售與管理費用（SG&A）佔比穩定下降，顯示公司在自動化與系統整合上的成效。研發費用持續投入於數位銀行與雲端支付，符合其轉型金融科技平台的策略。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**：
    *   **商譽 (Goodwill)**：截至 2024 Q3，商譽高達 375 億美元，佔總資產約 40%。這是多次大型併購（如 First Data）的產物，雖無立即減損風險，但需關注未來收購企業的獲利是否達標。
    *   **周轉情況**：應收帳款周轉天數保持穩定，符合金融服務業特性。
*   **負債與償債能力**：
    *   **流動性**：流動比率與速動比率約在 1.0 左右。雖然看似偏低，但由於其業務具備高度訂閱制與經常性收入特性，現金流預測性高，短期流動性風險極低。
    *   **長期風險**：總債務約 240 億美元。**Debt/EBITDA (槓桿率)** 目前約為 2.8x，公司目標維持在 2.0x - 2.5x。債務結構以長期固定利率債券為主，受短期利率波動影響有限。
*   **淨現金狀況**：公司並非淨現金公司，而是利用適度槓桿來極大化股東回報。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**：
    Fiserv 的現金轉換能力極強。2023 全年 OCF 達 46.7 億美元。2024 年前三季 OCF 已達 37 億美元，與淨利增長趨勢高度同步，盈餘品質優異。
*   **自由現金流 (FCF)**：
    *   **計算**：2024 年預計 FCF 將超過 45 億美元。
    *   **用途**：FCF 主要用於**股份回購**而非派息。2024 年前三季已投入約 38 億美元回購股票，這解釋了為何其 EPS 成長率能高於營收成長率。
*   **資本配置 (Capital Allocation)**：
    公司採取「回購優先」策略。過去 5 年流通股數大幅減少，有效提升了每股價值。資本支出 (CapEx) 佔營收比重維持在 6-7%，主要用於技術平台升級。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **杜邦分析 (DuPont Analysis)**：
    *   **純益率**：約 15-18%（受非現金攤銷影響，調整後更高）。
    *   **資產周轉率**：約 0.21（較低，主因是資產負債表上有龐大的商譽）。
    *   **財務槓桿**：約 2.5x - 3.0x。
    *   **ROE**：目前約 13-15%，透過高利潤率與財務槓桿的結合，為股東創造回報。
*   **ROIC (投入資本回報率)**：
    ROIC 約為 10-12%，高於其加權平均資本成本 (WACC, 約 8%)，顯示公司具備創造超額價值的能力。

### 5. 財務健康總結

| 維度 | 評等 (1-5★) | 關鍵評語 (簡短扼要) |
| :--- | :--- | :--- |
| **獲利能力** | ★★★★★ | 營業利益率持續擴張，Clover 帶動強勁有機增長。 |
| **償債安全性** | ★★★★ | 債務總量雖高，但槓桿率逐年下降，現金流覆蓋能力強。 |
| **現金流品質** | ★★★★★ | FCF 轉換率極高，盈餘含金量充足，回購力道大。 |
| **資本效率** | ★★★★ | 透過大規模回購提升 EPS，ROIC 穩定高於資本成本。 |

**最終結論：**
1. **整體評級**：**優良**
2. **核心摘要**：Fiserv 已成功從傳統後端支付處理商轉型為領先的金融科技平台。其財務特徵為「高利潤、強現金流、高槓桿但受控」。雖然資產負債表商譽較高，但其強大的自由現金流產生能力與積極的股份回購策略，使其在升息環境下仍具備極強的抗風險能力與成長韌性。
3. **關鍵監測指標**：
    *   **Organic Revenue Growth**：觀察是否能維持在 9-11% 的目標區間。
    *   **Adjusted Operating Margin**：觀察規模經濟是否能推動利潤率突破 40%。
    *   **Free Cash Flow Per Share**：作為衡量股東回報核心能力的指標。
