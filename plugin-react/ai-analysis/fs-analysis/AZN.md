# AstraZeneca (AZN) 財務報表深度分析報告

作為資深美股分析師，針對 AstraZeneca (AZN) 最新揭露的 2024 年上半年（H1）財報及年度趨勢，進行以下專業拆解：

### 1. 損益表分析 (Income Statement Analysis)
*   **營收成長動能**：AZN 展現了強勁的內生性成長。2024 年上半年總營收達 256.17 億美元，按固定匯率（CER）計算增長 18%。成長核心來自**腫瘤治療（Oncology, +22%）**與**心血管、腎臟及代謝（CVRM, +22%）**。關鍵藥物如 Tagrisso (+12%)、Farxiga (+36%) 及 Enhertu 表現卓越。成長主要來自銷量增加而非單純漲價，顯示其產品具備極強的市場競爭力。
*   **獲利能力與利潤率**：
    *   **毛利率**：核心產品毛利率維持在 82% 左右的高水準，顯示其專利藥物的定價權。
    *   **營業利益率**：目前約 23.31%，核心營業利益率（Core Operating Margin）則更高。隨著 Alexion 整合完成及規模經濟顯現，利潤率呈現擴張趨勢。
*   **費用控制**：研發費用（R&D）佔營收比重約 21-23%，這在大型藥廠中屬於高投入，但與其「由科學驅動」的成長策略相符。行銷費用（SG&A）佔比隨營收擴大而相對稀釋，顯示營運槓桿正在發揮作用。

### 2. 資產負債表分析 (Balance Sheet Analysis)
*   **資產品質與結構**：截至 2024 年中，公司擁有約 80 億美元現金。應收帳款周轉天數穩定，未見異常堆積。
*   **負債與償債能力**：
    *   **流動性**：流動比率 1.01，速動比率 0.79。雖然數據看似偏低，但考慮到製藥業穩定的現金流入，短期償債風險受控。
    *   **長期風險**：債務對權益比（Debt/Equity）為 0.66，長期債務約 240 億美元。自收購 Alexion 以來，槓桿率已顯著下降，淨債務/EBITDA 比率處於健康區間。
*   **無形資產與商譽**：商譽與無形資產佔總資產比重較高（約 60%），主要來自併購。目前核心產品線銷售強勁，短期內無重大減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)
*   **營業現金流 (OCF)**：2024 年上半年 OCF 達 51 億美元。盈餘品質良好，OCF 與淨利變動趨勢基本同步，顯示利潤具備現金支撐。
*   **自由現金流 (FCF)**：扣除約 11 億美元的資本支出（CapEx）後，FCF 表現穩健。公司利用 FCF 支付股息（2024 中期股息增加 0.20 美元至 1.00 美元）並進行小規模技術併購（如 Amolyt Pharma）。
*   **資本配置**：AZN 採取「研發優先、兼顧派息、策略併購」的模式。資本支出主要投向產能擴張（如新加坡與美國的新廠），以支撐未來生物製劑與抗體偶聯藥物（ADC）的產能需求。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)
*   **ROE (22.6%) 拆解**：
    *   **淨利率 (17.68%)**：處於行業中上游。
    *   **資產周轉率 (0.48)**：符合重資產研發型藥廠特性。
    *   **財務槓桿 (2.6x)**：適度的槓桿放大了股東回報。
*   **ROIC (13.7%)**：明顯高於其加權平均資本成本 (WACC, 約 7-8%)，顯示公司每投入一分錢都能創造超額價值，具備強大的護城河。

**最終結論：**
1. **整體評級**：**優良**
2. **核心摘要**：AstraZeneca 正處於產品收割期，憑藉腫瘤與稀有病領域的強大管線，實現了遠超大藥廠平均水平的營收增速。財務結構在後併購時代持續優化，獲利能力與現金流均處於歷史高位，足以應對高額研發投入與股息發放。
3. **關鍵監測指標**：
    *   **Core Operating Margin**：觀察是否能突破 30% 大關以驗證規模經濟。
    *   **Free Cash Flow Margin**：監控資本支出擴大後對現金流的稀釋程度。
    *   **Net Debt/EBITDA**：確保債務水平隨利潤增長持續下降。
