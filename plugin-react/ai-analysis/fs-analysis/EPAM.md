作為一位資深美股分析師，我將對EPAM Systems Inc (EPAM) 的財務狀況進行全面拆解，並根據最新的財報數據進行評估。

---

### 1. 損益表分析 (Income Statement Analysis)

-   **營收成長動能**
    EPAM的營收在過去幾年呈現穩健增長，但近期增速有所放緩。2025財年營收達到54.57億美元，較2024年增長15.4%。其中，有機固定匯率營收增長4.9%。然而，進入2026年，營收成長動能減弱。2026年第一季度營收為14.00億美元，同比增長7.6%。第二季度營收為14.15億美元，同比增長4.5%，有機固定匯率營收增長3.4%。2026年上半年總營收為28.15億美元，同比增長6.0%。
    營收增長主要來自於對AI原生技術的持續投入和戰略轉型。AI原生營收在2026年第二季度已超過1.6億美元，佔總營收的11%左右，並連續六個季度實現兩位數的環比增長。然而，北美客戶將支出從任務型服務（如手動測試、UX）轉向AI主導的現代化速度快於新收入的產生，加上內部市場推廣執行上的不足，導致北美市場表現不佳，進而影響了整體營收增長預期。公司正透過商業轉型（銷售能力建設、客戶優先級排序）來應對此挑戰。

-   **獲利能力與利潤率**
    EPAM的獲利能力在2026年第二季度有所改善。2026年第二季度GAAP營業利益率為10.8%，較2025年同期的9.3%有所提升。非GAAP營業利益率也從2025年同期的15.0%增長至16.4%。2026年上半年GAAP營業利益率為9.6%。
    從年度數據來看，2025財年GAAP營業利益率為9.5%，低於2024年的10.9%。非GAAP營業利益率也從2024年的16.7%下降至2025年的15.2%。這表明2025年利潤率面臨壓力，但在2026年上半年開始回升。
    淨利率方面，2026年第二季度GAAP淨利潤為1.02979億美元，淨利率約為7.28% (102.979M / 1415M)。2025財年GAAP淨利潤為3.777億美元，淨利率約為6.92% (377.7M / 5457M)。2024財年GAAP淨利潤為4.545億美元，淨利率約為9.61% (454.5M / 4727M)。淨利率在2025年有所下滑，但在2026年第二季度顯示出改善跡象。毛利率在2026年第二季度同比有所改善。整體而言，利潤率在經歷2025年的壓力後，於2026年開始擴張，顯示出公司在成本控制和服務組合優化方面的努力。

-   **費用控制**
    公司在2025年、2024年和2023年分別支出了1460萬美元、1320萬美元和1740萬美元用於人道主義承諾，其中一部分計入銷貨成本。這表明公司在社會責任方面有持續投入。雖然沒有直接的研發費用和行銷費用佔比數據，但營業利益率的變化間接反映了費用控制的狀況。2026年上半年營業利益率的改善，可能與公司在營運效率和費用管理上的努力有關。

### 2. 資產負債表分析 (Balance Sheet Analysis)

-   **資產品質與結構**
    截至2026年6月30日，EPAM的現金、現金等價物及受限現金為7.943億美元，較2025年12月31日的13.01億美元大幅減少。這一下降主要與上半年營運現金流為負以及大量的股份回購有關。
    應收帳款在2026年第二季度增至12.7億美元，高於2025年第二季度的11.6億美元和2024年第一季度的9.314億美元。這可能反映了營收增長，但也意味著更多資金被客戶未支付的發票佔用。2026年第二季度的應收帳款周轉天數 (DSO) 為82天，高於第一季度的76天，這是一個需要關注的效率指標，可能導致現金回收速度變慢。

-   **負債與償債能力**
    EPAM的流動性指標表現健康。流動比率和速動比率均為2.75，顯示公司擁有充足的短期資產來覆蓋短期負債。
    長期債務方面，公司在2026年第二季度大幅減少了長期債務，從2026年3月31日的1.65億美元降至2026年6月30日的2500萬美元。這使得EPAM的債務水平相對其35.2億美元的股東權益而言非常低。債務對權益比率僅為0.04，長期債務對權益比率為0.03，表明公司財務槓桿極低，償債能力非常安全。公司還擁有7億美元的循環信貸額度，並於2025年10月3日簽訂了2030年到期的新循環信貸額度，具有潛在擴大至12億美元的能力。截至2026年6月30日，淨現金狀況良好，儘管現金餘額有所下降。

-   **無形資產與商譽**
    截至2026年第二季度，商譽和無形資產總計約15.8億美元，約佔總資產的三分之一。這反映了收購業務在EPAM資產基礎中的重要性。雖然目前沒有減損風險的具體信息，但如此高的佔比需要持續監測，以確保這些資產的價值能夠持續實現。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**
    EPAM的營業現金流在2026年上半年出現顯著弱化。2026年上半年，公司營運活動使用了3880萬美元現金，而2025年同期則提供了7740萬美元現金。具體來看，2026年第一季度營運現金流為負3640萬美元，第二季度為負240萬美元。這與其同期實現的淨利潤形成對比，表明盈餘品質存在隱憂。
    導致營運現金流為負的主要原因包括變動薪酬支付增加和應收帳款周轉天數 (DSO) 上升。營運資產和負債的變動在2026年第二季度減少了1.037億美元的現金流，在第一季度減少了1.318億美元。相比之下，2025財年營運活動提供了6.549億美元現金，高於2024年的5.592億美元，顯示出過去年度強勁的現金生成能力。

-   **自由現金流 (FCF)**
    由於營運現金流為負，2026年第二季度自由現金流為負1800萬美元。資本支出在2026年第二季度為1420萬美元。
    從年度數據來看，2025財年自由現金流為6.127億美元，2024年為5.271億美元，2023年為5.342億美元。這表明公司在過去幾年有足夠的現金用於擴張。
    公司預計2026年自由現金流轉換率將降至約70%（低於通常的80-90%），但預計下半年將超過100%，並在2026年之後恢復到80-90%的正常水平。

-   **資本配置 (Capital Allocation)**
    EPAM在資本配置方面非常積極，主要集中在股份回購和債務償還。2026年第二季度回購了8500萬美元的股票，上半年累計回購4.09億美元。2026年第一季度回購了3.24億美元股票，其中包括3億美元的加速股票回購協議。自回購計劃啟動以來，已向股東返還了16億美元。
    此外，公司在2026年第二季度償還了大量長期債務，使其從1.65億美元降至2500萬美元。這顯示公司在管理資本結構和提升股東回報方面的承諾。公司在2024年透過收購NEORIS和First Derivative加速了全球戰略，表明其也將資金用於戰略性擴張。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

-   **回報率指標**
    *   **ROE (股東權益報酬率)**：根據基本面數據，EPAM的ROE為11.18%。
        *   **杜邦分析拆解 (以2025年數據為例)**：
            *   淨利率 (Net Profit Margin) = 淨利潤 / 營收 = $377.7M / $5457M = 6.92%
            *   資產周轉率 (Asset Turnover) = 營收 / 平均總資產。2025年總資產49億美元，2024年總資產48億美元。平均總資產約為 (4.9B + 4.8B) / 2 = 4.85B。資產周轉率 = $5457M / $4850M = 1.125次。
            *   權益乘數 (Equity Multiplier) = 平均總資產 / 平均股東權益。2025年股東權益37億美元，2024年股東權益36億美元。平均股東權益約為 (3.7B + 3.6B) / 2 = 3.65B。權益乘數 = $4850M / $3650M = 1.329。
            *   ROE = 淨利率 x 資產周轉率 x 權益乘數 = 6.92% x 1.125 x 1.329 = 10.35%。這與提供的11.18%接近，差異可能來自於平均值的計算方式或數據來源的微小差異。2025年的ROE較2024年有所下降，主要受淨利率下滑影響。
    *   **ROIC (投入資本回報率)**：基本面數據顯示ROI為11.06%。雖然沒有直接的WACC數據，但ROIC高於其低廉的債務成本，表明公司投資資本的效益良好。然而，2026年上半年營運現金流的惡化可能會對未來的ROIC產生負面影響。

-   **效率指標**
    *   資產周轉率：如上述杜邦分析所示，2025年約為1.125次，顯示資產利用效率尚可。
    *   應收帳款周轉天數 (DSO)：2026年第二季度DSO為82天，較第一季度的76天有所延長。這表明應收帳款回收效率下降，需要密切關注。

**最終結論：**
1.  **整體評級**：**存在隱憂**
2.  **核心摘要**：EPAM Systems Inc在償債安全性方面表現卓越，擁有極低的債務和充足的流動性。然而，公司在2026年上半年面臨營收增速放緩及營運現金流轉負的挑戰，主要受北美市場轉型和應收帳款回收效率下降影響。儘管利潤率有所改善且AI業務展現潛力，但現金流品質的惡化和DSO的延長是當前主要的財務隱憂。公司積極的股份回購策略也消耗了大量現金。
3.  **關鍵監測指標**：
    *   **營業現金流 (Operating Cash Flow)**：特別是其與淨利潤的關係，以及營運現金流何時能恢復正增長。

    *   **自由現金流轉換率 (Free Cash Flow Conversion Rate)**：關注公司能否實現下半年自由現金流轉換率超過100%的預期，並恢復至正常水平。
