身為資深美股分析師，我將針對Salesforce Inc (CRM) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Salesforce展現了穩健的營收成長趨勢。過去幾年的年度營收持續增長，從2022財年的265億美元增至2026財年的415億美元，年增長率為10%。截至2026年7月31日的2027財年第二季度，公司營收達到113.5億美元，年增長10.8% (或以固定匯率計算增長11%)。其中，訂閱與支援服務營收為108.2億美元，年增長12% (固定匯率下增長11%)。

營收成長主要來自於其核心CRM產品的強勁需求，以及對AI和數據產品的投資。例如，Agentforce和Data 360的年度經常性收入 (ARR) 在2027財年第二季度達到近39億美元，年增長超過210%，其中Agentforce ARR超過15億美元，年增長超過240%。此外，併購也是營收增長的重要驅動力。2025年11月以96億美元收購的Informatica，在2027財年第二季度貢獻了4.56億美元的營收。公司預計2027財年全年營收將達到461億至464億美元，年增長11%-12%，其中Informatica將貢獻超過3個百分點的增長。近期還宣布了對Contentful、Fin以及Braze的收購，這些都將進一步強化其產品組合並貢獻未來營收。

**獲利能力與利潤率**
Salesforce的獲利能力表現良好。2026財年的營業利益率擴張至20%。在2027財年第二季度，GAAP營業利益率為20.5%，非GAAP營業利益率更高達34.1%。這顯示公司在核心營運上具有較高的效率。毛利率方面，根據提供的基本面數據為74.69%，顯示其產品和服務具有強大的定價能力和較低的變動成本。

然而，2027財年第二季度的GAAP稀釋後每股淨利為4.29美元，年增119%，非GAAP稀釋後每股淨利為5.90美元，年增103%。值得注意的是，GAAP每股淨利受到26.1億美元戰略投資淨收益的顯著提振，該收益約貢獻了每股2.43美元。若排除此一次性收益，其核心獲利能力仍需持續關注。

**費用控制**
儘管財報摘要未提供研發費用 (R&D) 與行銷費用 (S&A) 的具體佔比，但公司在2027財年第二季度實現了20.5%的GAAP營業利益率，並在2026財年將營業利益率擴張至20%。這表明公司在費用控制方面表現出「有效的成本管理和營運效率」。Salesforce持續投資於AI創新，如Agentforce平台，這類投資通常會體現在研發費用中，但其高毛利率和擴張的營業利益率顯示公司能夠有效平衡成長投資與獲利能力。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2026年7月31日，Salesforce的總資產為1096.2億美元。其中，現金及約當現金為83.1億美元，佔總資產的比例約為7.58%，顯示公司擁有充足的流動性。作為一家軟體公司，存貨通常不是其主要資產，因此存貨周轉率的風險較低。應收帳款周轉情況未在摘要中明確提及，但對於訂閱制為主的軟體公司，應收帳款的回收效率是關鍵。

**負債與償債能力**
*   **流動性**：根據提供的基本面數據，Salesforce的流動比率 (Current Ratio) 和速動比率 (Quick Ratio) 均為0.76。這兩個比率均低於1，表明其流動資產不足以完全覆蓋流動負債。這在某些快速成長的軟體公司中並非罕見，因為它們可能依賴遞延收入 (unearned revenue) 作為營運資金，且客戶通常預付訂閱費用。然而，這仍需密切關注，以確保短期償債能力不會惡化。
*   **長期風險**：截至2026年7月31日，長期負債為392.9億美元。根據提供的基本面數據，債務對權益比 (Debt/Equity) 為1.1，長期債務對權益比 (LT Debt/Eq) 為1.09。這表示公司的債務水平相對較高，股東權益與債務的比例接近1:1。雖然軟體公司通常擁有穩定的現金流，可以支持較高的債務水平，但過高的債務仍會增加財務風險。截至2026年7月31日，股東權益為383.8億美元。
*   **淨現金 (Net Cash)**：以現金及約當現金83.1億美元對比長期負債392.9億美元，公司處於淨負債狀態，顯示其營運資金部分依賴外部借款。

**無形資產與商譽**
Salesforce透過多項併購進行擴張，例如Informatica (96億美元) 和Braze (56.6億美元)。這些併購通常會產生大量的商譽和無形資產。雖然財報摘要未提供具體的商譽金額，但投資者應關注其佔總資產的比例，並評估未來是否存在商譽減損的風險，這可能會對獲利能力產生負面影響。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
Salesforce的營業現金流表現強勁。2026財年，營業現金流達到150億美元，年增15%。在2027財年第二季度，營業現金流為13億美元，年增71%。截至2026年7月31日的過去十二個月 (TTM) 營業現金流未直接提供，但自由現金流為152億美元。

*   **盈餘品質**：在2027財年第二季度，營業現金流 (13億美元) 低於GAAP淨利 (約35.2億美元，由稀釋後EPS 4.29美元乘以約8.21億股稀釋後股份計算得出)。這主要是由於該季度淨利受到26.1億美元戰略投資淨收益的顯著提振。若排除此類非經常性收益，營業現金流與核心淨利潤的匹配度會更高，顯示其盈餘品質在正常營運下是健康的。

**自由現金流 (FCF)**
Salesforce的自由現金流表現出色。2027財年第二季度自由現金流為11億美元，年增81%。截至2026年7月31日的過去十二個月自由現金流為152億美元。該季度資本支出 (CapEx) 約為2億美元 (13億美元OCF - 11億美元FCF)。強勁的自由現金流表明公司有足夠的現金用於內部擴張、潛在併購、償債、派息或股份回購。

**資本配置 (Capital Allocation)**
Salesforce在資本配置上採取了多管齊下的策略：
*   **併購**：公司持續透過戰略性併購來擴大其產品組合和市場份額，例如Informatica、Contentful、Fin和Braze。Braze的收購預計將由現金資助，且不預期產生債務。
*   **股份回購**：公司正在執行一項250億美元的加速股票回購計畫 (ASR)，預計於2026年10月完成最終結算。2026財年已回購127億美元的股票。這有助於提升每股盈餘並回饋股東。
*   **發放股息**：2027財年第二季度向股東支付了3.64億美元的股息。2026財年支付了16億美元的股息。這顯示公司在成長的同時也開始向股東提供現金回報。
*   **資本支出**：雖然具體金額未詳述，但從OCF與FCF的差額來看，資本支出相對較低，符合軟體公司的特性。

整體而言，Salesforce的資本配置策略積極且多元，旨在平衡成長、股東回報和財務彈性。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：根據提供的數據為19.38%。
    *   **杜邦分析拆解**：
        *   淨利率 (Net Profit Margin)：根據截至2026年7月31日的過去十二個月淨利97億美元和營收439億美元計算，約為22.1%。
        *   資產周轉率 (Asset Turnover)：根據過去十二個月營收439億美元和總資產1096.2億美元計算，約為0.40倍。這表明每1美元資產產生0.40美元的營收，對於軟體公司而言，由於其資產結構中無形資產佔比較高，此比率通常較低。
        *   財務槓桿 (Financial Leverage)：根據總資產1096.2億美元和股東權益383.8億美元計算，約為2.86倍。
    *   將這些數字代入杜邦公式：ROE = 淨利率 x 資產周轉率 x 財務槓桿 = 22.1% x 0.40 x 2.86 ≈ 25.27%。此計算結果略高於提供的19.38%，差異可能來自於數據採樣時間點或計算方式的細微差異。但無論如何，ROE接近或超過20%顯示公司為股東創造了良好的回報。
*   **ROIC (投入資本回報率)**：根據提供的數據為12.07%。ROIC衡量公司投資資本的效益。雖然沒有WACC的具體數據，但12.07%的ROIC表明公司能夠有效地利用其投入資本產生回報。

**效率指標**
*   **資產周轉率**：如上所述，約為0.40倍。這反映了軟體行業的特性，即資產密集度相對較低，但無形資產和研發投入較高。
*   **存貨周轉天數 (DIO)** 和 **應收帳款周轉天數 (DSO)**：財報摘要中未提供具體數據。對於Salesforce這類以訂閱服務為主的軟體公司，應收帳款周轉天數是更重要的效率指標，因為它反映了客戶付款的速度。
