# Oracle Corp (ORCL) 財務報表深度分析報告

作為資深美股分析師，針對 Oracle（甲骨文）最新的財務表現（結合 FY2025 Q1 財報與市場數據）進行以下專業拆解：

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**：
    Oracle 正處於從傳統軟體授權向雲端轉型的爆發期。FY2025 Q1 總營收達 133 億美元，年增 7%（固定匯率下增長 8%）。成長核心來自 **雲端服務 (Cloud Services)**，其收入達 56 億美元，年增 21%。特別是 **OCI (Oracle Cloud Infrastructure)** 營收大增 45%，顯示其在 AI 算力需求下的強勁競爭力。剩餘履約義務 (RPO) 飆升至 990 億美元（年增 53%），預示未來營收成長動能極其強勁。
*   **獲利能力與利潤率**：
    *   **毛利率**：維持在 71% 左右（Non-GAAP），反映其 SaaS 與 IaaS 業務具備高度規模經濟。
    *   **營業利益率**：Non-GAAP 營業利益率達 43%，較去年同期擴張。這顯示 Oracle 在擴張雲端基礎設施的同時，能有效控制營運成本。
    *   **純益率**：GAAP 純益率約 22%，獲利能力穩定。
*   **費用控制**：
    研發費用 (R&D) 持續投入於 AI 整合與資料庫技術（如 Autonomous Database），行銷費用 (S&A) 佔比穩定。公司透過與 AWS、Google Cloud 及 Azure 的多雲合作，降低了獲客門檻，提升了行銷效率。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**：
    截至最新財報，現金與等價物約 110 億美元。應收帳款周轉天數 (DSO) 保持穩定，顯示客戶回款品質良好。
*   **負債與償債能力**：
    *   **流動性**：流動比率與速動比率約 1.17，短期償債能力尚可，但並不寬裕。
    *   **長期風險**：總債務約 870 億美元，主要源於先前收購 Cerner 的融資。Debt/Equity 比率高達 2.53，財務槓桿較高。然而，Oracle 正在利用強勁的現金流逐步償還債務，過去一年已償還數十億美元債務，債務結構趨向穩定。
*   **無形資產與商譽**：
    商譽佔總資產比重較高（約 500 億美元），主要來自 Cerner 收購。目前 Cerner 整合進度符合預期，短期內無重大減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**：
    過去 12 個月 (TTM) 營業現金流達 191 億美元，盈餘品質極高，OCF 顯著高於淨利，顯示折舊攤銷與遞延收入（雲端預收款）貢獻巨大。
*   **自由現金流 (FCF)**：
    TTM 自由現金流為 113 億美元。值得注意的是，資本支出 (CapEx) 大幅增加至 69 億美元，主要用於擴建 AI 資料中心。儘管 CapEx 侵蝕 FCF，但這是為了支撐 RPO 轉化為營收的必要投資。
*   **資本配置 (Capital Allocation)**：
    Oracle 目前優先順序為：1. 資本支出（擴建雲端）；2. 償還債務；3. 派發股息（殖利率約 1.39%）。股份回購規模較往年縮減，顯示管理層目前更看重業務擴張與去槓桿。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **ROE (41.6%) 拆解**：
    *   **高純益率** (26.1%)：體現軟體業的高附加價值。
    *   **資產周轉率** (0.38)：較低，反映雲端基礎設施屬於資本密集型投入。
    *   **財務槓桿**：高槓桿放大了 ROE。雖然 ROE 數字亮眼，但需警惕債務成本。
*   **ROIC (投入資本回報率)**：
    約 8.5%，雖高於 WACC，但仍有提升空間。隨著 OCI 設施利用率提高，預計 ROIC 將進入上升通道。
*   **效率指標**：
    存貨極低（硬體佔比小），核心效率在於資料中心的上架速度與客戶遷移效率。

### 5. 財務健康總結 (Financial Health Summary)

| 維度 | 評等 (1-5★) | 關鍵評語 (簡短扼要) |
| :--- | :--- | :--- |
| **獲利能力** | ★★★★★ | 雲端轉型成功，營業利益率極具競爭力。 |
| **償債安全性** | ★★★ | 債務總額偏高，但現金流足以覆蓋利息支出。 |
| **現金流品質** | ★★★★ | OCF 強勁，FCF 受高 CapEx 壓制但屬良性投資。 |
| **資本效率** | ★★★★ | RPO 爆發式增長，預示未來資產回報率將提升。 |

**最終結論：**
1. **整體評級**：**優良**
2. **核心摘要**：Oracle 已成功轉型為雲端與 AI 基礎設施領軍者。雖然資產負債表因收購 Cerner 承擔較高債務，但其強大的營業現金流與創紀錄的 RPO（990 億美元）提供了極高的成長確定性。隨著 AI 需求持續，Oracle 正處於利潤擴張與債務縮減的良性循環。
3. **關鍵監測指標**：
    *   **RPO (Remaining Performance Obligations) 成長率**：判斷未來營收的可預見性。
    *   **Free Cash Flow Margin**：觀察在高 CapEx 壓力下，現金流的生成效率。
    *   **Net Debt / EBITDA**：監測去槓桿進度是否符合預期。
