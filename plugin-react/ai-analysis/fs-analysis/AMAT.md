# Applied Materials Inc (AMAT) 財務狀況全面拆解

作為一名資深美股分析師，我將對Applied Materials Inc (AMAT) 的財務狀況進行全面拆解，並根據損益表、資產負債表、現金流量表以及核心財務指標的分析結果，給出具體的財務健康評等。本次分析將主要參考公司最新的2025財年年報 (10-K) 及2026財年第二季度季報 (10-Q)。

---

### 1. 損益表分析 (Income Statement Analysis)

#### 營收成長動能
Applied Materials在過去幾年展現了穩健的營收成長。從2021財年的230.63億美元增長至2025財年的283.7億美元，年複合增長率約為5.3%。
*   2025財年營收為283.7億美元，較2024財年的271.8億美元增長4.38%。
*   2024財年營收增長2.49%。
*   2023財年營收增長2.83%。
*   2022財年營收增長11.84%。
*   最新季度，即2026財年第二季度（截至2026年4月26日），公司實現營收79.1億美元，較去年同期增長11%。
營收成長主要受半導體產業強勁需求驅動，特別是AI運算基礎設施的快速擴建，以及公司在領先邏輯、DRAM和先進封裝領域的強大領導地位。公司管理層預計2026年半導體設備業務將增長超過30%。成長主要來自於市場需求增加和公司產品的差異化價值定價。

#### 獲利能力與利潤率
Applied Materials的獲利能力表現強勁且利潤率呈現擴張趨勢。
*   **毛利率 (Gross Margin)**：
    *   2025財年為48.67% (138.08億美元毛利 / 283.7億美元營收)。
    *   2024財年為47.45%。
    *   2023財年為46.69%。
    *   2022財年為46.50%。
    *   2021財年為47.33%。
    *   2026財年第二季度GAAP毛利率達到49.9%，非GAAP毛利率為50.0%，創下25年來新高。這顯示公司在產品定價和成本控制方面表現出色，並受益於差異化產品的價值定價。
*   **營業利益率 (Operating Margin)**：
    *   2025財年為29.22% (82.89億美元營業利益 / 283.7億美元營收)。
    *   2024財年為28.94%。
    *   2023財年為28.86%。
    *   2022財年為30.20%。
    *   2021財年為29.87%。
    *   2026財年第二季度GAAP營業利益率為31.9%，非GAAP營業利益率為32.1%。營業利益率的擴張表明公司在營收增長的同時，有效控制了營運費用，實現了規模經濟效益。
*   **純益率 (Net Profit Margin)**：
    *   2025財年為24.67% (69.98億美元淨利 / 283.7億美元營收)。
    *   2024財年為26.41%。
    *   2023財年為25.85%。
    *   2022財年為25.30%。
    *   2021財年為25.53%。
    *   2026財年第二季度GAAP淨利潤為28.1億美元，純益率高達35.52%。值得注意的是，此高淨利潤部分受益於股權投資的未實現收益和較低的有效稅率。若以非GAAP淨利潤22.86億美元計算，純益率約為28.90%。

#### 費用控制

    *   2025財年為35.7億美元，佔營收的12.58%。
    *   2024財年為32.33億美元，佔營收的11.90%。

SG&A佔比相對穩定，顯示公司在支持銷售和行政運營方面的費用控制良好。

### 2. 資產負債表分析 (Balance Sheet Analysis)

#### 資產品質與結構
*   **現金與短期投資佔比**：截至2026年4月26日，現金及約當現金為63.01億美元，短期投資為19.4億美元，合計82.41億美元。這佔總資產402.86億美元的約20.46%，顯示公司擁有充足的流動性。
*   **應收帳款 (AR) 與存貨 (Inventory) 的周轉情況**：
    *   截至2026年4月26日，應收帳款為63.72億美元，存貨為63.43億美元。
    *   截至2025年10月26日，應收帳款為51.85億美元，存貨為59.15億美元。
    *   2025財年應收帳款周轉天數 (DSO) 約為66.7天 (51.85億美元 / 283.7億美元 * 365天)，存貨周轉天數 (DIO) 約為148天 (59.15億美元 / 145.6億美元銷貨成本 * 365天)。這些周轉天數在半導體設備行業屬於合理範圍，但存貨周轉天數相對較長，可能反映了供應鏈管理或產品複雜性。公司管理層表示已增加庫存以應對未來需求增長。目前沒有明顯的存貨堆積或應收帳款回收過慢的風險。

#### 負債與償債能力
*   **流動性**：
    *   **流動比率 (Current Ratio)**：截至2025年10月26日，流動資產208.81億美元，流動負債79.99億美元。流動比率為2.61。這高於業界普遍認為的2.0健康標準，顯示公司短期償債能力強勁。
    *   **速動比率 (Quick Ratio)**：截至2025年10月26日，速動資產 (現金及約當現金+短期投資+應收帳款) 137.58億美元，流動負債79.99億美元。速動比率為1.72。這也高於1.0的健康標準，表明公司在不依賴存貨銷售的情況下，仍有良好的短期償債能力。
*   **長期風險**：
    *   **債務對權益比 (Debt/Equity)**：截至2026年4月26日，總債務為65億美元，股東權益為239.09億美元。債務對權益比為0.27。截至2025年10月26日，總債務為65.55億美元 (包含流動負債中的短期債務1億美元和長期債務64.55億美元)，股東權益為204.15億美元。債務對權益比為0.32。這遠低於1.0的水平，顯示公司財務槓桿使用保守，長期償債風險較低。
    *   **長期債務對權益比 (LT Debt/Eq)**：截至2025年10月26日，長期債務為64.55億美元，股東權益為204.15億美元。長期債務對權益比為0.316。這也處於健康水平。
*   **淨現金 (Net Cash) 狀況**：截至2026年4月26日，公司持有現金、約當現金及投資總計133.8億美元 (63億美元現金及約當現金 + 19.4億美元短期投資 + 51.4億美元長期投資)。總債務約為65億美元。因此，公司處於顯著的淨現金狀態，財務非常穩健。

#### 無形資產與商譽
*   截至2026年4月26日，商譽為38.24億美元，其他無形資產為3.3億美元。
*   截至2025年10月26日，商譽為37.07億美元，其他無形資產為2.26億美元。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

#### 營業現金流 (OCF)
*   2025財年營業現金流為79.58億美元。
*   2024財年營業現金流為86.77億美元。
*   2023財年營業現金流為87億美元。
*   2026財年上半年（截至2026年4月26日）營業現金流為25.31億美元。
*   2026財年第二季度單季營業現金流為8.45億美元。
營業現金流與淨利潤基本同步增長，顯示公司盈餘品質良好。2025財年淨利潤為69.98億美元，營業現金流為79.58億美元，營業現金流高於淨利潤，表明公司盈利的現金含量高，盈餘品質優異。

#### 自由現金流 (FCF)
*   **2025財年**：營業現金流79.58億美元 - 資本支出22.6億美元 = 自由現金流56.98億美元。
*   **2024財年**：營業現金流86.77億美元 - 資本支出11.9億美元 = 自由現金流74.87億美元。
*   **2023財年**：營業現金流87億美元 - 資本支出11.06億美元 = 自由現金流75.94億美元。
*   **2026財年第二季度單季**：營業現金流8.45億美元 - 資本支出6.35億美元 = 自由現金流2.1億美元。
*   **2026財年上半年**：營業現金流25.31億美元 - 資本支出12.81億美元 = 自由現金流12.5億美元。
公司持續產生可觀的自由現金流，儘管2026財年第二季度單季自由現金流因較高的資本支出而顯著下降。這表明公司有足夠的現金用於擴張、派息和回購。

#### 資本配置 (Capital Allocation)
Applied Materials的資本配置策略清晰，主要用於支持業務增長、回饋股東。
*   **資本支出 (CapEx)**：公司持續進行大量資本支出，2025財年為22.6億美元，2026財年上半年為12.81億美元。這反映了公司對新產品和技術的投資，以及擴大製造能力的承諾，以滿足AI驅動的半導體需求。
*   **股息發放與股份回購**：公司積極通過股息和股份回購回饋股東。2026財年第二季度，公司向股東返還了7.65億美元，其中包括4億美元的股份回購和3.65億美元的股息。公司還宣布將季度股息提高15%。
*   **併購**：公司也進行戰略性併購，例如計劃中的NEXX收購，以擴展技術和客戶合作策略。
整體而言，Applied Materials的資本配置效率較高，平衡了成長投資和股東回報。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

#### 回報率指標
*   **ROE (股東權益報酬率)**：根據提供的基本面數據，AMAT的ROE為39.69%。
    *   **杜邦分析 (2025財年)**：
        *   淨利率 (Net Profit Margin)：24.67% (69.98億美元淨利 / 283.7億美元營收)。
        *   資產周轉率 (Asset Turnover)：0.78次 (283.7億美元營收 / 362.99億美元總資產)。
        *   權益乘數 (Equity Multiplier)：1.78倍 (362.99億美元總資產 / 204.15億美元股東權益)。
        *   計算ROE = 24.67% * 0.78 * 1.78 = 34.28%。雖然與提供的39.69%略有差異（可能由於計算時點或平均值差異），但仍顯示公司擁有極高的股東權益報酬率，主要得益於強勁的淨利率和適度的財務槓桿。
*   **ROIC (投入資本回報率)**：提供的ROI為28.49%。這是一個非常高的回報率，表明公司在投入資本方面創造了顯著的價值，遠超其加權平均資本成本 (WACC)，顯示出卓越的資本配置效率和競爭優勢。

#### 效率指標
*   **資產周轉率 (Asset Turnover)**：2025財年為0.78次，表明公司資產利用效率良好，每1美元資產能產生0.78美元的營收。
*   **存貨周轉天數 (DIO)**：2025財年約為148天，顯示存貨管理效率尚可，但仍有優化空間。
*   **應收帳款周轉天數 (DSO)**：2025財年約為66.7天，表明應收帳款回收效率良好。
