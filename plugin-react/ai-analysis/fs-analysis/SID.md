### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Companhia Siderurgica Nacional (CSN) 在2025財年實現了R$ 44,797.9百萬的淨營收，較2024年的R$ 43,690百萬增長了2.5%。這主要得益於其礦業、物流和能源業務的良好表現。然而，最新的2026年第一季度淨營收為R$ 11.8億，雖然鋼鐵市場價格和鐵礦石價格上漲抵消了鋼鐵銷量12%的下降和鐵礦石銷量16%的下降，但整體營收仍面臨壓力。從季度趨勢來看，2025年第四季度淨營收為R$ 11,403.2百萬，較第三季度的R$ 11,794百萬下降3.3%，也較2024年同期下降5.2%，這反映了年末和雨季的季節性營運疲軟，以及2024年第四季度鐵礦石價格快速上漲的有利影響不再。營收成長主要來自於多樣化業務板塊的貢獻，而非單一業務的銷量或漲價驅動。

**獲利能力與利潤率**
CSN在2025年的毛利潤為R$ 12,393.7百萬，毛利率為27.7%，較2024年的26.8%提升了0.9個百分點。這顯示公司在營收略有增長的情況下，通過營運效率的提升實現了毛利率的擴張。然而，儘管毛利率有所改善，公司在2025年仍錄得R$ 2.0百萬的淨虧損，但虧損幅度較2024年減少了22.74%。這表明公司在控制成本方面取得了一定進展，但整體盈利能力仍受高財務費用等因素影響。

從季度數據來看，2025年第四季度的毛利潤為R$ 3,668.1百萬，毛利率達到32.2%，較第三季度的29.4%顯著提升2.8個百分點。這反映了有利的成本動態，即使營收有所下降，公司仍能提高毛利率。2025年第三季度公司實現了R$ 76百萬的淨利潤，較前一季度的R$ 130百萬淨虧損有顯著改善。

營業利益率方面，2025年鋼鐵業務的調整後EBITDA利潤率為10.0%，較2024年的6.9%有所提升。能源業務在2025年的調整後EBITDA利潤率高達37.4%。這表明公司在不同業務板塊的獲利能力存在差異，且部分業務表現強勁。整體而言，利潤率呈現波動但有改善的趨勢，尤其在毛利率層面。

**費用控制**
財報中未直接提供研發費用 (R&D) 與行銷費用 (S&A) 的具體佔比數據。然而，S&P Global Ratings指出，CSN在2026年的EBITDA可能因礦業成本上升、水泥業務增長放緩以及鋼鐵業務持續面臨挑戰而受限。這暗示公司在營運成本控制方面仍面臨壓力。公司管理層正試圖通過資產剝離和新的融資線來改善資本結構。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2026年第一季度末，CSN的現金及約當現金為R$ 14.6億。這筆現金足以覆蓋其短期債務。2025年12月，公司現金餘額為R$ 15.1億，其中R$ 3.5億在控股公司層面。財報中未提供應收帳款 (AR) 與存貨 (Inventory) 的具體周轉情況，因此無法直接評估是否存在存貨堆積或應收帳款回收過慢的風險。

**負債與償債能力**
*   **流動性**：CSN在2025年的流動比率 (Current Ratio) 為1.11，速動比率 (Quick Ratio) 為0.70。流動比率略高於1，速動比率低於1，這表明公司依賴存貨來滿足短期負債，流動性狀況尚可但並非非常強勁。
*   **長期風險**：截至2026年第一季度末，CSN的合併淨債務達到R$ 40,505.0百萬。淨債務對過去12個月EBITDA的比率為3.36倍。S&P Global Ratings在2026年3月將CSN的評級從'B+'下調至'B'，主要原因是預計2026年EBITDA將受限，且槓桿率將維持在5.0x-6.0x的高端範圍。公司管理層的目標是將淨債務/EBITDA維持在約1倍的水平，並在併購和下行週期時不超過2倍。目前3.36倍的槓桿率遠高於管理層的目標，顯示其債務負擔較重。
    *   債務結構方面，截至2025年12月，公司短期債務為R$ 10.4億，其中R$ 6.2億在控股公司層面。公司正在積極進行負債管理，包括新的鐵礦石預付款協議和資產出售計劃。季後，CSN簽署了一筆12億美元的過渡性貸款，主要以其水泥業務作為抵押，旨在減少中短期債務。
*   **淨現金 (Net Cash) 狀況**：公司處於淨負債狀態，而非淨現金狀態。

**無形資產與商譽**
截至2025年12月31日，CSN合併財務報表中的無形資產（包括商譽）為R$ 5,033百萬，較2024年的R$ 4,379百萬有所增加。無形資產佔總資產的比例需要進一步分析，但其絕對金額較大，且每年需要進行減值測試。商譽過高可能存在減損風險，尤其是在公司盈利能力承壓的情況下。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
財報中未直接提供2025年或2026年第一季度的營業現金流 (OCF) 具體數字。然而，2026年第一季度的自由現金流為負R$ 1,597.7百萬。這主要是由於季節性營運疲軟、營運資金消耗、高額財務費用和大量債務攤銷所致。這表明營運產生的現金流未能覆蓋其需求，盈餘品質存在隱憂，若OCF長期低於淨利，可能暗示公司盈利的現金含量不足，或存在大量非現金費用。

**自由現金流 (FCF)**
2026年第一季度，CSN的自由現金流 (FCF) 為負R$ 1,597.7百萬。這表明公司目前沒有足夠的現金用於擴張、派息或回購，反而需要外部融資來彌補現金缺口。S&P Global Ratings預計2026年自由營運現金流 (FOCF) 將出現R$ 410百萬的赤字。這對公司的財務健康構成壓力。

**資本配置 (Capital Allocation)**
2026年第一季度的資本支出 (CapEx) 為R$ 1,125.6百萬，較前一季度下降44.9%。S&P Global Ratings預計2026年的資本支出為R$ 6.2億。公司正在進行礦業設施擴張，目標是到2026年將產量從2021年的水平翻倍，到2031年翻三倍。這表明公司將資金主要投向資本支出以支持長期增長戰略。然而，在自由現金流為負的情況下，大規模資本支出可能會進一步加劇現金流壓力。公司也通過資產出售和新的融資來管理債務，顯示其在資本配置上優先考慮償債和維持流動性。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：CSN在2025年的標準化股東權益報酬率 (Normalized ROE) 為-6.53%。負的ROE表明公司未能為股東創造價值，這與其2025年的淨虧損一致。
*   **ROIC (投入資本回報率)**：2025年的標準化投入資本回報率 (Normalized ROIC) 為3.80%。這表明公司投資資本的效益較低。如果ROIC低於其加權平均資本成本 (WACC)，則意味著公司正在摧毀價值。考慮到其高槓桿和負盈利，ROIC很可能低於WACC。

**效率指標**
*   **資產周轉率、存貨周轉天數 (DIO)、應收帳款周轉天數 (DSO)**：財報中未直接提供這些具體指標。然而，2026年第一季度淨營運資金增加至R$ 3,897.7百萬，這可能暗示營運資金效率有所下降，需要更多資金來支持營運。

**最終結論：**
1.  **整體評級**：存在隱憂
2.  **核心摘要**：Companhia Siderurgica Nacional (SID) 的財務健康狀況存在顯著隱憂。儘管2025年營收略有增長且毛利率有所改善，但公司仍處於淨虧損狀態，且槓桿率高企，遠超其內部目標。最令人擔憂的是，自由現金流持續為負，表明公司營運產生的現金不足以支持其擴張和償債需求。S&P Global Ratings的評級下調也印證了其面臨的財務壓力。
3.  **關鍵監測指標**：
    *   **淨債務/EBITDA**：監測其槓桿率是否能有效降低至管理層目標範圍。
    *   **自由現金流 (FCF)**：關注公司能否轉為正向自由現金流，以支持營運和減少對外部融資的依賴。
    *   **毛利率與淨利潤率**：觀察公司在鋼鐵、礦業等核心業務的盈利能力是否能持續改善並轉虧為盈。
