# Companhia Siderurgica Nacional ADR (SID) 財務狀況全面拆解

作為一名資深美股分析師，我將針對Companhia Siderurgica Nacional ADR (SID) 的財務狀況進行全面拆解，並根據最新的財報數據（主要參考2025年年報及2026年第一季度財報）進行分析。

---

### 1. 損益表分析 (Income Statement Analysis)

-   **營收成長動能**：
    SID在2025財年的淨營收達到R$ 44,797.9百萬，較2024年增長2.5%。2026年第一季度，公司營收為2.13億美元，超出分析師預期。營收增長主要來自於多元化業務板塊的貢獻，特別是礦業部門受益於鐵礦石價格上漲和營運改善。鋼鐵部門在2025年第三季度也實現了銷量增長，主要受惠於海外市場的強勁表現，儘管國內市場因進口競爭面臨價格調整壓力。水泥部門亦有增長貢獻。2025年總產量達到45.6百萬噸，創下CSN歷史新高。

-   **獲利能力與利潤率**：
    SID的獲利能力面臨嚴峻挑戰。2026年第一季度，公司每股盈餘(EPS)為-0.084美元，遠低於分析師預期。截至2026年5月的過去十二個月(TTM)淨利潤為-R$ 2.00億，顯示公司處於持續虧損狀態。2023財年淨利潤為R$ 403百萬，較2022年大幅減少81%。毛利率方面，截至2026年5月的TTM毛利率為27.4%，與提供數據的27.17%相近，顯示毛利率相對穩定。然而，淨利潤率為負值（TTM約-4.5%），表明公司在扣除所有費用後未能實現盈利。
    營業利益率方面，提供數據為10%。EBITDA利潤率在2026年第一季度擴張至31.2%，2023財年調整後EBITDA利潤率為25%，2023年第四季度為29.1%。儘管EBITDA利潤率有所改善，但未能有效轉化為淨利潤，這可能與高額的財務費用有關。公司在2025年實現了歷史最高的總產量和四年來最低的鋼鐵生產成本，這暗示了規模經濟的潛力，但尚未完全體現在淨利潤上。

-   **費用控制**：
    2025財年，銷售、一般及管理費用(SG&A)為R$ 6,012.3百萬，較2024年下降4.7%，主要得益於鋼鐵部門商業活動的減少，顯示公司在費用控制方面做出努力。然而，2025年第四季度其他營業收入和費用錄得R$ 1,543.7百萬的負餘額，較第三季度大幅增長353.1%，這是一個值得關注的費用激增。

### 2. 資產負債表分析 (Balance Sheet Analysis)

-   **資產品質與結構**：
    公司最近期報告的現金及現金等價物為R$ 13.28億，這是一筆可觀的現金儲備。然而，報告中未提供應收帳款(AR)與存貨(Inventory)的具體周轉天數，因此無法直接評估存貨堆積或應收帳款回收過慢的風險。

-   **負債與償債能力**：
    -   **流動性**：
        SID的流動比率(Current Ratio)為1.11，速動比率(Quick Ratio)為0.70。流動比率略高於1，表明公司短期資產勉強能覆蓋短期負債。但速動比率低於1，顯示公司在不依賴存貨變現的情況下，短期償債能力較弱，存在流動性壓力。
    -   **長期風險**：
        SID的負債水平極高。最近期報告的總債務為R$ 50.86億。股東權益對債務比(Total Debt/Equity)為323.93%（約3.24倍），提供數據為4.01，兩者均顯示極高的財務槓桿。長期債務對權益比(LT Debt/Equity)為265.50%（約2.66倍），提供數據為3.28，同樣處於高位。
        2026年第一季度，公司的槓桿比率（淨債務/EBITDA）從3.47倍改善至3.36倍，儘管有所改善，但仍處於高位，對於週期性行業而言風險較大。更令人擔憂的是，2025年的利息覆蓋率(Interest Coverage)僅為0.62，這意味著公司的營業利潤不足以支付其利息費用，償債能力存在重大風險。截至2023年第四季度，公司擁有R$ 16億的流動性，但淨債務在2024年第一季度較去年同期增加了R$ 1.2億。考慮到總債務和現金餘額，淨債務規模龐大。

-   **無形資產與商譽**：
    報告中未提供有關商譽(Goodwill)及其減損風險的具體信息。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**：
    2023年第四季度，公司實現了R$ 387百萬的強勁現金流，有助於減少債務。然而，2026年第一季度報告顯示自由現金流為負。過去十二個月(TTM)的槓桿自由現金流(Levered Free Cash Flow)為-423.35百萬美元，而未槓桿自由現金流(Unlevered Free Cash Flow)為89.86百萬美元。槓桿和未槓桿自由現金流之間的巨大差異突顯了債務和利息支付對公司現金流的沉重負擔。
    -   **盈餘品質**：由於近期淨利潤為負且自由現金流為負，營業現金流並未與淨利潤同步增長，甚至無法覆蓋資本支出和債務需求，這表明公司的盈餘品質不佳，或其核心業務未能產生足夠的現金。

-   **自由現金流 (FCF)**：
    2026年第一季度，SID的自由現金流為負，TTM槓桿自由現金流為-423.35百萬美元。這表明公司在支付資本支出和債務義務後，沒有足夠的現金用於擴張、派息或股票回購。提供的數據中股息率為"-"，與負自由現金流的狀況一致。

-   **資本配置 (Capital Allocation)**：
    公司在2023年下半年投入了R$ 1.6百萬的資本支出，被描述為「最高」並顯示「項目快速進展」。SID積極通過發行債券和債權來管理其債務，並將資金用於基礎設施投資。這表明公司主要將資金用於維持和發展其核心業務，同時努力應對其龐大的債務負擔。然而，負的自由現金流限制了其在擴張、派息或回購方面的靈活性。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

-   **回報率指標**：
    -   **ROE (股東權益報酬率)**：
        提供的ROE為-0.1567，Morningstar 2025年標準化ROE為-6.53%。兩者均為負值，表明公司正在為股東創造負回報，損害股東價值。
        杜邦分析顯示，負的淨利潤率是導致負ROE的主要原因。儘管公司擁有極高的財務槓桿（債務權益比超過3倍），但這種高槓桿在淨利潤為負的情況下，反而會放大負回報，對股東權益造成更大的侵蝕。
    -   **ROIC (投入資本回報率)**：
        Morningstar 2025年標準化ROIC為3.80%。雖然為正值，但考慮到公司的高負債和相關風險，其加權平均資本成本(WACC)可能更高。若ROIC低於WACC，則意味著公司未能有效利用其投入資本創造價值。

-   **效率指標**：
    報告中未直接提供資產周轉率、存貨周轉天數(DIO)和應收帳款周轉天數(DSO)的具體數據。然而，2025年創紀錄的總產量 可能暗示了一定的資產利用效率，但若產品價格受壓，高周轉率也難以轉化為盈利。

**最終結論：**
1.  **整體評級**：具重大風險
2.  **核心摘要**：Companhia Siderurgica Nacional (SID) 面臨嚴峻的財務挑戰。公司近期持續虧損，股東權益報酬率為負，顯示盈利能力嚴重不足。其資產負債表呈現極高的財務槓桿，債務權益比超過3倍，且利息覆蓋率低於1，償債能力存在重大隱憂。儘管營收有所增長且EBITDA利潤率有所改善，但營運現金流不穩定，自由現金流為負，表明公司難以從核心業務產生足夠現金。整體而言，SID的財務健康狀況不佳，存在重大風險。
3.  **關鍵監測指標**：
    *   **淨債務/EBITDA (Net Debt/EBITDA)**：持續監測其槓桿比率，目標是顯著降低。
    *   **自由現金流利潤率 (Free Cash Flow Margin)**：觀察公司能否從營運中產生正向自由現金流，以支持其營運和債務償還。
    *   **利息覆蓋率 (Interest Coverage Ratio)**：密切關注其能否產生足夠的營業利潤來覆蓋其龐大的利息支出。
