### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Companhia Siderurgica Nacional (SID) 的營收在過去幾年呈現波動。根據最新數據，該公司2025年的年度營收為448.0億巴西雷亞爾 (BRL)，較2024年的436.9億BRL增長2.54%。回溯至過去五年，其營收在2021年達到479.1億BRL的高峰，隨後在2022年和2024年有所下降，但在2023年和2025年再次增長。具體而言，2021年營收增長48.4%，2022年下降2.3%，2023年增長11.6%，2024年下降24.6%，2025年增長15.8% (此處數據與略有差異，以的BRL數據為準)。最近的2026年第二季度，SID的營收為21.8億美元，超出預期2.83%。從營收趨勢來看，公司營收波動較大，可能受到大宗商品價格、巴西國內經濟狀況以及國際市場需求等多重因素影響。公司業務多元化，涵蓋鋼鐵、礦業、水泥、能源和物流，其中鋼鐵和礦業是主要的營收來源。2026年第二季度鋼鐵銷售量同比增長16.7%，主要得益於巴西的反傾銷措施以及國內外需求的增強。

**獲利能力與利潤率**
SID的獲利能力面臨挑戰。根據最新數據，其毛利率為25.78%，營業利益率 (EBIT Margin) 為7.76%，而淨利率 (Net Income Margin) 則為-5.82%。這表明公司在扣除銷售成本後仍有一定利潤空間，但營業費用和財務費用侵蝕了大部分利潤，導致最終錄得淨虧損。2026年第二季度，公司報告調整後每股虧損0.1121美元。
分業務板塊來看，2026年第二季度鋼鐵業務的EBITDA利潤率從第一季度的7%上升至10.5%，管理層預計下半年將達到15-17%，這得益於定價策略和反傾銷措施。水泥業務EBITDA利潤率達到30-32%的歷史新高，物流業務EBITDA利潤率也達到45.2%。儘管部分業務板塊表現強勁，但整體淨利潤仍為負，顯示公司在成本控制和財務費用方面存在壓力。

**費用控制**
2025年全年，銷售、一般及管理費用 (SG&A) 總計60.123億BRL，較2024年下降4.7%，主要原因是鋼鐵業務商業活動減少。這表明公司在某些費用方面進行了控制。然而，儘管營運層面有所改善，但高昂的財務成本和投資需求持續消耗營運收益，導致自由現金流持續為負。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2026年第二季度末，SID的淨營運資本 (Net Working Capital) 降至30.464億BRL，環比下降21.8%，主要來自於庫存的減少。這表明公司在優化營運資本方面取得進展，有助於釋放現金。然而，具體的應收帳款和存貨周轉天數數據未直接提供，無法判斷是否存在存貨堆積或應收帳款回收過慢的風險。

**負債與償債能力**
*   **流動性**：SID的流動比率 (Current Ratio) 為1.15，速動比率 (Quick Ratio) 為0.79。流動比率略高於1，速動比率低於1，表明公司短期償債能力尚可，但對存貨的依賴較高。
*   **長期風險**：SID的負債水平非常高。截至2026年第二季度末，合併淨債務為421.382億BRL，淨債務/過去12個月EBITDA (Net Debt/LTM EBITDA) 為3.49倍。債務對權益比 (Debt/Equity) 高達4.47，甚至有報告指出為356.987% (約3.57倍)，顯示公司高度槓桿化。高額債務是SID面臨的重大風險，財務費用持續消耗公司利潤。公司正在通過資產出售來降低債務負擔，例如出售德國長材業務Stahlwerk Thüringen和水泥業務。
*   **淨現金狀況**：截至2026年第二季度末，現金及現金等價物總計154億BRL，足以覆蓋短期債務。然而，考慮到龐大的淨債務，公司整體處於淨負債狀態。

**無形資產與商譽**
報告中未直接提供商譽 (Goodwill) 的具體金額，因此無法評估其佔比及減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
2026年第二季度，SID報告自由現金流轉為正值，達到8.081億BRL。然而，這得益於融資操作（包括過渡性貸款）和營運資本的釋放。排除這些影響後，調整後的自由現金流仍為負7.14億BRL。這表明儘管營運有所改善，但公司核心營運活動產生的現金流仍不足以覆蓋其需求，盈餘品質存在隱憂。過去五個季度，調整後的自由現金流累計為負49億BRL。

**自由現金流 (FCF)**
如前所述，儘管2026年第二季度報告的自由現金流為正，但調整後仍為負。這意味著公司沒有足夠的現金用於擴張、派息或回購。事實上，SID目前不支付股息。持續的負自由現金流是公司面臨的關鍵問題，表明其無法通過內部產生現金來減少債務或支持增長。

**資本配置 (Capital Allocation)**
2026年第二季度，公司投資支出 (CapEx) 達到14.14億BRL，較第一季度增長25.6%。這表明公司仍在進行資本擴張。然而，鑑於其高額債務和負調整自由現金流，公司主要的資金投向應是償債。公司正積極通過資產出售（如水泥業務）來籌集資金以減少債務。資本配置的效率受到高槓桿和持續負現金流的影響，可能導致公司在戰略性投資方面受限。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：SID的股東權益報酬率 (ROE) 為-20.40% (來自用戶提供數據) 或-23.22%，顯示公司目前處於虧損狀態，未能為股東創造價值。
    *   **杜邦分析拆解 (基於用戶提供數據)**：
        *   淨利率 (Profit Margin): -5.86%
        *   資產周轉率 (Asset Turnover): ROA / Profit Margin = -0.0263 / -0.0586 ≈ 0.448
        *   權益乘數 (Financial Leverage): ROE / ROA = -0.204 / -0.0263 ≈ 7.75
        *   ROE = 淨利率 x 資產周轉率 x 權益乘數 = -5.86% x 0.448 x 7.75 ≈ -20.40%
    *   高權益乘數 (7.75) 表明公司高度依賴債務融資，這在高淨利率為負的情況下會放大虧損，導致ROE為負。
*   **ROIC (投入資本回報率)**：SID的投入資本回報率 (ROIC) 為-4.46% (來自用戶提供數據) 或4.13%。如果採用-4.46%，則表明公司投資資本的效益為負，遠低於其加權平均資本成本 (WACC)，未能有效利用投入資本。如果採用4.13%，雖然為正，但仍需與WACC比較才能判斷是否創造價值。考慮到公司持續虧損和高負債，ROIC可能偏低。

**效率指標**
*   **資產周轉率**：約0.448 (根據杜邦分析計算)，表明公司資產利用效率不高，每單位資產產生的營收較少。
*   **存貨周轉天數 (DIO)**、**應收帳款周轉天數 (DSO)**：具體數據未直接提供，但2026年第二季度淨營運資本下降主要來自於庫存減少，這可能暗示存貨周轉有所改善。
