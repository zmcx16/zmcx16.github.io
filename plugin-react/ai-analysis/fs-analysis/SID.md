Companhia Siderurgica Nacional ADR (SID) 是一家巴西綜合鋼鐵生產商，業務涵蓋鋼鐵、礦業、物流、能源和水泥等多個領域。作為資深美股分析師，我將根據其最新財報（主要為2026年第二季度、2026年第一季度及2025年全年報告）對其財務狀況進行全面拆解。

---

### 1. 損益表分析 (Income Statement Analysis)

-   **營收成長動能**
    Companhia Siderurgica Nacional (SID) 在2025年實現了R$ 44,797.9百萬的淨營收，較2024年增長2.5%。這項增長主要得益於礦業、物流和能源業務的良好表現。其中，礦業部門在2025年實現了歷史最佳營運表現，物流部門也因貨運量增加和Tora Group的併購而成為主要增長動力。
    然而，進入2026年，營收表現有所波動。2026年第一季度，公司報告的營收為20.1億美元（約R$ 10.41億，按R$ 5.18/USD匯率計算），略低於分析師預期。到了2026年第二季度，鋼鐵業務的淨營收環比增長14.3%至R$ 6,076百萬，主要受銷量增加和定價改善的推動。鋼鐵銷量同比增長16.7%，得益於巴西的反傾銷措施以及國內外需求的增強。能源部門淨營收達R$ 395.5百萬，物流部門淨營收達R$ 1,213.9百萬。整體而言，公司營收成長動能來自於多元化業務的支撐，特別是礦業和物流在2025年的強勁表現，以及2026年第二季度鋼鐵業務的復甦。

-   **獲利能力與利潤率**
    2025年全年，公司毛利潤為R$ 12,393.7百萬，毛利率為27.7%，較2024年增長0.9個百分點。這反映了公司在營運效率上的提升。2025年第四季度毛利率更高達32.2%，環比增長2.8個百分點，顯示出成本動態的有利變化。
    然而，2026年第一季度毛利率降至23.12%。2026年第二季度，儘管綜合調整後EBITDA環比增長4.6%，同比增長5%至R$ 2,773百萬，但EBITDA利潤率為23.4%，略低於上一季度的23.9%。鋼鐵部門的調整後EBITDA利潤率從第一季度的7.0%大幅提升至第二季度的10.5%，絕對EBITDA環比增長61.8%。能源部門的調整後EBITDA利潤率高達62.1%，物流部門為45.2%。
    整體來看，公司的利潤率波動較大，但多元化業務（特別是能源和物流）展現出較高的利潤率，有助於穩定整體獲利能力。鋼鐵業務的利潤率在2026年第二季度有所改善，但仍需持續關注其穩定性。

-   **費用控制**
    財報摘要中未提供詳細的研發費用 (R&D) 和行銷費用 (S&A) 佔比數據。然而，2025年全年銷貨成本 (COGS) 為R$ 32,404.2百萬，較2024年略增1.3%，主要由於礦業銷量創紀錄和多式聯運業務的擴張。2025年第四季度銷貨成本環比下降7.1%，同比下降6.2%，反映出商業活動的減少，特別是鋼鐵和水泥部門。這表明公司在成本控制方面具有一定的彈性，但具體費用結構仍需查閱完整財報。

### 2. 資產負債表分析 (Balance Sheet Analysis)

-   **資產品質與結構**
    2026年第二季度，公司淨營運資本 (Net Working Capital) 降至R$ 3,046.4百萬，環比下降21.8%，主要得益於庫存的減少。這表明公司在營運資本管理方面有所改善，降低了存貨堆積的風險。應收帳款周轉情況未在最新報告中詳細說明，但營運資本的改善通常意味著資產效率的提升。

-   **負債與償債能力**
    -   **流動性**：根據提供的基本面數據，公司的流動比率 (Current Ratio) 為1.11，速動比率 (Quick Ratio) 為0.73。流動比率略高於1，速動比率低於1，這表明公司短期償債能力尚可，但對存貨的依賴性較高，若存貨變現能力不佳，可能存在流動性壓力。
    -   **長期風險**：截至2026年第二季度，公司合併淨負債為R$ 42,138.2百萬。淨負債對過去12個月EBITDA的比率 (Net Debt/LTM EBITDA) 為3.49倍。儘管現金生成有所改善，但這一槓桿比率仍然偏高。提供的基本面數據顯示債務對權益比 (Debt/Eq) 為4.01，長期債務對權益比 (LT Debt/Eq) 為3.28，這些數據也印證了公司較高的財務槓桿。高負債水平增加了公司的長期財務風險。
    -   **淨現金狀況**：截至2026年第二季度，現金及現金等價物總計R$ 15.4億，足以覆蓋短期債務。儘管淨負債高企，但充足的現金儲備在一定程度上提供了緩衝。

-   **無形資產與商譽**
    最新財報摘要中未提供無形資產與商譽的具體數據，因此無法評估其佔比及減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**
    2026年第二季度，公司實現了R$ 808.1百萬的正自由現金流，扭轉了近期負現金流的局面。這主要得益於穩健的營運、營運資本的釋放以及近期融資交易。雖然未直接提供營業現金流數據，但正向的自由現金流表明營運活動產生了足夠的現金。過去幾個季度淨利潤為負值（例如2026年第一季度EPS為-0.09美元，2026年第二季度EPS為-0.12美元），而自由現金流轉正，這可能暗示了較好的盈餘品質，即淨利潤的負值可能受到非現金項目（如折舊攤銷）的影響，而實際現金流表現優於帳面利潤。

-   **自由現金流 (FCF)**
    2026年第二季度自由現金流為正R$ 808.1百萬。同期投資支出 (CapEx) 達到R$ 1,414.0百萬。自由現金流轉正是一個積極信號，表明公司有能力產生現金用於擴張、償債或股東回報。

-   **資本配置 (Capital Allocation)**
    2026年第二季度，公司投資了R$ 1,414.0百萬。管理層將自由現金流的改善歸因於資本結構優化、庫存削減和抑制前期現金消耗的舉措。公司維持每年分配80%至100%淨利潤的股息政策，但實際金額和時間由董事會決定。這表明公司傾向於將利潤回饋股東，同時也注重通過投資來支持業務增長。
