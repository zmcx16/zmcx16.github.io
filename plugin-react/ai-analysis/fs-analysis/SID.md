### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Companhia Siderurgica Nacional (SID) 的營收在過去幾年呈現波動。根據最新數據，2026年TTM (Trailing Twelve Months) 營收為85.2億美元，而2025年為81.8億美元，較2024年的78.6億美元有所增長。然而，2024年的營收較2023年的92.1億美元下降了14.68%。最近的季度表現顯示，2026年第二季度營收為21.8億美元，超出預期並同比增長。2026年第一季度綜合淨營收為106.038億巴西雷亞爾，同比下降2.8%。

營收增長主要來自於多個業務板塊。在2024年第四季度，淨營收達到120.26億巴西雷亞爾，環比增長8.7%，主要受惠於礦業部門鐵礦石價格回升帶來的價格實現改善。此外，鋼鐵部門的銷售量較2023年第四季度增長10.4%，也對營收增長做出了積極貢獻。2025財年，礦業營收增長17.6%至154億巴西雷亞爾，主要受銷量增長和亞洲強勁鐵礦石需求推動。這表明公司的營收增長是銷量增加和產品價格上漲的綜合結果，尤其是在礦業和鋼鐵領域。

**獲利能力與利潤率**
SID的獲利能力指標顯示出壓力。
*   **毛利率 (Gross Margin)**：根據提供的數據為27.22%。2024年第四季度毛利率為31.5%，較上一季度顯著提升6.8個百分點，全年毛利率為26.8%，較上一年增長0.4個百分點。這表明公司在成本控制和定價方面有所改善，但整體仍受市場波動影響。
*   **營業利益率 (Operating Margin)**：為9.89%。
*   **純益率 (Net Margin)**：為-5.86%。公司在2026年第一季度錄得淨虧損5.55億巴西雷亞爾，第二季度調整後淨虧損為每股0.1121美元。這顯示公司目前處於虧損狀態，淨利潤率為負，表明其將營收轉化為淨利潤的能力較弱。

利潤率的波動性較大，尤其是在淨利潤層面持續為負，表明公司尚未實現穩定的獲利。儘管毛利率和營業利益率在某些季度有所改善，但未能有效傳導至淨利潤，可能存在規模經濟效益不顯著或財務費用過高的問題。

**費用控制**
由於缺乏研發費用 (R&D) 和行銷費用 (S&A) 的具體佔比數據，難以直接評估其合理性。然而，從營業利益率和淨利潤率的表現來看，公司在費用控制方面可能面臨挑戰，或者其高額的財務費用（如利息支出）嚴重侵蝕了營業利潤。S&P Global Ratings指出，2026年EBITDA可能因礦業成本上升、水泥業務增長放緩以及鋼鐵業務持續挑戰而受限。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
*   **現金與短期投資佔比**：截至2026年3月31日，現金及現金等價物為128.228億巴西雷亞爾。相對於總資產的具體佔比未直接提供，但考慮到其龐大的總債務，現金儲備顯得相對有限。
*   **應收帳款 (AR) 與存貨 (Inventory) 的周轉情況**：缺乏具體周轉率數據。然而，2026年第一季度其他營業費用大幅增加，主要由於存貨損失和已實現的現金流避險影響，這可能暗示存貨管理存在一定風險。

**負債與償債能力**
SID的負債水平是其財務健康狀況中的一個重大隱憂。
*   **流動性**：
    *   **流動比率 (Current Ratio)**：為1.15。雖然略高於1，但仍處於較低水平，表明公司短期償債能力較為緊張。最新年度數據顯示為1.08x，在2026年第二季度略微改善至1.15x。
    *   **速動比率 (Quick Ratio)**：為0.79。低於1的速動比率表明公司在不依賴存貨銷售的情況下，短期償債能力較弱。
*   **長期風險**：
    *   **債務對權益比 (Debt/Equity)**：高達4.47。這遠高於行業平均水平，顯示公司嚴重依賴債務融資，股東權益佔比極低，財務槓桿極高。其他數據顯示，截至2026年3月，總債務為股東權益的317.3%。
    *   **長期債務對權益比 (LT Debt/Eq)**：為3.77。
    *   **淨現金 (Net Cash) 狀況**：截至2026年3月31日，總債務為504.352億巴西雷亞爾，而現金為128.228億巴西雷亞爾，這意味著公司存在巨大的淨債務。截至2026年第二季度，淨債務達到421億巴西雷亞爾。
    *   **債務結構**：公司面臨2026年和2027年大量到期債務的再融資需求。為應對此，公司已採取行動，包括一項12億美元的五年期過渡貸款，用於再融資2026年至2028年到期的債務，並正在進行水泥子公司的剝離程序。這表明公司正積極管理其債務結構，但高額債務仍是主要風險。

**無形資產與商譽**
搜尋結果未提供具體的商譽 (Goodwill) 數據，因此無法評估其是否存在減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
SID的營業現金流表現不佳。2026年第一季度營業現金流 (CFO) 僅為1.158億巴西雷亞爾，第二季度為1.172億巴西雷亞爾。相較於同期淨虧損（第一季度淨虧損5.55億巴西雷亞爾，第二季度淨虧損7.94億巴西雷亞爾），營業現金流雖然為正，但金額非常小，遠低於淨利潤的絕對值（儘管淨利潤為負）。
*   **盈餘品質**：營業現金流長期低於淨利潤（或在淨利潤為負時，營業現金流僅微薄為正），表明公司的盈餘品質較差。這可能意味著公司的會計利潤未能有效轉化為實際現金流入，或者營運活動產生現金的能力不足以覆蓋其虧損。

**自由現金流 (FCF)**
自由現金流 (FCF) 狀況令人擔憂。
*   **計算與分析**：
    *   2026年第一季度：OCF 1.158億巴西雷亞爾 - 資本支出 (CapEx) 11.26億巴西雷亞爾 = FCF -10.08億巴西雷亞爾。
    *   2026年第二季度：OCF 1.172億巴西雷亞爾 - 資本支出 (CapEx) 13.79億巴西雷亞爾 = FCF -12.63億巴西雷亞爾。
    *   FCF利潤率在第一季度為-9.5%，第二季度為-11.2%。
    *   值得注意的是，有報導稱2026年第二季度自由現金流轉為正8.08億巴西雷亞爾。然而，KoalaGains的詳細數據顯示，營業現金流遠不足以覆蓋資本支出，導致自由現金流深度為負。S&P Global Ratings也預計2026年自由營運現金流 (FOCF) 將出現4.1億巴西雷亞爾的赤字。綜合來看，公司自由現金流持續為負的可能性較高，這意味著公司沒有足夠的現金用於擴張、派息或回購，反而需要外部融資來彌補現金缺口。

**資本配置 (Capital Allocation)**
公司近年來資金主要投向資本支出，尤其是在礦業擴張項目（P15項目）和水泥產能提升方面。2026年和2027年預計每年資本支出為62億巴西雷亞爾。由於自由現金流為負，這些資本支出主要通過債務發行來彌補。公司也積極進行債務再融資，例如將2028年到期的部分高級票據交換為2030年到期的新票據。此外，公司正在尋求通過資產出售（如水泥子公司）來改善資本結構和去槓桿化。這表明公司正在努力優化資本配置，但目前效率較低，且高度依賴外部融資和資產出售。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：為-20.4%。負的ROE表明公司正在為股東創造負回報，即股東權益正在被侵蝕。
    *   **杜邦分析拆解**：
        *   淨利潤率 (Net Profit Margin)：-5.86%
        *   資產周轉率 (Asset Turnover)：未直接提供，但可以從ROA和淨利潤率推斷。
        *   財務槓桿 (Financial Leverage, Equity Multiplier)：1 + Debt/Equity = 1 + 4.47 = 5.47。
        *   ROE = 淨利潤率 x 資產周轉率 x 財務槓桿。由於淨利潤率為負，即使有高財務槓桿也無法產生正回報。
*   **ROIC (投入資本回報率)**：為-4.46%。負的ROIC表明公司投資資本的效益不佳，未能產生足夠的回報來覆蓋其資本成本。Morningstar的數據顯示其標準化ROIC為4.20%，與提供的數據存在差異，但即使是正值，也需要與WACC進行比較。考慮到公司的高負債和較高的借貸成本，其加權平均資本成本 (WACC) 可能較高，因此ROIC很可能低於WACC，意味著公司正在破壞價值。

**效率指標**
*   **資產周轉率 (Asset Turnover)**：未直接提供。
*   **存貨周轉天數 (DIO) 與應收帳款周轉天數 (DSO)**：未直接提供。但如前所述，2026年第一季度存貨損失導致其他營業費用增加，可能暗示存貨管理效率有待提升。

**最終結論：**
1.  **整體評級**：具重大風險
2.  **核心摘要**：Companhia Siderurgica Nacional (SID) 的財務健康狀況存在重大風險。公司長期處於淨虧損狀態，獲利能力極弱。其資產負債表高度槓桿化，債務權益比遠超合理水平，流動性緊張，償債壓力巨大。營業現金流微薄且自由現金流持續為負，表明公司營運無法產生足夠現金來支持其高額資本支出，需依賴外部融資和資產出售。資本回報率為負，顯示公司正在破壞股東價值。儘管公司積極進行債務重組和資產剝離以改善資本結構，但其核心業務的盈利能力和現金生成能力仍是主要挑戰。
3.  **關鍵監測指標**：
    *   **淨債務/EBITDA (Net Debt/EBITDA)**：密切關注此槓桿比率的變化，公司目標是將其維持在3.5x以下。
    *   **自由現金流利潤率 (Free Cash Flow Margin)**：監測公司能否將自由現金流轉為持續正值，以證明其營運可持續性。
    *   **鋼鐵和礦業部門EBITDA利潤率**：關注核心業務板塊的盈利能力改善，特別是鋼鐵部門能否達到管理層預期的15-17%利潤率。
