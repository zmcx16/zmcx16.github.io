# AMZN (Amazon.com Inc) 財務報表深度分析報告

### 1. 損益表分析 (Income Statement Analysis)
*   **營收成長動能**：
    Amazon 最新 2024 年第一季（Q1）財報顯示，淨銷售額達 1,433 億美元，年增 13%。成長動能主要來自兩大高毛利引擎：**AWS 雲端服務**（營收 250 億美元，年增 17%）與**廣告業務**（營收 118 億美元，年增 24%）。相較於過去幾年受疫情紅利消退影響，目前成長已趨於穩健，且 AWS 成長率重新加速，顯示企業雲端支出回升及 AI 需求帶動。
*   **獲利能力與利潤率**：
    *   **毛利率 (Gross Margin)**：數據顯示為 51.37%，反映出服務型收入（AWS、廣告、第三方賣家服務）佔比提升，結構性優化了零售業務的低毛利本質。
    *   **營業利益率 (Operating Margin)**：從去年同期的 3.7% 大幅躍升至 10.7%（Q1 實際值），主要歸功於物流網絡的「區域化」改革，顯著降低了履約成本。
    *   **規模經濟**：隨著營收規模擴大，固定成本被有效攤提，營業利益（153 億美元）的成長速度遠超營收成長速度，展現強大的經營槓桿。
*   **費用控制**：
    研發費用（Technology and Content）持續維持高位，以支撐生成式 AI 的基礎設施投入。行銷費用佔比相對穩定，顯示其品牌護城河已降低了獲客成本。

### 2. 資產負債表分析 (Balance Sheet Analysis)
*   **資產品質與結構**：
    Amazon 持有約 730 億美元的現金及等價物。存貨周轉情況良好，隨著物流效率提升，存貨堆積風險較低。應收帳款周轉天數維持在行業領先水平，顯示對下游極強的議價能力。
*   **負債與償債能力**：
    *   **流動性**：流動比率 0.99 與速動比率 0.82 雖略低於 1，但考慮到 Amazon 強大的經營現金流與「負營運資金循環」（先收客戶錢、後付供應商錢）的特性，短期償債風險極低。
    *   **長期風險**：債務對權益比 (Debt/Equity) 為 0.48，長期債務結構穩定。總資產負債率處於健康區間，無明顯財務壓力。
*   **無形資產與商譽**：
    商譽佔總資產比例不高，主要來自過去對 Whole Foods 等公司的收購，目前未見重大減損跡象。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)
*   **營業現金流 (OCF)**：
    這是 Amazon 財報最強勁的部分。過去 12 個月 (TTM) 的 OCF 達到 991 億美元，較去年同期的 543 億美元大幅增長 82%。現金流增長遠超淨利增長，顯示盈餘品質極高。
*   **自由現金流 (FCF)**：
    計算 TTM FCF 為 501 億美元（對比去年同期為流出 33 億美元）。這標誌著 Amazon 已走出後疫情時代的大規模資本支出擴張期，進入收割期。
*   **資本配置 (Capital Allocation)**：
    *   **資本支出 (CapEx)**：主要投向 AWS 的伺服器與 AI 晶片。
    *   **效率**：公司目前不支付股息，資金優先用於再投資高回報項目（如 AI 基礎設施）。雖然回購規模較小，但強勁的 FCF 為未來資本回饋提供了巨大空間。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)
*   **回報率指標**：
    *   **ROE (27.42%)**：表現優異。拆解來看，主要驅動力來自**淨利率的擴張**（從近乎零回升至雙位數）以及穩定的資產周轉率，而非單純依賴財務槓桿。
    *   **ROIC (15.22%)**：顯著高於其加權平均資本成本 (WACC)，說明公司每投入一塊錢資本都能創造超額價值。
*   **效率指標**：
    資產周轉率正在回升，反映出過去幾年投資的物流基礎設施利用率正在提高。

### 5. 財務健康總結

| 維度 | 評等 (1-5★) | 關鍵評語 (簡短扼要) |
| :--- | :--- | :--- |
| **獲利能力** | ★★★★★ | AWS 與廣告雙引擎驅動，利潤率進入快速擴張期。 |
| **償債安全性** | ★★★★ | 債務槓桿合理，現金儲備充足，抗風險能力強。 |
| **現金流品質** | ★★★★★ | FCF 實現驚人反轉，經營現金流極其強勁。 |
| **資本效率** | ★★★★ | ROE 顯著提升，AI 投資回報率值得期待。 |

**最終結論：**
1. **整體評級**：**優良**
2. **核心摘要**：Amazon 正處於從「規模擴張」轉向「利潤收割」的關鍵拐點。透過優化零售物流成本與高毛利的 AWS、廣告業務佔比提升，公司獲利能力與自由現金流均創下歷史性佳績。儘管 AI 資本支出龐大，但其強大的 OCF 足以支撐，財務結構極其穩健。
3. **關鍵監測指標**：
    *   **AWS Operating Margin**：觀察 AI 投入是否持續轉化為高利潤。
    *   **Free Cash Flow Margin**：衡量每營收一元能轉化為多少可動用現金。
    *   **Shipping & Fulfillment Cost as % of Sales**：監控零售端效率優化是否持續。
