# Target Corp (TGT) 財務狀況全面拆解報告

作為資深美股分析師，針對 Target (TGT) 最新公佈的 2024 財年第三季（Q3）財報及年度趨勢，進行深度財務分析。

### 1. 損益表分析 (Income Statement Analysis)
*   **營收成長動能**：
    Target 最新 Q3 營收為 256.7 億美元，年增僅 1.1%，低於市場預期。同店銷售額（Comparable Sales）僅增長 0.3%，顯示成長動能疲軟。過去 3-5 年營收雖從 2019 年的 780 億美元成長至 2023 年的 1,074 億美元，但目前的成長主要受通膨帶動的客單價支撐，而非銷量（Traffic）的大幅擴張。非必需品（Discretionary）類別持續低迷，抵銷了民生必需品的增長。
*   **獲利能力與利潤率**：
    *   **毛利率 (Gross Margin)**：約 27.2%，受惠於成本控制，但被促銷活動抵銷。
    *   **營業利益率 (Operating Margin)**：本季降至 4.6%（去年同期為 5.2%），顯著低於管理層長期目標 6%。
    *   **純益率 (Net Margin)**：目前約 3.24%，處於歷史中低位。
    獲利能力正受到「數位履約成本增加」與「庫存短縮（Shrinkage/盜竊）」的雙重擠壓，規模經濟效應在當前低成長環境下難以發揮。
*   **費用控制**：
    SG&A 費用佔比上升，主要源於工資上漲及為了應對供應鏈不確定性而增加的物流支出。行銷費用維持穩定，但轉化效率因消費者支出趨於謹慎而下降。

### 2. 資產負債表分析 (Balance Sheet Analysis)
*   **資產品質與結構**：
    *   **存貨 (Inventory)**：最新數據顯示存貨約 152 億美元，年增約 3%。雖然管理層強調庫存結構健康，但面對疲軟的 Q4 展望，若銷售不如預期，可能面臨新一輪降價清倉風險。
    *   **應收帳款**：周轉正常，零售業特性使其 AR 風險極低。
*   **負債與償債能力**：
    *   **流動性**：流動比率 0.93，速動比率 0.3。速動比率偏低反映出高度依賴存貨變現，短期流動性壓力較大。
    *   **長期風險**：債務對權益比 (Debt/Equity) 為 1.17，長期債務約 140 億美元。雖然槓桿率尚在可控範圍，但利息保障倍數因利潤下滑而有所承壓。
*   **無形資產與商譽**：
    商譽佔比極低，資產負債表相對「乾淨」，不存在大規模商譽減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)
*   **營業現金流 (OCF)**：
    TTM（過去十二個月）OCF 表現穩健，約 80 億美元。盈餘品質尚可，OCF 持續高於淨利，顯示折舊攤銷與營運資本管理尚能支撐現金流入。
*   **自由現金流 (FCF)**：
    FCF (OCF - CapEx) 保持正值。Target 每年投入約 30-40 億美元於門市翻新與供應鏈自動化。目前的 FCF 足以覆蓋約 20 億美元的年度股息支出。
*   **資本配置 (Capital Allocation)**：
    *   **股息**：連續 50 年以上調升股息（Dividend King），目前殖利率 3.05%，具備吸引力。
    *   **回購**：近期因利潤波動，股份回購節奏放緩，優先保留現金以應對不確定的零售環境。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)
*   **杜邦分析 (ROE 拆解)**：
    *   **ROE (22.02%)** = 純益率 (3.24%) × 資產周轉率 (1.8-1.9) × 財務槓桿 (3.5-4.0)。
    *   高 ROE 主要依賴「高資產周轉」與「財務槓桿」，而非高利潤率。一旦營收增速放緩，ROE 容易出現劇烈波動。
*   **效率指標**：
    *   **ROIC (10.12%)**：高於 WACC（約 7-8%），顯示公司仍能創造超額價值，但領先優勢正在縮小。
    *   **存貨周轉天數**：約 60-65 天，需關注是否因非必需品滯銷而拉長。

### 5. 財務健康總結

| 維度 | 評等 (1-5★) | 關鍵評語 (簡短扼要) |
| :--- | :--- | :--- |
| **獲利能力** | ★★★ | 營業利益率跌破 5%，非必需品需求疲軟壓抑利潤。 |
| **償債安全性** | ★★★ | 債務結構穩定，但速動比率偏低，短期流動性偏緊。 |
| **現金流品質** | ★★★★ | OCF 強勁且高於淨利，足以支撐股息發放。 |
| **資本效率** | ★★★★ | ROE 表現優異，資產周轉率維持零售業高水準。 |

**最終結論：**
1. **整體評級**：**穩健但存在隱憂**
2. **核心摘要**：Target 財務結構依然穩固，特別是在現金流產生能力與股息回饋方面。然而，近期財報顯示其在宏觀經濟壓力下，獲利能力顯著承壓，尤其是營業利益率的下滑與指引的下調，反映出公司在成本控制與轉嫁通膨壓力上的困境。
3. **關鍵監測指標**：
    *   **Operating Margin**：能否回升至 6% 的長期目標。
    *   **Comparable Sales Growth**：特別是實體店面與數位渠道的流量變化。
    *   **Inventory-to-Sales Ratio**：觀察是否存在庫存積壓導致 Q4 必須大幅折扣的風險。
