ServiceNow Inc (NOW) 是一家領先的企業工作流程和雲端軟體公司，受益於數位轉型、自動化和企業人工智慧的採用。本分析將深入探討其財務狀況，以評估其獲利能力、償債能力和資本效率。

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
ServiceNow展現出強勁且持續的營收成長動能。根據最新財報，2026年第二季度的訂閱收入達到38.77億美元，年增長率為24.5% (23%以固定匯率計算)。總營收在2026年第二季度達到39.87億美元，年增長24% (22.5%以固定匯率計算)。這表明公司在軟體即服務 (SaaS) 領域的市場需求持續旺盛，且其AI相關產品的擴張策略正在奏效。過去幾年的年營收趨勢也顯示穩健增長，主要驅動力來自於訂閱收入的增加，而非單純的漲價或大規模併購。

**獲利能力與利潤率**
ServiceNow的獲利能力持續改善，利潤率呈現擴張趨勢。
*   **毛利率 (Gross Margin)**：2026年第二季度估計毛利率約為77.7%，相較於2025年第二季度的76.2%有所提升。這表明公司在提供訂閱服務方面具有較高的效率和規模經濟效應。
*   **營業利益率 (Operating Margin)**：2026年第二季度估計營業利益率約為22.6%，高於2025年第二季度的20.2%。營業利益率的擴張顯示公司在營收增長的同時，對營運費用的控制也日益精進。
*   **純益率 (Net Margin)**：2026年第二季度估計純益率約為17.6%，優於2025年第二季度的15.5%。淨利率的提升反映了公司整體獲利能力的增強。

利潤率的穩定擴張表明ServiceNow正在實現規模經濟，隨著營收的增長，其固定成本被更有效地分攤。

**費用控制**
*   **研發費用 (R&D)**：作為一家技術驅動的軟體公司，ServiceNow的研發費用佔營收比重合理且符合其創新策略。例如，2025年研發費用佔總營收的18.0% (18億美元 / 100億美元)。這筆投入對於維持其產品競爭力、開發新的AI功能至關重要。
*   **行銷費用 (S&A)**：2025年行銷費用佔總營收的30.0% (30億美元 / 100億美元)。此佔比相對較高，但對於快速增長的SaaS公司而言，投入市場擴張和客戶獲取是必要的。隨著公司規模擴大，預期此佔比有望逐步優化。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
*   **現金與短期投資佔比**：截至2026年6月30日，ServiceNow擁有38億美元的現金及現金等價物和22億美元的短期投資，合計60億美元。這筆充裕的流動資產為公司提供了強大的財務彈性，可用於戰略投資、併購或應對市場波動。
*   **應收帳款 (AR) 與存貨 (Inventory) 的周轉情況**：截至2026年6月30日，應收帳款淨額為27億美元。由於ServiceNow是軟體服務公司，其存貨幾乎為零，因此不存在存貨堆積的風險。應收帳款的周轉效率需進一步結合營收數據計算，但通常SaaS公司的應收帳款回收週期相對穩定。

**負債與償債能力**
*   **流動性**：
    *   **流動比率 (Current Ratio)**：截至2026年6月30日，流動資產為95億美元，流動負債為65億美元。流動比率為1.46 (95億美元 / 65億美元)。這表明公司短期償債能力健康，能夠覆蓋其短期債務。
    *   **速動比率 (Quick Ratio)**：由於存貨極低，速動比率與流動比率相近，約為1.46，顯示其即時償債能力良好。
*   **長期風險**：
    *   **債務佔資產比 (Total Debt/Assets)**：截至2026年6月30日，總負債為130億美元，總資產為265億美元。債務佔資產比為49.1% (130億美元 / 265億美元)。
    *   **債務對權益比 (Debt/Equity)**：截至2026年6月30日，總負債為130億美元，股東權益為135億美元。債務對權益比為96.3% (130億美元 / 135億美元)。雖然債務比率略高，但對於成長型科技公司而言，適度利用債務槓桿進行擴張是常見策略，且其強勁的現金流能有效支持債務。
    *   **淨現金 (Net Cash)**：截至2026年6月30日，淨現金為 (現金及短期投資60億美元 - 長期債務32億美元) = 28億美元。公司處於淨現金狀態，顯示其財務狀況穩健。
*   **無形資產與商譽**：截至2026年6月30日，商譽為42億美元。商譽佔總資產的比例約為15.8% (42億美元 / 265億美元)。對於透過併購擴張的科技公司而言，存在一定數量的商譽是正常的。目前來看，該比例尚在可控範圍，但仍需持續關注未來是否有減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
ServiceNow的營運現金流表現強勁，且與淨利同步增長。
*   2025年營業現金流為30億美元，淨利為18億美元。
*   2024年營業現金流為25億美元，淨利為15億美元。
*   2023年營業現金流為20億美元，淨利為11億美元。
OCF持續高於淨利，表明公司的盈餘品質良好，其利潤主要由實際現金流入支持，而非會計調整。

**自由現金流 (FCF)**
*   **2025年FCF**：30億美元 (OCF) - 5億美元 (CapEx) = 25億美元。
*   **2024年FCF**：25億美元 (OCF) - 4億美元 (CapEx) = 21億美元。
*   **2023年FCF**：20億美元 (OCF) - 3億美元 (CapEx) = 17億美元。
ServiceNow產生了充裕的自由現金流，這顯示公司有足夠的現金用於內部擴張、潛在的併購、償還債務以及股份回購。公司目前不派發股息。

**資本配置 (Capital Allocation)**
ServiceNow的資本配置策略主要集中於支持業務增長和提升股東價值。
*   **資本支出 (CapEx)**：主要用於支持其基礎設施和技術平台的擴張，以應對不斷增長的客戶需求。
*   **併購**：公司也進行戰略性併購，以擴展其產品組合和市場份額。例如，2025年用於併購的現金為8億美元。
*   **股份回購**：ServiceNow積極進行股份回購，以回報股東並管理股本。例如，2025年回購了10億美元的普通股。
整體而言，ServiceNow的資本配置效率較高，資金主要投向能夠產生長期價值的領域。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：
    *   2025年ROE = 淨利18億美元 / (2025年股東權益130億美元 + 2024年股東權益100億美元)/2 = 18億美元 / 115億美元 = 15.65%。
    *   **杜邦分析拆解 (2025年)**：
        *   淨利率 (Net Profit Margin) = 18億美元 / 100億美元 = 18.0%
        *   資產周轉率 (Asset Turnover) = 100億美元 / (250億美元 + 200億美元)/2 = 100億美元 / 225億美元 = 0.44
        *   權益乘數 (Equity Multiplier) = (250億美元 + 200億美元)/2 / (130億美元 + 100億美元)/2 = 225億美元 / 115億美元 = 1.96
        *   ROE = 18.0% * 0.44 * 1.96 = 15.5% (略有捨入誤差)。
    ServiceNow的ROE主要受其較高的淨利率和適度的財務槓桿驅動。資產周轉率對於SaaS公司而言通常較低，因為其資產主要為無形資產和技術平台。
*   **ROIC (投入資本回報率)**：由於缺乏WACC的具體數據，難以精確計算ROIC並與WACC比較。然而，鑑於其強勁的獲利能力和自由現金流，預計其ROIC應能超過其資本成本。

**效率指標**
*   **資產周轉率**：2025年為0.44，對於輕資產的軟體公司而言，此周轉率尚可接受。
*   **應收帳款周轉天數 (DSO)**：
    *   2025年應收帳款周轉率 = 100億美元 (營收) / (25億美元 + 20億美元)/2 (平均應收帳款) = 100億美元 / 22.5億美元 = 4.44次。
    *   2025年DSO = 365天 / 4.44次 = 82.2天。
    約82天的DSO表明客戶支付週期相對較長，但對於企業級軟體服務而言，這在一定程度上是行業慣例。
