ServiceNow Inc (NOW) 作為美股市場的領先企業軟體服務提供商，展現出強勁的成長潛力與穩健的營運表現。本分析將深入探討其損益表、資產負債表及現金流量表，並結合核心財務指標，全面評估其財務健康狀況。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    ServiceNow的營收呈現持續且強勁的成長趨勢。過去幾年，總營收從2022年的72億美元增長至2023年的90億美元（年增25%），2024年達到110億美元（年增22.2%），並在2025年進一步攀升至133億美元（年增20.9%）。最新季度，即2026年第二季度，總營收達39.87億美元，較去年同期32.15億美元成長24% (以固定匯率計算為22.5%)。其中，訂閱營收為38.77億美元，年增24.5% (以固定匯率計算為23%)。
    營收成長主要來自於其核心訂閱服務的擴張，以及對人工智慧 (AI) 和網路安全領域的策略性併購。例如，2025年收購Moveworks以增強企業搜尋和虛擬代理能力，並計劃收購Armis Security以擴展網路安全產品。2026年第二季度的營收增長也受益於Armis和Veza的收購。值得注意的是，ServiceNow的AI年度合約價值 (AI ACV) 在2026年第二季度已突破10億美元，顯示AI產品正成為其新的重要成長引擎。

*   **獲利能力與利潤率**
    *   **毛利率 (Gross Margin)**：ServiceNow的毛利率長期保持在75%以上的高水準，2022年約為79.2%，2023年約為78.9%，2024年約為79.1%，2025年約為77.4%。這反映了其軟體產品的強大定價能力和較低的變動成本。
    *   **營業利益率 (Operating Margin)**：營業利益率在2022年的4.9%逐步擴張至2025年的13.5%，顯示公司在規模擴大後，營運效率有所提升。然而，2026年第二季度營業利益為1.62億美元，營業利益率約4.1%，較去年同期的3.58億美元（約11.1%）大幅下降。
    *   **純益率 (Net Margin)**：純益率在2022年的4.5%增長至2025年的13.1%。但2026年第二季度淨利為2.98億美元，純益率約7.5%，較去年同期的3.85億美元（約12.0%）有所下降。
    利潤率的變化顯示，儘管毛利率穩定，但2026年第二季度的營業利益率和純益率受到較高的銷售、研發和併購相關費用影響而短期承壓。這表明公司正處於積極投資成長的階段，短期內可能犧牲部分利潤以換取長期市場份額和技術領先。從2022-2025年營業利益率的擴張來看，公司具備實現規模經濟的潛力，但大規模的投資活動可能暫時抵消了部分效益。

*   **費用控制**
    *   **研發費用 (R&D)**：研發費用絕對金額持續增長，從2022年的18億美元增至2025年的30億美元，年增16%。其佔總營收的比例約在22.6%至25.0%之間，相對穩定。這與ServiceNow作為一家技術驅動的軟體公司，持續投入AI創新和平台增強的策略高度相符。
    *   **行銷費用 (S&A)**：行銷費用從2022年的35億美元增至2025年的55億美元。然而，其佔總營收的比例從2022年的48.6%下降至2025年的41.4%，顯示公司在市場擴張的同時，銷售效率有所提升。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**
    *   **現金與短期投資佔比**：截至2026年第二季度，現金及現金等價物為25億美元，短期投資為21.6億美元，合計46.6億美元。這佔總資產316.7億美元的約14.7%。相較於2025年底的101億美元現金及投資，現金儲備有所下降，主要原因為大規模併購活動 (如Armis和Veza) 以及股票回購。
    *   **應收帳款 (AR) 與存貨 (Inventory) 的周轉情況**：作為軟體服務公司，ServiceNow幾乎沒有存貨。應收帳款的變動對營運現金流的影響在近年來為負值，表明應收帳款有所增加，這在快速成長的訂閱模式公司中是常見現象，需持續關注其回收效率。

*   **負債與償債能力**
    *   **流動性**：
        *   **流動比率 (Current Ratio)**：截至2026年第二季度，流動比率約為0.62 (流動資產85.1億美元 / 流動負債約137.15億美元)。提供的基本面數據為0.65。
        *   **速動比率 (Quick Ratio)**：提供的基本面數據為0.65。
        流動比率和速動比率均低於1，這在訂閱制軟體公司中並非異常，因為其遞延收入 (Deferred Revenue) 通常很高，被計入流動負債，但實際上並非現金流出，而是未來營收的保證。
    *   **長期風險**：
        *   **債務對權益比 (Debt/Equity)**：截至2026年第二季度，長期債務增至54.35億美元。總負債為191.5億美元，股東權益為125.2億美元 (總資產316.7億美元 - 總負債191.5億美元)。因此，總債務對權益比約為1.53，長期債務對權益比約為0.43。這高於提供的基本面數據 (Debt/Eq 0.68, LT Debt/Eq 0.5)。長期債務的顯著增加主要用於資助大規模併購和股票回購，這提升了公司的財務槓桿。
    *   **淨現金 (Net Cash) 狀況**：截至2026年第二季度，現金及短期投資合計46.6億美元，而總債務 (長期債務加商業票據) 約為75.35億美元。這意味著公司處於約28.75億美元的淨負債狀態。相較於2025年底擁有101億美元現金和投資的狀況，財務結構因大規模併購和融資活動而發生了顯著變化。

*   **無形資產與商譽**
    截至2026年第二季度，商譽 (Goodwill) 大幅增加至98.37億美元，主要源於Armis (76億美元) 和 Veza (12億美元) 的收購。商譽佔總資產的約31.0%。高比例的商譽可能存在減損風險，尤其是在併購標的未來表現不如預期或經濟環境惡化的情況下。投資者應密切關注公司未來的商譽減損測試結果。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**
    ServiceNow的營運現金流持續穩健增長，從2022年的27.23億美元增至2025年的54.44億美元。2026年上半年，營運現金流為22.57億美元。營運現金流的強勁增長與淨利潤趨勢大致同步，顯示公司核心業務具有卓越的現金產生能力。
    *   **盈餘品質**：2025年淨利為17.48億美元，而營運現金流為54.44億美元。營運現金流遠高於淨利，這是一個良好的盈餘品質指標，表明公司的利潤有堅實的現金支持，可能與較高的非現金費用 (如折舊攤銷、股權激勵) 和遞延收入的增加有關。

*   **自由現金流 (FCF)**
    2025年自由現金流達46億美元，較前一年增長34.0%。2026年上半年非GAAP自由現金流為22.99億美元。公司擁有充足的自由現金流，並將其用於戰略擴張和股東回報。ServiceNow利用自由現金流進行了大規模的併購 (如Armis和Veza)，並積極進行股票回購，2025年第四季度回購了5.97億美元股票，並在2026年1月額外授權50億美元的回購計劃。公司目前不派發股息。

*   **資本配置 (Capital Allocation)**
    ServiceNow的資金主要投向戰略性併購 (如AI和網路安全領域的Moveworks、Armis和Veza)、持續的研發投入以推動產品創新，以及透過股票回購來管理稀釋效應和回報股東。這種積極的資本配置策略旨在擴大市場份額和強化技術領先地位。然而，大規模併購也帶來了商譽增加和短期內負債上升的風險，其整合效果和未來收益貢獻將是關鍵。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**
    *   **ROE (股東權益報酬率)**：提供的基本面數據為14.24%。2025年ROE約為16.7% (淨利17.48億美元 / 股東權益104.7億美元)。2026年第二季度 (TTM) ROE約為13.3% (淨利16.7億美元 / 股東權益125.2億美元)。ROE保持在健康水平，但受淨利潤短期波動和股東權益變動影響略有下降。
    *   **杜邦分析 (2025年)**：
        *   淨利率：13.1%
        *   資產周轉率：0.51 (總營收133億美元 / 總資產260.4億美元)
        *   權益乘數：2.49 (總資產260.4億美元 / 股東權益104.7億美元)
        *   ROE = 13.1% (淨利率) x 0.51 (資產周轉率) x 2.49 (權益乘數) = 16.6%。ServiceNow的ROE主要由其高淨利率和適度的財務槓桿驅動。
    *   **ROIC (投入資本回報率)**：提供的基本面數據ROI為8.9%。儘管缺乏WACC數據無法精確判斷，但公司持續的營收和利潤增長，以及對AI等高潛力領域的投資，表明其應能產生超過資本成本的回報。

*   **效率指標**
    *   **資產周轉率**：2025年為0.51，對於輕資產的軟體公司而言是合理水平。
    *   **存貨周轉天數 (DIO)**：不適用。
    *   **應收帳款周轉天數 (DSO)**：缺乏足夠數據精確計算，但公司需持續有效管理應收帳款以優化現金回收效率。
