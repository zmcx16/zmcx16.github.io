ServiceNow Inc (NOW) 作為企業軟體領域的領導者，以其雲端運算平台和自動化工作流程解決方案聞名。作為資深美股分析師，我將深入剖析其財務報表，以揭示公司的真實財務狀況、獲利能力及潛在風險。

---

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
ServiceNow展現了強勁且持續的營收成長動能。過去五年（2021-2025年）的年營收從2021年的59億美元穩步增長至2025年的132.8億美元，年複合增長率約為22.5%。最新季度（2026年第二季度）的總營收達到39.87億美元，同比增長24%。其中，訂閱營收為38.77億美元，同比增長24.5%。這種增長主要來自於其訂閱服務的擴張，包括新客戶的增加和現有客戶購買量的提升。公司在2025年擁有603個年度合約價值（ACV）超過500萬美元的客戶，較前一年有所增加。此外，ServiceNow透過策略性收購（如2025年收購Moveworks以增強AI能力，以及2026年計畫收購Armis Security以擴展網路安全產品）來強化其產品組合，這也可能貢獻了部分營收增長。

**獲利能力與利潤率**
ServiceNow的毛利率在過去幾年保持在較高水平，顯示其產品和服務具有強大的定價能力。2021年至2024年，毛利率從77.1%上升至79.2%，但在2025年略降至77.5%。截至2026年6月30日的過去十二個月（TTM）毛利率為74.8%，而2026年第二季度單季毛利率為70.68%。儘管近期季度毛利率有所波動，但整體仍處於健康區間，表明公司在提供雲端軟體服務方面具有效率。

營業利益率方面，公司呈現顯著改善。從2021年的4.22%穩步提升至2025年的17.03%。這表明公司在營收增長的同時，有效控制了營運費用，實現了規模經濟效應。然而，2026年第二季度單季營業利益率為4.06%，較2025年第二季度的0.67%有所提升，但較2026年第一季度的13.34%大幅下降。這可能與該季度特定的營運支出或收購相關成本有關，需要進一步關注。

純益率方面，2025年淨利潤為17.48億美元，相較於2024年的14.25億美元有所增長。截至2026年6月30日的過去十二個月淨利潤為16.7億美元。整體而言，公司的獲利能力在持續增長，但季度間的利潤率波動值得留意。

**費用控制**
ServiceNow在研發（R&D）和銷售與管理（S&A）費用方面投入巨大，這與其作為一家高成長科技公司的定位相符。2025年，研發投入增長16%至30億美元，主要用於AI創新和平台增強。這些投資對於維持其產品競爭力及市場領導地位至關重要。隨著營收規模的擴大，若能持續優化費用結構，將有助於進一步提升利潤率。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2026年6月30日，ServiceNow的總資產為316.66億美元。現金及短期投資在2025年為62.84億美元，但在2026年6月30日（TTM）降至46.64億美元。這一下降可能與公司在2026年進行的加速股票回購（20億美元）以及收購Veza（12.5億美元）和Armis（77.5億美元，預計下半年完成）等活動有關。應收帳款在2025年為26.27億美元，2026年6月30日（TTM）為22.01億美元。作為軟體服務公司，ServiceNow通常沒有大量存貨，因此存貨周轉風險較低。應收帳款的變化需要結合營收增長來評估其回收效率。

**負債與償債能力**
*   **流動性**：根據提供的數據，ServiceNow的流動比率（Current Ratio）為0.65，速動比率（Quick Ratio）為0.65。這兩個比率均低於1，表明其短期償債能力存在一定壓力。然而，對於訂閱制軟體公司而言，預收收入（Unearned Revenue）通常較高，且現金流穩定，因此傳統流動性指標可能無法完全反映其真實的流動性狀況。截至2026年6月30日，總流動資產為85.14億美元，總流動負債為106.38億美元。
*   **長期風險**：截至2026年6月30日（TTM），總負債為191.52億美元，股東權益為125.14億美元。債務對權益比（Debt/Equity）為0.68，顯示公司在資本結構中適度使用了債務槓桿。2025年，公司發行了15億美元的長期債務。S&P Global預計，即使考慮到Armis收購案可能部分透過債務融資，ServiceNow仍將保持穩健的流動性狀況。
*   **淨現金狀況**：儘管現金及短期投資有所下降，但公司仍持有數十億美元的現金，且營運現金流強勁，整體淨現金狀況相對健康。

**無形資產與商譽**
截至2026年6月30日（TTM），ServiceNow的商譽從2025年的35.78億美元大幅增長至98.37億美元。這主要歸因於其近期進行的重大收購，例如Moveworks和Armis Security。商譽的大幅增加需要密切關注，以評估未來是否存在減損風險，尤其是在收購整合不順或被收購公司表現不如預期的情況下。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
ServiceNow的營業現金流（OCF）表現非常出色，且與淨利潤同步增長，甚至超越淨利潤。從2021年的21.91億美元穩步增長至2025年的54.44億美元。截至2026年6月30日的過去十二個月（TTM）營業現金流為53.08億美元。這表明公司的核心業務產生了充沛的現金，其盈餘品質良好，淨利潤的實現伴隨著實際的現金流入。

**自由現金流 (FCF)**
自由現金流（FCF）是衡量公司財務彈性的關鍵指標。2025年，ServiceNow的自由現金流為45.8億美元（營業現金流54.44億美元 - 資本支出8.68億美元）。2026年第二季度單季自由現金流為4.73億美元。強勁的自由現金流表明公司有足夠的內部資金用於業務擴張、潛在的併購、償還債務或回饋股東。

**資本配置 (Capital Allocation)**
ServiceNow的資本配置策略主要集中在以下幾個方面：
*   **資本支出 (CapEx)**：過去幾年資本支出持續增長，從2021年的3.92億美元增至2025年的8.68億美元。這反映了公司對基礎設施和技術的持續投資，以支持其快速增長的業務。
*   **併購**：公司積極透過併購來擴展其產品和技術能力，例如2025年收購Moveworks（24億美元）和2026年計畫收購Armis Security（77.5億美元）。這些併購是其成長策略的重要組成部分。
*   **股份回購**：2025年，ServiceNow回購了1030萬股普通股，價值18億美元，並有額外14億美元的授權回購計畫。2026年預計將進行25億至30億美元的股票回購。這表明公司在產生大量現金流後，也積極透過回購來提升股東價值。
*   **償債**：公司在2025年發行了15億美元的長期債務，同時也可能利用部分現金流進行債務管理。

整體而言，ServiceNow的資本配置效率較高，能夠在投資成長的同時，也兼顧股東回報。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：ServiceNow的股東權益報酬率（ROE）在2025年為15.5%，截至2026年6月30日的過去十二個月（TTM）為14.2%。這表明公司為股東創造價值的能力良好。
    *   **杜邦分析拆解ROE**：
        *   **淨利潤率 (Net Profit Margin)**：截至2026年6月30日的TTM淨利潤為16.7億美元，營收為147.3億美元，淨利潤率約為11.34% (與提供數據一致)。
        *   **資產周轉率 (Asset Turnover)**：截至2026年6月30日的TTM營收為147.3億美元，總資產為316.66億美元，資產周轉率約為0.46倍。
        *   **權益乘數 (Equity Multiplier)**：截至2026年6月30日的TTM總資產為316.66億美元，股東權益為125.14億美元，權益乘數約為2.53倍。
        *   ROE = 淨利潤率 (11.34%) x 資產周轉率 (0.46) x 權益乘數 (2.53) ≈ 13.2% (與14.2%接近，差異可能來自數據取捨或計算時點)。
*   **ROIC (投入資本回報率)**：ServiceNow的投入資本回報率（ROIC）在2025年為12.2%，截至2026年6月30日的過去十二個月（TTM）為8.8%。提供的數據為8.9%。這表明公司在利用其投入資本產生回報方面表現穩健。考慮到其加權平均資本成本（WACC）在2026年8月24日為9.52%，TTM ROIC (8.8%) 略低於WACC，這可能意味著公司在近期創造的經濟利潤有限，甚至略有價值破壞。然而，Finbox的ROIC分析顯示其ROIC在2021-2025年呈上升趨勢，並在2025年達到12.2%，這表明長期來看，公司投資資本的效益是正向的。

**效率指標**
*   **資產周轉率**：如上述杜邦分析所示，TTM資產周轉率約為0.46倍。對於軟體服務公司而言，資產周轉率通常不會像製造業那樣高，但仍需關注其效率。
*   **存貨周轉天數 (DIO)**：由於ServiceNow是軟體服務公司，其存貨極少，因此此指標不適用。
*   **應收帳款周轉天數 (DSO)**：應收帳款周轉天數需要更詳細的數據來計算，但應收帳款佔總資產的比例相對穩定，表明其應收帳款管理效率尚可。

**最終結論：**
1.  **整體評級**：穩健
2.  **核心摘要**：ServiceNow展現出強勁的營收增長動能和優異的現金流產生能力，其核心業務獲利能力持續改善。儘管短期流動性指標偏低，且近期大規模併購導致商譽大幅增加，但充沛的營業現金流和積極的資本配置策略為其提供了穩健的財務基礎。公司在AI領域的持續投入和市場擴張潛力巨大。
3.  **關鍵監測指標**：

    *   **淨債務/EBITDA (Net Debt/EBITDA)**：關注大規模併購後債務水平的變化，以及公司去槓桿的速度。
    *   **商譽減損測試結果 (Goodwill Impairment Test Results)**：密切關注未來財報中商譽的評估，以判斷是否存在減損風險。
