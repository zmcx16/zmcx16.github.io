# ServiceNow Inc (NOW) 財務狀況全面拆解

作為一位資深美股分析師，我對ServiceNow Inc (NOW) 的財務報表進行了深入分析，並參考了其最新的2025年年報 (10-K) 及2026年第一季度季報 (10-Q) 等官方文件。

---

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    ServiceNow展現了強勁且持續的營收成長動能。過去五年，公司營收保持雙位數增長：2021年為58.96億美元，2022年增至72.45億美元 (年增22.88%)，2023年達89.71億美元 (年增23.82%)，2024年為109.84億美元 (年增22.44%)，2025年進一步攀升至132.78億美元 (年增20.89%)。截至2026年3月31日的過去十二個月 (TTM) 營收為139.60億美元，年增21.72%。

    營收成長主要來自其訂閱制雲端平台服務的擴張。2025年第四季度訂閱收入達34.66億美元，年增21% (以固定匯率計算為19.5%)。截至2025年12月31日，公司當前剩餘履約義務 (cRPO) 達128.5億美元，年增25% (以固定匯率計算為21%)，顯示未來營收具有高度可見性。此外，ServiceNow積極投資於AI創新，並透過策略性併購 (如2024年第四季度收購Mission Secure以強化OT服務) 來擴大其平台能力和市場份額，進一步推動營收增長。

*   **獲利能力與利潤率**
    *   **毛利率 (Gross Margin)**：ServiceNow的毛利率一直保持在極高水平，2023年為78.59%，2024年為79.18%，2025年為77.53%，截至2026年3月31日TTM為76.56%。這反映了其SaaS商業模式的固有優勢、強大的定價能力和高效的服務交付能力。
    *   **營業利益率 (Operating Margin)**：營業利益率呈現穩步擴張趨勢，從2023年的8.49%提升至2024年的12.42%，並在2025年達到13.74%，截至2026年3月31日TTM為13.44%。這表明公司在營收增長的同時，有效控制了營運費用，展現出規模經濟效益。
    *   **純益率 (Net Margin)**：純益率在2023年因稅務利益達到19.29%的異常高點 (當年所得稅費用為負7.23億美元)。排除此特殊因素，2024年純益率為12.97%，2025年為13.16%，截至2026年3月31日TTM為12.59%。整體而言，公司保持了穩健的底線獲利能力。

*   **費用控制**
    *   **研發費用 (R&D) 佔比**：研發費用佔營收比重在過去幾年維持在22%至24%之間 (2025年為22.29%，2024年為23.15%，2023年為23.68%，2026年3月31日TTM為23.75%)。這顯示公司持續投入大量資源於產品創新和平台開發，尤其是在AI領域，這與其成長策略高度吻合。
    *   **行銷費用 (S&A) 佔比**：銷售與行銷費用佔營收比重呈現下降趨勢，從2023年的46.42%降至2025年的41.50%，截至2026年3月31日TTM為42.68%。這表明ServiceNow的銷售效率正在提高，品牌認知度增強，使其能夠以更低的相對成本獲取客戶和推動銷售。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**
    *   **現金與短期投資佔比**：截至2025年12月31日，現金及現金等價物為37.26億美元，較2024年的23.04億美元顯著增加。公司持有充裕的流動資產，為其提供了強大的財務彈性和戰略投資空間。
    *   **應收帳款 (AR) 與存貨 (Inventory) 的周轉情況**：作為一家軟體公司，存貨對ServiceNow而言不具重要性。從現金流量表來看，應收帳款的變動 (Changes in Receivables) 在2025年為負3.12億美元，2024年為負2.54億美元，2023年為負3.00億美元。負值表示應收帳款增加，這在快速成長的公司中是常見現象，需持續關注其回收效率，但目前並未顯示出明顯的回收過慢風險。

*   **負債與償債能力**
    *   **流動性**：
        *   **流動比率 (Current Ratio)**：截至2025年12月31日，流動資產為104.71億美元，流動負債為104.43億美元，流動比率約為1.00。這表明公司短期償債能力健康，流動資產足以覆蓋流動負債。
        *   **速動比率 (Quick Ratio)**：由於存貨極少，速動比率與流動比率相近，同樣顯示健康的短期償債能力。
    *   **長期風險**：
        *   **債務對權益比 (Debt/Equity)**：截至2025年12月31日，長期債務淨額為14.91億美元，股東權益為129.64億美元。債務對權益比約為0.115，遠低於基本面數據提供的0.21。這顯示ServiceNow的債務結構極為保守，主要依賴股東權益和遞延收入進行融資，長期財務風險極低。
        *   **淨現金 (Net Cash) 狀況**：公司現金及現金等價物 (37.26億美元) 遠高於其長期債務淨額 (14.91億美元)，擁有顯著的淨現金頭寸，財務狀況非常穩健。

*   **無形資產與商譽**
    截至2025年12月31日，商譽為46.99億美元，無形資產淨額為53.13億美元。相較於2024年，商譽從14.82億美元大幅增加，無形資產淨額從45.83億美元增長。這主要歸因於公司近年來的策略性併購活動。對於軟體公司而言，透過併購獲取技術和客戶基礎是常見的成長模式。儘管商譽和無形資產佔總資產比重較高，但鑑於公司強勁的營運表現和AI領域的戰略佈局，目前並未顯示出重大的減損風險，但仍需持續關注。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**
    ServiceNow的營業現金流持續強勁增長，遠超其淨利潤。2023年OCF為33.98億美元，2024年增至42.67億美元 (年增25.57%)，2025年進一步增長至54.44億美元 (年增27.58%)。截至2026年3月31日TTM的OCF為54.37億美元。
    *   **盈餘品質**：OCF顯著高於淨利潤 (2025年淨利17.48億美元，OCF 54.44億美元)，表明公司盈餘品質極佳。這主要得益於大量的非現金費用 (如折舊攤銷13.59億美元和股權激勵費用19.55億美元)，以及訂閱制業務模式下遞延收入的顯著增長 (2025年遞延收入變動為11.79億美元)。遞延收入的增加代表公司預先收取了大量現金，是SaaS公司健康發展的重要標誌。

*   **自由現金流 (FCF)**
    ServiceNow產生了可觀且不斷增長的自由現金流 (FCF = OCF - 資本支出)。
    *   2023年FCF：33.98億美元 - 6.94億美元 = 27.04億美元
    *   2024年FCF：42.67億美元 - 8.52億美元 = 34.15億美元
    *   2025年FCF：54.44億美元 - 8.68億美元 = 45.76億美元
    *   2026年3月31日TTM FCF：54.37億美元 - 8.04億美元 = 46.33億美元。
    強勁的自由現金流表明公司在滿足營運和資本支出需求後，仍有充足現金用於擴張、回購股份或進行其他策略性投資。基本面數據提供的P/FCF為21.16，與我計算的TTM FCF相符。

*   **資本配置 (Capital Allocation)**
    ServiceNow的資本配置策略清晰且高效：
    *   **資本支出 (CapEx)**：資本支出逐年增加，從2023年的6.94億美元增至2025年的8.68億美元，反映公司持續投資於基礎設施和技術以支持業務擴張。
    *   **併購 (Acquisitions)**：公司積極透過併購來強化其產品組合和市場地位，2025年用於業務併購的現金流出為10.84億美元，截至2026年3月31日TTM更高達23.91億美元，其中2026年第一季度單季併購支出達13.25億美元。
    *   **股份回購 (Share Repurchases)**：ServiceNow積極執行股份回購計畫，以管理股權稀釋並回饋股東。2025年第四季度回購約360萬股，耗資5.97億美元。2026年1月，董事會額外授權50億美元用於股份回購，並計劃啟動20億美元的加速股票回購計畫。
    *   **股息**：公司目前不派發股息，符合其成長型科技公司的定位。
    整體而言，ServiceNow的資本配置效率良好，平衡了成長投資與股東回報。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**
    *   **ROE (股東權益報酬率)**：根據2025年數據，淨利潤17.48億美元，股東權益129.64億美元，計算得ROE為13.48%。基本面數據提供的ROE為16.07%，差異可能來自於計算時點的股東權益值。
        *   **杜邦分析 (2025年)**：
            *   淨利率 (Net Profit Margin)：13.16%
            *   資產周轉率 (Asset Turnover)：0.57 (營收132.78億美元 / 平均總資產232.105億美元)
            *   權益乘數 (Equity Multiplier)：2.06 (平均總資產232.105億美元 / 平均股東權益112.865億美元)
            *   ROE = 13.16% x 0.57 x 2.06 = 15.43%。這表明ServiceNow的ROE主要由穩健的淨利率和適度的資產周轉率貢獻，並透過合理的財務槓桿進行放大。
    *   **ROIC (投入資本回報率)**：基本面數據提供的ROI為12.51%。雖然缺乏WACC數據進行直接比較，但考慮到公司強勁的獲利能力和現金流，其投入資本回報率應能有效超越資本成本。

*   **效率指標**
    *   **資產周轉率 (Asset Turnover)**：2025年為0.57。對於輕資產的軟體公司而言，此水平尚屬合理，顯示其資產運用效率良好。
    *   **存貨周轉天數 (DIO) / 應收帳款周轉天數 (DSO)**：由於ServiceNow無實體存貨，DIO不適用。DSO雖未直接計算，但現金流量表中應收帳款的持續增長與營收增長同步，未見明顯惡化跡象。
