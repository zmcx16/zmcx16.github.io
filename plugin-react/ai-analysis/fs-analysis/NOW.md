作為一位資深美股分析師，我將針對ServiceNow Inc (NOW) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。ServiceNow的財政年度結束於12月31日。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    ServiceNow展現出強勁且持續的營收成長動能。根據最新數據，ServiceNow在2026年第一季度實現了38億美元的營收，年增長率為22.09%。截至2026年3月31日的過去十二個月（TTM）營收為139.6億美元，年增長率為14.4%。
    從過去五年的年度營收來看，ServiceNow的成長軌跡如下:
    *   2021年：59億美元 (年增30.47%)
    *   2022年：72.5億美元 (年增22.88%)
    *   2023年：89.7億美元 (年增23.82%)
    *   2024年：109.8億美元 (年增22.44%)
    *   2025年：132.8億美元 (年增20.88%)
    過去五年的營收複合年增長率（CAGR）為24.1%。這種持續的高速成長主要來自於其訂閱式服務模式以及對企業數位轉型和AI平台的強勁需求。公司在2026年第一季度有16筆超過500萬美元淨新年度合約價值（ACV）的交易，年增長近80%，且擁有630個ACV超過500萬美元的客戶，年增約22%。這表明其成長主要來自於客戶基礎的擴大和現有客戶的增購。

*   **獲利能力與利潤率**
    ServiceNow的獲利能力表現穩健，但近期毛利率略有下降。
    *   **毛利率 (Gross Margin)**：截至2026年3月的過去十二個月毛利率為76.56%。2026年第一季度毛利率為75.1%，較上一季度下降1.6個百分點。2025財年的毛利率為77.5%，較2024年的79.2%有所下降。儘管如此，對於SaaS公司而言，75%以上的毛利率仍屬強勁，顯示其核心訂閱服務具有良好的定價能力和成本管理效率.
    *   **營業利益率 (Operating Margin)**：截至2026年3月的過去十二個月營業利益率為14.70%。2026年第一季度營業利益率為13.3%，較上一季度上升0.9個百分點。ServiceNow的營業利益率呈現擴張趨勢，其5年平均營業利益率增長率為30.80%。
    *   **純益率 (Net Margin)**：截至2026年3月的過去十二個月純益率為12.59%。2026年第一季度純益率為12.4%，較上一季度上升1.2個百分點。2025財年純益率為13.16%。
    利潤率的穩定和擴張表明公司在營收增長的同時，也能有效控制成本並提升營運效率，尤其是在營業利益率方面。

*   **費用控制**
    ServiceNow作為一家成長型軟體公司，其費用結構反映了對市場擴張和產品創新的投入。
    *   **研發費用 (R&D)**：截至2026年3月的過去十二個月研發費用為30.8億美元。2026年第一季度研發費用為8.23億美元。2024財年研發費用佔營收的23.2%。研發費用持續增長，反映了公司在AI、機器學習和平台創新方面的持續投資，這與其作為「AI平台」的成長策略高度相符。
    *   **行銷費用 (S&A)**：2024財年銷售和行銷費用佔營收的35.1%。這筆費用佔比較高，符合成長階段公司積極獲取客戶和維持市場份額的策略。

        *   **速動比率 (Quick Ratio)**：截至2026年3月的過去十二個月速動比率為0.84。這與流動比率相似，反映了類似的流動性狀況。
    *   **長期風險**：

        *   **淨現金 (Net Cash)**：公司擁有54.8億美元的淨現金頭寸，或每股5.31美元。這表明公司財務狀況非常健康，沒有淨債務壓力。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**
    ServiceNow的營業現金流表現強勁，且與淨利潤同步增長。
    *   2025財年營業現金流為54.4億美元。
    *   2026年第一季度營業現金流為16.7億美元。
    營業現金流的健康增長表明公司核心業務產生現金的能力強勁，且盈餘品質良好，淨利潤能夠有效轉化為現金。

*   **自由現金流 (FCF)**
    ServiceNow的自由現金流表現出色，為公司提供了充足的財務彈性。
    *   **計算並分析 FCF (OCF - CapEx)**：
        *   2025財年自由現金流為45.8億美元。
        *   2026年第一季度自由現金流為15.3億美元。
        *   2026年第一季度資本支出為1.41億美元。
    自由現金流在2025年達到每股4.37美元，年增長33.4%，三年複合年增長率為27.0%。這顯示公司不僅能自給自足地支持其成長計畫，還有足夠的現金用於其他資本配置活動。

*   **資本配置 (Capital Allocation)**
    ServiceNow的資本配置策略主要集中在業務擴張、研發投入和股東回報。
    *   **資金主要投向**：
        *   **資本支出 (CapEx)**：2026年第一季度資本支出為1.41億美元。預計2026年和2027年年度資本支出總額為9億至10億美元。
        *   **併購**：公司透過戰略性併購來擴展其AI能力和市場份額。
        *   **股份回購**：2026年第一季度，ServiceNow回購了22億美元的股票，向股東返還資本。預計2026年股票回購總額為25億至30億美元，2027年為13億至17億美元。
    *   **資本配置效率**：公司將大量資金投入研發和銷售，以推動其高成長策略，同時透過股票回購向股東返還價值。強勁的自由現金流支持了這些投資和回報，顯示其資本配置效率良好。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**
    *   **ROE (股東權益報酬率)**：截至2026年7月的過去十二個月ROE為14.98%。截至2026年3月的過去十二個月ROE為16.07%。2025財年ROE為13.48%。ServiceNow的ROE在2019年轉正後，呈現穩定增長趨勢，反映了公司盈利能力對股東權益的有效利用。
        *   **杜邦分析拆解 (截至2026年3月TTM數據)**:
            *   **淨利率 (Net Profit Margin)**：12.59%
            *   **資產周轉率 (Asset Turnover)**：0.62 (2025年調整後為0.59)
            *   **權益乘數 (Financial Leverage)**：未直接提供，但可從ROE = 淨利率 x 資產周轉率 x 權益乘數推算。
            ROE = 12.59% (淨利率) x 0.62 (資產周轉率) x 權益乘數 = 16.07%。
            權益乘數 ≈ 16.07% / (12.59% * 0.62) ≈ 16.07% / 7.8058% ≈ 2.06。
            這表明公司在利用資產和財務槓桿方面相對有效，但主要驅動力來自於其高淨利率。
    *   **ROIC (投入資本回報率)**：截至2026年3月的過去十二個月ROIC為16.78%。2026年3月季度年化ROIC為5.74%。2024年3月ROIC為8.4%。ServiceNow的ROIC在過去三年從4.3%增長到8.4% (截至2024年3月)。雖然最新的季度年化ROIC (5.74%) 低於其加權平均資本成本 (WACC) 9.97%，但過去十二個月的ROIC (16.78%) 則顯著高於WACC，表明公司整體上能有效利用投入資本創造價值。

*   **效率指標**
    *   **資產周轉率 (Asset Turnover)**：截至2026年3月的過去十二個月資產周轉率為0.62。2025年調整後的總資產周轉率為0.59，呈現輕微下降趨勢。這可能反映了公司對長期資產的持續投資，或業務策略轉向更注重成長而非即時資產效率。
    *   **存貨周轉天數 (DIO)**：不適用，因ServiceNow為軟體公司，無實體存貨。
    *   **應收帳款周轉天數 (DSO)**：未直接提供，但鑑於其訂閱模式和強勁的現金流，預計應收帳款回收效率良好。
