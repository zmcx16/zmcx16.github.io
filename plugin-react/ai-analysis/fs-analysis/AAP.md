### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Advance Auto Parts 的營收近年來呈現波動且略顯疲軟的趨勢。
*   **2022年**：淨銷售額為111.55億美元，較2021年增長1.43%。
*   **2023年**：淨銷售額為112.88億美元，較2022年增長1.2%。
*   **2024年**：淨銷售額顯著下降至90.94億美元，較2023年減少15.69%。這一下降主要受到2024年重組計劃中關閉500多家公司門店和200家獨立門店的影響。
*   **2025年**：淨銷售額進一步下降至86.01億美元，較2024年減少5.41%。儘管有53週的額外貢獻，但門店關閉的影響仍在持續。然而，可比店面銷售額在2025年實現了0.8%的增長，這是三年來的首次正增長，顯示核心業務在調整後有所改善。
*   **最新季度 (2026年第二季度，截至2026年7月18日)**：淨銷售額為20億美元，較去年同期微幅下降0.5%。可比店面銷售額下降0.5%，主要由於DIY (Do-It-Yourself) 客戶需求疲軟，但專業安裝 (Pro) 渠道實現了低個位數增長。

整體而言，營收成長動能受到門店優化和DIY市場疲軟的挑戰，但專業安裝業務表現出韌性。

**獲利能力與利潤率**
AAP的獲利能力在過去幾年經歷了顯著波動，尤其是在2024年和2025年受到重組成本的嚴重影響。
*   **毛利率 (Gross Margin)**：
    *   2022年：47.03% (基於提供的數據，與搜尋結果的GAAP毛利/營收計算略有差異，但趨勢一致)。
    *   2023年：40.1%。
    *   2024年：GAAP毛利率為37.5%，調整後為42.2%。
    *   2025年：GAAP毛利率為43.4%，調整後為43.9%。
    *   2026年第二季度：GAAP毛利率為46.2%，調整後亦為46.2%。這其中包括2600萬美元的關稅退款，對毛利率有正面影響。
    毛利率在2023年和2024年有所下滑，主要受庫存相關項目和供應鏈成本上升影響。2025年和2026年第二季度則有所改善，部分得益於重組計劃帶來的營運效率提升和戰略採購。

*   **營業利益率 (Operating Margin)**：
    *   2022年：6.0%。
    *   2023年：1.0%。
    *   2024年：GAAP營業虧損率為(7.8)%，調整後營業利益率為0.4%。
    *   2025年：GAAP營業虧損率為(0.5)%，調整後營業利益率為2.5%。
    *   2026年第二季度：GAAP營業利益率為5.1%，調整後營業利益率為5.6%。這顯示公司在經歷了2023-2024年的低谷後，獲利能力正在顯著恢復，調整後營業利益率同比擴張超過250個基點。

*   **純益率 (Net Margin)**：
    *   2022年：約6.86% (基於EPS $7.65和約11.155B營收)。
    *   2023年：約0.44% (基於EPS $0.50和約11.288B營收)。
    *   2024年：GAAP淨虧損，稀釋每股虧損9.80美元。
    *   2025年：稀釋每股收益1.13美元。
    *   2026年第二季度：稀釋每股收益0.90美元。
    淨利潤率的波動性更大，尤其是在2024年因重組費用導致巨額虧損。2025年和2026年第二季度已恢復盈利。

利潤率在2023-2024年期間受到嚴重壓縮，主要由於產品成本上升、供應鏈效率低下以及重組相關的一次性費用。2025年和2026年第二季度顯示出利潤率擴張的跡象，尤其是在調整後基礎上，表明公司在成本控制和營運效率方面取得進展。規模經濟效應在營收下滑期間難以體現，但隨著營運效率的提升，未來有望逐步顯現。

**費用控制**
*   **銷售、一般及行政費用 (SG&A)**：
    *   2023年：佔淨銷售額的39.1%。
    *   2024年：GAAP SG&A佔淨銷售額的45.3%，調整後為41.8%。
    *   2025年：GAAP SG&A佔淨銷售額的43.9%，調整後為41.4%。
    *   2026年第二季度：GAAP SG&A佔淨銷售額的41.1%，調整後為40.6%。
    SG&A費用佔比在2024年因銷售額下降而顯著上升，但隨後在2025年和2026年第二季度有所改善，這得益於成本節約措施和門店數量減少。公司在2023年第四季度實施了企業支出和員工人數的顯著削減。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：
    *   22年：7.65 (EPS) / (股東權益/股數) = 7.65 / (2170M/59.5M) = 7.65 / 36.47 = 20.98% (近似值，基於2024年股東權益和2022年EPS)
    *   23年：0.50 (EPS) / (股東權益/股數) = 0.50 / (2170M/59.5M) = 0.50 / 36.47 = 1.37% (近似值)
    *   24年：淨虧損，ROE為負。
    *   25年：1.13 (EPS) / (2198M/59.5M) = 1.13 / 36.94 = 3.06% (近似值)
    提供的數據顯示ROE為0.0484 (4.84%)，這可能是一個調整後的或不同時間點的數據。根據最新的財報數據，ROE在2024年為負，2025年恢復正值但仍較低。

    **杜邦分析 (以2025年數據為例，使用調整後數據或GAAP數據，此處使用GAAP數據進行近似計算)**：
    *   淨利潤率 (Net Profit Margin) = 淨利潤 / 營收 = (1.13 * 59.5M) / 8601M = 67.235M / 8601M = 0.78%
    *   資產周轉率 (Asset Turnover) = 營收 / 總資產 = 8601M / 11826M = 0.73
    *   權益乘數 (Equity Multiplier) = 總資產 / 股東權益 = 11826M / 2198M = 5.38
    *   ROE = 淨利潤率 x 資產周轉率 x 權益乘數 = 0.78% x 0.73 x 5.38 = 3.06% (與上述EPS計算結果一致)
    2025年的ROE較低，主要受淨利潤率較低影響，儘管資產周轉率和財務槓桿相對穩定。

*   **ROA (資產報酬率)**：
    *   2025年：淨利潤67.235M / 總資產11826M = 0.57%。
    提供的數據顯示ROA為0.0096 (0.96%)。ROA較低，反映公司利用資產產生利潤的效率不高。

*   **ROI (投資報酬率)**：
    提供的數據顯示ROI為0.0112 (1.12%)。

**效率指標**
*   **資產周轉率 (Asset Turnover)**：
    *   2025年：0.73 (如上計算)。
    資產周轉率在營收下降的背景下有所承壓，表明公司資產利用效率有待提高。

*   **存貨周轉天數 (DIO)**：

    *   25年：存貨36.46億美元 / (銷貨成本 / 365天) = 3646 / ( (8601M * (1-0.434)) / 365) = 3646 / (4867.234 / 365) = 3646 / 13.33 = 273天 (近似值)
    存貨周轉天數較長且有增加趨勢，可能存在存貨積壓或管理效率問題。

*   **應收帳款周轉天數 (DSO)**：

    *   **可比店面銷售額 (Comparable Store Sales Growth)**：特別是DIY和Pro渠道的表現，以評估核心業務的健康狀況和市場需求趨勢。
