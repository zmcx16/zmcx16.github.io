# Teradata Corp (TDC) 財務深度分析報告

作為資深美股分析師，針對 Teradata (TDC) 的最新財務數據（結合 2023 年報與 2024 年前三季財報）進行全面拆解。Teradata 目前正處於從傳統地端授權轉向雲端訂閱制（SaaS）的轉型關鍵期，這反映在其財務報表的結構性變化中。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**：
    *   **結構轉型**：2023 全年營收為 18.33 億美元，較 2022 年的 17.95 億美元僅微增 2%。然而，核心動能來自**公有雲 ARR (年度經常性收入)**，2024 年 Q3 達到 6.11 億美元，年增達 35%。
    *   **成長來源**：總營收停滯是因為公司主動減少了低毛利的諮詢服務與一次性授權，轉向高毛利的訂閱收入。這種「換血」過程導致短期總營收增速緩慢，但收入品質提升。
*   **獲利能力與利潤率**：
    *   **毛利率**：維持在 61.2% 的高水準，反映其數據平台 Vantage 的技術護城河。
    *   **營業利益率**：目前約 7.92%，處於較低水平。主因是轉型期間需維持高額的雲端基礎設施成本與研發投入。
    *   **純益率**：數據顯示 Profit Margin 為 27.08%，但需注意這包含了一次性的稅務利益或非經常性損益。常態化（Non-GAAP）純益率較能反映真實獲利。
*   **費用控制**：
    *   研發費用 (R&D) 佔比約 16-18%，行銷費用 (S&A) 佔比約 40%。在雲端轉型期，S&A 居高不下是為了與 Snowflake、Databricks 等原生雲端對手競爭，費用控制尚屬合理但缺乏規模經濟效應。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**：
    *   **現金狀況**：截至 2024 年 Q3，現金及等價物約 3.25 億美元。應收帳款周轉天數 (DSO) 約 75 天，表現穩定，無明顯壞帳風險。
    *   **存貨**：作為軟體公司，存貨極低，無跌價損失風險。
*   **負債與償債能力**：
    *   **流動性**：流動比率與速動比率均為 0.91。雖然低於 1.0，但考慮到軟體公司有大量「遞延收入」（Deferred Revenue，屬負債但無須現金償還），實際流動性風險極低。
    *   **債務結構**：總債務/權益比 (Debt/Eq) 僅 0.17，長期債務/權益比 0.09。總債務約 4.98 億美元，對比其現金流產生能力，債務壓力非常輕微。
*   **無形資產與商譽**：
    *   商譽約 4.4 億美元，佔總資產比重約 24%，處於健康區間，近期無重大併購，減損風險低。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**：
    *   **盈餘品質極高**：2023 年 OCF 為 3.57 億美元，遠高於 GAAP 淨利。這主因是折舊攤銷與股權激勵費用（SBC）等非現金支出佔比高，且訂閱制帶來的預收款項增加了現金流入。
*   **自由現金流 (FCF)**：
    *   2023 年 FCF 達 3.13 億美元。以目前約 25.5 億美元的市值計算，**P/FCF 僅 3.46 倍**，這在科技股中屬於極度低估的水平，顯示公司具備極強的現金產生能力。
*   **資本配置 (Capital Allocation)**：
    *   **股份回購**：TDC 採取極其激進的回購策略。2023 年回購了約 3.18 億美元的股票，幾乎將所有 FCF 回饋給股東。
    *   **資本支出**：CapEx 佔營收比重極低（約 2-3%），屬於輕資產營運模式。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **ROE (股東權益報酬率)**：
    *   數據顯示 ROE 為 119.12%。這是一個「失真」的指標，主因是公司長期大量回購股票導致股東權益（分母）極小，人為推高了 ROE，並非單純靠獲利能力驅動。
*   **ROIC (投入資本回報率)**：
    *   ROI 為 71.12%，顯示其投入資本的效率極高，遠超其加權平均資本成本 (WACC)，具備創造超額價值的能力。
*   **效率指標**：
    *   資產周轉率約 1.0x，在軟體產業中屬中規中矩。

### 5. 財務健康總結

| 維度 | 評等 (1-5★) | 關鍵評語 (簡短扼要) |
| :--- | :--- | :--- |
| **獲利能力** | ★★★ | 轉型期 GAAP 利潤波動大，但雲端 ARR 成長強勁。 |
| **償債安全性** | ★★★★★ | 債務槓桿極低，利息保障倍數高，財務結構穩健。 |
| **現金流品質** | ★★★★★ | FCF 極其充沛，P/FCF 估值極具吸引力。 |
| **資本效率** | ★★★★ | ROIC 表現優異，激進回購有效提升每股價值。 |

**最終結論：**
1. **整體評級**：**穩健**（具備價值投資屬性）
2. **核心摘要**：TDC 正處於「黎明前的黑暗」，雖然總營收受轉型拖累顯得平庸，但其**現金流產生能力極強**且估值極低（P/FCF < 4）。公司透過激進回購支撐股價，財務結構極其安全。若雲端 ARR 能持續保持 30% 以上增長，隨著舊有地端成本攤銷完畢，利潤將迎來爆發式增長。
3. **關鍵監測指標**：
    *   **Public Cloud ARR Growth**：是否維持在 30% 以上。
    *   **Free Cash Flow Margin**：能否穩定在 15-20% 區間。
    *   **Non-GAAP Operating Margin**：觀察轉型後的規模經濟是否顯現（目標應 > 15%）。
