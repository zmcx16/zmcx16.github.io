# Teradata Corp (TDC) 財務報表深度分析報告

作為資深美股分析師，針對 Teradata (TDC) 的財務狀況，結合最新 2024 年第三季（Q3）財報與年度趨勢，分析如下：

### 1. 損益表分析 (Income Statement Analysis)
*   **營收成長動能**：
    Teradata 正處於從傳統地端（On-premise）轉向雲端訂閱制（SaaS）的轉型末期。2024 年 Q3 總營收為 4.4 億美元，同比持平。核心動能來自**公有雲 ARR（年度經常性收入）**，該指標達到 5.7 億美元，同比增長 26%（按固定匯率計算）。總 ARR 為 15.27 億美元。營收成長並非來自銷量大增，而是來自現有客戶向雲端平台 VantageCloud 的遷移及客單價提升。
*   **獲利能力與利潤率**：
    *   **毛利率**：維持在 61.2% 的高水準，顯示其數據倉儲技術具備競爭力，雲端轉型並未嚴重侵蝕毛利。
    *   **營業利益率**：GAAP 營業利益率約 7.9%，Non-GAAP 則達 19.5%。利潤率擴張受限於研發與雲端基礎設施的持續投入。
    *   **純益率**：數據顯示 Profit Margin 達 27.08%，這主要受到稅務資產撥回或一次性項目影響，常態化純益率較低。
*   **費用控制**：
    研發費用（R&D）佔比約 15-18%，行銷費用（S&A）佔比約 30-35%。在面對 Snowflake 與 Databricks 的競爭下，費用控制尚屬嚴謹，並未出現失控性支出。

### 2. 資產負債表分析 (Balance Sheet Analysis)
*   **資產品質與結構**：
    現金及等價物約 3.2 億美元。應收帳款周轉天數（DSO）保持穩定，無明顯壞帳風險。由於是軟體公司，存貨極低，資產結構輕量化。
*   **負債與償債能力**：
    *   **流動性**：流動比率與速動比率均為 0.91，低於 1.0 的傳統安全線，反映出遞延收入（Deferred Revenue）佔比較高，這是訂閱制公司的常見現象，實質短期償債壓力不大。
    *   **長期風險**：債務對權益比（Debt/Equity）僅 0.17，長期債務結構穩定，淨現金狀況良好。
*   **無形資產與商譽**：
    商譽佔比穩定，近期無重大併購，因此減損風險較低。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)
*   **營業現金流 (OCF)**：
    TDC 的現金流表現遠優於淨利。2024 年前三季營運現金流強勁，主要受益於訂閱預收款。
*   **自由現金流 (FCF)**：
    P/FCF 僅 3.83，顯示公司產生現金的能力極強。2024 年預期 FCF 將達到 3.4 億至 3.8 億美元區間。
*   **資本配置 (Capital Allocation)**：
    *   **股份回購**：TDC 極其激進地進行回購，這是導致其 ROE 異常高（119%）的主因（分母權益被大幅壓縮）。
    *   **資本支出**：CapEx 佔比較低，顯示其業務模式具備高資本效率。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)
*   **回報率指標**：
    *   **ROE (119.1%)**：此數字具備誤導性，拆解後發現主要是「財務槓桿」與「極低的股東權益」所致，而非單純獲利暴增。
    *   **ROIC**：實際投入資本回報率約在 20-25% 之間，遠高於 WACC，顯示公司仍具備創造超額價值的能力。
*   **效率指標**：
    資產周轉率穩定，雲端轉型帶來的預收款增加優化了營運資金循環。

### 5. 財務健康總結

| 維度 | 評等 (1-5★) | 關鍵評語 (簡短扼要) |
| :--- | :--- | :--- |
| **獲利能力** | ★★★ | 轉型期營收成長停滯，但雲端 ARR 增長亮眼。 |
| **償債安全性** | ★★★★ | 債務負擔極輕，利息保障倍數高。 |
| **現金流品質** | ★★★★★ | FCF 極其強勁，估值倍數（P/FCF）極具吸引力。 |
| **資本效率** | ★★★★ | 透過大規模回購極大化股東回報，資本結構精簡。 |

**最終結論：**
1. **整體評級**：**穩健**
2. **核心摘要**：Teradata 是一家典型的「現金牛」轉型公司。雖然總營收成長緩慢，但其雲端轉型已見成效，且具備極強的自由現金流產生能力。極低的 P/E 與 P/FCF 顯示市場對其競爭壓力過度擔憂，財務結構因大規模回購而顯得極其精煉。
3. **關鍵監測指標**：
    *   **Public Cloud ARR Growth**：是否能維持 20% 以上增長。
    *   **Free Cash Flow Margin**：觀察是否能持續保持在營收的 15-20% 以上。
    *   **Non-GAAP Operating Margin**：觀察在 AI 投入增加下，利潤率是否能維持在 20% 附近。
