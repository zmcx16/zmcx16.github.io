Zim Integrated Shipping Services Ltd. (ZIM) 是一家全球領先的貨櫃航運公司。作為資深美股分析師，我將根據其最新財報數據及市場資訊，對ZIM的財務狀況進行全面拆解。

### 1. 損益表分析 (Income Statement Analysis)

-   **營收成長動能**
    ZIM的營收在近年呈現波動。根據2025年年報（20-F），公司2025年全年總營收為69.0億美元，相較於2024年的84.3億美元有所下降。這一下降主要歸因於運費率的降低以及貨運量的小幅減少。2025年全年貨運量為3,663千TEU，略低於2024年的3,751千TEU；平均每TEU運費率從2024年的1,888美元降至2025年的1,551美元。
    從季度數據來看，2025年第四季度的總營收為14.8億美元，也低於2024年第四季度的21.7億美元，同樣是受到運費率下降和貨運量減少的影響。
    然而，最新的市場動態顯示，ZIM在2026年第二季度取得了「強勁的業績」，並且在2026年10月6日上調了2026年全年財測，預計調整後EBITDA將達到27億至30億美元，調整後EBIT將達到14億至17億美元，這反映了市場需求持續強勁和運費率的有利勢頭。這表明公司營收動能可能在2026年有所恢復。

-   **獲利能力與利潤率**
    ZIM的獲利能力在2025年面臨壓力。2025年全年營業利益（EBIT）為10.2億美元，較2024年的25.3億美元大幅下滑。這導致營業利益率（EBIT Margin）從2024年的約30%降至2025年的約14.8%。
    從提供的基本面數據來看，ZIM的毛利率 (Gross Margin) 為10.97%，營業利益率 (Oper. Margin) 為5.67%，純益率 (Profit Margin) 為2.15%。這些數據反映了在當前市場環境下，公司的獲利空間受到壓縮。雖然2026年財測上調預示著利潤率可能改善，但航運業的週期性特點使其利潤率波動較大，難以維持穩定擴張。目前數據並未明確顯示規模經濟效應。

-   **費用控制**
    由於缺乏詳細的損益表分項數據（如研發費用、行銷費用佔比），無法對費用控制進行深入分析。然而，航運業的費用結構主要受燃料成本、港口費用、租船費用等營運成本影響。公司在2021-2022年透過長期租船協議更新船隊，並在2025年完成船隊更新計畫，其中約40%為LNG動力船，旨在改善成本結構並支持長期獲利增長。這顯示公司正透過現代化和環保船隊來優化營運效率和成本。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**
    由於缺乏具體的營業現金流數據，無法直接比較其與淨利的增長情況。然而，航運業的營業現金流通常受運費波動影響較大。在運費高漲時期，OCF會非常強勁，反之則可能承壓。2025年營業利益的下降，預計也會對營業現金流產生負面影響。

-   **自由現金流 (FCF)**
    2025年資本支出為2.18億美元，與2024年的2.14億美元相近。由於缺乏營業現金流數據，無法精確計算FCF。然而，提供的基本面數據中P/FCF為3.24，這是一個相對較低的數值，可能暗示其自由現金流在某些時期表現良好，或者市場對其未來FCF預期較低。考慮到2025年獲利下降，FCF可能也面臨壓力。

-   **資本配置 (Capital Allocation)**
    ZIM在資本配置方面，主要投入於船隊更新和擴張。公司在2021-2022年透過長期租船協議確保了現代化船隊，並在2025年完成了船隊更新計畫。此外，公司在2025年下半年簽訂了22艘新造船的租船協議，並預計在2026年下半年開始交付額外36艘新造船。這表明公司將大量資金投入於資本支出以提升競爭力。
    在股息方面，ZIM自2021年IPO以來，已向股東派發了高達58億美元的股息，或每股48.42美元。僅2025年，公司就派發了2.4億美元的股息，或每股1.99美元。這顯示公司在過去獲利豐厚時，積極回饋股東。然而，在獲利承壓時期，這種高派息政策的可持續性需要關注。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

-   **回報率指標**
    -   **ROE (股東權益報酬率)**：提供的基本面數據顯示ROE為3.56%。這是一個相對較低的數字，表明公司利用股東資金創造利潤的效率不高。
        杜邦分析拆解：ROE = 純益率 x 資產周轉率 x 財務槓桿。
        純益率 (Profit Margin) 為2.15%。
        ROA (資產報酬率) 為1.27%。由於ROA = 純益率 x 資產周轉率，因此資產周轉率約為1.27% / 2.15% ≈ 0.59倍。
        財務槓桿 (Equity Multiplier) = ROE / ROA = 3.56% / 1.27% ≈ 2.8倍。
        較低的ROE主要受純益率和資產周轉率的影響，儘管財務槓桿較高，但未能有效提升股東回報。
    -   **ROIC (投入資本回報率)**：提供的基本面數據顯示ROI為1.71%。這是一個非常低的數字，遠低於一般認為的資本成本（WACC）。這表明公司投資資本的效益不佳，未能有效創造超額價值。

-   **效率指標**
    提供的數據中未包含資產周轉率、存貨周轉天數 (DIO)、應收帳款周轉天數 (DSO) 的具體數值，但從上述ROA和純益率推算的資產周轉率約為0.59倍，顯示資產利用效率有待提高。
