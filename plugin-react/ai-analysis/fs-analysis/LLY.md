# Eli Lilly (LLY) 財務報表深度分析報告

作為資深美股分析師，針對 Eli Lilly (LLY) 最新揭露的 2024 財年全年及第四季財報，結合提供之基本面數據，進行以下專業拆解。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**：
    LLY 展現了製藥業罕見的爆發式成長。2024 全年營收達 454.2 億美元，年增 33%。第四季營收更達 135.4 億美元，年增 42%。
    *   **成長來源**：核心動能來自 GLP-1 藥物。Mounjaro (糖尿病) 全年貢獻 125.8 億美元，Zepbound (肥胖症) 在上市首年即突破 50 億美元。這屬於典型的「銷量驅動型」成長，且因需求遠超產能，漲價空間與銷量潛力依然巨大。
*   **獲利能力與利潤率**：
    *   **毛利率 (Gross Margin)**：2024 全年 GAAP 毛利率達 80.6%，較去年提升。這反映了高價值生物製劑的規模經濟效應。
    *   **營業利益率 (Operating Margin)**：數據顯示為 51.25% (Non-GAAP)，GAAP 則約 33.6%。利潤率正在擴張，主因是營收增速遠超固定成本增長。
*   **費用控制**：
    *   **研發費用 (R&D)**：2024 年投入約 105 億美元，佔營收約 23%。這在同業中處於高位，顯示公司積極佈局阿茲海默症 (Donanemab) 及下一代口服減肥藥。
    *   **行銷費用 (SG&A)**：隨新藥上市增加，但佔比隨營收規模擴大而相對稀釋。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**：
    *   **存貨與應收帳款**：存貨周轉天數略有上升，主因是公司為應對全球需求積極備貨及擴大產線。
    *   **固定資產**：PP&E (廠房設備) 顯著增加，公司在印第安納州、愛爾蘭及德國投入數百億美元擴建產能，這是未來營收轉化的核心資產。
*   **負債與償債能力**：
    *   **流動性**：流動比率 1.39，速動比率 1.0，處於健康水位，足以應付短期債務。
    *   **長期風險**：Debt/Equity 為 1.23，總債務約 280 億美元。雖然槓桿率看似較高，但考量到其 EBITDA 成長速度，利息保障倍數極高，財務風險極低。
*   **無形資產與商譽**：商譽佔比相對穩定，近期無重大溢價併購導致的減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**：2024 年 OCF 表現強勁，與淨利同步增長。盈餘品質高，非現金支出（如折舊攤銷）與營運資本變動處於合理區間。
*   **自由現金流 (FCF)**：
    *   計算：OCF 減去資本支出 (CapEx)。由於 LLY 正處於史詩級的產能擴張期（2024 資本支出超過 60 億美元），FCF 受到一定程度壓抑，但 P/FCF 66.62 顯示市場對其未來現金流折現給予極高溢價。
*   **資本配置 (Capital Allocation)**：
    *   **優先順序**：1. 產能擴建（CapEx）；2. 研發投入；3. 股息發放（連續多年增長，殖利率 0.5%）；4. 併購（如收購 Morphic）。
    *   **效率**：資本配置極其精準，專注於代謝疾病與神經科學的高回報領域。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **杜邦分析 (ROE 拆解)**：
    *   **ROE 86.09%**：這是一個極高的數字。拆解後發現，除了高純益率 (31.9%) 外，財務槓桿與資產周轉率的優化共同推升了回報率。
*   **ROIC (投入資本回報率)**：31.61%，遠高於其 WACC (約 8-9%)，顯示公司每投入 1 元資本都能創造顯著的超額價值。
*   **效率指標**：資產周轉率隨 GLP-1 藥物放量持續改善，顯示資產利用效率進入上升週期。

**最終結論：**
1. **整體評級**：**優良**
2. **核心摘要**：LLY 目前處於財務基本面的「黃金時代」。憑藉 Mounjaro 與 Zepbound 的壟斷性需求，營收與利潤呈現非線性增長。儘管為了擴產導致資本支出巨大且債務略增，但這屬於為未來 5-10 年成長奠定基礎的良性擴張。極高的 ROE 與利潤率顯示其具備極強的護城河。
3. **關鍵監測指標**：
    *   **Manufacturing CapEx Progress**：觀察產能釋放速度是否能緩解缺貨壓力。
    *   **Non-GAAP Operating Margin**：觀察隨著營收規模擴大，營業槓桿是否持續優化。
    *   **R&D Pipeline Success (Donanemab)**：阿茲海默症藥物的商業化進展將決定下一波估值重估。
