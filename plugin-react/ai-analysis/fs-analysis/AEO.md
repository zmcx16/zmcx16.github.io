## American Eagle Outfitters Inc. (AEO) 財務狀況全面拆解

作為一名資深美股分析師，我將對 American Eagle Outfitters Inc. (AEO) 的財務狀況進行全面拆解，深入分析其損益表、資產負債表、現金流量表，並結合核心財務指標進行評估。

### 1. 損益表分析 (Income Statement Analysis)

#### 營收成長動能
AEO 近年來展現出穩健的營收成長動能。在截至2024年2月3日的2023財年，公司實現了創紀錄的53億美元總營收，較2022財年增長5%。

從最新的季度數據來看：
*   2025財年第一季度（截至2024年5月4日），總淨營收為11億美元，同比增長6%，其中可比銷售額增長7%。
*   2025財年第二季度（截至2024年8月1日），總營收達到13億美元，同比增長8%，可比銷售額增長4%。
*   2025財年第三季度（截至2024年11月2日），總淨營收為13億美元，同比下降1%，但可比銷售額仍增長3%。
*   22026財年第一季度（截至2026年5月2日），總淨營收增長10%至11.95億美元，可比銷售額增長8%。其中，Aerie 品牌營收增長34%，可比銷售額增長25%，而 American Eagle 品牌營收下降2%，可比銷售額下降2%。
*   2026財年第二季度（截至2026年8月1日），總淨營收為13.8億美元，較去年同期增長7.5%，可比銷售額增長6%。

營收成長主要來自於其核心品牌 American Eagle 和 Aerie 的銷售增長，特別是 Aerie 品牌持續表現強勁，實現了創紀錄的營收增長。公司也透過門店擴張和重新設計來提升品牌參與度。值得注意的是，零售日曆的調整對季度營收產生了約1500萬美元至5500萬美元的影響。

#### 獲利能力與利潤率
AEO 的獲利能力在近期有所改善，但利潤率波動較大。
*   **毛利率 (Gross Margin)**：
    *   2025財年第一季度為40.6%，擴張了240個基點。
    *   2025財年第二季度為38.6%，擴張了90個基點。
    *   2025財年第三季度毛利潤下降3%，毛利率因促銷活動增加和初始加價率持平而下降。
    *   2026財年第一季度毛利率為38.2%，同比增長860個基點，主要得益於銷售額增長、較低的租賃負擔以及去年同期7500萬美元庫存減記的影響。
    *   2026財年第二季度毛利率顯著擴張980個基點至48.7%，其中包含1.79億美元的關稅退款收益，但商品毛利率因 American Eagle 的促銷活動抵消了 Aerie 的強勁表現而下降了330個基點。
*   **營業利益率 (Operating Margin)**：
    *   2023財年 GAAP 營業利潤為2.23億美元，調整後營業利潤為3.75億美元，較2022財年增長39%。
    *   2025財年第一季度調整後營業利益率為6.8%，擴張了270個基點，營業利潤為7800萬美元。
    *   2025財年第二季度營業利益率提高240個基點至7.8%，營業利潤為1.01億美元。
    *   2025財年第三季度 GAAP 營業利益率為8.2%，調整後營業利益率為9.6%，營業利潤為1.06億美元。
    *   2026財年第一季度營業利潤為2820萬美元，相較去年同期的8500萬美元營業虧損有顯著改善。
    *   2026財年第二季度營業利潤達到2.11億美元，較去年同期1.031億美元翻倍，其中包含1.61億美元的關稅退款淨收益。
*   **純益率 (Net Margin)**：
    *   2026財年第二季度淨利潤為1.341億美元，稀釋後每股盈餘為0.79美元。

利潤率的波動顯示公司在成本控制和定價策略上面臨挑戰，尤其是在促銷活動增加時。然而，近期關稅退款對毛利率和營業利潤產生了顯著的正面影響。

#### 費用控制
*   **銷售、一般及管理費用 (SG&A)**：
    *   2025財年第一季度 SG&A 費用為3.33億美元，增長7%。
    *   2025財年第三季度 SG&A 費用為3.51億美元，下降3%，並產生了50個基點的槓桿效應。
    *   2026財年第一季度 SG&A 費用為3.765億美元，同比增長11%，佔營收的31.5%，增長40個基點，主要受計劃中的廣告投入驅動。
    *   2026財年第二季度 SG&A 費用增長19%，佔銷售額的29.6%，其中包括1800萬美元與關稅退款相關的激勵費用，其餘增長主要反映了計劃中的廣告投入。

SG&A 費用在某些季度與銷售增長保持一致，但在其他季度則因廣告投入和激勵費用而有所上升。公司持續專注於提高效率以實現 SG&A 的槓桿作用。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

#### 營業現金流 (OCF)
*   2023財年，AEO 產生了5.81億美元的強勁營業現金流。
*   2026財年上半年（年初至今），營業現金流改善至1.163億美元，而去年同期為現金使用。
*   營業現金流與淨利潤的同步增長是衡量盈餘品質的重要指標。2026財年第二季度，公司淨利潤為1.341億美元，而上半年營業現金流為1.163億美元，顯示盈餘品質良好，營運產生的現金與淨利潤大致同步。

#### 自由現金流 (FCF)
*   **計算 FCF (OCF - CapEx)**：
    *   2023財年 FCF = 5.81億美元 (OCF) - (未提供具體 CapEx，但公司投資了品牌並回報股東1.04億美元)。
    *   2026財年上半年 FCF = 1.163億美元 (OCF) - 1.276億美元 (CapEx) = -1130萬美元。
    *   2026財年第二季度 CapEx 為6600萬美元。
*   儘管2026財年上半年自由現金流為負，但考慮到公司在業務上的投資（資本支出）以及向股東返還現金，這可能是一個暫時現象。公司預計2024財年資本支出約為2億至2.5億美元。P/FCF 為8.85，表明市場對其自由現金流的估值相對合理。

#### 資本配置 (Capital Allocation)
*   **資金主要投向**：
    *   **資本支出 (CapEx)**：2025財年第一季度資本支出為3600萬美元。2026財年第二季度資本支出為6600萬美元。2026財年上半年資本支出為1.276億美元。公司預計2024財年資本支出約為2億至2.5億美元，用於業務投資。
    *   **派發股息**：2025財年第一季度支付了約2500萬美元的季度現金股息。2026財年第二季度通過季度股息向股東返還了2100萬美元。
    *   **股份回購**：2023財年回購了100萬股股票，並授權未來回購3000萬股。2026財年上半年回購了2.31億美元的股票（2040萬股），稀釋股份減少約10%。
*   **資本配置效率**：公司積極通過資本支出投資業務，同時通過股息和股票回購向股東返還現金，顯示其在平衡增長和股東回報方面的策略。大規模的股票回購表明管理層對公司未來前景的信心，並有助於提升每股收益。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

#### 回報率指標
*   **ROE (股東權益報酬率)**：AEO 的 ROE 為20.36%，表現良好。
    *   **杜邦分析拆解 ROE** (ROE = 淨利率 x 資產周轉率 x 權益乘數)：
        *   淨利率 (Profit Margin) 為5.91%。
        *   資產周轉率 (Asset Turnover) = ROA / 淨利率 = 8.08% / 5.91% ≈ 1.37。
        *   權益乘數 (Equity Multiplier) = ROE / ROA = 20.36% / 8.08% ≈ 2.52。
        *   驗證：5.91% x 1.37 x 2.52 ≈ 20.36%。
    *   AEO 的 ROE 主要由其健康的淨利率和適度的財務槓桿驅動。資產周轉率顯示其資產利用效率尚可。
*   **ROIC (投入資本回報率)**：AEO 的 ROI 為9.98%。由於 WACC 未提供，無法直接比較，但9.98%的 ROI 表明公司在投資資本方面產生了不錯的回報。
