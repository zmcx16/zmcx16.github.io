作為一名資深美股分析師，我將對 Eastman Chemical Co (EMN) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Eastman Chemical Co 的營收在過去幾年呈現波動。從年度數據來看，公司在2021年實現了顯著增長，營收達到104.76億美元，較2020年增長23.6%。2022年營收微幅增長至105.80億美元，增幅1.0%。然而，2023年營收下滑12.9%至92.10億美元，2024年略有回升至93.82億美元，增長1.9%。到了2025年，營收再次下降6.7%至87.52億美元。
就最新季度（截至2026年9月30日的第三季度）而言，EMN 的銷售收入為23.85億美元，較去年同期（2025年第三季度）的22.02億美元增長8%。這項增長主要得益於更高的銷售價格和產品組合的改善，其中化學中間體（Chemical Intermediates）部門的銷售額增長了16%，主要來自12%的價格上漲和4%的銷量/產品組合增長。先進材料（Advanced Materials）部門的銷售額增長5%，主要來自4%的價格上漲。這表明近期營收增長主要由價格上漲和部分銷量改善共同推動。

**獲利能力與利潤率**
EMN 的獲利能力在過去幾年有所波動。
*   **毛利率 (Gross Margin)**：從2021年的23.9%下降至2022年的20.2%，隨後在2023年回升至22.4%，2024年達到24.4%的近期高點，但在2025年又降至21.1%。截至2026年9月30日的過去十二個月 (TTM) 毛利率為20.57%。這顯示毛利率在過去五年內呈現波動，2025年和2026年TTM的毛利率低於2024年的水平，表明成本壓力或定價能力受到挑戰。
*   **營業利益率 (Operating Margin)**：與毛利率趨勢相似，2021年為12.2%，2022年降至11.0%，2023年回升至14.1%，2024年為13.6%，2025年則顯著下降至8.9%。截至2026年9月30日的過去十二個月 (TTM) 營業利益率為9.59%。2025年的營業利益率是過去十年來的最低點。
*   **純益率 (Net Margin)**：2021年為8.3%，2022年為7.5%，2023年和2024年均為9.7%，但在2025年大幅下降至5.4%。
利潤率的波動表明公司在成本控制和定價方面面臨挑戰，尤其是在2025年，毛利率、營業利益率和純益率均出現顯著下滑。這可能與原材料成本、能源成本上升以及市場需求疲軟有關。儘管2026年第三季度營收有所增長，但TTM利潤率仍顯示出壓力。

**費用控制**
雖然具體的研發費用 (R&D) 和銷售與管理費用 (S&A) 佔比未在搜索結果中直接提供，但營業利益率的變化可以間接反映費用控制情況。2025年營業利益率的顯著下降（從2024年的13.6%降至8.9%）表明，除了毛利率壓力外，費用控制可能也面臨挑戰，或者營收下降導致固定費用佔比提高。公司在2025年實現了約1億美元的成本節約，超過了7500萬美元的目標，這表明公司正在積極應對成本壓力。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2026年9月30日，EMN 的總資產為154.7億美元。
*   **現金與短期投資佔比**：截至2026年9月30日，現金及約當現金為7.68億美元。相對於總資產，現金佔比約為4.96%，顯示公司持有一定量的流動性資產。
*   **應收帳款 (AR) 與存貨 (Inventory) 的周轉情況**：
    *   **存貨周轉率 (Inventory Turnover)**：2021年為5.5倍，隨後逐年下降，2022年為5.0倍，2023年為4.0倍，2024年為3.9倍，2025年降至3.5倍。截至2026年9月30日的過去十二個月 (TTM) 存貨周轉率為0.85倍。存貨周轉率的持續下降，特別是2025年達到五年低點，可能暗示存貨堆積或銷售放緩的風險。
    *   **應收帳款周轉天數 (DSO)**：雖然沒有直接提供DSO，但營運現金流受到應收帳款壓力的影響。
整體而言，存貨周轉率的下降是一個值得關注的信號，可能反映市場需求疲軟或供應鏈管理效率下降。

**負債與償債能力**
*   **流動性**：
    *   **流動比率 (Current Ratio)**：截至2026年9月30日為1.57，與提供的基本數據一致。過去幾年，流動比率在2021年為1.56，2022年為1.16，2023年為1.35，2024年為1.51，2025年為1.37。目前的1.57顯示公司短期償債能力尚可，高於1.0的健康水平。
    *   **速動比率 (Quick Ratio)**：截至2026年9月30日為0.75，略低於提供的基本數據0.79。這表示公司在不依賴存貨的情況下，短期償債能力相對較弱，但對於製造業而言，0.75仍可接受，但需密切關注。
*   **長期風險**：
    *   **債務對權益比 (Debt/Equity)**：截至2026年9月30日為0.70 (或0.8237)。過去幾年，2021年為0.73，2022年為0.77，2023年為0.84，2024年為0.78，2025年為0.78。目前的債務權益比低於其十年平均0.95，顯示公司的財務槓桿有所改善，處於相對健康的水平。
    *   **長期債務對權益比 (LT Debt/Eq)**：提供的基本數據為0.71。
    *   **淨現金 (Net Cash) 狀況**：截至2026年9月30日，現金及約當現金為7.68億美元，總借款為52.18億美元。這意味著公司處於淨負債狀態，淨負債約為44.5億美元。
債務結構方面，公司在2026年第一季度發行了6億美元的4.5%票據，並償還了2027年到期的1.5億美元定期貸款。這表明公司正在積極管理債務期限結構。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
*   2025年，營運活動提供的現金流接近10億美元，而2024年約為13億美元。這顯示2025年營運現金流有所下降，主要由於現金收益減少。
*   截至2026年9月30日的第三季度，營運現金流為3.77億美元。
*   **盈餘品質**：2025年淨利潤為4.74億美元，而營運現金流為9.70億美元。營運現金流顯著高於淨利潤，這通常是一個積極信號，表明公司的盈餘質量較高，淨利潤有較好的現金支持。然而，2026年第三季度營運現金流為3.77億美元，而淨利潤為2.52億美元，營運現金流仍高於淨利潤，但差距縮小。

**自由現金流 (FCF)**
*   **計算並分析 FCF (OCF - CapEx)**：
    *   2025年，營運現金流為9.70億美元。雖然2025年的資本支出 (CapEx) 未直接提供，但2024年的資本支出為5.99億美元。如果假設2025年CapEx與2024年相近，那麼2025年的自由現金流約為9.70億美元 - 5.99億美元 = 3.71億美元。
    *   根據另一來源，2025年的自由現金流為4.24億美元。
*   公司在2025年產生了足夠的自由現金流，用於擴張、派息和回購。管理層預計2026年的資本支出約為4億美元。

**資本配置 (Capital Allocation)**
*   **資金主要投向**：
    *   **股息與回購**：2025年，公司通過股息和股票回購向股東返還了約5億美元。公司已連續16年提高股息。
    *   **資本支出**：2024年資本支出為5.99億美元，主要用於增長計劃和工廠現代化項目。2026年預計資本支出約為4億美元。
    *   **償債**：2026年第一季度償還了1.5億美元的定期貸款。
*   **資本配置效率**：公司致力於通過創新驅動的有機增長模式、差異化的循環經濟解決方案、強勁的自由現金流以及紀律和平衡的資本部署來創造價值。儘管營運環境充滿挑戰，公司仍能產生穩健的營運現金流並持續向股東返還資本，顯示其資本配置策略在維持股東回報方面具有一定效率。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：
    *   2021年為14.58%，2022年為14.44%，2023年為16.64%，2024年為15.96%，但在2025年大幅下降至7.99%。截至2026年第二季度，ROE為7.23%。
    *   **杜邦分析拆解 (利潤率 x 周轉率 x 財務槓桿)**：2025年ROE的顯著下降主要歸因於淨利潤率的下降（從2024年的9.7%降至5.4%），儘管資產周轉率和財務槓桿可能也有影響，但利潤率的壓力是主要因素。
*   **ROIC (投入資本回報率)**：
    *   2021年為9.92%，2022年為8.36%，2023年為8.40%，2024年為9.94%，但在2025年降至6.44%。截至2026年第二季度，ROIC為5.44%。
    *   截至2026年9月，EMN 的TTM ROIC為9.46%，而其加權平均資本成本 (WACC) 為7.22%。這表明公司目前產生的投資回報率高於其資本成本，正在創造超額收益。然而，ROIC在2025年和2026年第二季度呈現下降趨勢，需要關注其持續性。

**效率指標**
*   **資產周轉率 (Asset Turnover)**：2025年為0.59倍，2024年為0.62倍，2023年為0.63倍，2022年為0.72倍，2021年為0.68倍。資產周轉率在2025年有所下降，表明資產利用效率有所降低。
*   **存貨周轉天數 (DIO)**：2025年存貨周轉率為3.5倍，約為365 / 3.5 = 104天。這比2021年的約66天（365/5.5）有所增加，表明存貨持有時間變長，可能存在存貨管理效率下降或需求疲軟的問題。
*   **應收帳款周轉天數 (DSO)**：雖然沒有直接提供DSO，但營運現金流受到應收帳款壓力的影響。

    *   **存貨周轉天數 (Days Inventory Outstanding, DIO)**：密切關注存貨周轉效率，以評估市場需求和供應鏈管理的健康狀況，避免存貨堆積風險。
