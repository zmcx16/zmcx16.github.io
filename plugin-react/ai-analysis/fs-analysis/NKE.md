### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Nike在過去幾年的營收呈現波動。
*   2021財年營收為445.38億美元。
*   2022財年增長至467.10億美元。
*   2023財年進一步增長至512.17億美元，主要受NIKE Direct和批發業務的雙位數增長推動，其中NIKE Direct營收達213億美元，增長14%。
*   然而，最新的2026財年（截至2026年5月31日）全年營收為464億美元，與去年同期持平（按報告基準），按貨幣中性基準計算則下降2%。這顯示出營收成長動能面臨挑戰。
*   最新季度（2026財年第四季度）營收為110億美元，按報告基準下降1%，按貨幣中性基準下降4%。其中，批發營收增長4%至66億美元，而NIKE Direct營收下降7%至41億美元，主要由於NIKE品牌數位銷售下降12%和NIKE自有門店銷售下降7%。大中華區和EMEA地區的下降抵消了北美地區的增長。

整體而言，Nike的營收成長在2023財年達到高峰後，於2026財年呈現停滯甚至略微下滑的趨勢，主要受到NIKE Direct和Converse業務的疲軟，以及大中華區和EMEA地區的挑戰影響。

**獲利能力與利潤率**
*   **毛利率 (Gross Margin)**：
    *   2021財年：(199.62 / 445.38) = 44.82% (計算自)
    *   2022財年：(214.79 / 467.10) = 45.98% (計算自)
    *   2023財年：(222.92 / 512.17) = 43.52% (計算自)
    *   2026財年：42.9%。
    *   2026財年第四季度毛利率顯著增長890個基點至49.2%，主要得益於國際緊急經濟權力法案 (IEEPA) 關稅的預期回收約9億美元。
    *   然而，2026財年第三季度毛利率為40.2%，下降130個基點，主要由於北美地區關稅上漲。
    利潤率在2022財年達到高峰後有所下滑，2026財年全年毛利率為42.9%，略高於2023財年，但季度間波動較大，尤其受到一次性關稅回收的影響。

*   **營業利益率 (Operating Margin)**：
    *   2021財年營業費用：130.25億美元。營業利益：199.62 - 130.25 = 69.37億美元。營業利益率：(69.37 / 445.38) = 15.58%。
    *   2022財年營業費用：148.04億美元。營業利益：214.79 - 148.04 = 66.75億美元。營業利益率：(66.75 / 467.10) = 14.30%。
    *   2023財年營業費用：163.77億美元。營業利益：222.92 - 163.77 = 59.15億美元。營業利益率：(59.15 / 512.17) = 11.55%。
    *   2026財年全年銷售和管理費用為161億美元，與去年持平。營業利益：199.016 - 161 = 38.016億美元 (使用計算出的2026財年毛利)。營業利益率：(38.016 / 464) = 8.19%。
    *   2026財年第四季度營業利潤為13億美元。營業利益率：(1.3 / 11.0) = 11.82% (計算自)。
    *   2026財年第三季度EBIT利潤率為5.6%。
    營業利益率呈現下降趨勢，表明公司在控制營運成本方面面臨壓力，儘管2026財年第四季度因關稅回收而有所改善，但全年來看仍較低。

*   **純益率 (Net Margin)**：
    *   2021財年：(57.27 / 445.38) = 12.86% (計算自)
    *   2022財年：(60.46 / 467.10) = 12.94% (計算自)
    *   2023財年：(50.70 / 512.17) = 9.90% (計算自)
    *   2026財年：(3.1 / 46.4) = 6.68% (計算自)
    純益率在2023財年和2026財年持續下滑，顯示公司最終獲利能力受到侵蝕。

**費用控制**
*   **研發費用 (R&D) 與行銷費用 (S&A)**：
    *   Nike的「需求創造費用 (Demand creation expense)」可視為行銷費用，而「營運管理費用 (Operating overhead expense)」則包含研發及其他管理費用。
    *   2023財年，需求創造費用為40.60億美元，營運管理費用為123.17億美元，總銷售和管理費用為163.77億美元。
    *   2026財年全年銷售和管理費用為161億美元，與去年持平。
    *   2026財年第四季度銷售和管理費用為41億美元，下降2%。
    *   2026財年第三季度銷售和管理費用為40億美元，增長2%。
    雖然2026財年銷售和管理費用總額與去年持平，但營收的停滯導致費用佔比相對提高，對營業利益率造成壓力。公司正在進行成本重組，2026財年第三季度產生了2.3億美元的稅前遣散費，這表明公司正努力優化費用結構以應對挑戰。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
*   2026財年第四季度，營運活動產生的現金為4.3億美元。
*   2026財年全年營運活動產生的現金流包括約3億美元的IEEPA關稅回收。
*   2023財年，營運產生的現金用於股票回購、現金股利、資本支出和償還5億美元債務。
*   2024財年第三季度，營運產生的現金被股票回購、現金股利、資本支出和債券償還抵消。
營運現金流的具體數字在年度報告中未完全披露，但從描述來看，營運現金流足以支持部分資本配置活動。2026財年第四季度營運現金流為4.3億美元，相對於淨利潤11億美元，顯示盈餘品質可能存在一定程度的非現金項目影響。

**自由現金流 (FCF)**
*   **2026財年第四季度**：
    *   營業現金流：4.3億美元。
    *   資本支出 (CapEx)：1.46億美元。
    *   自由現金流 (FCF) = 4.3億美元 - 1.46億美元 = 2.84億美元。
*   **2026財年**：
    *   資本支出 (CapEx)：-4.3億美元。
    *   2025財年自由現金流為32.7億美元。
自由現金流在2026財年第四季度為正，但相對較低。2025財年自由現金流為32.7億美元，顯示公司有能力產生現金用於擴張和回報股東。

**資本配置 (Capital Allocation)**
*   **2026財年**：
    *   向股東返還約25億美元，包括24億美元的股利（增長5%）和1.23億美元的股票回購（回購180萬股）。
*   **2023財年**：
    *   向股東返還約75億美元，包括20億美元的股利（增長10%）和55億美元的股票回購（回購5000萬股）。
*   **2024財年第三季度**：
    *   向股東返還約14億美元，包括5.62億美元的股利（增長6%）和8.66億美元的股票回購（回購790萬股）。
Nike持續透過股利和股票回購向股東返還資本。然而，2026財年的股票回購金額顯著下降，表明公司可能在保留現金或面臨較大的營運挑戰。資本支出持續進行，但具體金額未在所有年份詳細披露。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：
    *   2026財年：淨利潤31億美元 / 股東權益148.6億美元 (計算得出) = 20.86%。
    *   2023財年：淨利潤50.70億美元 / 股東權益140.04億美元 = 36.20%。
    ROE從2023財年的高點顯著下降，表明公司為股東創造回報的能力有所減弱。
*   **ROA (資產報酬率)**：
    *   2026財年：淨利潤31億美元 / 總資產384.1億美元 = 8.07%。
    *   2023財年：淨利潤50.70億美元 / 總資產375.31億美元 = 13.51%。
    ROA同樣呈現下降趨勢，反映公司利用資產產生利潤的效率降低。
*   **ROIC (投入資本回報率)**：
    由於缺乏稅後淨營業利潤 (NOPAT) 和投入資本的詳細數據，無法精確計算ROIC。

**效率指標**
*   **資產周轉率 (Asset Turnover)**：
    *   2026財年：營收464億美元 / 總資產384.1億美元 = 1.21次。
    *   2023財年：營收512.17億美元 / 總資產375.31億美元 = 1.37次。
    資產周轉率有所下降，表明公司利用資產產生銷售的效率降低。
*   **存貨周轉天數 (DIO)**：
    *   2026財年銷貨成本：264.984億美元 (計算得出)。存貨：75億美元。
    *   存貨周轉率 = 264.984 / 75 = 3.53次。
    *   DIO = 365 / 3.53 = 103.4天。
    *   2023財年銷貨成本：289.25億美元。存貨：85億美元。
    *   存貨周轉率 = 289.25 / 85 = 3.40次。
    *   DIO = 365 / 3.40 = 107.4天。
    存貨周轉天數略有改善，顯示存貨管理效率有所提升。
