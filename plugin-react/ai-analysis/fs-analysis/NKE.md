作為一位資深美股分析師，我將針對Nike, Inc. (NKE) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。根據網路搜尋結果，Nike已於2026年6月30日發布了2026財年第四季度及全年財報（截至2026年5月31日），以及2026財年第三季度財報（截至2026年2月28日）。我將主要參考這些最新官方數據進行分析。

### 1. 損益表分析 (Income Statement Analysis)

-   **營收成長動能**
    Nike在2026財年面臨營收成長停滯的挑戰。2026財年全年營收為464億美元，與2025財年持平，若以不考慮匯率影響的基礎計算，則下降了2%。這表明公司在核心業務上存在壓力。
    從季度表現來看，2026財年第四季度營收為110億美元，較去年同期下降1%，以不考慮匯率影響的基礎計算則下降4%。第三季度營收為113億美元，與去年同期持平，以不考慮匯率影響的基礎計算則下降3%。
    營收結構方面，批發業務在2026財年第四季度增長4%（報告基礎）和1%（不考慮匯率影響），在第三季度增長5%（報告基礎）和1%（不考慮匯率影響），顯示批發渠道再次成為成長引擎。然而，NIKE Direct（直營）營收在第四季度下降7%（報告基礎）和9%（不考慮匯率影響），其中數位業務下降12%。Converse品牌表現尤其疲軟，2026財年全年營收下降31%，第四季度下降32%，第三季度更是下降35%。
    地區表現上，北美市場的成長部分抵消了大中華區和EMEA（歐洲、中東和非洲）地區的下滑。值得注意的是，大中華區營收在第三季度以不考慮匯率影響的基礎下降10%，管理層預計第四季度將下降20%，這對Nike而言是一個顯著的拖累。營收成長的停滯主要反映了銷量壓力及部分地區的疲軟，而非漲價或併購帶來的成長。

-   **獲利能力與利潤率**
    **毛利率 (Gross Margin)**：
    2026財年全年毛利率為42.9%，較去年同期增加20個基點。
    然而，季度表現波動較大。2026財年第四季度毛利率顯著提升890個基點至49.2%，主要得益於國際緊急經濟權力法案（IEEPA）關稅預期回收的利好影響。相比之下，第三季度毛利率則下降130個基點至40.2%，主要由於北美地區較高的關稅相關產品成本。這種波動性表明，儘管全年毛利率略有改善，但季度間的獲利能力仍受外部因素（如關稅）的顯著影響。
    **營業利益率 (Operating Margin)**：
    根據提供的基本面數據，Nike的營業利益率為8.77%。由於最新財報未直接提供營業利益率的詳細變化，我們將主要關注毛利率和淨利率的趨勢。
    **純益率 (Net Margin)**：
    2026財年全年淨利潤為31億美元，較2025財年下降3%。稀釋後每股盈餘（EPS）為2.10美元，亦下降3%。
    第四季度淨利潤為11億美元，同比大幅增長407%，其中包含與IEEPA關稅回收相關的0.52美元每股盈餘收益。若扣除此一次性收益，實際獲利能力增長幅度將大幅縮小。第三季度淨利潤為5億美元，同比下降35%，稀釋後每股盈餘為0.35美元，同樣下降35%。
    利潤率的波動和全年淨利潤的下降表明，Nike的獲利能力面臨壓力，且規模經濟效應並未完全顯現，成本壓力（如關稅）和營收停滯對利潤產生負面影響。

-   **費用控制**
    **銷售與管理費用 (Selling and Administrative Expense, S&A)**：
    2026財年全年S&A費用為161億美元，與去年持平。
    第四季度S&A費用下降2%至41億美元。然而，第三季度S&A費用則增長2%至40億美元，主要由於員工遣散費和不利的匯率變動，部分被品牌行銷費用下降所抵消。
    **研發費用 (R&D)**：
    財報摘要中未明確提及研發費用的具體佔比或變化，但S&A費用中包含行銷費用。需求創造費用（Demand creation expense，屬於S&A的一部分）在第三季度持平。營運管理費用（Operating overhead expense）在第三季度增長3%。
    整體而言，S&A費用在營收停滯的情況下保持相對穩定，顯示公司在費用控制方面有所努力，但部分費用（如遣散費）的增加也反映了公司在營運調整中的成本。

### 2. 資產負債表分析 (Balance Sheet Analysis)

-   **資產品質與結構**
    **現金與短期投資**：
    截至2026財年結束，現金及約當現金和短期投資為90億美元，較去年減少約1億美元。截至2026財年第三季度末（2月28日），現金及約當現金和短期投資為81億美元，較去年減少約23億美元。現金餘額的下降表明公司在營運、投資和融資活動中消耗了部分現金。
    **應收帳款 (Accounts Receivable, AR)**：
    2026財年應收帳款從2025財年的47億美元躍升至59億美元。此增長部分歸因於IEEPA關稅的預期回收，以及批發營收增加和付款時間的影響。
    **存貨 (Inventory)**：
    2026財年存貨為75億美元，與去年持平，主要反映了單位數量的增加被產品組合轉變所抵消。2026財年第三季度存貨為75億美元，下降1%，主要反映了單位數量的減少和產品組合轉變，部分被北美地區較高關稅導致的產品成本增加所抵消。儘管存貨總額保持穩定，但應收帳款的顯著增加和存貨成本的上升（受關稅影響）值得關注。
    **存貨堆積或應收帳款回收過慢的風險**：
    應收帳款周轉天數 (DSO) 在2026財年達到47天，遠高於歷史平均的36天。這是一個明確的風險信號，表明公司在應收帳款回收方面可能面臨挑戰，或者客戶付款週期延長，這會影響公司的營運現金流。

-   **負債與償債能力**
    **流動性**：
    根據提供的基本面數據，流動比率 (Current Ratio) 為1.96，速動比率 (Quick Ratio) 為1.36。這些比率顯示Nike擁有健康的短期償債能力，能夠應對短期債務。
    **長期風險**：

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (Operating Cash Flow, OCF)**
    2026財年，營運活動產生的現金流中包含約3億美元的IEEPA關稅回收款。這筆一次性收益對當期營業現金流有正面影響。
    然而，2026財年第三季度，營運產生的現金流被現金股利、債券償還、資本支出和股份回購等現金流出所抵消，甚至超過了營運現金流入。這表明在某些季度，公司的核心營運活動產生的現金可能不足以覆蓋其所有的現金需求。
    **盈餘品質**：
    2026財年淨利潤為31億美元，而營業現金流中包含一次性關稅回收款。若扣除此一次性因素，營業現金流的品質可能不如表面所示。第三季度營業現金流未能完全覆蓋其他現金流出，也暗示了盈餘品質可能存在一定壓力，即淨利潤的產生可能部分依賴非現金項目或一次性收益。應收帳款的顯著增加也可能導致部分利潤未能及時轉化為現金。

-   **自由現金流 (Free Cash Flow, FCF)**
    雖然沒有直接提供FCF的具體數值，但從2026財年第三季度「營運產生的現金被現金股利、債券償還、資本支出和股份回購所抵消」的描述來看，該季度的自由現金流可能受到擠壓，甚至可能為負。這意味著公司可能沒有足夠的內部現金流來同時支持擴張、派息和回購，可能需要動用現金儲備或增加借款。

-   **資本配置 (Capital Allocation)**
    2026財年，Nike向股東返還了約25億美元，其中包括24億美元的股息（增長5%）和1.23億美元的股份回購（回購180萬股）。這表明公司持續重視股東回報。
    資本支出是現金流出的一部分。
    2026財年投入資本回報率 (ROIC) 為18.7%，低於2025財年的20.2%。這表明公司在資本配置方面的效率略有下降，投資資本產生利潤的能力有所減弱。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

-   **回報率指標**
    **ROE (股東權益報酬率)**：
    根據提供的基本面數據，ROE為22.14%。
    我們嘗試進行杜邦分析拆解（使用2026財年數據）：
    *   淨利潤率 (Net Profit Margin) = 淨利潤 / 營收 = 31億美元 / 464億美元 = 6.68%
    *   資產周轉率 (Asset Turnover) = 營收 / 總資產 = 464億美元 / 384億美元 = 1.21次
    *   權益乘數 (Equity Multiplier) = 總資產 / 股東權益。由於沒有直接提供股東權益，但已知總資產為384億美元，且負債與股東權益總額相同。根據Debt/Eq為0.74，我們可以估算權益乘數。若Debt/Eq = 0.74，則Equity = Assets / (1 + Debt/Eq) = 38.4 / (1+0.74) = 22.07億美元 (估算)。權益乘數 = 38.4 / 22.07 = 1.74。
    *   ROE = 淨利潤率 x 資產周轉率 x 權益乘數 = 6.68% x 1.21 x 1.74 ≈ 14.05%。
    此計算結果（14.05%）與提供的基本面數據（22.14%）存在差異，這可能是由於數據來源的時間點不同，或基本面數據中的ROE是基於不同的計算期間。但從拆解來看，Nike的淨利潤率和資產周轉率均面臨壓力，這將直接影響ROE的表現。
    **ROIC (投入資本回報率)**：
    2026財年ROIC為18.7%，低於2025財年的20.2%。雖然18.7%仍是一個相對健康的水平，但下降趨勢表明公司投資資本的效益正在減弱。

-   **效率指標**
    **資產周轉率**：
    如上所述，2026財年資產周轉率約為1.21次，顯示資產利用效率一般，且在營收停滯下難以提升。
    **存貨周轉天數 (DIO)**：
    2026財年存貨為75億美元，銷貨成本未直接提供，但營收為464億美元。若以毛利率42.9%估算銷貨成本為464億 * (1-0.429) = 265億美元。DIO = (存貨 / 銷貨成本) * 365天 = (75億 / 265億) * 365 ≈ 103天。存貨周轉天數較長，可能存在存貨管理效率提升的空間。
    **應收帳款周轉天數 (DSO)**：
    2026財年DSO為47天，顯著高於歷史平均的36天。這是一個重要的警示信號，表明應收帳款回收效率下降，可能影響現金流。
