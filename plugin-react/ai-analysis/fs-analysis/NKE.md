### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    Nike在2026財年實現了464億美元的營收，與去年同期持平，若以匯率中性計算則下降了2%。這顯示公司在最新財年的營收成長面臨停滯甚至輕微下滑的壓力。在2026財年第四季度，營收為110億美元，較去年同期下降1%，以匯率中性計算則下降4%。這一下滑主要由於大中華區和EMEA（歐洲、中東和非洲）地區的下降，部分被北美地區的增長所抵消。這表明Nike的營收成長動能目前較為疲軟，且區域市場表現不一。

*   **獲利能力與利潤率**
    Nike在2026財年的毛利率為42.9%，較去年同期增加了20個基點。這顯示公司在成本控制或定價策略上有所改善。然而，其營業利益（Operating Income）為41.8億美元，淨利潤（Net Income）為31.1億美元，較去年同期下降3%。這導致淨利率約為6.7% (3.11B / 46.4B)。儘管毛利率有所提升，但淨利潤的下降表明營業費用或稅務因素可能對最終獲利產生了負面影響。目前來看，利潤率的擴張能力受到挑戰，規模經濟效應可能未能完全轉化為淨利潤的增長。

*   **費用控制**
    2026財年的銷售和管理費用（Selling and Administrative Expense）為161億美元，與去年同期持平。考慮到營收的停滯，這意味著銷售和管理費用佔營收的比例有所上升，可能對營業利益率造成壓力。雖然具體的研發費用數據未直接提供，但行銷費用作為S&A的一部分，其佔比持平可能反映了公司在市場推廣上的持續投入，以應對競爭並維持品牌影響力。然而，在營收不增長的情況下，費用控制的效率需要進一步審視。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**
    截至2026年5月31日，Nike的現金及約當現金和短期投資約為90億美元，較去年減少約1億美元。這顯示公司擁有充足的流動性。存貨（Inventories）為75億美元，與去年同期持平。儘管營收停滯，存貨水平保持穩定，這可能表明公司在供應鏈管理和庫存去化方面做得不錯，沒有出現明顯的存貨堆積風險。應收帳款周轉天數（DSO）和存貨周轉天數（DIO）等效率指標將在後續章節進一步分析。

*   **負債與償債能力**
    *   **流動性**：根據提供的基本面數據，Nike的流動比率（Current Ratio）為1.96，速動比率（Quick Ratio）為1.36。這些比率均高於1，表明公司擁有良好的短期償債能力，能夠應對短期債務。
    *   **長期風險**：Nike的總債務為110.4億美元，現金為90.3億美元，淨現金狀況為負20.2億美元。債務對權益比（Debt/Equity）為0.74，長期債務對權益比（LT Debt/Eq）為0.58。這些比率顯示Nike的債務水平處於可控範圍，儘管存在淨負債，但相對於其股東權益而言，槓桿水平並不過高，長期償債風險相對穩定。
    *   **淨現金狀況**：公司擁有90.3億美元的現金，但總債務為110.4億美元，因此淨負債為20.2億美元。這表示公司需要依賴未來的現金流來償還部分債務，而非完全由現有現金覆蓋。

*   **無形資產與商譽**
    本次分析未直接獲得Nike無形資產和商譽的具體數據。然而，對於品牌型公司而言，品牌價值是其核心無形資產。若無形資產佔總資產比重過高，且其價值未能持續創造經濟效益，則可能存在減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**
    Nike在過去12個月（TTM）的營業現金流（Operating Cash Flow）為28.7億美元。同期淨利潤為31.1億美元。營業現金流略低於淨利潤，這可能暗示盈餘品質存在輕微的非現金項目影響，例如折舊攤銷較高或營運資本變動（如應收帳款增加或應付帳款減少）導致現金流出。然而，兩者差距不大，表明其核心營運仍能產生穩定的現金流。

*   **自由現金流 (FCF)**
    Nike在過去12個月的資本支出（Capital Expenditures）為-6.84億美元。因此，自由現金流（FCF）計算為營業現金流減去資本支出，即28.7億美元 - 6.84億美元 = 21.86億美元。公司擁有足夠的自由現金流用於擴張、派息或回購。

*   **資本配置 (Capital Allocation)**
    在2026財年，Nike向股東返還了約25億美元，其中包括24億美元的股息（增長5%）和1.23億美元的股票回購（回購180萬股）。這表明公司在資本配置上傾向於通過股息回報股東，同時也進行了小規模的股票回購。自由現金流足以覆蓋這些股東回報，顯示其資本配置策略是可持續的。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**
    *   **ROE (股東權益報酬率)**：Nike的股東權益報酬率（ROE）為22.14%。
        杜邦分析拆解：
        *   淨利率 (Net Profit Margin) = 淨利潤 / 營收 = 3.11B / 46.4B = 6.7%
        *   資產周轉率 (Asset Turnover) = 營收 / 總資產 = 1.24
        *   權益乘數 (Equity Multiplier) = 總資產 / 股東權益 = (總資產 / 營收) * (營收 / 淨利潤) * (淨利潤 / 股東權益) = (1 / Asset Turnover) * (1 / Net Profit Margin) * ROE = (1/1.24) * (1/0.067) * 0.2214 ≈ 2.63 (此為推算值，實際需從財報獲取總資產和股東權益)
        高ROE主要得益於其穩定的淨利率和較高的資產周轉率，同時適度的財務槓桿也起到了一定作用。
    *   **ROIC (投入資本回報率)**：Nike的投入資本回報率（ROIC）為19.55%。公司的加權平均資本成本（WACC）約為7.91%。由於ROIC (19.55%) 顯著高於WACC (7.91%)，這表明Nike的投資資本效益非常高，公司能夠有效地利用其資本創造價值。

*   **效率指標**
    *   **資產周轉率 (Asset Turnover)**：1.24。這表示每1美元的資產能產生1.24美元的營收，效率良好。
    *   **存貨周轉率 (Inventory Turnover)**：3.51。這意味著公司每年存貨周轉3.51次，相對較慢，可能反映了時尚產業的特性或對未來銷售的預期。
    *   **應收帳款周轉天數 (DSO)**：未直接提供，但通常與營收和應收帳款水平相關。若營收停滯而應收帳款增加，則DSO可能惡化。
