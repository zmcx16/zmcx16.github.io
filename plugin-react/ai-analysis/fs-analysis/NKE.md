作為資深美股分析師，我將對Nike (NKE) 的財務狀況進行全面拆解。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**：
    Nike的營收成長動能近年來顯著放緩。從過去3-5年來看，公司營收在2024財年達到513.62億美元的峰值後，於2025財年下滑至463.09億美元，並在2026財年微幅回升至463.98億美元，五年複合年增長率幾乎持平，為-0.17%。若觀察近三年，營收甚至呈現負成長，複合年增長率為-3.24%。
    最新季度（2027財年第一季度，截至2026年8月31日）營收為112億美元，較去年同期下降4%（按報告基準），若排除匯率影響則下降5%。營收下滑主要受大中華區和歐洲、中東及非洲地區（EMEA）的下降影響，儘管北美地區有所增長。Nike Direct（直營）營收下降8%，而批發營收僅下降1%，顯示直營渠道面臨較大壓力。管理層預計2027財年全年營收將出現高個位數百分比的下降。

*   **獲利能力與利潤率**：
    Nike的獲利能力和利潤率呈現明顯的下降趨勢。
    *   **毛利率 (Gross Margin)**：2027財年第一季度為42.8%，較去年同期增長60個基點，主要得益於倉儲和物流成本的降低。然而，從年度趨勢來看，毛利率從2022財年的45.98%下降至2025財年的42.73%，2026財年略微回升至42.9%。儘管最新季度有所改善，但整體仍低於歷史平均水平。
    *   **營業利益率 (Operating Margin)**：此指標的惡化更為顯著。2027財年第一季度為7.69%。2026財年為8.18%，遠低於2022財年的14.29%。營業利益率的持續壓縮反映了營收增長停滯以及費用控制的挑戰。
    *   **純益率 (Net Margin)**：2027財年第一季度淨利潤7.12億美元，營收112.13億美元，計算得出純益率約為6.35%。2026財年淨利潤31億美元，營收464億美元，純益率約為6.68%。這與其歷史上9%至12%的水平相比，有顯著下降。
    *   **規模經濟**：利潤率的下降表明公司在當前環境下未能有效實現規模經濟效益，反而面臨成本上升和定價能力受限的壓力。

*   **費用控制**：
    銷售與管理費用（SG&A）在2027財年第一季度下降3%至39億美元。2026財年該費用與前一年持平，約為161億美元。公司已啟動名為「PACE」的營運重組計劃，預計到2031財年將實現25億美元的累計成本節約，但同時也將產生約10億美元的稅前費用。這表明公司正積極應對費用壓力，但短期內重組成本將對盈利造成影響。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**：
    *   **現金與短期投資佔比**：截至2026年8月31日，Nike持有83.7億美元的現金及等價物。
    *   **應收帳款 (AR) 周轉情況**：截至2026年8月31日的最近十二個月應收帳款周轉率為8.0倍。2026財年為7.82倍。應收帳款平均收回天數從2023年的29天延長至2026年的47天，這表明公司收回客戶款項的速度變慢，可能影響短期現金流。
    *   **存貨 (Inventory) 周轉情況**：截至2026年8月31日的最近十二個月存貨周轉率為3.27倍。2026財年為3.5倍。存貨平均處理天數在2027財年第一季度增加到107天，高於2026財年第四季度的106天。儘管2026財年存貨總額為75億美元，與前一年持平，但單位數量有所增加，被產品組合變化抵消。
    *   **存貨堆積或應收帳款回收過慢的風險**：應收帳款回收速度放緩及存貨周轉天數增加，均指向潛在的存貨積壓和現金回收效率下降風險，這可能對公司的營運資金管理構成挑戰。

*   **負債與償債能力**：
    *   **流動性**：
        *   **流動比率 (Current Ratio)**：2027財年第一季度為2.07。2026財年為1.96。該比率從2021年和2023年的2.72持續下降。儘管仍高於1，但下降趨勢值得關注。
        *   **速動比率 (Quick Ratio)**：2027財年第一季度為1.39。2026財年為1.19。該比率從2021年的1.85持續下降。雖然仍高於1，表明公司無需依賴存貨即可償還短期債務，但安全邊際正在縮小。
    *   **長期風險**：
        *   **債務對權益比 (Debt/Equity)**：截至2026年8月31日為0.39。2026財年為0.73。該比率低於其10年平均水平（0.52或0.82），顯示公司的財務槓桿相對較低，長期償債風險尚在可控範圍。
        *   **債務結構**：截至2026年8月31日，總債務為110.7億美元。
    *   **淨現金 (Net Cash) 狀況**：截至2026年8月31日，Nike的現金及等價物為83.7億美元，而總債務為110.7億美元，導致淨負債9.9億美元，從淨現金轉為輕微淨負債狀態。

*   **無形資產與商譽**：
    本次搜尋結果未提供具體的無形資產與商譽數據，因此無法評估其是否存在過高或減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**：
    Nike的營業現金流狀況令人擔憂。2027財年第一季度營業現金流僅為1.35億美元，遠低於去年同期的2.22億美元。截至2026年8月31日的最近十二個月，營業現金流為50.35億美元，同比大幅下降41.44%。2026財年全年營業現金流為28.68億美元，較2025財年下降22.44%，而2025財年已較2024財年下降50.22%。
    *   **盈餘品質**：2026財年淨利潤為31億美元，而營業現金流為28.68億美元。營業現金流略低於淨利潤，且長期呈現大幅下滑趨勢，這表明公司的盈餘質量可能存在隱憂，淨利潤的實現可能更多依賴非現金項目或營運資金的變動。

*   **自由現金流 (FCF)**：
    截至2026年8月31日的最近十二個月自由現金流為21.1億美元（扣除資本支出6.76億美元後）。2026財年自由現金流為22億美元（扣除資本支出6.86億美元後）。然而，2026財年的自由現金流不足以覆蓋當年的股息支付（24億美元）。
    *   **公司是否有足夠的現金用於擴張、派息或回購？** 鑑於2026財年自由現金流未能覆蓋股息，這表明公司在現金產生方面面臨壓力，可能需要動用儲備或舉債來維持股息支付，這限制了其用於擴張或股票回購的靈活性。

*   **資本配置 (Capital Allocation)**：
    過去幾年，Nike的資金主要用於派發股息。2026財年，公司派發了24億美元的股息，並回購了1.23億美元的股票。
    *   **資本配置的效率**：由於自由現金流不足以覆蓋股息，這暗示了在當前營運環境下，公司的資本配置效率可能受到影響，尤其是在維持股息政策方面。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**：
    *   **ROE (股東權益報酬率)**：截至2026年8月31日的最近十二個月ROE為21.56%。
        *   **杜邦拆解 (基於截至2026年8月31日的最近十二個月數據)**：
            *   淨利潤率 (Net Profit Margin) = 淨利潤 / 營收 = 30.9億美元 / 458.9億美元 = 6.73%
            *   資產周轉率 (Asset Turnover) = 營收 / 總資產 = 458.9億美元 / (30.9億美元 / 0.0823) = 1.22 (總資產由ROA計算得出，ROA為8.23%)
            *   權益乘數 (Equity Multiplier) = 總資產 / 股東權益 = (30.9億美元 / 0.0823) / 152.2億美元 = 2.47 (股東權益為152.2億美元)
            *   ROE = 淨利潤率 × 資產周轉率 × 權益乘數 = 0.0673 × 1.22 × 2.47 ≈ 0.2028 (20.28%)。此計算結果與直接報告的21.56%接近，差異可能來自於數據取樣或計算方式的細微不同。從杜邦分析來看，Nike的ROE主要受較高的權益乘數（財務槓桿）和尚可的資產周轉率支撐，但淨利潤率的下降是主要拖累。
    *   **ROIC (投入資本回報率)**：截至2026年8月31日的最近十二個月ROIC為11.53%。若ROIC能持續高於其加權平均資本成本（WACC），則表示公司仍在創造價值。然而，鑑於盈利能力和現金流的惡化，ROIC的未來趨勢值得密切關注。

*   **效率指標**：
    *   **資產周轉率 (Asset Turnover)**：如上述杜邦分析所示，最近十二個月為1.22。
    *   **存貨周轉天數 (DIO)**：2027財年第一季度為107天。
    *   **應收帳款周轉天數 (DSO)**：2026財年為47天。
    這些效率指標的惡化，反映了公司在營運資產管理方面的效率正在下降。

**最終結論：**
1.  **整體評級**：存在隱憂
2.  **核心摘要**：Nike的財務健康狀況目前存在顯著隱憂。營收成長停滯，獲利能力指標全面下滑，尤其營業利益率大幅壓縮。營運現金流急劇惡化，導致自由現金流不足以覆蓋股息支付，顯示其核心業務的現金產生能力面臨嚴峻挑戰。存貨與應收帳款周轉效率降低，進一步加劇了流動性壓力。儘管償債能力目前尚可，但持續惡化的現金流和盈利趨勢，以及下調的財測，預示未來風險升高。
3.  **關鍵監測指標**：
    *   **Free Cash Flow Margin (自由現金流利潤率)**：衡量公司將營收轉化為自由現金流的能力，鑑於目前FCF不足以支付股息，此指標至關重要。
    *   **Inventory Turnover (存貨周轉率)**：監測存貨管理效率，避免存貨積壓導致的減值風險和現金流壓力。
    *   **Operating Margin (營業利益率)**：反映核心業務的盈利能力和費用控制效率，其持續改善是公司轉型的關鍵信號。
