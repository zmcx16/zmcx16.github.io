作為一位資深美股分析師，我將針對Nike, Inc. (NKE) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。根據網路搜尋結果，我將主要參考Nike於2026年6月30日發布的2026財年第四季度及全年財報（截至2026年5月31日），以及2026年7月15日提交的2026財年10-K報告摘要。

---

### 1. 損益表分析 (Income Statement Analysis)

-   **營收成長動能**：
    Nike在2026財年全年營收為464億美元，按報告基準持平，按匯率中性基準則下降2%。這顯示公司面臨營收成長停滯的挑戰。其中，NIKE品牌營收為452億美元，按報告基準增長1%，按匯率中性基準下降1%，主要由於大中華區和EMEA地區的下滑，部分被北美地區的增長所抵消。
    從渠道來看，2026財年批發業務營收增長6%至275億美元，而NIKE Direct營收則下降6%至177億美元，主要由於NIKE品牌數位業務下降12%和NIKE自有門店下降4%。Converse品牌營收大幅下降31%至12億美元，反映了所有地區的普遍疲軟。
    最新季度（2026財年第四季度）營收為110億美元，按報告基準下降1%，按匯率中性基準下降4%。這表明公司在短期內仍面臨「營收逆風」且「銷售去化仍具挑戰」。營收停滯主要來自於銷量下滑和部分地區的疲軟，而非漲價或併購帶來的顯著增長。

-   **獲利能力與利潤率**：
    2026財年全年毛利率為42.9%，較去年同期增長20個基點。這主要得益於倉儲和物流成本的降低以及有利的匯率影響，但部分被較高的產品成本所抵消。
    值得注意的是，2026財年第四季度毛利率大幅增長890個基點至49.2%，其中約900個基點的增益來自於國際緊急經濟權力法案（IEEPA）關稅的預期回收。若排除此一次性因素，毛利率實際上可能有所承壓。
    2026財年營業利益為38億美元，同比增長2.6%，營業利益率為8.2%。淨利潤為31億美元，同比下降3%，淨利率約為6.68%（31億美元 / 464億美元）。
    利潤率的變化顯示，在排除一次性關稅回收的影響後，公司的獲利能力面臨挑戰，尤其是在營收停滯的情況下。雖然全年毛利率略有提升，但營業利益率和淨利率的表現顯示公司在控制成本和費用方面仍需努力，規模經濟效應在營收停滯下未能充分體現。

-   **費用控制**：
    2026財年全年銷售及管理費用（Selling and administrative expense）為161億美元，與去年持平。這表明公司在營收持平的情況下，有效控制了整體費用支出。
    在2026財年第三季度，需求創造費用（Demand creation expense）為11億美元，與去年持平，儘管體育行銷費用增加和匯率不利，但被品牌行銷費用的降低所抵消。營運管理費用（Operating overhead expense）增長3%至29億美元，主要由於員工遣散費和不利匯率變動，部分被其他行政成本降低所抵消。
    公司在2026財年進行了組織重組，產生了3.85億美元的員工遣散費。這些費用控制措施與公司在營收承壓下提升效率的策略相符，顯示管理層正積極應對挑戰。

### 2. 資產負債表分析 (Balance Sheet Analysis)

-   **資產品質與結構**：
    截至2026年5月31日，Nike的現金及約當現金和短期投資為90億美元，較去年約下降1億美元。這顯示公司仍保有充足的流動性。
    存貨為75億美元，與去年持平。儘管存貨總額持平，但報告指出這反映了單位數量的增加，被產品組合的轉變所抵消。在營收停滯的背景下，存貨持平可能暗示存貨周轉效率的壓力，需要密切關注未來季度存貨水平是否會因銷售去化挑戰而堆積。
    應收帳款（Accounts Receivable）在2026財年末達到59.3億美元，較去年同期47.2億美元增長25.7%，而營收卻持平。應收帳款的顯著增長可能暗示公司在收款方面面臨壓力，或為了刺激銷售而放寬了信用條款，這增加了應收帳款回收過慢的風險，並影響了營運現金流。

-   **負債與償債能力**：
    **流動性**：根據提供的數據，流動比率（Current Ratio）為1.96，速動比率（Quick Ratio）為1.36。這些比率顯示Nike的短期償債能力處於健康水平，能夠應對短期債務。
    **長期風險**：債務對權益比（Debt/Equity）為0.74，長期債務對權益比（LT Debt/Eq）為0.58。截至2026財年末，長期債務為59.4億美元，較去年同期的79.6億美元有所下降。股東權益增長12.5%至148.7億美元。這表明公司的債務結構有所改善，長期償債風險降低，財務槓桿處於合理範圍。
    **淨現金狀況**：公司擁有90億美元的現金及短期投資，顯示其淨現金狀況良好，具備一定的財務彈性。

-   **無形資產與商譽**：
    本次搜尋結果未提供具體的無形資產與商譽數據。在缺乏詳細數據的情況下，無法評估商譽是否過高或存在減損風險。然而，作為一個品牌驅動型公司，Nike的品牌價值是其核心無形資產。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**：
    2026財年營運現金流（Operating Cash Flow, OCF）為28.7億美元，同比大幅下降22.4%。而同期淨利潤僅下降3%至31億美元。
    **盈餘品質**：OCF長期低於淨利潤，且在2026財年OCF僅為淨利潤的92%，這是值得關注的盈餘品質問題。主要原因在於應收帳款的大幅增加（12.1億美元），這意味著雖然公司在損益表上確認了收入和利潤，但實際收到的現金卻減少了，顯示現金轉換效率下降。

-   **自由現金流 (FCF)**：
    2026財年資本支出（Capital Expenditures, CapEx）為6.84億美元，同比增長59.1%。
    自由現金流（FCF = OCF - CapEx）為21.8億美元，同比大幅下降33.2%。FCF的顯著下降表明公司用於擴張、派息或回購的現金能力受到壓力。

-   **資本配置 (Capital Allocation)**：
    2026財年，公司向股東支付了24.1億美元的股息，同比增長5%。然而，股票回購金額大幅減少至1.23億美元（回購180萬股），較去年同期下降95%。
    儘管自由現金流大幅下降，但股息支付卻有所增加，這導致2026財年股息支付（24.1億美元）甚至超過了自由現金流（21.8億美元）。這表明公司的資本配置策略可能面臨挑戰，在營運現金流和自由現金流承壓的情況下，維持高額股息支付可能會限制公司未來的投資彈性或導致槓桿率上升。資本配置效率在當前環境下顯得不佳。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

-   **回報率指標**：
    **ROE (股東權益報酬率)**：根據提供的數據，NKE的ROE為22.14%。
    杜邦分析拆解ROE (淨利率 x 資產周轉率 x 財務槓桿)：
    *   淨利率 (Net Profit Margin)：6.68% (FY2026)
    *   資產周轉率 (Asset Turnover)：由於缺乏2026財年總資產的確切數字，我們使用2026財年營收464億美元和2026年Q3總資產384.1億美元作為近似值進行估算，資產周轉率約為1.21次 (464億美元 / 384.1億美元)。
    *   財務槓桿 (Equity Multiplier = Total Assets / Equity)：使用2026年Q3總資產384.1億美元和2026財年末股東權益148.7億美元，財務槓桿約為2.58倍 (384.1億美元 / 148.7億美元)。
    *   估算ROE = 6.68% x 1.21 x 2.58 ≈ 20.8%。這與提供的22.14%接近，表明其ROE主要來自於健康的淨利率和適度的財務槓桿，但資產周轉率在營收停滯下可能面臨壓力。
    **ROIC (投入資本回報率)**：2026財年ROIC為18.7%，較去年同期的20.2%有所下降。雖然18.7%仍是一個不錯的回報率，但下降趨勢值得關注。公司投資資本的效益有所減弱，需要評估其是否仍顯著超過其加權平均資本成本（WACC）。

-   **效率指標**：
    **資產周轉率**：如上所述，估算約為1.21次。在營收持平的情況下，資產周轉率的提升空間有限。
    **存貨周轉天數 (DIO)**：存貨為75億美元，2026財年銷貨成本（COGS）未直接提供，但毛利率為42.9%，則COGS約為464億美元 * (1 - 0.429) = 265.9億美元。存貨周轉率 = COGS / 存貨 = 265.9億美元 / 75億美元 ≈ 3.55次。DIO = 365 / 3.55 ≈ 102.8天。存貨周轉天數較長，且存貨金額持平於去年，在銷售去化挑戰下，可能存在存貨管理效率下降的風險。
    **應收帳款周轉天數 (DSO)**：應收帳款為59.3億美元，營收為464億美元。應收帳款周轉率 = 營收 / 應收帳款 = 464億美元 / 59.3億美元 ≈ 7.82次。DSO = 365 / 7.82 ≈ 46.7天。應收帳款周轉天數的增加（應收帳款增長25.7%而營收持平）表明公司在應收帳款回收方面效率下降，這直接影響了營運現金流。
