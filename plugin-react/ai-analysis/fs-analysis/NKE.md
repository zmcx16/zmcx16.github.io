# Nike, Inc. (NKE) 財務狀況全面拆解與健康評等

作為一位資深美股分析師，我將針對運動服飾巨頭 Nike, Inc. (NKE) 的財務報表進行全面深入分析，涵蓋損益表、資產負債表、現金流量表及核心財務指標，以揭示其財務真實狀況、獲利能力及潛在風險，並最終給出具體的財務健康評等。本次分析將主要依據公司最新的財報數據，包括截至2026年5月31日的財年報告（FY2026）及過往年度數據。

---

### 1. 損益表分析 (Income Statement Analysis)

#### 營收成長動能
Nike的營收在過去幾年呈現波動。FY2023營收為512.17億美元，FY2024微幅增長至513.62億美元，但FY2025則顯著下滑10%至463.09億美元。FY2026營收大致持平於464.00億美元，僅微增0.2%。從貨幣中性角度看，FY2026全年營收下降2%。

最新季度（FY2026 Q4）營收為110億美元，較去年同期下降1%。其中，NIKE Direct營收下降7%，主要受NIKE Brand Digital下降12%及NIKE自有門市下降7%影響。批發業務則逆勢增長4%。這表明公司在數位直營渠道面臨挑戰，而批發渠道表現相對穩健。營收下滑主要歸因於促銷活動增加、渠道組合變化以及部分經典鞋款銷售下降。

#### 獲利能力與利潤率
*   **毛利率 (Gross Margin)**：
    *   FY2024: 44.6% (228.87億美元毛利 / 513.62億美元營收)
    *   FY2025: 42.7% (197.90億美元毛利 / 463.09億美元營收)
    *   FY2026: 42.9% (199.10億美元毛利 / 464.00億美元營收)
    毛利率在FY2025出現明顯下滑，主要由於折扣增加和渠道組合變化。FY2026略有回升20個基點至42.9%，但仍低於FY2024水平。最新Q4 FY2026毛利率大幅提升890個基點至49.2%，主要得益於國際緊急經濟權力法案 (IEEPA) 關稅的預期回收。

*   **營業利益率 (Operating Margin)**：
    *   FY2024: 12.3% (63.11億美元營業利益 / 513.62億美元營收)
    *   FY2025: 8.0% (37.02億美元營業利益 / 463.09億美元營收)
    *   FY2026: 8.2% (38.00億美元營業利益 / 464.00億美元營收)
    營業利益率在FY2025大幅收縮，FY2026略有改善，但仍遠低於FY2024水平，顯示公司在營收下滑的同時，成本控制壓力較大。

*   **純益率 (Net Margin)**：
    *   FY2024: 11.1% (57.00億美元淨利 / 513.62億美元營收)
    *   FY2025: 7.0% (32.19億美元淨利 / 463.09億美元營收)
    *   FY2026: 6.7% (31.08億美元淨利 / 464.00億美元營收)
    純益率呈現逐年下滑趨勢，FY2026淨利下降3%至31.08億美元。這表明公司在營收增長停滯和毛利率承壓的背景下，整體獲利能力受到侵蝕。

#### 費用控制
*   **銷售與管理費用 (Selling and Administrative Expense, S&A)**：
    *   FY2024: 165.76億美元
    *   FY2025: 160.88億美元
    *   FY2026: 161.10億美元
    S&A費用在FY2025有所下降，FY2026則大致持平。FY2026 S&A費用佔營收的比例約為34.7% (161.10億美元 / 464.00億美元)，相較於FY2024的32.3% (165.76億美元 / 513.62億美元) 有所上升，顯示在營收停滯的情況下，費用佔比壓力增加。公司在FY2026的營運改善主要來自於成本紀律而非需求增長。

### 2. 資產負債表分析 (Balance Sheet Analysis)

#### 資產品質與結構
*   **現金與短期投資**：
    *   FY2024: 115.82億美元 (現金98.60億美元 + 短期投資17.22億美元)
    *   FY2025: 91.51億美元 (現金74.64億美元 + 短期投資16.87億美元)
    *   FY2026: 90.27億美元 (現金75.63億美元 + 短期投資14.64億美元)
    現金及短期投資在FY2025和FY2026呈現下降趨勢，反映公司現金流壓力增加或資本配置策略的調整。

*   **應收帳款 (Accounts Receivable, AR)**：
    *   FY2024: 44.27億美元
    *   FY2025: 47.17億美元
    *   FY22026: 59.31億美元
    應收帳款在FY2026大幅增長25.7%至59.31億美元，而同期營收僅微增0.2%。這表明應收帳款回收速度變慢，可能存在營收品質下降或客戶付款條件放寬的風險，對營運現金流產生負面影響。

*   **存貨 (Inventory)**：
    *   FY2024: 75.19億美元
    *   FY22025: 74.89億美元
    *   FY2026: 75.01億美元
    存貨水平在過去三年相對穩定，FY2026基本持平於前一年。FY2026 Q3存貨為75億美元，下降1%，主要反映單位數量減少和產品組合轉變，部分被產品成本增加抵消。這顯示公司在管理存貨方面取得一定成效，避免了大規模存貨堆積的風險。

#### 負債與償債能力
*   **流動性**：
    *   **流動比率 (Current Ratio)** = 流動資產 / 流動負債
        *   FY2024: 253.82億美元 / 95.76億美元 = 2.65
        *   FY2025: 233.62億美元 / 103.95億美元 = 2.25
        *   FY2026: 246.03億美元 / 106.91億美元 = 2.30
    流動比率在FY2025有所下降，FY2026略有回升，但仍保持在2倍以上，顯示公司短期償債能力尚屬健康。

    *   **速動比率 (Quick Ratio)** = (現金及約當現金 + 短期投資 + 應收帳款) / 流動負債
        *   FY2024: (98.60 + 17.22 + 44.27) / 95.76 = 1.67
        *   FY2025: (74.64 + 16.87 + 47.17) / 103.95 = 1.33
        *   FY2026: (75.63 + 14.64 + 59.31) / 106.91 = 1.39
    速動比率在FY2025和FY2026有所下降，但仍高於1，表明公司在不依賴存貨變現的情況下，仍具備一定的短期償債能力。

*   **長期風險**：
    *   **債務佔資產比 (Total Debt/Assets)**：
        *   FY2025: (103.95億美元流動負債 + 79.56億美元長期債務) / 365.79億美元總資產 = 183.51億美元 / 365.79億美元 = 0.50
        *   FY2026: (106.91億美元流動負債 + 59.40億美元長期債務) / 384.10億美元總資產 = 166.31億美元 / 384.10億美元 = 0.43
    總債務佔資產比在FY2026有所改善，顯示公司在降低整體槓桿方面有所努力。

    *   **債務對權益比 (Debt/Equity)**：
        *   FY2025: 183.51億美元總債務 / 132.00億美元股東權益 = 1.39
        *   FY2026: 166.31億美元總債務 / 148.00億美元股東權益 = 1.12
    債務對權益比在FY2026顯著下降，從FY2025的1.77倍降至1.58倍，再到計算出的1.12，表明公司財務槓桿有所降低，償債安全性提升。

*   **淨現金 (Net Cash) 狀況**：
    *   FY2026長期債務為59.40億美元，現金及短期投資為90.27億美元。公司處於淨現金狀態，顯示其財務狀況穩健，有能力應對債務。

#### 無形資產與商譽
*   **商譽 (Goodwill)**：FY2024、FY2025和FY2026均為2.40億美元。
*   **無形資產 (Other Intangible Assets)**：FY2024、FY2025和FY2026均為2.59億美元。
商譽和無形資產佔總資產的比例非常小，且保持穩定，表明公司主要資產為實體資產和營運資本，無形資產減損風險較低。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

#### 營業現金流 (OCF)
*   FY2024: 74.29億美元
*   FY2025: 36.98億美元
*   FY2026: 28.68億美元
營業現金流在FY2025和FY2026呈現顯著下降趨勢，FY2026較FY2025下降22.4%。這與淨利潤的下降趨勢一致，但OCF的下降幅度更大。

*   **盈餘品質**：
    *   OCF / 淨利潤 (Cash Conversion Ratio)：
        *   FY2024: 74.29億美元 / 57.00億美元 = 1.30 (130%)
        *   FY2025: 36.98億美元 / 32.19億美元 = 1.15 (115%)
        *   FY2026: 28.68億美元 / 31.08億美元 = 0.92 (92%)
    FY2026的OCF首次低於淨利潤，現金轉換率降至92%。這表明盈餘品質有所惡化，主要原因在於應收帳款的大幅增加（FY2026應收帳款增加12.1億美元）。應收帳款的積壓導致營運活動產生的現金減少，儘管淨利潤下降幅度較小。

#### 自由現金流 (FCF)
*   **FCF (OCF - CapEx)**：
    *   FY2024: 74.29億美元 - 8.12億美元 = 66.17億美元
    *   FY2025: 36.98億美元 - 4.30億美元 = 32.68億美元
    *   FY2026: 28.68億美元 - 6.84億美元 = 21.84億美元
自由現金流在過去兩年大幅下降，FY2026較FY2025下降33.2%。這表明公司用於擴張、派息或回購的現金能力受到嚴重影響。

#### 資本配置 (Capital Allocation)
*   **資本支出 (CapEx)**：
    *   FY2024: 8.12億美元
    *   FY2025: 4.30億美元
    *   FY2026: 6.84億美元
    資本支出在FY2025有所減少，FY2026則有所增加59.1%，但整體規模相對穩定。

*   **派發股息 (Dividends Paid)**：
    *   FY2024: 21.69億美元
    *   FY2025: 23.00億美元
    *   FY2026: 24.07億美元
    股息支付持續增長，FY2026達到24.07億美元。值得注意的是，FY2026的股息支付已超過當年的自由現金流 (21.84億美元)，這是一個警訊，可能需要動用其他資金來源來維持股息支付。

*   **股份回購 (Share Repurchases)**：
    *   FY2024: 42.50億美元
    *   FY2025: 29.85億美元
    *   FY2026: 1.46億美元
    股份回購在FY2026大幅削減95%至1.46億美元，與前幾年的積極回購形成鮮明對比。這反映了公司在自由現金流壓力下，優先保障股息支付，並大幅縮減了回購規模。

*   **資本配置效率**：
    過去幾年，Nike的資本配置從積極的股息和回購轉向更保守的策略，尤其是在FY2026大幅削減回購。由於自由現金流顯著下降且不足以覆蓋股息支付，公司的資本配置效率面臨挑戰。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

#### 回報率指標
*   **ROE (股東權益報酬率)** = 淨利潤 / 股東權益
    *   FY2024: 57.00億美元 / 144.00億美元 = 39.6%
    *   FY2025: 32.19億美元 / 132.00億美元 = 24.4%
    *   FY2026: 31.08億美元 / 148.00億美元 = 21.0%
    ROE在過去兩年顯著下降，反映公司為股東創造回報的能力減弱。

    *   **杜邦分析 (DuPont Analysis)**：ROE = 純益率 x 資產周轉率 x 財務槓桿
        *   **純益率 (Net Margin)**：FY2026為6.7%。
        *   **資產周轉率 (Asset Turnover)** = 營收 / 總資產
            *   FY2024: 513.62億美元 / 381.10億美元 = 1.35
            *   FY2025: 463.09億美元 / 365.79億美元 = 1.27
            *   FY2026: 464.00億美元 / 384.10億美元 = 1.21
            資產周轉率呈現下降趨勢，表明公司利用資產產生營收的效率降低。
        *   **財務槓桿 (Financial Leverage)** = 總資產 / 股東權益
            *   FY2024: 381.10億美元 / 144.00億美元 = 2.65
            *   FY2025: 365.79億美元 / 132.00億美元 = 2.77
            *   FY2026: 384.10億美元 / 148.00億美元 = 2.59
            財務槓桿在FY2025略有上升，FY2026有所下降。ROE的下降主要是由於純益率和資產周轉率的雙重壓力。

*   **ROIC (投入資本回報率)**：
    *   FY2024: 34.9%
    *   FY2025: 20.2%
    ROIC在FY2025大幅下降至20.2%，顯示公司投資資本的效益顯著降低。雖然沒有FY2026的具體數據，但考慮到淨利潤和營業現金流的持續下降，預計ROIC可能進一步承壓。

#### 效率指標
*   **資產周轉率**：如上所述，從FY2024的1.35下降至FY2026的1.21，效率有所降低。
*   **存貨周轉天數 (DIO)** = (平均存貨 / 銷貨成本) * 365
    *   FY2025: (74.89億美元 / 265.19億美元) * 365 = 103天
    *   FY2026: (75.01億美元 / 264.90億美元) * 365 = 103天
    存貨周轉天數保持穩定，表明存貨管理效率尚可。
*   **應收帳款周轉天數 (DSO)** = (平均應收帳款 / 營收) * 365
    *   FY2025: (47.17億美元 / 463.09億美元) * 365 = 37天
    *   FY2026: (59.31億美元 / 464.00億美元) * 365 = 47天
    應收帳款周轉天數從FY2025的37天增加到FY2026的47天，表明應收帳款回收速度明顯放緩，這與營業現金流下降的原因一致。

**最終結論：**
1.  **整體評級**：存在隱憂
2.  **核心摘要**：Nike的財務健康狀況在過去兩年呈現明顯惡化趨勢。儘管公司在FY2026的營收大致持平，但獲利能力、現金流品質和資本效率均顯著下降。應收帳款積壓導致營業現金流大幅縮水，自由現金流已不足以覆蓋股息支付，迫使公司大幅削減股份回購。雖然短期償債能力尚可，長期債務負擔有所減輕，但整體營運效率和盈利能力面臨嚴峻挑戰。
3.  **關鍵監測指標**：
    *   **Free Cash Flow Margin (自由現金流利潤率)**：衡量公司將營收轉化為自由現金流的能力，其持續下降是核心風險。
    *   **Accounts Receivable Turnover Days (應收帳款周轉天數)**：監測應收帳款回收效率，其惡化直接影響現金流。
    *   **Gross Margin (毛利率)**：反映公司定價能力和成本控制，其穩定性對恢復盈利至關重要。
