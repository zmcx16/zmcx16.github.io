作為一位資深美股分析師，我將針對Nike, Inc. (NKE) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Nike在2026財年（截至2026年5月31日）的總營收為464億美元，與去年同期持平（按報告基準），若以匯率中性計算則下降2%。這顯示公司在過去一年面臨營收成長停滯的挑戰。從季度表現來看，2026財年第四季度的營收為110億美元，較去年同期下降1%（按報告基準），匯率中性計算則下降4%。

營收結構方面，2026財年批發業務營收為275億美元，增長6%（按報告基準），匯率中性計算增長4%。然而，NIKE Direct（直營）業務營收為177億美元，下降6%（按報告基準），匯率中性計算下降8%，主要由於NIKE品牌數位業務下降12%及NIKE自有門市下降4%所致。這表明公司在直營渠道的表現不佳，批發業務的增長部分抵消了直營業務的下滑。

從地區來看，2026財年北美地區營收增長5%，而大中華區營收下降13%，EMEA（歐洲、中東和非洲）地區營收下降3%。這顯示北美市場表現相對穩健，但大中華區和EMEA市場的疲軟對整體營收造成壓力。

**獲利能力與利潤率**
2026財年Nike的毛利率為42.9%，較去年同期增長20個基點。然而，2026財年第四季度的毛利率顯著增長至49.2%，這主要歸因於一筆9.86億美元的IEEPA關稅預期回收所帶來的890個基點的提升。若排除此一次性收益，毛利率的實際改善幅度較小。

營業利益率和純益率方面，雖然財報未直接提供2026財年的營業利益率，但根據提供的基本面數據，營業利益率為8.77%，淨利率為6.7%。2026財年淨利潤為31億美元，同比下降3%，稀釋後每股盈餘(EPS)為2.10美元，同比下降3%。若排除第四季度關稅回收的一次性收益，2026財年調整後的EPS約為1.58美元，遠低於前一年的2.16美元。這表明在一次性收益的掩蓋下，公司的核心獲利能力面臨挑戰，利潤率並未穩定擴張，且規模經濟效應似乎未能有效體現。

**費用控制**
2026財年銷售與管理費用(Selling and Administrative Expense)為161億美元，與去年同期持平。儘管營收持平，但費用未隨之下降，這可能對獲利能力構成壓力。公司管理層表示正在採取行動降低成本、簡化營運並調整分銷網絡以匹配未來需求。研發費用通常包含在銷售與管理費用中，但具體佔比未在摘要中明確。考慮到Nike作為品牌驅動型公司，行銷費用（包含在S&A中）的合理佔比對於維持品牌影響力至關重要。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2026年5月31日，Nike的存貨為75億美元，與去年同期持平。儘管營收停滯，存貨水平保持不變，這需要密切關注其周轉效率，以避免潛在的存貨積壓風險。應收帳款周轉情況未在摘要中直接提及，但若營收增長放緩，應收帳款的回收速度也需關注。

**負債與償債能力**
*   **流動性**：根據提供的基本面數據，流動比率(Current Ratio)為1.96，速動比率(Quick Ratio)為1.36。這兩個比率均高於1，顯示公司擁有足夠的流動資產來覆蓋短期負債，流動性狀況健康。
*   **長期風險**：截至2026財年，Nike的總債務約為59億美元。提供的基本面數據顯示，債務對權益比(Debt/Equity)為0.74，長期債務對權益比(LT Debt/Eq)為0.58。這些比率顯示公司的債務水平處於可控範圍，財務槓桿適中。
*   **淨現金狀況**：2026財年公司擁有約76億美元的流動性（現金及短期投資），而短期債務為20億美元。這表明公司擁有充足的淨現金頭寸，能夠應對短期債務壓力。

**無形資產與商譽**
財報摘要中未提供具體的無形資產和商譽數據。然而，作為一個強大的品牌公司，Nike的品牌價值是其核心無形資產。若無形資產佔比較高，需關注其減損風險，尤其是在營收和獲利能力面臨挑戰的時期。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
2026財年，Nike的自由現金流(FCF)為21.8億美元，較去年同期下降近33億美元，主要由於營運現金流的下降。這表明儘管淨利潤在一次性收益的推動下有所增長，但營運活動產生的實際現金流卻大幅減少，顯示盈餘品質存在隱憂。OCF長期低於淨利可能暗示應收帳款增加、存貨積壓或折舊攤銷等非現金費用佔比較高。

**自由現金流 (FCF)**
2026財年自由現金流為21.8億美元。雖然公司仍能產生正向自由現金流，但其大幅下降（近33億美元）是一個警示信號。這可能限制公司未來在擴張、派息或回購方面的靈活性。根據提供的數據，P/FCF為25.0，顯示市場對其自由現金流的估值相對較高。

**資本配置 (Capital Allocation)**
2026財年，Nike向股東返還了約25億美元，其中包括24億美元的股息（增長5%）和1.23億美元的股票回購。然而，其自由現金流僅為21.8億美元，這意味著公司支付的股息（24億美元）已超過其當年的自由現金流。這可能導致公司需要動用現金儲備或增加借款來維持股息支付，長期來看可能不可持續，並可能導致未來6-12個月內股息削減的風險。資本支出方面，財報摘要未提供具體數據，但其對OCF的影響已體現在FCF的計算中。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：提供的數據顯示ROE為0.2214 (22.14%)。
    *   **杜邦分析拆解 (基於提供的數據和FY2026淨利率42.9%的毛利率，但淨利率為6.7%)**：
        *   淨利率 (Net Profit Margin)：6.7% (來自基本面數據)
        *   資產周轉率 (Asset Turnover)：ROA / 淨利率 = 0.0829 / 0.067 ≈ 1.24 (次)
        *   權益乘數 (Equity Multiplier)：ROE / ROA = 0.2214 / 0.0829 ≈ 2.67
    *   ROE = 淨利率 (6.7%) x 資產周轉率 (1.24) x 權益乘數 (2.67) ≈ 22.14%。
    *   雖然ROE看起來不錯，但其背後可能受到財務槓桿的影響，且淨利率在排除一次性收益後實際較低，這會影響ROE的品質。
*   **ROIC (投入資本回報率)**：提供的數據顯示ROI為0.1327 (13.27%)。ROIC通常更為精確，但此處使用ROI作為參考。公司投資資本的效益需要與其加權平均資本成本(WACC)進行比較。若ROI高於WACC，則表示公司創造了股東價值。考慮到營收和獲利能力的挑戰，ROIC的趨勢值得關注。

**效率指標**
*   **資產周轉率**：約1.24次，表明公司資產的利用效率一般。
*   **存貨周轉天數 (DIO)**：2026財年存貨與去年持平，而營收停滯，這可能意味著存貨周轉天數有所延長，存在存貨堆積的風險。
