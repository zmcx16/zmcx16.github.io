作為一位資深美股分析師，我將針對Nike, Inc. (NKE) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。

---

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Nike在2024財年（截至2024年5月31日）的總營收為514億美元，較前一財年的512億美元增長1%（按報告和貨幣中性基準計算）。然而，最新公布的2025財年第一季度（截至2024年8月31日）營收為116億美元，較去年同期下降10%（按報告基準）和9%（按貨幣中性基準）。

從細項來看，2024財年第四季度（截至2024年5月31日）營收為126億美元，較去年同期下降2%（按報告基準），但按貨幣中性基準持平。其中，NIKE Direct營收下降7-8%，NIKE Digital下降10%，而批發（Wholesale）營收則增長5-8%。進入2025財年第一季度，NIKE Direct營收下降13%（按報告基準），主要由於NIKE品牌數位業務下降20%所致，但NIKE自有門店增長1%部分抵消了這一影響。批發營收也下降了8%。Converse品牌營收在2024財年第四季度下降18%，在2025財年第一季度下降15%。

整體而言，Nike的營收成長動能正在減弱，特別是其直接面向消費者（DTC）和數位渠道面臨壓力，這與公司過去幾年強調DTC策略的趨勢有所不同。營收下降主要歸因於流量放緩、促銷活動增加以及某些經典鞋款銷售下降。

**獲利能力與利潤率**
Nike的毛利率（Gross Margin）表現穩健且有所擴張。2024財年毛利率為44.6%。2024財年第四季度毛利率增長110個基點至44.7%，主要得益於戰略性定價、較低的海洋運費和物流成本，以及較低的倉儲成本，部分被NIKE Direct較低的利潤率和不利的匯率變動所抵消。2025財年第一季度毛利率進一步增長120個基點至45.4%，主要由於NIKE品牌產品成本降低、倉儲和物流成本下降以及前期戰略定價的效益。

營業利益率（Operating Margin）方面，2024財年營業費用（Operating overhead expense）為123億美元，與前一年持平。淨利潤（Net Income）在2024財年增長12%至57億美元。然而，2025財年第一季度淨利潤為11億美元，同比下降28%，稀釋每股收益（Diluted EPS）為0.70美元，下降26%。這表明儘管毛利率有所改善，但營收下降對淨利潤產生了顯著負面影響。

**費用控制**
銷售、管理及行政費用（SG&A）在2024財年增長1%至166億美元。2024財年第四季度SG&A費用按報告基準下降7%，其中包括4000萬美元的重組費用。2025財年第一季度，銷售和行政費用下降2%至40億美元。其中，需求創造費用（Demand creation expense）增長15%至12億美元，主要反映了對關鍵體育賽事的品牌行銷投資。營運管理費用（Operating overhead expense）下降7%至28億美元，主要由於工資相關費用降低。這顯示公司在控制部分費用方面有所努力，但對品牌行銷的投資仍在增加，這與其「Win Now」轉型策略相符.

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2024財年末，Nike的庫存（Inventory）為75億美元，同比下降11%。這是一個積極的信號，表明公司在去庫存方面取得了進展，有助於緩解存貨堆積的風險。應收帳款周轉情況未在最新財報中具體提及，但庫存的改善通常伴隨著更健康的營運資本管理。

**負債與償債能力**
*   **流動性**：根據提供的基本面數據，Nike的流動比率（Current Ratio）為2.07，速動比率（Quick Ratio）為1.39。這些比率顯示公司擁有健康的短期償債能力，能夠有效覆蓋其流動負債。
*   **長期風險**：債務對權益比（Debt/Equity）為0.73，長期債務對權益比（LT Debt/Eq）為0.56。這表明公司在一定程度上利用了債務融資，但相對於股東權益而言，債務水平仍在可控範圍內，不構成過高的長期償債風險。
*   **淨現金狀況**：雖然具體淨現金數據未在最新季度報告中直接提供，但穩健的流動性比率和強勁的營運現金流（後續分析）表明公司擁有良好的現金狀況。

**無形資產與商譽**
最新的財報摘要中未具體提及商譽（Goodwill）和無形資產的詳細情況。對於Nike這樣以品牌價值為核心的公司，品牌本身就是其最重要的無形資產。通常情況下，只要品牌價值保持強勁，商譽減損的風險相對較低。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
Nike在2024財年產生的營運現金流（Cash flow from operations）為74億美元，同比增長27%。這是一個非常強勁的表現，遠超其淨利潤的增長速度，顯示公司從核心業務中產生現金的能力非常出色。

*   **盈餘品質**：由於營運現金流顯著高於淨利潤，這表明Nike的盈餘品質良好，其利潤並非主要來自非現金會計調整，而是有實際現金流入支持。

**自由現金流 (FCF)**
雖然最新的財報摘要中未直接提供資本支出（CapEx）的具體數字，但強勁的營運現金流為自由現金流（FCF = OCF - CapEx）提供了堅實的基礎。鑑於其營運現金流的強勁增長，預計其自由現金流也將保持健康水平，為公司的擴張、派息和回購提供充足的資金。

**資本配置 (Capital Allocation)**
Nike在資本配置方面表現出對股東回報的堅定承諾。
*   **派發股息**：2024財年派發股息22億美元，增長8%。2025財年第一季度派發股息5.58億美元，增長6%。公司已連續22年增加股息派發，顯示其財務紀律和對股東的承諾。
*   **股份回購**：2024財年回購了約42億美元的股票（總回報64億美元減去22億美元股息）。2025財年第一季度回購了12億美元的股票。這些回購是其四年180億美元股票回購計劃的一部分。
*   **資本支出**：雖然具體數字未提供，但公司持續投資於創新和品牌行銷，以支持未來的成長。

整體而言，Nike的資本配置策略平衡了對業務的再投資與對股東的回報，且效率良好。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：提供的數據顯示ROE為21.56%。
    *   **杜邦分析拆解 (基於提供的數據和推算)**：
        *   淨利潤率 (Net Profit Margin)：提供的數據為6.74%。
        *   資產周轉率 (Asset Turnover)：ROA (8.23%) / 淨利潤率 (6.74%) ≈ 1.22。
        *   權益乘數 (Equity Multiplier)：ROE (21.56%) / ROA (8.23%) ≈ 2.62。
        *   因此，ROE = 淨利潤率 (6.74%) x 資產周轉率 (1.22) x 權益乘數 (2.62) ≈ 21.56%。
    *   Nike的ROE主要受到其穩健的淨利潤率和適度的財務槓桿的推動。
*   **ROIC (投入資本回報率)**：提供的數據為12.99%。根據2025財年年報，ROIC為20.2%（截至2025年5月31日），而2024財年為34.9%。ROIC的下降值得關注，這可能表明公司投資資本的效益有所降低。雖然沒有直接的WACC數據，但ROIC高於一般企業的WACC水平通常被視為良好，但其下降趨勢需要警惕。

**效率指標**
*   **資產周轉率**：如杜邦分析所示，約為1.22。這表明公司每1美元資產能產生約1.22美元的營收。
*   **存貨周轉天數 (DIO)**：2024財年庫存下降11%至75億美元，這是一個積極的信號，表明存貨管理效率有所提升。
*   **應收帳款周轉天數 (DSO)**：最新財報未提供具體數據，但通常對於消費品公司，應收帳款周轉速度較快。
