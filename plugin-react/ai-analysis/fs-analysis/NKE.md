作為一位資深美股分析師，我將對Nike, Inc. (NKE) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    Nike在最近的財報中顯示出營收成長動能減弱的趨勢。截至2026年8月31日的第一季度（Q1 FY2027），Nike的總營收為112億美元，較去年同期下降4%（按報告基礎），若以匯率中性計算則下降5%。其中，大中華區營收按匯率中性計算下降26%，EMEA地區下降5%，Converse品牌營收下降28%，NIKE Direct營收下降9%。這些下降主要歸因於NIKE Sportswear和Jordan Brand的表現不佳，分別呈現低雙位數和中雙位數的下滑，對整體業績構成顯著拖累。儘管北美地區營收增長2%，NIKE Performance產品組合也實現高個位數增長，但未能完全抵消其他地區和品牌的疲軟。
    回顧2026財年（截至2026年5月31日），Nike全年營收為464億美元，按報告基礎持平，按匯率中性計算則下降2%。這表明公司在過去一年中已面臨營收停滯甚至下滑的挑戰。管理層預計2027財年營收將呈現高個位數下降，顯示短期內營收壓力將持續存在。

*   **獲利能力與利潤率**
    Nike的獲利能力在近期呈現波動。截至2026年8月31日的第一季度，毛利率為42.8%，較去年同期上升60個基點（42.2%）。毛利率的改善主要得益於倉儲和物流成本的降低。然而，淨利潤從去年同期的7.27億美元下滑至7.12億美元，稀釋後每股盈餘（EPS）也下滑2%至0.48美元。
    在2026財年，全年毛利率為42.9%，較前一年微幅增長20個基點。然而，在2026財年第三季度，毛利率曾下降130個基點至40.2%，主要受北美關稅上漲和Converse盈利能力下降的影響。這表明儘管近期毛利率有所回升，但其穩定性仍受多重因素影響。
    從提供的基本面數據來看，Nike的營業利益率（Oper. Margin）為8.82%，純益率（Profit Margin）為6.74%。雖然毛利率在最新季度有所改善，但營收下滑和淨利潤的微幅下降顯示公司在將毛利轉化為淨利方面仍面臨挑戰，規模經濟效應可能因營收壓力而受到影響。

*   **費用控制**
    Nike在費用控制方面展現出一定的紀律。截至2026年8月31日的第一季度，銷售、一般及行政費用（SG&A）下降了3%。在2026財年，SG&A費用與前一年持平，約為161億美元。這表明公司在營收下滑的背景下，正努力控制營運費用以支撐獲利。
    公司近期宣布了一項名為「Pace」的多年期營運模式改革計畫，目標是在2031財年前實現約25億美元的累計節省，預計產生約10億美元的實施成本，其中2027財年預計產生約3億美元的重組費用。這項計畫顯示Nike正積極調整其成本結構，以提升長期效率和獲利能力，儘管短期內會產生一次性費用。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**
    截至2026年8月31日，Nike的現金及約當現金和短期投資總計84億美元，顯示公司擁有充足的流動性資產。
    然而，應收帳款（AR）與存貨（Inventory）的周轉情況需要密切關注。有分析指出，Nike的存貨比率在同業中相對較高，且大部分流動資產由存貨和應收帳款組成。這可能暗示存在存貨堆積或應收帳款回收過慢的風險，尤其是在營收下滑的環境下，這會對公司的現金流產生壓力。最新的Q1 FY2027財報中，營運現金流因營運資本及其他資產負債變動而減少8.46億美元，進一步印證了營運資本管理可能面臨挑戰。

*   **負債與償債能力**
    *   **流動性**：根據提供的基本面數據，Nike的流動比率（Current Ratio）為2.07，速動比率（Quick Ratio）為1.39。這些比率通常被認為是健康的，表明公司有足夠的流動資產來覆蓋短期負債。然而，考慮到存貨佔比較高，速動比率（排除存貨）更能反映其即時償債能力，1.39的速動比率仍屬穩健。
    *   **長期風險**：提供的基本面數據顯示，債務佔權益比（Debt/Equity）為0.73，長期債務佔權益比（LT Debt/Eq）為0.56。這些比率表明Nike的債務水平處於可控範圍，財務槓桿使用適度，長期償債風險不高。
    *   **淨現金狀況**：截至2026年8月31日，公司擁有84億美元的現金及短期投資。雖然未直接提供總債務數據，但考慮到其穩健的流動性和債務比率，公司應處於淨現金狀況或擁有較強的淨現金產生能力。

*   **無形資產與商譽**
    本次搜尋結果未提供Nike無形資產與商譽的具體數值及佔比，因此無法直接評估其是否存在過高或減損風險。然而，作為一個全球知名品牌，Nike的品牌價值（無形資產）是其核心競爭力之一。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**
    Nike的營業現金流在最新季度表現不佳。截至2026年8月31日的第一季度，營運活動提供的現金為1.35億美元，遠低於去年同期的2.22億美元。營運現金流的顯著下降主要是由於營運資本及其他資產負債的變動，導致營運現金減少了8.46億美元。
    *   **盈餘品質**：營業現金流大幅低於淨利潤（Q1 FY2027淨利潤為7.12億美元），這是一個重要的警訊。當OCF長期低於淨利時，可能暗示盈餘品質不佳，即淨利潤的實現更多依賴於非現金會計調整而非實際現金流入，例如應收帳款增加或存貨積壓。最新季度的數據明確指出營運資本變動是主要原因，這與資產負債表分析中對應收帳款和存貨的擔憂相符。

*   **自由現金流 (FCF)**
    自由現金流（FCF = OCF - 資本支出）在最新季度可能面臨壓力。由於Q1 FY2027的營業現金流僅為1.35億美元，即使資本支出保持在較低水平，自由現金流也將非常有限，甚至可能為負。這表明公司目前用於擴張、派息或回購的現金可能不足，需要依賴現有現金儲備或外部融資。

*   **資本配置 (Capital Allocation)**
    在截至2026年8月31日的第一季度，Nike支付了6.1億美元的股息，但沒有進行任何股份回購。這顯示在營運現金流緊張的情況下，公司仍將維持股息支付作為優先事項。然而，缺乏股份回購活動可能反映了公司對未來現金流的謹慎態度，或將更多資金用於內部重組（如Pace計畫的實施成本）和核心業務的投資。資本配置的效率在當前營收下滑和現金流承壓的環境下，將是未來需要密切關注的重點。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**
    *   **ROE (股東權益報酬率)**：根據提供的基本面數據，Nike的ROE為21.56%。這是一個相對較高的數字，表明公司為股東創造價值的能力較強。
        *   **杜邦分析拆解 (ROE = 淨利率 x 資產周轉率 x 權益乘數)**：
            *   **淨利率 (Profit Margin)**：提供的數據為6.74%。這表示每單位營收能轉化為的淨利潤。
            *   **資產周轉率 (Asset Turnover)**：未直接提供，但營收下滑可能導致資產周轉效率降低。
            *   **權益乘數 (Equity Multiplier)**：由債務對權益比0.73推算，權益乘數約為1.73 (1 + Debt/Equity)。這表明公司適度使用了財務槓桿來提升股東回報。
        綜合來看，Nike的ROE主要得益於相對健康的淨利率和適度的財務槓桿，但資產周轉率可能因近期營收壓力而受到影響。
    *   **ROIC (投入資本回報率)**：提供的ROI為12.99%，ROA為8.23%。ROIC衡量公司利用其投入資本產生利潤的效率。雖然未直接提供加權平均資本成本（WACC），但12.99%的ROI表明公司投資資本的效益尚可。然而，在營收下滑和獲利承壓的背景下，ROIC的趨勢值得警惕，需確保其持續高於WACC以創造經濟價值。

*   **效率指標**
    *   **資產周轉率**：未直接提供，但考慮到營收下滑和存貨可能積壓的情況，資產周轉效率可能面臨挑戰。
    *   **存貨周轉天數 (DIO)**：未直接提供具體數值，但分析指出Nike的存貨比率較高，這可能意味著存貨周轉天數較長，存在存貨管理效率不佳的風險。
    *   **應收帳款周轉天數 (DSO)**：未直接提供具體數值，但營運現金流因營運資本變動而大幅減少，暗示應收帳款回收可能存在延遲，導致DSO可能拉長。
