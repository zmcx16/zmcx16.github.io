作為一位資深美股分析師，我將對Nike, Inc. (NKE) 的財務狀況進行全面拆解，並根據最新的財報數據進行評估。分析將主要基於公司截至2026年5月31日的2026財年年報（10-K）及最近的季度報告（Q3 FY2026）。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    Nike在2026財年的總營收為464億美元，與去年同期持平（reported basis），若以不考慮匯率影響的基礎計算則下降2%。這顯示公司在營收增長方面面臨挑戰。
    回顧過去幾年，Nike的營收趨勢如下：
    *   FY2026: $46.40 billion (年增 0.19%)
    *   FY2025: $46.31 billion (年減 9.84%)
    *   FY2024: $51.36 billion (年增 0.28%)
    *   FY2023: $51.22 billion (年增 9.65%)
    *   FY2022: $46.71 billion (年增 4.88%)
    從數據來看，Nike在2025財年經歷了顯著的營收下滑，2026財年則呈現停滯。最新的2026財年第四季度營收為110億美元，同比下降1%（reported basis），若以不考慮匯率影響的基礎計算則下降4%。營收下滑主要來自於Nike Direct業務的下降（第四季度下降7%，全年下降6%），其中Nike品牌數位銷售下降12%，Nike自有門店銷售下降4%。Converse品牌營收在第四季度更是大幅下降32%。批發業務在第四季度增長4%（reported basis），部分抵消了Direct業務的疲軟。這表明公司正在從過去過度依賴DTC（Direct-to-Consumer）策略轉向重新加強與批發夥伴的合作，但整體營收增長動能不足，且面臨區域性（大中華區和EMEA下降）及品牌（Converse表現不佳）的挑戰。

*   **獲利能力與利潤率**
    *   **毛利率 (Gross Margin)**：2026財年毛利率為42.9%，較去年同期增加20個基點。然而，在2026財年第三季度，毛利率為40.2%，下降了130個基點，主要原因是北美地區關稅上漲。第四季度毛利率則大幅增長至49.2%，其中包含約900個基點的IEEPA關稅預期回收收益。剔除此一次性收益，毛利率仍面臨壓力。
    *   **營業利益率 (Operating Margin)**：2026財年營業利益為38億美元，營業利益率為8.2%。這相較於2024財年的12.3%有顯著下降。這表明儘管毛利率有所改善，但營運費用可能侵蝕了部分利潤。
    *   **純益率 (Net Margin)**：2026財年淨利潤為31億美元，同比下降3%。純益率為6.7%。在2026財年第三季度，淨利潤為5億美元，同比大幅下降35%。這反映了公司在營收增長停滯和成本壓力下，獲利能力受到擠壓。

    利潤率的變化顯示出不穩定性。毛利率在2026財年第四季度因一次性收益而大幅提升，但在此之前，受關稅等因素影響而承壓。營業利益率和純益率均呈現下降趨勢，表明公司尚未展現出規模經濟效應，或其成本控制未能有效抵消營收壓力。

*   **費用控制**
    *   **銷售與管理費用 (Selling and Administrative Expense, S&A)**：2026財年S&A費用為161億美元，與去年持平。其中，需求創造費用（Demand creation expense）為48億美元，增長1%，主要由於體育行銷費用增加，部分被品牌行銷費用下降抵消。營運管理費用（Operating overhead expense）為114億美元，與去年持平，儘管行政成本下降，但被員工遣散費和匯率不利變動抵消。
    *   **研發費用 (R&D)**：Nike在2026財年並未單獨披露有意義的研發費用，多數數據顯示為0或不適用。這可能意味著研發費用被歸入其他費用項目，例如需求創造費用或營運管理費用。對於一家以創新為核心的運動品牌而言，若研發投入不足或未透明化，可能對其長期競爭力構成隱憂。

    整體而言，S&A費用保持穩定，但營收增長停滯使得費用佔比相對提高。在營收增長乏力時，費用控制的效率將直接影響獲利能力。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**
    截至2026年5月31日，Nike的總資產為384.1億美元。
    *   **現金與短期投資**：現金及約當現金和短期投資合計為90.27億美元，較去年同期略微下降約1億美元。這筆現金儲備為公司提供了良好的流動性。
    *   **應收帳款 (Accounts Receivable, AR)**：應收帳款為59.31億美元。值得注意的是，在營收持平的情況下，應收帳款增加了12.1億美元，增幅達25.7%。這導致應收帳款周轉率從2023財年的12.40下降至2026財年的7.82。應收帳款平均收款天數從2023年的29天增加到2026年的47天。這是一個重要的警訊，可能暗示公司在收款方面面臨壓力，或為了刺激銷售而放寬了信用條件，增加了壞帳風險。
    *   **存貨 (Inventory)**：存貨為75億美元，與去年持平。存貨周轉率在2026財年為3.53次，存貨周轉天數（DIO）為122.57天。儘管存貨金額持平，但考慮到營收增長停滯，存貨周轉效率並未顯著改善，仍需密切關注是否存在存貨積壓的風險。

*   **負債與償債能力**
    *   **流動性**：
        *   **流動比率 (Current Ratio)**：根據提供的數據，流動比率為1.96。最新的財報數據顯示，截至2026年5月31日，流動資產為246.03億美元，流動負債為125.5億美元。計算得出流動比率約為1.96 (246.03 / 125.5)，與提供數據一致。這表明公司短期償債能力良好。
        *   **速動比率 (Quick Ratio)**：提供的速動比率為1.36。這也顯示公司在不依賴存貨銷售的情況下，仍具備健康的短期償債能力。
    *   **長期風險**：
        *   **債務佔資產比 (Total Debt/Assets)**：截至2026年5月31日，總債務為110.3億美元（調整後），總資產為384.1億美元。債務佔資產比約為28.7% (110.3 / 384.1)。這表明公司的資產負債結構相對穩健，債務水平可控。
        *   **債務對權益比 (Debt/Equity)**：截至2026年5月31日，總債務為110.3億美元，股東權益為148.65億美元。債務對權益比約為0.74 (110.3 / 148.65)。這與提供的數據0.74一致，顯示公司財務槓桿處於合理水平。
        *   **淨現金 (Net Cash)**：截至2026年5月31日，現金及短期投資為90.27億美元，總債務為110.3億美元。因此，公司處於淨負債狀態，淨現金為-20.03億美元。這表示公司的現金儲備不足以完全覆蓋其總債務。

*   **無形資產與商譽**
    截至2026年5月31日，商譽為2.4億美元，與2025財年持平。可辨識無形資產淨額為2.59億美元，自2024財年以來保持不變。總無形資產為4.99億美元。相對於總資產384.1億美元，無形資產佔比非常小，因此減損風險相對較低。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (Operating Cash Flow, OCF)**
    2026財年營業現金流為28.7億美元，較2025財年的37億美元下降了22.4%。這與淨利潤僅下降3%形成鮮明對比。
    *   **盈餘品質**：2026財年的現金轉換率（Operating Cash Flow / Net Income）為92% (2.87B / 3.11B)。這是三年來首次跌破100%，顯示盈餘品質有所惡化。主要原因是應收帳款大幅增加12.1億美元，而營收卻持平。這表明公司雖然在帳面上實現了利潤，但實際收到現金的速度變慢，可能存在營運資金管理效率下降的問題。

*   **自由現金流 (Free Cash Flow, FCF)**
    2026財年資本支出（Capital Expenditure）為6.84億美元。
    自由現金流 (FCF) = 營業現金流 (OCF) - 資本支出 (CapEx)
    FCF = $2.87 billion - $0.684 billion = $2.186 billion。
    2026財年自由現金流為21.86億美元，較2025財年下降33.2%。自由現金流的顯著下降，限制了公司用於擴張、派息或回購股票的現金能力。

*   **資本配置 (Capital Allocation)**
    *   **資金投向**：在2026財年，公司向股東返還了約25億美元。其中，股息支付為24億美元，較去年增長5%。股票回購僅為1.23億美元，回購了180萬股，相較於前幾年的大規模回購（2024財年42.5億美元，2025財年29.9億美元）大幅減少了95%。資本支出為6.84億美元，較2025財年增長59.1%。
    *   **資本配置效率**：儘管公司持續派發股息，但自由現金流的下降和股票回購的大幅縮減，表明公司在現金生成方面面臨壓力，導致其資本配置策略發生調整。資本支出增加可能反映了公司對未來增長的投資，但其效率需在未來觀察。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**
    *   **ROE (股東權益報酬率)**：提供的ROE為0.2214。最新的數據顯示，截至2026年8月10日，Nike的ROE為20.9%。
        *   **杜邦分析拆解 (FY2026)**：
            *   淨利率 (Net Profit Margin) = 淨利潤 / 營收 = $3.11B / $46.4B = 6.7%
            *   資產周轉率 (Asset Turnover) = 營收 / 總資產 = $46.4B / $38.41B = 1.21次
            *   權益乘數 (Financial Leverage) = 總資產 / 股東權益 = $38.41B / $14.865B = 2.58次
            *   ROE = 淨利率 x 資產周轉率 x 權益乘數 = 6.7% x 1.21 x 2.58 = 20.9% (與最新數據一致)。
        ROE的下降主要歸因於淨利率和資產周轉率的下降，儘管財務槓桿略有增加，但未能完全抵消前兩者的負面影響。
    *   **ROIC (投入資本回報率)**：2026財年ROIC為14.0%。截至2026年8月12日，Nike的加權平均資本成本 (WACC) 為7.92%。由於ROIC (14.0%) 高於WACC (7.92%)，表明公司投資資本的效益仍超過其資本成本，為股東創造了價值。然而，ROIC從2024財年的21.6%下降至2026財年的14.0%，顯示資本運用效率有所下滑。

*   **效率指標**
    *   **資產周轉率 (Asset Turnover)**：2026財年為1.21次。資產周轉率在過去幾年呈現下降趨勢，從2024財年的1.4次下降至2026財年的1.21次。這表明公司利用資產產生營收的效率正在降低。
    *   **存貨周轉天數 (Days Inventory Outstanding, DIO)**：截至2026年5月，DIO為122.57天。這意味著公司需要約四個月的時間才能將存貨轉化為銷售，效率一般。
    *   **應收帳款周轉天數 (Days Sales Outstanding, DSO)**：截至2026年5月，DSO為47天。相較於2023年的29天顯著增加，表明公司回收應收帳款的速度變慢，對現金流產生負面影響。

**最終結論：**
1.  **整體評級**：存在隱憂
2.  **核心摘要**：Nike在2026財年面臨營收增長停滯、獲利能力下降的挑戰。儘管其償債能力依然穩健，但營業現金流顯著惡化，應收帳款大幅增加導致盈餘品質下降。資本效率指標也呈現下滑趨勢，表明公司在利用資產創造營收和利潤方面效率降低。公司正處於轉型期，從DTC策略調整至重新平衡批發渠道，但轉型陣痛明顯。
3.  **關鍵監測指標**：
    *   **自由現金流利潤率 (Free Cash Flow Margin)**：衡量公司將營收轉化為自由現金流的能力，尤其在營收停滯時更顯重要。
    *   **應收帳款周轉天數 (Days Sales Outstanding, DSO)**：持續監測DSO，以評估公司收款效率是否改善，避免營運現金流進一步惡化。
    *   **Nike Direct營收增長率**：觀察DTC業務（尤其是數位銷售）能否恢復增長，這對公司長期毛利率和品牌溢價至關重要。
