作為一位資深美股分析師，我將對Nike, Inc. (NKE) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Nike的營收成長動能近期顯著放緩，甚至出現下滑。
*   **最新季度 (Q3 FY2026，截至2026年2月28日)**：營收為113億美元，按報告基準持平，按貨幣中性基準則下降3%。
    *   批發業務營收為65億美元，按報告基準增長5%，按貨幣中性基準增長1%，主要受北美地區增長推動。
    *   NIKE Direct營收為45億美元，按報告基準下降4%，按貨幣中性基準下降7%，主要由於NIKE品牌數位業務下降9%及NIKE自有門店下降5%。
    *   Converse品牌營收為2.64億美元，按報告基準下降35%，按貨幣中性基準下降37%，所有地區均出現下滑。
*   **過去年度趨勢 (FY2021-FY2025)**：
    *   FY2025：營收為463.1億美元，較FY2024下降10%（貨幣中性下降9%）。
    *   FY2024：營收為513.6億美元。
    *   FY2023：營收為512.2億美元。
    *   FY2022：營收為467.1億美元。
    *   FY2021：營收為445.4億美元。
    從FY2023的512.2億美元增長至FY2024的513.6億美元後，FY2025營收大幅下滑至463.1億美元，顯示公司面臨較大的營收壓力。FY2025的營收下滑主要歸因於NIKE Direct流量減少，以及為減少市場上某些鞋類產品供應而增加的降價促銷和批發夥伴的退貨。

**獲利能力與利潤率**
Nike的獲利能力和利潤率近期呈現壓力。
*   **毛利率 (Gross Margin)**：
    *   Q3 FY2026：毛利率為40.2%，較去年同期下降130個基點，主要由於北美地區關稅上漲。
    *   FY2025：毛利率為42.7%。
    *   FY2024：毛利率為44.7%.
    毛利率在FY2024達到高點後，FY2025和Q3 FY2026均呈現下滑趨勢，表明成本壓力（如關稅）和市場促銷活動對公司獲利能力造成負面影響。
*   **營業利益率 (Operating Margin)**：
    *   Q3 FY2026：營業利益率為6.9%，略低於去年同期的7.0%。
    *   FY2025：營業利益為$3.1B.
    *   FY2024：營業利益為$3.86B.
    營業利益率的微幅下降，反映了營收壓力及費用增長對核心業務獲利的影響。
*   **純益率 (Net Margin)**：
    *   Q3 FY2026：淨利為5億美元，較去年同期下降35%。稀釋每股盈餘為0.35美元，下降35%。基於113億美元的營收，純益率約為4.42%。
    *   FY2025：淨利為32.19億美元，較FY2024的57億美元大幅下降。基於463.1億美元的營收，純益率約為6.95%。
    淨利潤和純益率的顯著下滑，表明公司在營收下降和成本壓力下，底線獲利能力受到嚴重侵蝕。

**費用控制**
*   **銷售與管理費用 (Selling and Administrative Expense, S&A)**：
    *   Q3 FY2026：S&A費用增長2%至40億美元。
    *   其中，需求創造費用為11億美元，與去年同期持平。
    *   營運管理費用增長3%至29億美元，主要由於員工遣散費和不利的匯率變動，部分被其他行政成本降低所抵消。
    *   Q3 FY2026包含約2.3億美元的員工遣散費。
    儘管營收面臨壓力，S&A費用仍在增長，特別是受遣散費影響，這顯示公司在進行成本結構調整，但短期內對獲利造成壓力。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
*   **現金與短期投資**：
    *   Q3 FY2026：現金及約當現金和短期投資為81億美元，較去年同期減少約23億美元。
    *   FY2025：現金及約當現金為74.64億美元，短期投資為16.87億美元。
    現金儲備有所下降，但仍保持在相對健康的水平。
*   **應收帳款 (Accounts Receivable, AR)**：
    *   FY2025：應收帳款淨額為47.17億美元，較FY2024的44.27億美元有所增加。應收帳款的增加可能暗示回收速度放緩或銷售條款放寬，需持續關注。
*   **存貨 (Inventory)**：
    *   Q3 FY2026：存貨為75億美元，較去年同期下降1%。這主要反映了單位數量減少和產品組合轉變，部分被北美地區關稅上漲導致的產品成本增加所抵消。
    *   FY2025：存貨為74.89億美元，較FY2024的75.19億美元略有下降。
    存貨水平的下降是一個積極信號，表明公司在清理庫存和改善供應鏈健康方面取得進展，尤其是在FY2025因市場促銷和退貨導致營收下滑的背景下。

**負債與償債能力**
*   **流動性**：
    *   流動比率 (Current Ratio)：2.14。
    *   速動比率 (Quick Ratio)：1.45。
    這些比率顯示Nike的短期償債能力良好，流動資產足以覆蓋流動負債，儘管速動比率略低於流動比率，但仍處於健康區間。
*   **長期風險**：
    *   債務對權益比 (Debt/Equity)：0.57 (57%)。這表明公司債務水平相對可控，股東權益對債務的覆蓋能力較強。
    *   總債務 (Total Debt)：80億美元。
    *   淨現金 (Net Cash)：Q3 FY2026現金及短期投資為81億美元，總債務為80億美元，表明公司處於淨現金狀態，財務彈性較高。

**無形資產與商譽**
*   **商譽 (Goodwill)**：FY2025為2.4億美元。
*   **可辨識無形資產淨額 (Identifiable intangible assets, net)**：FY2025為2.59億美元。
這些無形資產和商譽相對於FY2025總資產365.79億美元而言佔比很小，因此減損風險相對較低，對公司整體財務狀況影響不大。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (Operating Cash Flow, OCF)**
*   **最新季度 (Q3 FY2026)**：營業現金流為5.79億美元，較去年同期大幅下降67.7%。
*   **過去年度趨勢 (FY2023-FY2025)**：
    *   FY2025：營業現金流為36.98億美元，較FY2024下降50.22%。
    *   FY2024：營業現金流為74.29億美元，較FY2023增長27.19%。
    *   FY2023：營業現金流為58.41億美元，較FY2022增長12.59%。
營業現金流在FY2024達到高峰後，FY2025和Q3 FY2026均出現顯著下滑，這是一個重要的警示信號，表明公司核心營運產生現金的能力正在減弱。
*   **盈餘品質**：FY2025淨利為32.19億美元，營業現金流為36.98億美元。營業現金流高於淨利，表明盈餘品質尚可，利潤有現金支持。然而，Q3 FY2026營業現金流的急劇下降，需要密切關注其是否會長期低於淨利。

**自由現金流 (Free Cash Flow, FCF)**
*   **最新季度 (Q3 FY2026)**：自由現金流為2.84億美元，較上一季度下降26.4%。
*   **過去年度趨勢 (FY2023-FY2025)**：
    *   FY2025：自由現金流為32.68億美元，較FY2024下降50.61%。
    *   FY2024：自由現金流為66.17億美元，較FY2023增長35.82%。
    *   FY2023：自由現金流為48.72億美元，較FY2022增長9.98%。
自由現金流的趨勢與營業現金流相似，在FY2024達到高峰後顯著下滑。FY2025自由現金流仍為正，但大幅減少，表明公司用於擴張、派息或回購的現金能力受到限制。

**資本配置 (Capital Allocation)**
*   **FY2025**：公司向股東返還約53億美元，其中包括23億美元的股息（增長6%）和30億美元的股票回購（回購3760萬股）。
*   **Q3 FY2026**：營運產生的現金被現金股息、債券償還、資本支出和股票回購所抵消。該季度通過股息向股東返還約6.09億美元。
*   **資本支出 (CapEx)**：Q3 FY2026購置不動產、廠房及設備為1.93億美元，同比增長138.3%。FY2025資本支出約為4.3億美元。
儘管現金流面臨壓力，Nike仍在持續進行股息派發和股票回購，顯示其對股東回報的承諾。然而，FY2025資本回報（53億美元）超過了自由現金流（33億美元），這解釋了現金餘額的下降和股權基礎的變薄。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **股東權益報酬率 (ROE)**：
    *   FY2025：24.4%。這是一個強勁的回報率，但較FY2024的39.5%有所下降。
    *   杜邦分析 (基於FY2025數據)：
        *   淨利率 (Net Profit Margin) = 淨利 / 營收 = $3,219M / $46,309M = 6.95%
        *   資產周轉率 (Asset Turnover) = 營收 / 總資產 = $46,309M / $36,579M = 1.266
        *   財務槓桿 (Financial Leverage) = 總資產 / 股東權益 = $36,579M / $13,213M = 2.768
        *   ROE = 淨利率 x 資產周轉率 x 財務槓桿 = 6.95% x 1.266 x 2.768 = 24.35%。
    ROE的下降主要歸因於淨利率和資產周轉率的下降，反映了獲利能力和資產使用效率的減弱。
*   **投入資本回報率 (ROIC)**：
    *   FY2025：20.2%。
    *   FY2024：34.9%。
    ROIC從FY2024的34.9%大幅下降至FY2025的20.2%，表明公司投資資本的效益顯著降低。雖然20.2%仍高於一般WACC，但下降幅度值得警惕，暗示資本配置效率可能正在惡化。

**效率指標**
*   **資產周轉率**：FY2025為1.266，較FY2024的1.39 ($51.36B/$36.8B, assuming similar total assets)有所下降，表明資產利用效率有所降低。
*   **存貨周轉天數 (DIO)**：存貨下降1%，但營收也下降，需要更詳細的數據來計算周轉天數。但存貨總額的下降是一個積極信號，有助於改善效率。
*   **應收帳款周轉天數 (DSO)**：應收帳款增加，可能導致周轉天數增加，需要關注應收帳款回收效率。

    *   **自由現金流 (Free Cash Flow, FCF)**：監測其能否止跌回升，以支持未來的擴張、股息和回購，避免過度依賴外部融資。
    *   **NIKE Direct營收成長率**：特別是數位業務的表現，因其是公司長期成長策略的核心，近期下滑趨勢需扭轉。
