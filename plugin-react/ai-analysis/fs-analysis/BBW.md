## Build-A-Bear Workshop Inc (BBW) 財務狀況全面拆解

作為一位資深美股分析師，我將對Build-A-Bear Workshop Inc (BBW) 的財務報表進行深入分析，以評估其財務真實狀況、獲利能力及潛在風險。本次分析將基於公司最新的年報（10-K，截至2026年1月31日的財政年度，即FY25）及最新季報（8-K，截至2026年8月1日的第二財季，即Q2 FY26）數據。

### 1. 損益表分析 (Income Statement Analysis)

#### 營收成長動能
Build-A-Bear Workshop Inc. 在過去幾年展現了穩健的營收成長。
*   **年度趨勢：** 公司總營收從FY23的4.671億美元增長至FY24的4.964億美元，再進一步增長至FY25的5.298億美元。這顯示了連續的年度營收增長。
*   **最新季度：** 然而，最新季度數據顯示營收面臨壓力。Q2 FY26的總營收為1.153億美元，較Q2 FY25的1.242億美元下降了7.2%。上半財年（H1 FY26）總營收為2.406億美元，較H1 FY25的2.527億美元下降了4.8%。
*   **成長來源：** 根據公司報告，FY25的營收增長是來自於三個營運部門的增長。最新的Q2 FY26數據顯示，零售淨銷售額下降了7.1%，主要由於現有門店銷售額下降和電子商務需求減少，但新店開業部分抵消了這一影響。商業和國際特許經營收入合計增長了11.6%至2060萬美元，部分抵消了零售業務的下滑。公司在FY25淨增了64個全球體驗店，包括7個公司直營店、40個合作經營店和17個特許經營店。

#### 獲利能力與利潤率
*   **毛利率 (Gross Margin)：**
    *   FY25毛利為3.089億美元，毛利率為58.3% (308.9/529.8)。
    *   FY24毛利為2.894億美元，毛利率為58.3% (289.4/496.4)。
    *   FY23毛利為2.691億美元，毛利率為57.6% (269.1/467.1)。
    *   毛利率在過去三年保持相對穩定且較高水平，顯示公司在產品定價和成本控制方面表現良好。
    *   H1 FY26的綜合毛利為1.424億美元，毛利率為59.2% (142.361/240.6)。H1 FY25的綜合毛利為1.445億美元，毛利率為57.2% (144.497/252.7)。H1 FY26毛利率的提升主要得益於IEEPA關稅退款的影響，其中700萬美元與上一財年的成本相關。
*   **營業利益率 (Operating Margin)：**
    *   FY25營業利益（稅前收入）為6720萬美元，營業利益率為12.7% (67.2/529.8)。
    *   FY24營業利益為6710萬美元，營業利益率為13.5% (67.1/496.4)。
    *   FY23營業利益為6710萬美元，營業利益率為14.4% (67.1/467.1)。
    *   年度營業利益率呈現輕微下滑趨勢，儘管毛利率穩定，這可能與銷售、一般及行政費用(SG&A)的增長有關。
    *   H1 FY26稅前收入為3550萬美元，營業利益率為14.8% (35.5/240.6)。H1 FY25稅前收入為3490萬美元，營業利益率為13.8% (34.9/252.7)。H1 FY26營業利益率的提升主要歸因於較高的稅前收入和股數減少，部分被較高的稅率抵消。
*   **純益率 (Net Margin)：**
    *   FY25淨利為5020萬美元，純益率為9.5% (50.2/529.8)。
    *   FY24淨利為4980萬美元，純益率為10.0% (49.8/496.4)。
    *   FY23淨利為5000萬美元，純益率為10.7% (50.0/467.1)。
    *   純益率與營業利益率趨勢一致，顯示公司整體獲利能力在FY25略有收縮。
    *   Q2 FY26稀釋每股收益為0.70美元，而Q2 FY25為0.94美元。H1 FY26稀釋每股收益為2.16美元，而H1 FY25為2.11美元。

利潤率的穩定性在毛利率層面表現良好，但營業利益率和純益率在過去幾年略有波動，最新季度則呈現下滑。規模經濟效應可能受到SG&A費用增長的影響。

#### 費用控制
*   **SG&A佔比：**
    *   FY25 SG&A為2.417億美元，佔總營收的45.6% (241.7/529.8)。
    *   FY24 SG&A為2.223億美元，佔總營收的44.8% (222.3/496.4)。
    *   FY23 SG&A為2.020億美元，佔總營收的43.2% (202.0/467.1)。
    *   SG&A佔比逐年上升，這可能是導致營業利益率和純益率輕微下滑的原因。
    *   H1 FY26 SG&A為1.075億美元，佔總營收的44.7% (107.536/240.6)。H1 FY25 SG&A為1.099億美元，佔總營收的43.5% (109.954/252.7)。H1 FY26 SG&A佔比略有上升，但公司在Q2 FY26的SG&A費用下降了80個基點，主要由於激勵性薪酬費用降低以及利息收入增加。
*   **研發費用 (R&D)：** 財報中未單獨列出顯著的研發費用，這對於零售娛樂公司而言是常見的。費用主要集中在銷售、一般及行政開支。

SG&A費用的增長需要密切關注，以確保其與公司的成長策略（如新店擴張、品牌建設、電商投入）相符並帶來相應的營收效益。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

#### 回報率指標
*   **ROE (股東權益報酬率)：**
    *   FY25 ROE = 淨利5020萬美元 / 股東權益1.00億美元 = 50.2%。
    *   FY24 ROE = 淨利4980萬美元 / 股東權益9000萬美元 = 55.3%。
    *   提供的基本面數據顯示ROE為0.3281 (32.81%)。這與我根據財報計算的數據有較大差異，可能由於數據來源或計算時點不同。以財報數據為準，公司ROE非常高，顯示其為股東創造價值的能力強勁。
    *   **杜邦分析 (FY25)：**
        *   淨利潤率 (Net Profit Margin) = 50.2 / 529.8 = 9.5%
        *   資產周轉率 (Asset Turnover) = 529.8 / 200.0 = 2.65次
        *   權益乘數 (Equity Multiplier) = 200.0 / 100.0 = 2.0
        *   ROE = 9.5% * 2.65 * 2.0 = 50.35% (與直接計算結果一致)
    *   高ROE主要得益於健康的淨利潤率和較高的資產周轉率，以及適度的財務槓桿。
*   **ROIC (投入資本回報率)：**
    *   由於公司沒有長期帶息債務，其投入資本主要為股東權益。因此，ROIC會非常接近ROE。高ROIC表明公司投資資本的效益良好。
