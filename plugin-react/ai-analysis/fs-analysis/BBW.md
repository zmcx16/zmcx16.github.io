# Build A Bear Workshop Inc (BBW) 財務狀況全面拆解

作為一名資深美股分析師，我對Build-A-Bear Workshop Inc (BBW) 的財務報表進行了深入分析，旨在揭示其真實財務狀況、獲利能力及潛在風險。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**：
    Build-A-Bear Workshop Inc 的營收在過去五年呈現波動成長。2022財年營收達到4.1152億美元，實現了61.19%的顯著增長。隨後幾年成長速度放緩，2023財年增長13.71%至4.6794億美元，2024財年增長3.88%至4.8611億美元，2025財年增長2.12%至4.9640億美元，而2026財年則增長6.73%至5.2983億美元。然而，最新季度（2026年第三季度，截至2026年8月1日）的營收為1.153億美元，較上一季度下降8%，並較去年同期下降7.21%。這表明公司近期營收成長動能有所減弱，甚至出現負成長。公司營收主要來自直營店（DTC）零售銷售，包括電商平台，佔合併營收的92%（2025財年第三季度）。其成長策略包括實體店擴張（2024財年淨增64家店，2025財年預計淨增至少50家店）和電商發展。

*   **獲利能力與利潤率**：
    BBW的獲利能力表現穩健，但近期利潤率有輕微下降趨勢。
    *   **毛利率 (Gross Margin)**：截至2026年7月31日的過去十二個月（TTM）毛利率為56.69%，與提供的56.15%數據接近。過去三年平均為55%，五年平均為54%。高且相對穩定的毛利率顯示公司在產品定價和成本控制方面具有較強的實力，其產品可能擁有一定的品牌溢價。
    *   **營業利益率 (Operating Margin)**：TTM營業利益率為12.88%，與提供的12.34%數據接近。過去三年和五年平均均為13%。儘管整體穩定，但有分析指出其營業利益率呈現下降趨勢（從14%降至10%）。
    *   **純益率 (Net Margin)**：TTM純益率為9.96% (與提供的數據一致)。過去三年和五年平均均為11%。純益率也呈現下降趨勢（從11%降至10%）。
    整體而言，BBW的利潤率處於健康水平，但近期輕微的下降趨勢值得關注。高毛利率表明公司在市場上具有一定的競爭優勢。

*   **費用控制**：
    *   **銷售、一般及管理費用 (SG&A)**：2026年第三季度SG&A費用為5530萬美元，佔營收的45.1%。這個比例遠高於一般健康企業的15%-25%範圍。這可能暗示公司在銷售和管理費用方面存在效率問題，或者正在進行大量的行銷和擴張投資。對於零售業而言，SG&A佔比通常較高，但45.1%仍需仔細審視其合理性及對獲利的影響。
