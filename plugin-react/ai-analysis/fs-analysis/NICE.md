## NICE Ltd. ADR (NICE) 財務狀況全面拆解與健康評等

作為一名資深美股分析師，我將針對NICE Ltd. ADR (NICE) 的財務報表進行深入分析，以評估其財務真實狀況、獲利能力及潛在風險，並給出具體的財務健康評等。本次分析主要依據公司最新的2026年第二季度財報（截至2026年6月30日）以及過去幾年的年報數據。

---

### 1. 損益表分析 (Income Statement Analysis)

#### 營收成長動能
NICE的營收在過去幾年呈現穩健增長。從2021年的19.2億美元增長至2025年的29.454億美元，複合年增長率約為11.3%。截至2026年第二季度，公司報告營收為7.823億美元，較去年同期增長7.6%。最近十二個月（LTM）的營收達到30.7億美元。

營收增長主要受其雲端業務和AI解決方案的強勁需求推動。2026年第二季度，雲端營收達到6.09億美元，同比增長12.6%，佔總營收的78%。AI年度經常性收入（AI ARR）達到3.62億美元，佔雲端營收的15%，同比增長52%，顯示AI業務是重要的成長引擎。公司在2025年收購了對話式AI提供商Cognigy GmbH，這也為其AI能力和雲端平台CXone的增長提供了動力。

#### 獲利能力與利潤率
NICE的獲利能力在近期面臨壓力。
*   **毛利率 (Gross Margin)**：2026年第二季度，GAAP毛利率為64%，低於去年同期的66.8%。全年來看，2025年GAAP毛利率為66.4%，略低於2024年的66.7%。儘管雲端毛利率有所改善，但整體毛利率的下降反映了公司在AI轉型過程中，為爭取市場份額而採取的積極交易策略可能導致的盈利能力壓力。
*   **營業利益率 (Operating Margin)**：2026年第二季度，GAAP營業利益率顯著下降至13.3%，遠低於去年同期的22.1%。2025年全年GAAP營業利益率為21.9%，較2024年的20.0%有所提升。然而，最新季度的急劇下滑表明公司在營運費用控制或定價策略上可能存在挑戰，尤其是在AI解決方案競爭加劇的背景下。
*   **純益率 (Net Margin)**：2026年第二季度，GAAP淨利潤為8320萬美元，較去年同期的1.874億美元下降超過50%，導致稀釋每股收益從2.96美元降至1.40美元。純益率從2025年全年的20.78%下降至2026年第二季度的10.6%左右（83.2/782.3）。這反映了毛利率和營業利益率的雙重壓力。

整體而言，NICE的利潤率在過去幾年呈現擴張趨勢，但最新季度數據顯示其獲利能力正在惡化，這可能與其積極的AI轉型和市場競爭有關。規模經濟效應在雲端業務中有所體現，雲端毛利率有所改善，但整體盈利能力受到影響.

#### 費用控制
由於缺乏詳細的研發費用（R&D）和銷售與管理費用（S&A）佔比數據，我們主要從營業利益率的變化來推斷費用控制情況。2026年第二季度營業利益率的顯著下降（從22.1%降至13.3%） 表明費用可能未能與營收同步有效控制，或者公司正在加大對AI相關研發和市場推廣的投入。考慮到公司強調AI的增長動能和記錄的AI預訂量，加大研發和行銷投入以鞏固其在CXAI市場的領導地位是合理的策略，但短期內可能犧牲部分利潤。

### 2. 資產負債表分析 (Balance Sheet Analysis)

#### 資產品質與結構
截至2026年第二季度，NICE的總資產為51.2億美元。
*   **現金與短期投資佔比**：截至2026年第二季度，公司持有現金及短期投資3.547億美元。相對於總資產而言，現金佔比約為6.9%，顯示公司擁有一定的流動性儲備。
*   **應收帳款 (AR) 與存貨 (Inventory) 的周轉情況**：財報摘要中未提供應收帳款和存貨的具體數值，因此無法直接計算周轉率。然而，一般而言，軟體服務公司存貨較少，應收帳款周轉速度是關鍵。若營運現金流長期低於淨利，可能暗示應收帳款回收存在問題。
*   **存貨堆積或應收帳款回收過慢的風險**：目前數據不足以判斷。

#### 負債與償債能力
NICE的償債能力表現良好。
*   **流動性**：
    *   **流動比率 (Current Ratio)**：截至2026年第二季度，流動比率為1.33。這表示流動資產是流動負債的1.33倍，處於健康水平，表明公司有足夠的短期資產來覆蓋短期債務。
    *   **速動比率 (Quick Ratio)**：截至2026年第二季度，速動比率為1.08。這也表明公司在不依賴存貨的情況下，仍能有效應對短期債務，流動性良好。
*   **長期風險**：
    *   **債務佔資產比 (Total Debt/Assets)**：截至2026年第二季度，總債務為8822萬美元，總資產為51.2億美元。債務佔資產比約為1.7%，非常低。
    *   **債務對權益比 (Debt/Equity)**：截至2026年第二季度，債務對權益比為2.34%。這是一個極低的比例，表明公司主要依靠股東權益而非債務融資，財務槓桿風險極低。
    *   **債務結構（長短期）是否穩定**：公司在2026年第二季度末持有3.547億美元現金及短期投資，且幾乎沒有債務（8822萬美元），顯示其淨現金狀況非常健康。
*   **淨現金 (Net Cash) 狀況**：NICE在2026年第二季度末擁有3.547億美元的現金和短期投資，而總債務僅為8822萬美元，因此處於顯著的淨現金狀態，財務狀況非常穩健。

#### 無形資產與商譽
2025年10-K報告中提到「攤銷已收購無形資產」，這表明公司資產負債表上存在無形資產和商譽，這通常是軟體公司進行併購的結果。雖然具體數值未在摘要中提供，但鑑於公司在2025年進行了Cognigy的重大收購，商譽和無形資產可能佔總資產的較大比例。需要持續關注這些資產是否存在減損風險，尤其是在市場競爭加劇和AI技術快速迭代的背景下。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   2024年：8.3264億美元
*   2025年：7.1655億美元

營運產生的現金流在2024年達到高峰後，2025年有所下降，並在2026年第二季度繼續放緩。
*   **盈餘品質**：2026年第二季度，GAAP淨利潤為8320萬美元，而營業現金流為1.227億美元。營業現金流高於淨利潤，這通常是健康的跡象，表明公司的盈餘質量良好，淨利潤的實現伴隨著實際現金流入。然而，與去年同期相比，營業現金流的絕對值有所下降。

#### 自由現金流 (FCF)
*   **計算並分析 FCF (OCF - CapEx)**：
    *   2021年：4.37億美元
    *   2022年：4.478億美元
    *   2023年：5.322億美元
    *   2024年：7.977億美元

自由現金流在2024年達到峰值後，2025年下降12.5%至6.976億美元。2026年第二季度為9310萬美元，顯示公司仍能產生可觀的自由現金流，但季度環比和同比均有所下降。
*   **公司是否有足夠的現金用於擴張、派息或回購？** 儘管自由現金流有所下降，但公司仍有足夠的現金用於資本配置。NICE在2026年第二季度回購了5800萬美元的股票，年初至今已回購3.11億美元。這表明公司有能力通過股票回購向股東回報價值，同時也可能用於未來的擴張或併購。

#### 資本配置 (Capital Allocation)
*   **過去幾年資金主要投向哪裡？**
    *   **資本支出 (CapEx)**：NICE的資本支出相對較低且穩定，2025年為1892萬美元。這表明公司是輕資產運營模式，不需要大量的實物資產投資。
    *   **併購**：公司在2025年進行了Cognigy的重大收購，這會體現在投資現金流中。
    *   **償債**：公司債務水平極低，因此償債並非主要資金去向。
    *   **股份回購**：NICE積極進行股份回購，2026年第二季度回購5800萬美元，年初至今3.11億美元。這有助於提升每股收益，並向股東回報價值。
*   **資本配置的效率如何？** 公司將大部分現金流用於支持雲端和AI業務的增長，並通過股票回購回報股東。在AI轉型期間，對Cognigy等公司的收購是戰略性的，旨在增強其產品組合和市場競爭力。儘管短期盈利能力受壓，但這種資本配置策略旨在支持長期增長。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

#### 回報率指標
*   **ROE (股東權益報酬率)**：
    *   2025年GAAP淨利潤為6.121億美元，2025年股東權益為38.8億美元。
    *   2025年ROE = 612.1 / 3880 ≈ 15.77%。
    *   2026年第二季度LTM GAAP淨利潤為4.2545億美元，2026年第二季度股東權益為37.8億美元。
    *   2026年Q2 LTM ROE = 425.45 / 3780 ≈ 11.25%。
    *   **杜邦分析拆解 ROE (利潤率 x 周轉率 x 財務槓桿)**：
        *   **利潤率 (Net Profit Margin)**：2026年Q2 LTM為13.86% (425.45 / 3070)。較2025年的20.78%有所下降。
        *   **資產周轉率 (Asset Turnover)**：2026年Q2 LTM營收為30.7億美元，總資產為51.2億美元。資產周轉率 = 3070 / 5120 ≈ 0.60。
        *   **財務槓桿 (Equity Multiplier)**：2026年Q2 LTM總資產為51.2億美元，總權益為37.8億美元。財務槓桿 = 5120 / 3780 ≈ 1.35。
        *   **2026年Q2 LTM ROE ≈ 13.86% x 0.60 x 1.35 ≈ 11.22%**。
    *   ROE的下降主要歸因於淨利潤率的壓縮。資產周轉率和財務槓桿相對穩定且健康。

*   **ROIC (投入資本回報率)**：由於缺乏加權平均資本成本 (WACC) 的具體數據，無法精確計算ROIC與WACC的比較。然而，從其穩健的營業現金流和相對較低的資本支出來看，公司在投入資本方面的效率應屬良好。但隨著利潤率的下降，ROIC也可能面臨壓力。

#### 效率指標
*   **資產周轉率**：如上所述，2026年Q2 LTM資產周轉率約為0.60，表明資產利用效率一般，這對於軟體服務公司而言是常見的，因為其資產負債表上可能包含較多的無形資產。
*   **存貨周轉天數 (DIO) 與應收帳款周轉天數 (DSO)**：由於缺乏詳細的應收帳款和存貨數據，無法計算這些指標。但對於軟體服務公司，應收帳款周轉天數是更重要的效率指標。

**最終結論：**

2.  **核心摘要**：NICE Ltd.在雲端和AI領域展現出強勁的營收增長動能，並維持極高的償債安全性與健康的現金流。然而，公司在2026年第二季度面臨顯著的盈利能力壓力，毛利率和營業利益率均出現下滑，導致淨利潤大幅縮水。這反映了其在AI轉型和市場競爭加劇下的短期挑戰。儘管如此，其強勁的現金生成能力和低債務結構為其提供了應對這些挑戰的緩衝。
3.  **關鍵監測指標**：
    *   **GAAP 營業利益率 (Operating Margin)**：密切關注其在AI轉型期的變化，以評估公司在增長與盈利之間的平衡能力。
    *   **自由現金流利潤率 (Free Cash Flow Margin)**：監測公司將營收轉化為實際現金的能力，尤其是在營收增長放緩時。
    *   **AI 年度經常性收入 (AI ARR) 增長率**：評估其AI戰略的執行效果和市場接受度，這將是未來營收增長的核心驅動力。
