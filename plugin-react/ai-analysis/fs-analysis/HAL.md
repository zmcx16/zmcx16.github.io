# HAL (Halliburton Co) 財務分析報告

作為資深美股分析師，針對全球油田服務巨頭 Halliburton (HAL) 的最新財務狀況（結合 2023 年報及 2024 年前三季財報）進行深度拆解如下：

### 1. 損益表分析 (Income Statement Analysis)
- **營收成長動能**：
  - 2023 全年營收達 230 億美元，年增 13%。2024 年第三季營收為 57 億美元，與去年同期基本持平。
  - **動能來源**：成長動能已從北美轉向**國際市場**。北美市場因壓裂活動減少而出現個位數下滑，但國際營收（尤其是中東與拉丁美洲）持續強勁，抵消了北美疲軟。這顯示 HAL 成功透過全球佈局分散了地區性週期風險。
- **獲利能力與利潤率**：
  - **毛利率**：維持在約 18-20% 水準。
  - **營業利益率 (Operating Margin)**：2024 Q3 達 17.3%，表現穩健。
  - **純益率 (Net Margin)**：約 10-12%。
  - **規模經濟**：隨著數位化工具（如 iCruise, e-Power）的普及，服務效率提升，利潤率在營收持平的情況下仍能維持高位，顯示具備良好的成本轉嫁能力與規模經濟。
- **費用控制**：
  - SG&A 佔比穩定，研發費用專注於自動化與低碳技術，符合能源轉型趨勢，並未對短期獲利造成拖累。

### 2. 資產負債表分析 (Balance Sheet Analysis)
- **資產品質與結構**：
  - 截至 2024 Q3，現金及等價物約 21 億美元。
  - **周轉情況**：應收帳款周轉天數 (DSO) 維持在 65-70 天，存貨周轉穩定。在油服產業中，HAL 的資產變現效率屬於第一梯隊。
- **負債與償債能力**：
  - **流動性**：流動比率約 2.1，速動比率約 1.6，短期償債能力極佳。
  - **長期風險**：總債務約 76 億美元。債務對權益比 (D/E) 約 0.8，較過去幾年顯著下降。
  - **淨現金狀況**：雖然不是淨現金公司，但其 **Net Debt/EBITDA** 已降至約 1.1x，遠低於 2.0x 的警戒線，財務結構非常健康。
- **無形資產與商譽**：
  - 商譽約 20 億美元，佔總資產比例不高，且目前無重大減損跡象。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)
- **營業現金流 (OCF)**：
  - 2024 年前三季 OCF 表現強勁，盈餘品質高，OCF 與淨利高度同步，顯示獲利並非帳面數字，而是實質現金流入。
- **自由現金流 (FCF)**：
  - 2023 全年 FCF 達 23 億美元。2024 Q3 單季 FCF 約 5.4 億美元。
  - HAL 承諾將至少 50% 的 FCF 回饋股東，這在資本密集型的油服業中極具吸引力。
- **資本配置 (Capital Allocation)**：
  - **資本支出 (CapEx)**：嚴格控制在營收的 5-6% 左右，專注於高回報項目。
  - **股東回饋**：2024 Q3 透過股息與股份回購向股東發放了約 4.5 億美元。
  - **償債**：持續利用多餘現金償還高息債務，優化資產負債表。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)
- **回報率指標**：
  - **ROE (股東權益報酬率)**：目前約 25-28%。拆解來看，高 ROE 來自於穩定的純益率與高效的資產周轉，而非過度槓桿。
  - **ROIC (投入資本回報率)**：約 18%，遠高於其 WACC（約 9-10%），顯示公司具備創造超額價值的能力。
- **效率指標**：
  - 資產周轉率約 0.9x，在重資產行業中表現優異。

### 5. 財務健康總結

| 維度 | 評等 (1-5★) | 關鍵評語 (簡短扼要) |
| :--- | :--- | :--- |
| **獲利能力** | ★★★★☆ | 國際市場利潤率擴張，抵消北美疲軟。 |
| **償債安全性** | ★★★★☆ | 槓桿率持續下降，債務結構優化。 |
| **現金流品質** | ★★★★★ | FCF 產生能力極強，股東回饋慷慨。 |
| **資本效率** | ★★★★☆ | ROIC 遠超資本成本，資本配置精準。 |

**最終結論：**
1. **整體評級**：**優良**
2. **核心摘要**：HAL 目前處於財務最穩健的時期之一。儘管北美陸上活動放緩，但憑藉強大的國際市場競爭力與嚴格的資本紀律，公司維持了高水準的利潤率與現金流。資產負債表的去槓桿化已基本完成，使其在面對油價波動時具備極強的防禦性。
3. **關鍵監測指標**：
   - **International Revenue Growth**：觀察國際市場是否能持續填補北美缺口。
   - **Free Cash Flow Margin**：是否能維持在 10% 以上的高水準。
   - **Net Debt/EBITDA**：觀察是否持續維持在 1.2x 以下的健康區間。
