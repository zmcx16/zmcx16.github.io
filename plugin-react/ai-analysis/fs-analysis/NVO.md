### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Novo Nordisk在過去幾年展現了強勁的營收成長動能。
*   2021年淨銷售額為140,895百萬丹麥克朗。
*   2022年增長至176,954百萬丹麥克朗。
*   2023年進一步躍升至232,261百萬丹麥克朗。
這顯示2022年營收年增長率為25.6%，2023年為31.3% (以丹麥克朗計)。
最新季度數據顯示，2026年第一季度報告銷售額為96,823百萬丹麥克朗，較去年同期增長32% (按固定匯率CER計算)，主要受美國340B藥品定價計劃相關的準備金沖回268億丹麥克朗的非現金影響。若排除此一次性影響，調整後銷售額為70,063百萬丹麥克朗，按固定匯率計算下降4%，這反映了較低的實際價格，但部分被GLP-1產品的銷量增長所抵消。
營收增長主要來自於其GLP-1類糖尿病和肥胖症治療藥物（如Ozempic®和Wegovy®）的強勁需求和銷量增加。特別是肥胖症護理產品在2023年增長了147% (以丹麥克朗計)。2026年第一季度，Wegovy®口服藥在美國的推出表現強勁，總處方量超過200萬張，是美國GLP-1產品最強勁的銷量發布。

**獲利能力與利潤率**
Novo Nordisk的獲利能力和利潤率表現出色且穩定增長。
*   **毛利率 (Gross Margin)**：2023年毛利為196,900百萬丹麥克朗，毛利率約為84.86% (196,900 / 232,261)。2026年第一季度報告毛利為83,225百萬丹麥克朗，報告毛利率約為85.95% (83,225 / 96,823)。調整後毛利率為80.6%，顯示在剔除一次性項目後，毛利率仍保持在較高水平，但略有壓縮，這可能與產能擴張成本和負面匯率影響有關。
*   **營業利益率 (Operating Margin)**：
    *   2021年：41.59% (58,600 / 140,895)
    *   2022年：42.28% (74,809 / 176,954)
    *   2023年：44.16% (102,574 / 232,261)
    *   2026年第一季度報告營業利益率：61.56% (59,600 / 96,823)
    *   2026年第一季度調整後營業利益率：46.96% (32,900 / 70,063)
營業利益率呈現穩定擴張趨勢，表明公司在營收增長的同時，對營運成本的控制良好，並受益於規模經濟效應。即使在調整後，2026年第一季度的營業利益率仍接近歷史高位，顯示其核心業務的強勁獲利能力。
*   **純益率 (Net Margin)**：
    *   2021年：31.02% (43,700 / 140,895)
    *   2022年：31.38% (55,525 / 176,954)
    *   2023年：36.03% (83,683 / 232,261)
    *   2026年第一季度報告純益率：50.19% (48,600 / 96,823)
    *   2026年第一季度調整後純益率：38.50% (26,972 / 70,063) (基於調整後營業利潤和假設類似的稅費及財務項目計算)
純益率同樣呈現顯著增長，尤其在2023年和2026年第一季度（調整後），反映了公司強大的定價能力和高效的成本結構。

**費用控制**
*   **研發費用 (R&D)**：2026年第一季度研發費用為10,300百萬丹麥克朗。雖然缺乏歷史年度數據，但公司持續投資於研發，以推動新藥物和治療方案的開發，這與其作為創新驅動型製藥公司的成長策略相符。2026年第一季度研發費用佔調整後銷售額的比例約為14.7% (10,300 / 70,063)，顯示公司對未來增長的持續投入。
*   **行銷費用 (S&A)**：具體行銷費用數據未在搜尋結果中明確列出。然而，2026年第一季度財報提及，公司增加了對商業基礎設施的投資，特別是針對Wegovy®口服藥的推出，這表明行銷費用可能有所增加以支持新產品上市和市場擴張。
