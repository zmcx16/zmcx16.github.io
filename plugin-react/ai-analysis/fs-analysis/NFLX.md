作為一位資深美股分析師，我將對Netflix Inc (NFLX) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。

---

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Netflix的營收在過去幾年呈現穩健增長。2025財年總營收達到451.83億美元，較2024年的390.01億美元增長16%。2024年營收則較2023年的337.23億美元增長15.6%。最近一個季度，即2026年第二季度，營收為126億美元，同比增長13.4%。

營收成長主要來自於會員數量的增長、價格上調以及廣告業務的擴張。值得注意的是，Netflix在2025年停止報告會員數量，轉而專注於營收和營業利潤率作為主要財務指標。廣告收入在2025年超過15億美元，是2024年的2.5倍以上，並預計在2026年達到約30億美元。此外，Netflix於2025年12月4日簽訂協議，將以827億美元收購華納兄弟探索公司（WBD）的串流媒體和工作室業務（包括HBO Max和HBO），預計在12-18個月內完成，這將是未來重要的成長驅動力。

**獲利能力與利潤率**
Netflix的獲利能力顯著提升，利潤率呈現擴張趨勢。
*   **營業利潤率 (Operating Margin)**：從2023年的20.6%提升至2024年的26.7%，並在2025年進一步擴張至29.5%。2026年第二季度，營業利潤率為33.4%，儘管略低於2025年第二季度的34.1%，但仍顯示出強勁的獲利能力。公司預計2026財年全年營業利潤率將達到31.5%。
*   **淨利率 (Net Margin)**：2025財年淨利潤為109.81億美元，淨利率約為24.3%（109.81億美元 / 451.83億美元）。2024年淨利潤為87.12億美元，淨利率約為22.3%（87.12億美元 / 390.01億美元）。2023年淨利潤為54.08億美元，淨利率約為16.0%（54.08億美元 / 337.23億美元）。
利潤率的穩定擴張表明公司存在規模經濟效應，營收增長速度超過了銷貨成本、銷售與行銷費用以及一般與行政費用的增長。內容攤銷佔營收的比例從2022財年的44.4%下降到最近12個月（TTM）的35.8%，這也解釋了利潤率的提升。

**費用控制**
Netflix在費用控制方面表現良好。2025財年銷貨成本佔營收的比例為52%，低於2024年的54%。儘管內容攤銷費用在2025年增加了11.21億美元以支持現有和新內容，但整體成本控制仍有成效。然而，2026年第二季度，技術與開發費用以及銷售與行銷費用增長速度快於營收，導致營業利潤率同比略有下降。為應對此情況，Netflix於2026年10月宣布裁員約6%的全球員工，主要影響產品、技術、法律和人力資源團隊，旨在優化營運結構並提高人員效率。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2026年6月30日（2026年第二季度），Netflix的現金及短期投資為91.28億美元。總流動資產為138.53億美元。應收帳款為20.04億美元。由於Netflix主要提供串流服務，其業務模式不涉及實體存貨，因此沒有存貨堆積的風險。應收帳款周轉天數約為16.4天（基於2025年營收和應收帳款計算），顯示其應收帳款回收效率極高，符合訂閱制業務的特點。
公司最大的資產是內容資產，截至2025年底達到328億美元，這反映了其在內容創作和採購上的巨大投入。

**負債與償債能力**
*   **流動性**：Netflix的流動比率（Current Ratio）和速動比率（Quick Ratio）均為1.14。由於公司沒有實質存貨，這兩個比率相同。1.14的流動比率顯示公司短期償債能力尚可，但並非特別充裕。
*   **長期風險**：截至2026年6月30日，公司總債務為143億美元。債務佔權益比（Debt/Equity）為0.55，長期債務佔權益比（LT Debt/Eq）為0.46。這些比率顯示Netflix的債務水平處於合理範圍，並未過度依賴債務融資。
*   **淨現金 (Net Cash)**：截至2026年10月15日，Netflix處於淨負債狀態，淨現金為-75.3億美元，即每股-1.81美元。這表明其現金儲備不足以完全覆蓋所有債務。然而，公司在2025年通過償還債務減少了11.2億美元的債務。

**無形資產與商譽**
目前財報中未見商譽佔比過高的明確風險。然而，Netflix計劃以827億美元收購WBD的串流媒體和工作室業務，這筆交易規模龐大，一旦完成，很可能會在資產負債表上產生大量的商譽，未來需密切關注其減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
Netflix的營業現金流（OCF）呈現增長趨勢。2025財年OCF為101.49億美元，較2024年的73.61億美元和2023年的72.74億美元有顯著提升。2026年上半年，OCF達到70億美元，其中包含了來自取消與WBD交易的28億美元終止費。
營業現金流與淨利潤的關係：2025財年淨利潤為109.81億美元，而OCF為101.49億美元，兩者相對接近。這表明公司的盈餘品質良好，淨利潤大部分轉化為實際現金流入。營業現金流的波動主要受非現金調整的影響，特別是內容資產和負債的變動。

**自由現金流 (FCF)**
Netflix的自由現金流（FCF）表現強勁。2025財年FCF為95億美元，較2024年的69億美元增長36.7%。截至2026年6月30日的過去12個月（TTM），FCF達到112億美元。這顯示公司有充足的現金用於業務擴張、償債或股東回報。
公司在2025年投入了171億美元的現金內容投資，2026年上半年則投入了98億美元。儘管內容投資巨大，但強勁的OCF使其仍能產生可觀的FCF。

**資本配置 (Capital Allocation)**
Netflix的資本配置策略主要集中在內容投資和股權回購。
*   **內容投資**：公司持續大量投資於全球內容，特別是原創節目。
*   **股份回購**：2025年回購了8653.6萬股普通股，耗資91億美元。2026年上半年回購了6640萬股，耗資59億美元。截至2026年上半年，仍有271億美元的回購授權額度。
*   **償債**：2025年通過償還債務減少了11.2億美元的債務。
*   **股息**：公司目前沒有派發現金股息，且預計在可預見的未來也不會派發。
Netflix的資本配置效率較高，將大部分自由現金流用於回購股票，這有助於提升股東價值。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：初始數據顯示為49.54%。根據2025財年數據，ROE為42.8%，而截至2026年6月30日的TTM ROE為49.5%。高ROE表明公司為股東創造了卓越的回報。
    *   **杜邦分析拆解ROE**：
        *   **淨利率 (Net Margin)**：2025年為24.3%。
        *   **資產周轉率 (Asset Turnover)**：TTM為0.87。
        *   **權益乘數 (Financial Leverage)**：根據Debt/Equity 0.55，權益乘數約為1.55 (1 + 0.55)。
        *   ROE = 淨利率 x 資產周轉率 x 權益乘數 = 24.3% x 0.87 x 1.55 ≈ 32.7%。這與實際ROE 42.8% (FY2025) 或 49.5% (TTM) 存在差異，可能由於數據來源和計算時間點不同。但核心趨勢是高淨利率和適度槓桿共同推動了高ROE。
*   **ROIC (投入資本回報率)**：初始數據顯示為31.11%。截至2026年10月15日的TTM ROIC為32.43%。
    *   **WACC (加權平均資本成本)**：截至2026年10月14日，Netflix的WACC為9.99%。
    *   ROIC (32.43%) 遠高於WACC (9.99%)，這是一個非常積極的信號，表明Netflix的投資資本效率極高，能夠為股東創造顯著的經濟價值。

**效率指標**
*   **資產周轉率 (Asset Turnover)**：TTM為0.87。這表示每1美元資產能產生0.87美元的營收，對於內容密集型公司而言，效率尚可。
*   **存貨周轉天數 (DIO)**：不適用，因為Netflix沒有實體存貨。
*   **應收帳款周轉天數 (DSO)**：約16.4天（基於2025年營收和應收帳款計算）。極低的DSO表明公司能迅速收回客戶款項，現金流轉化效率高。

**最終結論：**
1.  **整體評級**：穩健
2.  **核心摘要**：Netflix展現出強勁的獲利能力和卓越的資本效率，營收持續增長且利潤率不斷擴張，自由現金流充裕並有效用於股權回購。儘管流動性略顯保守且處於淨負債狀態，但其穩健的營業現金流和高效的內容投資策略有效支撐了財務健康。即將進行的WBD收購將是未來成長的關鍵，但也需關注其對負債和商譽的影響。
3.  **關鍵監測指標**：
    *   **營業利潤率 (Operating Margin)**：監測其能否維持擴張趨勢，尤其是在內容投資和廣告業務增長的情況下。
    *   **自由現金流利潤率 (Free Cash Flow Margin)**：關注其能否持續保持高水平，以支持未來的擴張和股東回報。
    *   **淨債務/EBITDA (Net Debt/EBITDA)**：在WBD收購完成後，密切關注此指標，以評估公司槓桿水平的變化和償債壓力。
