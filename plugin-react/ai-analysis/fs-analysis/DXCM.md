# DXCM (Dexcom Inc) 財務報表深度分析報告

### 1. 損益表分析 (Income Statement Analysis)
*   **營收成長動能**：
    Dexcom 在 2024 年第三季度的營收為 9.94 億美元，較去年同期增長 11%。雖然相較於過去幾年 20-25% 的高成長有所放緩，但這主要受到美國銷售團隊重組及回扣（Rebate）政策調整的短期影響。成長核心仍來自於 **G7 系統** 的全球普及以及針對非胰島素依賴型二型糖尿病患者推出的 **Stelo (OTC)** 產品。銷量（Volume）增長依然強勁，顯示市場滲透率持續提升。
*   **獲利能力與利潤率**：
    *   **毛利率 (Gross Margin)**：維持在 64.18% 的高水準。儘管面臨產品更迭（G6 轉 G7）的成本壓力，但透過自動化生產與規模經濟，毛利率保持穩定。
    *   **營業利益率 (Operating Margin)**：約 23.98%。隨著營收規模擴大，營運槓桿效應顯現，營業利益率較往年有明顯擴張趨勢。
    *   **純益率 (Profit Margin)**：19.41%。公司已進入穩定的獲利期，不再是早期燒錢擴張的階段。
*   **費用控制**：
    研發費用 (R&D) 佔比約 12-15%，這對於維持 CGM（連續血糖監測）技術領先至關重要。行銷費用 (S&A) 雖然因 Stelo 上市有所增加，但整體佔營收比重受控，顯示管理層在擴張與獲利間取得了良好平衡。

### 2. 資產負債表分析 (Balance Sheet Analysis)
*   **資產品質與結構**：
    截至 2024 年第三季，Dexcom 持有約 24.7 億美元的現金、現金等價物及有價證券。應收帳款周轉天數 (DSO) 保持穩定，存貨周轉率良好，未見明顯的庫存積壓風險。
*   **負債與償債能力**：
    *   **流動性**：流動比率 1.74，速動比率 1.4，顯示短期償債能力極佳，無流動性危機。
    *   **長期風險**：總債務約 23.9 億美元，主要為可轉換公司債。債務對權益比 (Debt/Equity) 為 0.55，處於健康區間。
    *   **淨現金狀況**：現金儲備與總債務基本持平，淨債務接近於零，財務結構非常穩健。
*   **無形資產與商譽**：
    商譽佔總資產比例極低，資產負債表相對「乾淨」，不存在大規模資產減損的潛在威脅。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)
*   **營業現金流 (OCF)**：
    OCF 持續增長且與淨利同步，顯示盈餘品質極高。2024 年前三季度的營運現金流入強勁，足以支撐其資本支出與擴張需求。
*   **自由現金流 (FCF)**：
    P/FCF 為 28.79，反映市場對其現金產生能力給予較高估值。FCF 轉正且持續擴大，使公司有能力進行非有機成長（併購）或回饋股東。
*   **資本配置 (Capital Allocation)**：
    *   **資本支出 (CapEx)**：主要投入於馬來西亞等地的產能擴建，以降低長期生產成本。
    *   **股份回購**：公司近期執行了大規模的股份回購計畫（如 2024 年宣布的 7.5 億美元回購案），顯示管理層認為股價被低估，並致力於提升股東價值。
    *   **併購與研發**：資金優先投向技術升級與進入新市場（如 OTC 市場）。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)
*   **回報率指標**：
    *   **ROE (37.67%)**：表現極為優異。拆解來看，高 ROE 來自於高純益率 (19.4%) 與適度的財務槓桿，而非過度舉債。
    *   **ROIC (25.36%)**：遠高於其加權平均資本成本 (WACC，估計約 8-10%)，顯示公司每投入一塊錢資本都能創造超額回報，具備強大的競爭護城河。
*   **效率指標**：
    資產周轉率穩定，顯示公司在管理醫療器材設備資產方面具有高效能。

**最終結論：**
1. **整體評級**：**優良**
2. **核心摘要**：Dexcom 展現了典型的成長型藍籌股財務特徵。儘管營收增速因市場基數擴大及內部調整短期放緩，但其獲利能力（ROE 37%）與現金流產生能力極強。資產負債表穩健，淨現金狀況良好，且透過 Stelo 成功切入 OTC 市場，長期增長邏輯依然清晰。
3. **關鍵監測指標**：
    *   **Free Cash Flow Margin**：觀察 FCF 佔營收比重是否持續提升。
    *   **Stelo 營收貢獻度**：監測新產品在 OTC 市場的滲透速度。
    *   **Non-GAAP Operating Margin**：觀察銷售團隊重組後，營運效率是否如預期回升。
