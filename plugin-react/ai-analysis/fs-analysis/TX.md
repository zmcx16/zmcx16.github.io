# Ternium S.A. (TX) 財務深度分析報告

### 1. 損益表分析 (Income Statement Analysis)
*   **營收成長動能**：
    Ternium (TX) 2024 年第三季營收為 47.6 億美元，較去年同期微增 1%，主要受惠於墨西哥市場的出貨量增長（年增 5%），抵銷了南美地區（尤其是阿根廷）因宏觀經濟不穩導致的需求疲軟。過去 3-5 年，營收呈現週期性波動，目前的成長動能主要來自於**銷量驅動**而非價格，因為全球鋼價仍處於相對低位。
*   **獲利能力與利潤率**：
    *   **毛利率 (Gross Margin)**：目前約 16.13%，較歷史高點有所回落，反映了原料成本（鐵礦砂、能源）與鋼材售價之間的利差收窄。
    *   **營業利益率 (Oper. Margin)**：6.46%，顯示公司在成本控制上仍具競爭力，但受制於高昂的折舊費用與營運成本。
    *   **純益率 (Profit Margin)**：3.66%。雖然利潤率目前處於週期低谷，但隨著墨西哥新產能（如 Pesquería 廠）的規模經濟逐步顯現，利潤率具備擴張潛力。
*   **費用控制**：
    銷售與管理費用 (S&A) 保持穩定，公司並無大規模研發支出（鋼鐵業特性），主要支出集中於優化生產流程與環保合規。

### 2. 資產負債表分析 (Balance Sheet Analysis)
*   **資產品質與結構**：
    TX 擁有強大的資產負債表。現金與短期投資充足。存貨周轉天數保持在行業合理區間，未見明顯的存貨堆積風險。應收帳款 (AR) 品質良好，主要客戶為汽車與家電製造商，信用風險較低。
*   **負債與償債能力**：
    *   **流動性**：流動比率 (Current Ratio) 為 2.63，速動比率 (Quick Ratio) 為 1.53，顯示短期償債能力極佳，資金極其充裕。
    *   **長期風險**：債務對權益比 (Debt/Equity) 僅為 0.25，長期債務佔比低 (0.19)，這在資本密集型的鋼鐵業中屬於極其保守且健康的財務結構。
    *   **淨現金狀況**：公司維持強勁的淨現金頭寸，為未來的資本支出與股息發放提供了厚實的緩衝。
*   **無形資產與商譽**：
    商譽佔總資產比例極低，不存在重大的資產減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)
*   **營業現金流 (OCF)**：
    TX 的 OCF 表現穩健，2024 年前三季產生的現金流足以支撐其營運。盈餘品質高，OCF 通常能覆蓋淨利，顯示利潤具備真實的現金支撐。
*   **自由現金流 (FCF)**：
    目前 FCF 受到較大壓力，主因是公司正處於**高資本支出週期**。TX 正在墨西哥進行大規模投資（預計 2024 全年 CapEx 約 18 億美元），用於建設新的熱軋與冷軋產線。雖然短期 FCF 減少，但這是為了長期市佔率與成本優勢的戰略性投入。
*   **資本配置 (Capital Allocation)**：
    *   **資本支出**：主要投向墨西哥的產能擴張。
    *   **股息與回購**：公司維持約 4.08% 的高股息率，顯示其在擴張期仍注重股東回報。
    *   **效率**：資本配置聚焦於高成長的北美市場（USMCA 區域），策略清晰。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)
*   **回報率指標**：
    *   **ROE (4.64%)**：目前較低，拆解原因為：低純益率 (3.66%) x 中等資產周轉率 x 低財務槓桿 (1.3x)。這反映了公司目前處於「低槓桿、高投入、行業週期底部」的狀態。
    *   **ROIC (3.88%)**：略低於 WACC，顯示目前投資回報受鋼鐵週期壓制，需等待新產能投產後的效益釋放。
*   **效率指標**：
    資產周轉率穩定，存貨管理效率優於同業平均，顯示其在供應鏈管理上的優勢。

**最終結論：**
1. **整體評級**：**優良**
2. **核心摘要**：TX 是一家財務極其穩健的週期性龍頭。儘管全球鋼鐵環境波動，公司憑藉極低的負債率 (D/E 0.25) 與強大的現金儲備，成功支撐其在墨西哥的大規模擴張計劃。目前股價低於帳面價值 (P/B 0.87)，且具備 4% 以上的股息支撐，具備高度的安全邊際。
3. **關鍵監測指標**：
    *   **EBITDA per Ton**：監測單位獲利能力是否隨鋼價回升而改善。
    *   **CapEx 進度**：墨西哥新廠房的投產時程是否符合預期。
    *   **阿根廷宏觀風險**：南美業務的匯兌損益與需求恢復狀況。
