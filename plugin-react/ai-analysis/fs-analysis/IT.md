### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    Gartner的營收在過去幾年呈現穩定增長，但近期成長動能有所放緩。
    *   2021年營收：約47.4億美元 (根據2022年成長率推算)
    *   2022年營收：54.8億美元 (年增15.67%)
    *   2023年營收：59.1億美元 (年增7.87%)
    *   2024年營收：62.7億美元 (年增6.1%)
    *   2025年營收：65.0億美元 (年增3.7%)
    *   截至2026年3月31日的過去十二個月 (TTM) 營收：64.7億美元 (年增2.3%)
    *   2026年第一季度營收：15.1億美元 (年減1.5%)

    從數據來看，Gartner的營收成長率從2022年的雙位數放緩至2025年的3.7%和2026年第一季度的負成長。營收成長主要來自其核心的「洞察 (Insights)」業務，該業務貢獻了近90%的毛利，透過訂閱制研究、分析師諮詢和高階主管指導來服務客戶。然而，近期成長放緩受到宏觀經濟和地緣政治逆風的影響，特別是美國聯邦政府業務的逆風在2025年對整體合約價值 (CV) 成長造成近300個基點的衝擊。公司預計2026年合約價值成長將加速，因應這些逆風的影響逐漸減弱。

*   **獲利能力與利潤率**
    Gartner展現出強勁的獲利能力，但近期利潤率有所波動。
    *   截至2026年3月31日的TTM數據：
        *   毛利率 (Gross Margin)：68.99%
        *   營業利益率 (Operating Margin)：16.4%
        *   純益率 (Net Margin)：11.44%
    *   2025財年數據：
        *   營業利益率：15.8%
        *   純益率：11%

    毛利率長期維持在約69%的高水準，顯示其研究和諮詢服務具有強大的定價能力和規模經濟效益。營業利益率在2025年為15.8%，TTM略升至16.4%，顯示核心營運獲利能力相對穩健。然而，2025年淨利潤為7億美元，較2024年下降42%，主要受較高費用影響。2025年第三季度，公司因數位市場 (Digital Markets) 報告單位產生1.5億美元的商譽減損費用，導致當季營業利益和淨利大幅下降。

*   **費用控制**
    雖然沒有具體的研發費用 (R&D) 和行銷費用 (S&A) 佔比數據，但營業利益率的變化可以間接反映費用控制情況。2025年營業利益率從2024年的22.14%下降至14.90%，這表明費用支出相對營收有所增加，部分原因可能與上述的商譽減損以及其他營運費用上升有關。公司正透過業務和技術洞察轉型計畫，專注於影響力、數量、及時性和使用者體驗，並積極利用AI技術提升客戶參與度，這可能涉及相關的投資支出。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**
    截至2026年3月31日 (TTM)：
    *   現金及約當現金：16.67億美元
    *   總流動資產：36.48億美元
    *   應收帳款：14.12億美元
    Gartner的現金部位充足，短期投資佔比合理。由於其業務模式主要為服務業，不涉及大量存貨，因此存貨周轉率不適用。應收帳款佔流動資產的比例較高，需要持續關注其回收情況，以避免潛在的壞帳風險。

*   **負債與償債能力**
    *   **流動性**
        截至2026年3月31日 (TTM)：
        *   總流動負債：38.86億美元
        *   流動比率 (Current Ratio)：0.94
        流動比率低於1，顯示其短期償債能力存在一定壓力，流動資產不足以完全覆蓋流動負債。這可能與其預收收入 (Unearned Revenue) 較高有關，預收收入在2026年3月31日為30.19億美元，是其最大的流動負債項目之一。預收收入雖然是負債，但代表未來服務的承諾，通常是訂閱制商業模式的健康指標。
    *   **長期風險**
        截至2026年3月31日 (TTM)：
        *   總債務：約29.83億美元 (長期債務29.78億美元 + 流動負債中的500萬美元)
        *   股東權益：約5.15億美元 (總資產76.55億美元 - 總負債71.40億美元)
        *   債務對權益比 (Debt/Equity)：約5.79 (29.83億美元 / 5.15億美元)
        Gartner的債務對權益比相對較高，顯示公司在資本結構上較為依賴債務融資。儘管如此，公司在2025年成功發行了投資級債券，增加了槓桿，並回購了大量股票，這表明管理層對其償債能力有信心。截至2026年3月31日，公司淨現金狀況為負13.16億美元 (現金16.67億美元 - 總債務29.83億美元)，顯示為淨負債狀態。

*   **無形資產與商譽**
    截至2026年3月31日 (TTM)：
    *   商譽 (Goodwill)：27.40億美元
    商譽佔總資產的比例較高，約為35.8% (27.40億美元 / 76.55億美元)。2025年第三季度，公司因數位市場業務的長期盈利預測調整，確認了1.5億美元的商譽減損損失。這表明公司需要持續監測其無形資產的價值，以避免未來進一步的減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**
    *   截至2026年3月31日 (TTM) 營業現金流：13.68億美元
    *   2025財年營業現金流：12.90億美元 (年減13%)
    *   2024財年營業現金流：14.85億美元
    *   2023財年營業現金流：11.56億美元
    *   2022財年營業現金流：11.01億美元
    *   2021財年營業現金流：13.12億美元

    Gartner的營業現金流在過去幾年保持強勁，通常高於其淨利潤，顯示其盈餘品質良好。例如，截至2026年3月31日的TTM淨利潤為7.41億美元，而營業現金流為13.68億美元，這表明公司將淨利潤有效地轉化為現金。2025年營業現金流較2024年有所下降，但仍維持在13億美元左右的健康水平。

*   **自由現金流 (FCF)**
    *   截至2026年3月31日 (TTM) 自由現金流：約12.58億美元 (營業現金流13.68億美元 - 資本支出1.10億美元)
    *   2025財年自由現金流：11.75億美元 (年減15%)
    *   2024財年自由現金流：13.83億美元
    *   2023財年自由現金流：10.53億美元
    *   2022財年自由現金流：9.93億美元
    *   2021財年自由現金流：12.53億美元

    Gartner的自由現金流在過去幾年也表現出色，儘管2025年有所下降，但TTM仍維持在12.58億美元的水平。公司過去十年的自由現金流利潤率約為17.4%。充足的自由現金流為公司提供了靈活性，可用於擴張、償債、派息或回購股票。

*   **資本配置 (Capital Allocation)**
    Gartner在資本配置方面積極回報股東。
    *   **股份回購**：2025年回購了700萬股普通股，耗資20億美元，使流通股數量年減8%。2025年第三季度，公司回購了400萬股，耗資11億美元。董事會於2026年1月增加了5億美元的股票回購授權。
    *   **資本支出**：相對穩定且較低，2025年為1.15億美元，TTM為1.10億美元。這反映了其輕資產的商業模式。
    *   **償債**：公司在2025年透過首次投資級債券發行增加了槓桿，部分資金可能用於償還其他債務或支持回購。
    *   **併購/剝離**：公司已達成最終協議，將剝離其數位市場業務。

    Gartner的資本配置效率較高，透過大規模股票回購有效提升了股東價值，同時保持了健康的自由現金流。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**
    *   **ROE (股東權益報酬率)**：
        截至2026年3月31日 (TTM)：94.88%。2025財年：227.95%。
        如此高的ROE主要歸因於其相對較低的股東權益基礎 (約5.15億美元，截至2026年3月31日)，這可能是由於公司長期以來的大規模股票回購和累積利潤分配導致。透過杜邦分析拆解，高ROE反映了強勁的淨利潤率和高財務槓桿。
    *   **ROIC (投入資本回報率)**：
        截至2026年3月31日：13.49%。截至2025年第四季度：超過20%。截至2026年3月31日 (TTM)：48.81%。
        ROIC數據存在一定差異，但即使採用較保守的13.49% (截至2026年3月)，仍高於其加權平均資本成本 (WACC) 7.77% 或 9.33%。這表明Gartner能夠有效地利用其投入資本創造價值，其投資效益超過了資本成本，是一個高效的企業。

*   **效率指標**
    *   資產周轉率 (Asset Turnover)：截至2026年3月31日 (TTM) 為0.80。這表示每1美元的資產能產生0.80美元的營收，對於服務型公司而言是合理的。
    *   應收帳款周轉天數 (DSO)：雖然沒有直接數據，但應收帳款佔總資產的比例需要關注，以確保現金回收效率。
