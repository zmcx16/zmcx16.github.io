## Gartner, Inc. (IT) 財務狀況全面拆解與健康評等

作為一名資深美股分析師，我將對Gartner, Inc. (IT) 的財務狀況進行全面深入的分析，並結合其最新財報數據，評估其獲利能力、償債安全性、現金流品質及資本效率，最終給出具體的財務健康評等。

### 1. 損益表分析 (Income Statement Analysis)

Gartner主要透過研究 (Research)、會議 (Conferences) 和諮詢 (Consulting) 三大業務板塊提供服務。

-   **營收成長動能**
    根據最新的財報數據，Gartner在2025財年實現了65億美元的總營收，較2024年的62.67億美元增長了4%。若以FX中性計算，2025年營收增長約為3%。
    
    回顧過去幾年，Gartner的營收呈現穩健增長趨勢：
    *   2025年：65億美元 (年增4%)
    *   2024年：62.67億美元 (年增6%)
    *   2023年：59億美元 (年增8%)
    *   2022年：54.5億美元 (根據2023年10-K推算)
    *   2021年：47.3億美元 (根據2023年10-K推算)
    
    從最新季度來看，2026年第二季度總營收為17億美元，較2025年同期下降0.6% (FX中性下降1.6%)，但調整後營收增長2.8%。這一下降主要受到剝離Digital Markets業務的影響。分部門看，Insights (研究) 業務營收增長2.1%至12.9億美元，Conferences (會議) 業務營收大幅增長15.5%至2.44億美元，而Consulting (諮詢) 業務營收則下降8.8%至1.42億美元。
    
    營收成長主要來自於其訂閱制的研究服務，該服務在2024年和2023年分別佔總營收的約77%和76%。會議業務在2024年也實現了15%的增長，得益於更高的參展商和與會者收入。諮詢業務在2024年增長9%，主要來自合約優化服務。整體而言，Gartner的成長動能主要來自其核心訂閱制研究服務的客戶擴展和續約，以及會議業務的強勁復甦。

-   **獲利能力與利潤率**
    Gartner的獲利能力在過去幾年保持相對穩定，但最新年度和季度數據顯示一些波動。
    
    *   **毛利率 (Gross Margin)**：
        根據提供的基本面數據，Gartner的毛利率為66.7%。從2025年10-K報告來看，Insights業務的毛利率在2025年為77%，與2024年持平。2026年第二季度，Insights業務的貢獻毛利率為77.5%，Conferences為59.5%，Consulting為37.9%。整體毛利率相對較高且穩定，顯示其知識型服務的成本結構優勢。
    
    *   **營業利益率 (Operating Margin)**：
        提供的基本面數據顯示營業利益率為18.79%。
        2025年，營業收入為10.26億美元，較2024年下降11%，主要受1.5億美元商譽減損損失和銷售、一般及行政費用增加的影響。這導致2025年的營業利益率有所承壓。
        2026年第二季度，營業收入為3.785億美元，較去年同期有所改善。營業利益率為22.6%，高於去年同期的19.4%。
    
    *   **純益率 (Net Margin)**：
        提供的基本面數據顯示純益率為11.99%。
        2025年淨利為7.29億美元，較2024年下降42%，主要受商譽減損損失和所得稅費用增加的影響。稀釋後每股盈餘 (Diluted EPS) 從2024年的16.00美元降至2025年的9.65美元。
        2026年第二季度淨利為2.755億美元，較去年同期增長14.4%。稀釋後每股盈餘為4.14美元，較去年同期增長33.1%。
    
    整體而言，Gartner的利潤率在核心業務上保持穩定，但非經常性項目（如2025年的商譽減損）會對淨利潤產生較大影響。規模經濟效應在其高毛利率的研究業務中有所體現。

-   **費用控制**
    *   **銷售、一般及行政費用 (SG&A)**：
        2025年，SG&A費用有所增加，對營業收入造成壓力。
        22026年第二季度，SG&A費用有所下降，有助於營業收入的改善。
    *   **研發費用 (R&D)**：
        財報中未單獨列出研發費用，通常包含在服務開發成本中。Gartner持續投資於AI工具和專家洞察，以提升客戶參與度和內部效率。這些投資與其成長策略相符，旨在強化其核心研究產品的競爭力。

-   **負債與償債能力**

        提供的基本面數據中，債務佔資產比 (Total Debt/Assets) 和債務對權益比 (Debt/Equity) 均為"-"。

        淨現金狀況：考慮到現金和債務，Gartner的淨債務水平需要進一步計算，但其穩定的現金流有助於支持債務償還。
    
-   **無形資產與商譽**

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**
    Gartner的營業現金流表現強勁。
    *   2025年全年營業現金流為13億美元，較2024年下降13%。
    *   2024年全年營業現金流為15億美元，較2023年增長28%。
    *   2023年全年營業現金流為12億美元，較2022年增長5%。
    
    最新季度，2026年第二季度營業現金流為3.98億美元，較去年同期增長3.8%。
    
    **盈餘品質**：Gartner的營業現金流通常與淨利潤同步增長，甚至更高。例如，2023年自由現金流轉換率為GAAP淨利的122%。這表明其盈餘品質良好，淨利潤有堅實的現金流支持。

-   **自由現金流 (FCF)**
    自由現金流 (FCF) = 營業現金流 (OCF) - 資本支出 (CapEx)。
    *   2025年全年自由現金流為12億美元，較2024年下降15%。
    *   2024年全年自由現金流為14億美元，較2023年增長31%。
    *   2023年全年自由現金流為11億美元，較2022年增長6%。
    
    最新季度，2026年第二季度自由現金流為3.78億美元，較去年同期增長8.9%。
    
    Gartner擁有充足的自由現金流，這使其能夠支持業務擴張、股息支付（儘管目前不派發股息）和股份回購。

-   **資本配置 (Capital Allocation)**
    Gartner在資本配置上主要側重於股份回購和戰略性投資。
    *   **股份回購**：
        2026年第二季度，公司回購了360萬股普通股，耗資5.47億美元。
        2025年全年，公司回購了700萬股普通股，耗資約20億美元，使流通股數量同比減少8%。
        2024年全年，公司回購了160萬股普通股，耗資約7億美元，使流通股數量同比減少1%。
        董事會於2026年7月將股票回購授權增加了5億美元。
    *   **資本支出**：
        2024年第三季度資本支出為2600萬美元。
    *   **償債**：
        公司通過發行新債券來管理和調整債務結構，並償還部分現有債務。
    
    Gartner的資本配置效率較高，通過大規模股份回購有效提升了股東回報，同時保持了健康的現金流水平。
