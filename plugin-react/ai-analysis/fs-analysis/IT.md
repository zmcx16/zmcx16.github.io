## Gartner, Inc. (IT) 財務狀況全面拆解與健康評等

作為資深美股分析師，我將對Gartner, Inc. (IT) 的財務狀況進行深入分析，涵蓋損益表、資產負債表、現金流量表及核心財務指標，並據此給出具體的財務健康評等。

### 1. 損益表分析 (Income Statement Analysis)

Gartner主要透過其洞察 (Insights)、會議 (Conferences) 和諮詢 (Consulting) 三大業務板塊提供服務。

-   **營收成長動能**：
    Gartner的營收在過去幾年呈現穩健成長，但最新季度有所放緩。
    *   **年度營收趨勢**：
        *   2025年：64.97億美元，較2024年成長4%。
        *   2024年：62.70億美元，較2023年成長6%。
        *   2023年：59.00億美元，較2022年成長8%。
        *   2022年：54.80億美元。
    *   **最新季度營收**：
        *   2026年第一季度：15.11億美元，較2025年第一季度的15.34億美元下降1.5%。
    營收成長主要來自於Insights和Conferences業務的推動。2025年，歐洲、中東和非洲地區的營收成長12%，其他國際市場成長5%，顯示北美以外市場的強勁表現。然而，2026年第一季度營收出現小幅下滑，主要受外匯中性基礎上-4.3%的影響，儘管Insights業務營收仍成長3.1%。公司在2025年出售了Digital Markets業務，這也影響了營收結構。

-   **獲利能力與利潤率**：
    Gartner的獲利能力在2025年受到商譽減損的顯著影響。
    *   **毛利率 (Gross Margin)**：
        *   2026年第一季度：總營收15.11億美元，服務和產品開發成本4.29億美元，毛利約10.82億美元，毛利率約71.6%。
        *   2025年第一季度：總營收15.34億美元，服務和產品開發成本4.75億美元，毛利約10.59億美元，毛利率約69.0%。
        *   Insights業務的毛利率在2025年和2024年均為77%，保持穩定。
    *   **營業利益率 (Operating Margin)**：
        *   2025年：營業利益10.26億美元，營業利益率為15.8% (1026/6497)。
        *   2024年：營業利益11.53億美元 (推算)，營業利益率為18.4% (1153/6270)。
        *   2026年第一季度：營業利益3.16億美元，營業利益率為20.9% (316/1511)。
        *   2025年第一季度：營業利益2.78億美元，營業利益率為18.1% (278/1534)。
    *   **純益率 (Net Margin)**：
        *   2025年：淨利7.29億美元，純益率為11.2% (729/6497)。
        *   2024年：淨利12.54億美元，純益率為20.0% (1254/6270)。
        *   2023年：淨利8.82億美元，純益率為14.9% (882/5900)。
        *   2026年第一季度：淨利2.223億美元，純益率為14.7% (222.3/1511)。
        *   2025年第一季度：淨利2.109億美元，純益率為13.7% (210.9/1534)。
    利潤率在2025年因1.5億美元的商譽減損損失而大幅下降。排除此一次性影響，核心業務的獲利能力相對穩定，且2026年第一季度營業利益率和純益率均有所提升，顯示費用控制和營運效率的改善。Gartner的Insights業務貢獻了近90%的毛利，且其毛利率高達77%，顯示其核心訂閱服務具有強大的規模經濟效應.

-   **費用控制**：
    *   **銷售、一般及行政費用 (SG&A)**：
        *   2026年第一季度：7.263億美元。
        *   2025年第一季度：7.303億美元。
    *   **服務和產品開發成本 (Cost of services and product development)**：
        *   2026年第一季度：4.293億美元。
        *   2025年第一季度：4.750億美元。
    2026年第一季度，Gartner的服務和產品開發成本以及SG&A費用均較去年同期有所下降，這有助於提升其營業利益率和淨利率. 費用控制似乎與公司策略相符，尤其是在營收略有下降的情況下，費用下降有助於維持獲利能力。

### 2. 資產負債表分析 (Balance Sheet Analysis)

-   **資產品質與結構**：
    *   **現金與短期投資**：截至2025年12月31日，Gartner擁有17億美元的現金及現金等價物。截至2026年3月31日，現金及現金等價物為16.67億美元。這顯示公司擁有充足的流動性。
    *   **應收帳款 (AR) 與存貨 (Inventory)**：Gartner作為服務型公司，存貨通常不顯著。截至2026年3月31日，應收帳款淨額為14.11億美元，較2025年3月31日的16.85億美元有所下降。應收帳款的下降可能表明收款效率的提升或營收結構的變化。
    *   **無形資產與商譽**：截至2026年3月31日，商譽為27.40億美元，無形資產淨額為3.16億美元。2025年，公司因Digital Markets業務產生了1.5億美元的商譽減損損失。商譽佔總資產比重較高，且曾發生減損，這是一個需要持續關注的風險點。

-   **負債與償債能力**：
    *   **流動性**：
        *   **流動比率 (Current Ratio)**：
            *   2026年第一季度：流動資產36.48億美元 / 流動負債38.86億美元 = 0.94。
            *   2025年第一季度：流動資產40.66億美元 / 流動負債40.72億美元 = 1.00。
            流動比率略低於1，表明短期償債能力較為緊張，但對於以訂閱服務為主的Gartner，其遞延收入（Deferred Revenues）佔流動負債的很大一部分（2026年Q1為30.19億美元），這部分負債並非現金流出，而是未來提供服務的義務，因此實際流動性可能優於表面數字。
        *   **速動比率 (Quick Ratio)**：
            *   2026年第一季度：(現金16.67億 + 應收帳款14.11億) / 流動負債38.86億 = 0.79。
            *   2025年第一季度：(現金17.23億 + 應收帳款16.85億) / 流動負債40.72億 = 0.84。
            速動比率也顯示短期流動性一般，但同樣受遞延收入的影響。
    *   **長期風險**：
        *   **長期債務**：截至2026年3月31日，長期債務淨額為29.78億美元。
        *   **債務對權益比 (Debt/Equity)**：需要計算股東權益。
            *   截至2026年3月31日，總負債 (流動負債38.86億 + 長期債務29.78億 + 營運租賃負債2.76億 + 其他負債4.52億) = 75.92億美元。
            *   截至2026年3月31日，總資產 (流動資產36.48億 + 不動產2.05億 + 營運租賃使用權資產2.22億 + 商譽27.40億 + 無形資產3.16億 + 其他資產5.24億) = 71.55億美元。
            *   股東權益 = 總資產 - 總負債 = 71.55億 - 75.92億 = -4.37億美元。
            Gartner的股東權益為負值，這是一個重大警訊，表明公司資產不足以覆蓋其負債。這通常是由於持續的股份回購導致股本減少，以及累積虧損或商譽減損等因素造成。負股東權益使得債務對權益比無法有效計算，但其本身已反映出較高的財務風險。
        *   **淨現金 (Net Cash)**：公司在2025年發行了8億美元的優先票據，並償還了部分債務。儘管現金儲備充足，但考慮到龐大的債務總額和負股東權益，Gartner的淨現金狀況並非理想。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**：
    *   2025年：13億美元，較2024年下降13%。
    *   2024年：15億美元，較2023年成長28%。
    *   2023年：12億美元，較2022年成長5%。
    *   2026年第一季度：3.91億美元，較2025年第一季度的3.14億美元成長24.7%。
    *   **盈餘品質**：2025年營業現金流下降，而淨利潤也大幅下降，但OCF仍高於淨利潤（13億美元 vs 7.29億美元），表明盈餘品質尚可，非現金費用（如折舊攤銷、商譽減損）對淨利潤影響較大。2026年第一季度OCF顯著成長，且高於淨利潤，顯示良好的盈餘品質.

-   **自由現金流 (FCF)**：
    *   2025年：12億美元，較2024年下降15%。
    *   2024年：14億美元，較2023年成長31%。
    *   2023年：11億美元，較2022年成長6%。
    *   2026年第一季度：3.71億美元，較2025年第一季度的2.88億美元成長28.7%。
    Gartner持續產生可觀的自由現金流，這表明公司有足夠的現金用於營運、擴張和回報股東。儘管2025年FCF有所下降，但2026年第一季度強勁反彈，顯示其現金生成能力依然強勁.

-   **資本配置 (Capital Allocation)**：
    *   **股份回購**：Gartner積極進行股份回購。2025年回購了700萬股普通股，總計約20億美元。2024年回購了160萬股，總計約7億美元。2023年回購了180萬股，總計約6億美元。2026年第一季度回購了330萬股，總計5.35億美元。公司董事會還在2026年1月增加了5億美元的股票回購授權。
    *   **償債**：2025年發行了8億美元的新債，並償還了2.744億美元的2024年信貸協議下的債務。
    *   **資本支出 (CapEx)**：2026年第一季度，OCF為3.91億美元，FCF為3.71億美元，因此CapEx約為2000萬美元 (391-371)。這表明其資本支出相對較低，符合其輕資產的服務模式。
    Gartner的資本配置策略明顯傾向於透過大規模股份回購來回報股東，這也是導致股東權益為負的主要原因。雖然這可以提升每股盈餘，但也增加了財務槓桿和風險。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

-   **回報率指標**：
    *   **ROE (股東權益報酬率)**：由於股東權益為負，ROE無法有效計算，且負ROE通常被視為極差的表現。然而，這主要是由於公司積極的股份回購導致股東權益帳面價值為負，而非持續虧損。
    *   **ROIC (投入資本回報率)**：由於缺乏WACC和詳細的投入資本數據，無法精確計算。但從其穩定的營業現金流和自由現金流來看，核心業務的資本運用效率應屬良好。

-   **效率指標**：
    *   **資產周轉率**：
        *   2025年：營收64.97億美元 / 總資產 (Q1 2026總資產71.55億美元作為參考) = 約0.91次。
        Gartner作為服務型公司，資產周轉率通常不會像製造業那樣高。
    *   **存貨周轉天數 (DIO)**：不適用，Gartner為服務型公司，無顯著存貨。
    *   **應收帳款周轉天數 (DSO)**：
        *   2026年第一季度：(應收帳款14.11億 / 營收15.11億) * 90天 = 約84天。
        *   2025年第一季度：(應收帳款16.85億 / 營收15.34億) * 90天 = 約99天。
        應收帳款周轉天數有所改善，表明收款效率有所提升。

Gartner, Inc. (IT) 是一家全球領先的資訊科技研究與顧問公司，其財務表現深受其訂閱制商業模式和全球經濟環境影響。

### 整體評級：穩健

**核心摘要**：
Gartner展現出穩健的營收成長能力，尤其在Insights核心業務上表現強勁。儘管2025年因商譽減損導致淨利潤大幅下滑，但其營業現金流和自由現金流持續保持高水準，顯示強大的現金生成能力和盈餘品質。公司積極透過股份回購回報股東，但這也導致股東權益為負，增加了財務槓桿風險。短期流動性比率雖低於1，但考慮到遞延收入的特性，實際流動性風險可控。長期來看，其核心業務的穩定性和現金流能力是其財務健康的基石。

**關鍵監測指標**：
1.  **Contract Value (CV) 成長率**：作為Gartner未來營收的領先指標，CV的持續成長對其長期表現至關重要。
2.  **自由現金流利潤率 (Free Cash Flow Margin)**：衡量公司將營收轉化為可供分配現金的能力，尤其在積極回購股票的背景下，其可持續性值得關注。
3.  **淨債務/調整後EBITDA (Net Debt/Adjusted EBITDA)**：由於股東權益為負，此指標能更客觀地評估公司的償債能力和財務槓桿水平。
