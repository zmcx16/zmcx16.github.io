Gartner, Inc. (NYSE: IT) 是一家領先的技術研究與顧問公司，其財務表現受到市場高度關注。以下將針對其損益表、資產負債表、現金流量表進行全面分析，並評估其財務健康狀況。

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    Gartner的營收在過去幾年呈現穩健成長，但近期增速有所放緩。2021年至2025年，公司年營收從47.3億美元增長至65.0億美元，年複合成長率約為8.3%。具體來看，2022年營收增長15.67%，2023年增長7.87%，2024年增長6.10%，2025年則放緩至3.67%。
    最新季度（2026年第一季度）營收為15.11億美元，較去年同期下降1.5%（按報告匯率），若排除匯率影響則下降4.3%。這顯示公司面臨一定的營收壓力，儘管其Insights（洞察）業務仍是主要收入來源，佔總營收的絕大部分，且其毛利率穩定在77%。公司在2025年舉辦了53場實體會議，較2024年的51場有所增加，但總出席人數略有下降。營收成長主要來自Insights和Conferences業務的推動。

*   **獲利能力與利潤率**
    Gartner的獲利能力在2025年受到一次性因素影響而有所波動，但核心業務的利潤率保持相對穩定。
    *   **毛利率 (Gross Margin)**：2025財年為68.8%，較2024財年的68.3%略有提升。截至2026年第一季度，過去十二個月 (TTM) 的毛利率為69.3%。這顯示公司在提供服務方面的成本控制良好，具有較高的定價能力。
    *   **營業利益率 (Operating Margin)**：2025財年為14.90%，較2024財年的22.14%顯著下降。這主要是由於2025年產生了1.5億美元的商譽減損損失以及銷售、一般及管理費用增加。截至2026年第一季度，TTM營業利益率為15.34%。
    *   **純益率 (Net Margin)**：2025財年為11.2%，較2024財年的20.0%大幅下降。這同樣受到商譽減損損失和較高所得稅費用的影響。截至2026年第一季度，TTM純益率為11.4%。
    儘管2025年淨利潤因減損而大幅下降42%至7.29億美元，但調整後的EBITDA在2025年仍增長4%至16億美元，顯示其核心營運獲利能力依然穩健。2026年第一季度淨利潤為2.22億美元，同比增長5.4%。

*   **費用控制**
    2025年，Gartner的營業費用因商譽減損損失而顯著增加，導致營業利益下降。然而，公司管理層強調其靈活的成本管理策略，並持續投資於關鍵領域（如專家、AI、QBH）以推動未來營收增長。研發費用和行銷費用佔比的具體數據未直接提供，但從調整後EBITDA的增長來看，公司在費用控制和策略性投資之間尋求平衡。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **資產品質與結構**
    截至2026年3月31日（2026年第一季度），Gartner的現金及約當現金為16.67億美元。總流動資產為36.48億美元，總資產為76.55億美元。應收帳款和存貨周轉情況未直接提供，但作為一家研究和顧問公司，其存貨通常較少。

*   **負債與償債能力**
    Gartner的負債水平相對較高，但其現金流覆蓋能力良好。
    *   **流動性**：截至2026年3月31日，總流動資產為36.48億美元，而總流動負債為38.86億美元。這使得流動比率約為0.94 (36.48億/38.86億)，略低於1，表明短期資產未能完全覆蓋短期負債。速動比率（Quick Ratio）在提供的數據中為0.84，與流動比率接近，顯示其流動性存在一定壓力。
    *   **長期風險**：截至2026年3月31日，公司總負債為75.9億美元，長期債務為29.78億美元。由於股東權益僅為6340萬美元，導致其債務對權益比 (Debt/Equity) 高達4706.2%。然而，這種極高的比率主要是由於公司積極的股份回購導致股東權益大幅減少。更具參考價值的是淨債務對EBITDA比率，2025財年為1.32倍，顯示其槓桿水平在可控範圍內，尤其考慮到其強勁的現金流生成能力。
    *   **淨現金狀況**：截至2025年12月31日，Gartner擁有17.23億美元的現金及約當現金。公司目標維持約5億美元的營運現金，並將槓桿比率目標設定在2-2.5倍。

*   **無形資產與商譽**
    截至2026年3月31日，Gartner的商譽為27.40億美元。2025年，公司因Digital Markets業務產生了1.5億美元的商譽減損損失。這表明公司需要持續監測其無形資產的價值，以避免進一步的減損風險。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

*   **營業現金流 (OCF)**
    Gartner的營業現金流表現強勁。2025財年，營業現金流為12.9億美元，較2024財年的14.8億美元下降13%。然而，2026年第一季度營業現金流顯著增長24.7%至3.91億美元。公司營運產生的現金通常高於其淨利潤，這表明其盈餘品質良好。例如，2025財年淨利潤為7.29億美元，而營業現金流為12.9億美元。

*   **自由現金流 (FCF)**
    Gartner的自由現金流同樣表現出色。2025財年自由現金流為12億美元，較2024財年下降15%。2026年第一季度自由現金流大幅增長28.7%至3.71億美元。公司預計2026年自由現金流將達到11.35億美元或更高，並預期自由現金流轉換率為GAAP淨利潤的140%。這表明公司有充足的現金用於擴張、償債和股東回報。

*   **資本配置 (Capital Allocation)**
    Gartner積極透過股份回購向股東返還資本。2025年，公司回購了700萬股普通股，總計約20億美元，使流通股數量同比減少8%。2026年第一季度，公司進一步回購了330萬股普通股，耗資5.35億美元。此外，董事會於2026年4月將股份回購授權增加了6億美元。
    在債務管理方面，2025年公司發行了3.5億美元2031年到期的高級票據和4.5億美元2035年到期的高級票據，並利用部分收益償還了2.744億美元的2024年信貸協議未償款項。公司透過首次投資級債券發行增加了槓桿，以支持進一步的股份回購能力。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

*   **回報率指標**
    *   **ROE (股東權益報酬率)**：Gartner的ROE極高。2025財年為227.95%。如此高的ROE主要是由於公司積極的股份回購導致股東權益基數非常小。
        *   **杜邦分析拆解 (2025財年)**：
            *   **淨利率 (Net Profit Margin)**：11.2%
            *   **資產周轉率 (Asset Turnover)**：0.8x
            *   **權益乘數 (Equity Multiplier)**：由於股東權益極低，權益乘數會非常高，從而放大ROE。
        這表明公司在利用其資產產生銷售和控制成本方面表現良好，但其高ROE更多是財務槓桿的結果，而非單純的營運效率。
    *   **ROIC (投入資本回報率)**：Gartner的ROIC表現優異。2025財年為48.9%，截至2026年第一季度TTM為57.5%。這遠高於公司截至2026年6月13日的加權平均資本成本 (WACC) 9.54%，表明公司能夠有效地利用其投入資本產生超額回報。

*   **效率指標**
    *   **資產周轉率 (Asset Turnover)**：2025財年為0.8x，顯示公司資產利用效率尚可。
    *   **存貨周轉天數 (DIO)** 和 **應收帳款周轉天數 (DSO)**：作為服務型公司，存貨周轉率通常不適用。應收帳款周轉天數未直接提供，但其訂閱制業務模式有助於穩定現金流。

1.  **整體評級**：**穩健**
2.  **核心摘要**：Gartner展現出穩健的營運獲利能力和卓越的現金流生成能力，尤其在訂閱制Insights業務的支撐下，毛利率保持高位。儘管2025年因商譽減損導致淨利潤大幅下滑，且近期營收增速放緩，但其調整後EBITDA和自由現金流依然強勁。公司積極透過股份回購回報股東，並有效利用資本創造價值。其高負債對權益比主要是會計層面股東權益為負所致，實際槓桿水平（淨債務對EBITDA）仍屬健康。
3.  **關鍵監測指標**：
    *   **Contract Value (CV) 成長率**：作為訂閱制業務的領先指標，CV的加速成長將是未來營收動能的關鍵。
    *   **自由現金流利潤率 (Free Cash Flow Margin)**：持續監測其自由現金流佔營收的比例，以評估公司產生可支配現金的能力。
    *   **淨債務對調整後EBITDA比率 (Net Debt/Adjusted EBITDA)**：密切關注此槓桿指標，確保公司在積極回購股票的同時，維持健康的債務水平。
