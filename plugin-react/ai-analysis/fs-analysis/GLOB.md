# Globant S.A. (GLOB) 財務狀況全面拆解

### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**
    Globant S.A.近年來展現出穩健的營收增長。2023年營收達到20.96億美元，年增長率為17.7%。2024年營收預計在24.05億至24.40億美元之間，預期年增長率為14.7%至16.4%。2025年營收達到24億美元的紀錄。截至2026年第二季度，過去十二個月的總營收達到25億美元。然而，最新季度（2026年第二季度）的營收為6.144億美元，與去年同期相比基本持平，且2026年第三季度營收預計將年減1.6%至0.3%，顯示近期增長動能有所放緩。

    公司將其增長歸因於AI專業知識、行業專業化和全球佈局。特別是其AI Pods業務，在2026年第二季度實現了5280萬美元的年度經常性收入（ARR），環比增長61%，並預計到2026年底ARR將不低於1.1億美元，成為新的增長引擎。客戶集中度方面，2026年第二季度前十大客戶佔總營收的30.6%，顯示對大客戶的依賴性較高。

*   **獲利能力與利潤率**
    Globant的獲利能力在近期面臨壓力。IFRS毛利率從2022年的37.6%下降至2023年的36.1%，並在2026年第二季度進一步降至33.9%。這一下降趨勢可能受到拉丁美洲貨幣走強和法定成本增加的影響。

    IFRS營業利益率波動較大，從2022年的11.6%降至2023年的9.5%，在2025年第二季度一度降至1.0%，隨後在2026年第二季度回升至3.2%。非IFRS調整後的營業利益率在2026年第二季度為13.2%，低於2025年第二季度的15.0%。

    IFRS稀釋每股盈餘（EPS）在2026年第二季度為0.04美元，相較於2025年第二季度的負0.05美元有所改善，實現了微薄的淨利潤。然而，2023年全年IFRS稀釋EPS為3.64美元，2022年為3.47美元，顯示年度盈利能力仍較強，但季度表現波動較大。公司管理層預期AI Pods將帶來更高的利潤率。

*   **費用控制**
    財報中未直接提供研發費用 (R&D) 與行銷費用 (S&A) 的具體佔比數據。然而，營業利益率的波動間接反映了公司在費用控制或策略性投資方面的動態。公司在AI領域的積極投入，如AI Pods的開發和推廣，表明其在研發和市場拓展方面存在持續的策略性支出。

### 2. 資產負債表分析 (Balance Sheet Analysis)

*   **負債與償債能力**
    *   **流動性**：根據提供的基本面數據，流動比率 (Current Ratio) 和速動比率 (Quick Ratio) 均為1.84。這些比率表明公司擁有健康的短期償債能力，能夠有效應對短期債務。
    *   **長期風險**：債務對權益比 (Debt/Equity) 為0.25，長期債務對權益比 (LT Debt/Eq) 為0.22。這些比率相對較低，顯示公司對債務的依賴程度不高，長期償債風險較小。截至2024年3月31日，公司已從7.25億美元的信貸額度中提取1.05億美元，表明仍有充足的融資空間。
