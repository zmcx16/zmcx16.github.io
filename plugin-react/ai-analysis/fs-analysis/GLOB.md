### 1. 損益表分析 (Income Statement Analysis)

-   **營收成長動能**：
    Globant S.A.在過去幾年展現了強勁的營收成長。從2020財年到2024財年，公司營收的複合年均成長率 (CAGR) 約為31%，從8.1414億美元增長至24.2億美元，顯著超越同業如Accenture和Infosys的成長率。然而，近兩年營收成長速度已明顯放緩，從超高速成長轉為較為溫和的雙位數成長。
    
    2025財年，Globant的年營收達到24.549億美元，年增長率為1.6%。最新季度數據顯示，2026年第一季度營收為6.071億美元，較去年同期下降0.7%。公司預計2026財年全年營收將在24.62億美元至25.08億美元之間，年增長率預計為0.3%至2.2% (包含100個基點的匯率正面影響)。
    
    營收成長主要來自於其數位和認知轉型服務的需求，特別是近年來積極推動的AI原生服務和AI Pods模式，這些新服務和AI工具的嵌入正在提升其價值鏈，並在大型客戶中推動AI相關專案的增長。

-   **獲利能力與利潤率**：
    Globant的獲利能力和利潤率在過去幾年呈現穩定但未見顯著擴張的趨勢，且相較於行業領導者仍有差距。
    *   **毛利率 (Gross Margin)**：截至2026年3月31日的過去十二個月 (LTM) 毛利率為34.91%。2025財年IFRS毛利率為35.0%，較2024財年的35.7%有所下降。2026年第一季度IFRS毛利率為34.5%，略低於2025年第一季度的34.9%。非IFRS調整後毛利率在2021年達到38.21%的峰值後，至2024年下降至36.26%，顯示出利潤率壓縮而非擴張的趨勢。
    *   **營業利益率 (Operating Margin)**：LTM營業利益率為10.07%。2025財年IFRS營業利益率為7.0%，較2024財年的9.3%顯著下降。2026年第一季度IFRS營業利益率為8.5%，略高於2025年第一季度的8.2%。非IFRS調整後營業利益率在過去五年介於10.5%至12.4%之間波動，並在2022年達到12.39%的峰值後，於2024年降至10.53%。這表明公司在規模經濟方面尚未展現出持續的利潤率擴張能力，且利潤率水平低於Infosys (約21%) 和Accenture (約15%) 等同業。
    *   **純益率 (Net Margin)**：LTM純益率為4.46%。2026年第一季度調整後淨利潤率為10.7%。2025財年IFRS稀釋後每股盈餘 (EPS) 為2.29美元，較2024財年的3.72美元大幅下降。
    整體而言，Globant的利潤率雖然穩定，但並未呈現擴張趨勢，且在某些年份有所壓縮，這可能反映了市場競爭加劇或成本結構的變化。

-   **費用控制**：
    2026年第一季度，銷售、一般及管理費用 (SG&A) 佔營收的18.5%。雖然具體的研發費用佔比未直接提供，但作為一家技術服務公司，研發和創新投入對於維持競爭力至關重要。公司強調其AI原生服務和AI Pods的發展，這暗示了在技術創新方面的持續投入。費用控制對於維持其在成長放緩期的獲利能力至關重要。

### 2. 資產負債表分析 (Balance Sheet Analysis)

-   **資產品質與結構**：
    截至2026年3月31日，Globant的現金及約當現金和短期投資為2.005億美元。截至2026年第一季度，總資產為32.7億美元，較2025年第四季度減少1.59%。無形資產方面，公司擁有約19億美元的無形資產。作為一家服務型公司，其應收帳款周轉情況和存貨水平通常不是主要風險點，但應收帳款的回收效率仍需關注。

-   **負債與償債能力**：
    *   **流動性**：LTM流動比率為1.82，另一來源顯示為1.64。這表明公司擁有足夠的流動資產來覆蓋短期負債，流動性狀況健康。速動比率未直接提供，但考慮到其服務性質，存貨佔比可能不高，因此速動比率應與流動比率接近。
    *   **長期風險**：截至2026年3月31日，公司總負債為10.7億美元，較2025年第四季度減少7.08%。LTM總債務為4.6267億美元。債務佔資產比和債務對權益比 (Debt/Equity) 方面，LTM債務對權益比為0.21，另一來源顯示為21.80%。截至2025年3月，淨債務約為1.67億美元。截至2026年3月31日，公司現金為2.005億美元，總債務為4.6267億美元，淨現金狀況為負2.6213億美元。儘管存在淨債務，但債務對權益比相對健康，且利息覆蓋倍數為8倍，表明其償債能力良好。

-   **無形資產與商譽**：
    Globant的無形資產約為19億美元。對於一家依賴品牌、技術和客戶關係的服務公司而言，無形資產佔比較高是常見現象。然而，高額無形資產，尤其是商譽，若未來業務表現不佳，可能存在減損風險。目前數據未直接指出減損風險，但鑑於其成長放緩及利潤率壓縮，這是一個需要持續關注的指標。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**：
    截至2026年3月31日的過去十二個月，營業現金流為3.3992億美元。2025財年，公司實現了「有史以來最強勁的自由現金流」。2026年第一季度，營業現金流與淨利潤同步增長，顯示出良好的盈餘品質。

-   **自由現金流 (FCF)**：
    截至2026年3月31日的過去十二個月，資本支出為負1619萬美元，自由現金流為3.2373億美元。2026年第一季度，自由現金流為3610萬美元，這是自2019年以來首次在第一季度實現正自由現金流，自由現金流與調整後淨利潤的比率超過55%。這表明公司有足夠的現金用於營運、擴張，並有能力回報股東。

-   **資本配置 (Capital Allocation)**：
    Globant在資本配置方面表現出紀律性。公司在2026年第一季度投資了5000萬美元用於股票回購計畫，並宣布了一項新的1.25億美元回購計畫，以持續向股東回報價值。這表明公司在產生強勁自由現金流的同時，也積極通過股份回購來提升股東價值。過去幾年，資金主要投向有機增長和戰略性併購，以擴大其服務範圍和市場份額。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

-   **回報率指標**：
    *   **ROE (股東權益報酬率)**：截至2026年3月31日的過去十二個月ROE為5.20%。2026年3月ROE為7.02%，低於其十年中位數10.19%。
        *   **杜邦分析拆解 (LTM)**：
            *   淨利潤率 (Net Profit Margin): 4.46%
            *   資產周轉率 (Asset Turnover): (營收 $2.45B / 平均總資產 $3.27B) = ~0.75x (估算)
            *   權益乘數 (Equity Multiplier): (平均總資產 $3.27B / 平均股東權益 $2.2B) = ~1.49x (估算)
            *   ROE = 4.46% * 0.75 * 1.49 = ~4.98% (與5.20%接近，差異可能來自數據時間點或計算方式)
        ROE的下降主要受淨利潤率和資產周轉率的影響，表明公司在利用資產產生銷售和將銷售轉化為利潤方面的效率有所下降。
    *   **ROIC (投入資本回報率)**：截至2026年3月31日的過去十二個月ROIC為7.52%。2026年3月ROIC為5.66%。公司的加權平均資本成本 (WACC) 為9.04%或8.59%。由於ROIC (5.66%-7.52%) 低於WACC (8.59%-9.04%)，這表明Globant目前未能有效創造股東價值，其投資資本的效益未能超過其資本成本。

-   **效率指標**：
    *   **資產周轉率**：根據LTM營收24.5億美元和Q1 2026總資產32.7億美元估算，資產周轉率約為0.75倍。這表明公司資產利用效率一般。
    *   **存貨周轉天數 (DIO)** 和 **應收帳款周轉天數 (DSO)**：具體數據未直接提供。作為服務型公司，存貨通常不顯著。應收帳款周轉天數則需進一步分析以評估現金回收效率。

    *   **自由現金流利潤率 (Free Cash Flow Margin)**：評估公司產生現金的能力，以及其是否能持續支持擴張和股東回報，尤其是在營收成長趨緩的背景下。
