### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Globant S.A. 在過去幾年展現了顯著的營收成長。根據最新的財報數據，公司在2025財年實現了24.55億美元的營收，相較於2024財年的24.16億美元有所增長。然而，最新的季度數據顯示成長動能有所放緩。2026年第二季度的營收為6.144億美元，與去年同期基本持平。2026年上半年營收為12.215億美元，略低於2025年上半年的12.253億美元。

公司管理層將營收成長放緩歸因於新市場的疲軟、旅遊業的影響以及北美地區決策速度變慢。此外，公司向AI Pods的轉型也暫時影響了營收的報告。儘管如此，Globant的長期營收複合年增長率（2014-2025年）高達25.6%，顯示其在數位轉型和軟體服務領域的強勁歷史表現。公司積極推動AI相關業務，Glob.AI的年度經常性收入（ARR）在2026年第二季度達到5280萬美元，環比增長61%，並預計在2026年底前達到不低於1.1億美元。這表明公司正積極尋求新的成長引擎。

**獲利能力與利潤率**
Globant的獲利能力在近期面臨壓力，但長期來看仍保持穩健。
*   **毛利率 (Gross Margin)**：2026年第二季度的IFRS毛利率為33.9%，低於2025年同期的35.4%。非IFRS調整後毛利率為36.5%，也低於2025年同期的38.1%。2025財年的IFRS毛利率為34.9%，非IFRS調整後毛利率為37.6%。毛利率的下降主要受到外匯逆風、利用率降低以及一次性業務優化費用3230萬美元的影響。
*   **營業利益率 (Operating Margin)**：2026年第二季度的IFRS營業利益率為3.2%，相較於2025年同期的1.0%有所改善。非IFRS調整後營業利益率為13.2%，低於2025年同期的15.0%。2025財年的IFRS營業利益率為9.7%，非IFRS調整後營業利益率為15.5%。調整後營業利益率的下降同樣受到上述因素的影響。
*   **純益率 (Net Margin)**：2ant S.A. 2026年第二季度的IFRS稀釋每股盈餘為0.04美元，相較於2025年同期的虧損0.05美元有所改善。非IFRS調整後稀釋每股盈餘為1.40美元，低於2025年同期的1.53美元。2025財年的IFRS稀釋每股盈餘為0.93美元，非IFRS調整後稀釋每股盈餘為1.54美元。根據2026年第二季度調整後淨利潤6030萬美元和營收6.144億美元計算，調整後淨利率約為9.8%。

利潤率的波動顯示公司在當前宏觀經濟環境和業務轉型期面臨挑戰，但調整後的利潤率仍保持在相對健康的水平。規模經濟效應可能因市場逆風和轉型成本而暫時不明顯。

**費用控制**
公司在2026年第二季度啟動了一項業務優化計劃，包括勞動力調整和辦公室整合，產生了3230萬美元的一次性費用。這表明公司正在積極控制費用以應對挑戰並提升效率。雖然具體的研發費用 (R&D) 和銷售與管理費用 (S&A) 佔比未在最新摘要中詳細列出，但營業利益率的變化已反映了費用控制的整體情況。在營收成長放緩的背景下，有效的費用控制對於維持獲利能力至關重要。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**
*   **ROE (股東權益報酬率)**：根據提供的基本面數據，ROE為0.0536 (5.36%)。考慮到2026年第二季度IFRS稀釋每股盈餘僅為0.04美元，以及2025財年IFRS稀釋每股盈餘為0.93美元，其股東權益報酬率相對較低，可能受到淨利潤波動的影響。
    *   **杜邦分析拆解 (基於2025財年數據，假設股東權益為22億美元，營收24.55億美元，淨利潤約為0.93美元 * 43.18百萬股 = 40.15百萬美元 (基於2025年EPS和約43.18百萬股流通股))**：
        *   淨利潤率 (Net Profit Margin) = 淨利潤 / 營收 = 40.15M / 2455M ≈ 1.64%
        *   資產周轉率 (Asset Turnover) = 營收 / 總資產 = 2455M / 3200M ≈ 0.77
        *   權益乘數 (Equity Multiplier) = 總資產 / 股東權益 = 3200M / 2200M ≈ 1.45
        *   ROE = 淨利潤率 x 資產周轉率 x 權益乘數 = 1.64% x 0.77 x 1.45 ≈ 1.83%
        這個計算結果與提供的5.36%有較大差異，可能因為提供的ROE是基於調整後淨利潤或不同時間點的數據。若使用調整後淨利潤，ROE會更高。以提供的ROE 5.36%來看，仍有提升空間。
*   **ROIC (投入資本回報率)**：提供的基本面數據ROI為0.0439 (4.39%)。雖然沒有直接的WACC數據，但4.39%的ROIC表明公司從其投入資本中獲得的回報相對溫和。在當前利率環境下，公司需要努力提高ROIC以創造更大的股東價值。

*   **存貨周轉天數 (DIO) / 應收帳款周轉天數 (DSO)**：這些具體數據未在最新摘要中提供。作為服務型公司，應收帳款周轉效率是關鍵，需要密切關注。
