### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Globant S.A. 在過去幾年展現了穩健的營收成長。2023年全年營收達到20.96億美元，年增17.7%。2024年全年營收進一步增長至24.16億美元，年增15.3%。然而，進入2025年，營收成長動能有所放緩。2025年第一季度營收為6.111億美元，年增7.0%；第二季度營收為6.142億美元，年增4.5%；第三季度營收為6.171億美元，年增僅0.4%。最新的2026年第二季度營收為6.144億美元，與去年同期持平。

營收成長的驅動力主要來自於客戶數量的增加和現有客戶的錢包份額擴大。截至2025年3月31日止的過去十二個月，Globant服務了1,004個客戶（年營收超過10萬美元），其中有341個客戶的年營收超過100萬美元，高於一年前的318個。公司在AI相關業務方面表現強勁，2024年上半年AI相關營收較2023年上半年增長130%。2024年AI相關營收超過2.5億美元，年增120%，AI工作室貢獻了超過20%的營收。截至2026年第二季度，Glob.AI的年度經常性收入 (ARR) 達到5280萬美元，環比增長61%，預計2026年底將達到至少1.1億美元。這表明AI服務是公司未來重要的成長引擎。

**獲利能力與利潤率**
Globant的獲利能力在過去幾年保持相對穩定，但近期面臨壓力。

*   **毛利率 (Gross Margin)**：
    *   IFRS毛利率：2023年為36.1%，2024年略降至35.7%。2025年第一季度為34.9%，第二季度為35.4%，第三季度為34.8%。呈現小幅下滑趨勢。
    *   非IFRS調整後毛利率：2023年為38.1%，2024年為38.2%。2025年第一季度為38.0%，第二季度為38.1%，第三季度為38.1%。非IFRS調整後毛利率相對穩定，顯示核心業務的毛利空間較為堅韌。

*   **營業利益率 (Operating Margin)**：
    *   IFRS營業利益率：2023年為9.5%，2024年為9.3%。2025年第一季度為8.2%，第二季度大幅降至1.0%，第三季度回升至9.1%。2026年第二季度為3.2%。IFRS營業利益率波動較大，尤其在2025年第二季度顯著下降，這可能與一次性費用或會計調整有關。
    *   非IFRS調整後營業利益率：2023年為15.2%，2024年為15.4%。2025年第一季度為14.8%，第二季度為15.0%，第三季度為15.5%。2026年第二季度為13.2%。非IFRS調整後營業利益率在15%左右波動，顯示公司在核心營運層面的獲利能力較為穩定，但2026年第二季度有所下滑。

*   **純益率 (Net Margin)**：
    *   IFRS稀釋後每股盈餘 (EPS)：2023年為3.64美元，2024年為3.72美元。2025年第一季度為0.68美元，第二季度為-0.05美元（虧損），第三季度為0.73美元。2026年第二季度為0.04美元。IFRS淨利潤率受非經常性項目影響較大，2025年第二季度出現虧損，2026年第二季度也僅微薄盈利。
    *   非IFRS調整後稀釋後每股盈餘 (EPS)：2023年為5.74美元，2024年為6.40美元。2025年第一季度為1.50美元，第二季度為1.53美元，第三季度為1.53美元。2026年第二季度為1.40美元。非IFRS調整後EPS顯示公司在排除特定項目後仍能保持穩定的盈利能力，但2026年第二季度略有下降。

利潤率的變化顯示，儘管非IFRS調整後的毛利率和營業利益率相對穩定，但IFRS下的營業利益率和淨利率波動較大，尤其在2025年第二季度出現顯著下降，這與公司在2025年4月啟動的「業務優化計畫」相關，該計畫產生了一次性費用，主要與員工規模調整和辦公室縮減有關。這表明公司正在進行結構性調整以提升效率，但短期內對IFRS獲利產生負面影響。

**費用控制**
財報摘要中未提供詳細的研發費用 (R&D) 和行銷費用 (S&A) 佔比數據。然而，非IFRS調整後營業利益率的穩定性（約15%） 表明公司在核心營運費用方面有較好的控制。2023年第三季度，調整後銷售、一般及管理費用 (SG&A) 佔銷售額的18.3%，較去年同期下降50個基點。這顯示公司在行銷和管理費用方面有努力進行控制。公司持續投資於AI相關的創新，例如推出Globant GUT網絡和AI再造工作室，以及AI驅動的工具如Agur、Magnify和GeneXus，這些投資與其成長策略相符，旨在抓住AI應用帶來的市場機會。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**

提供的基本面數據顯示，流動比率 (Current Ratio) 和速動比率 (Quick Ratio) 均為1.84。雖然這些數據可能不是最新的，但若保持在此水平，則表明公司擁有健康的短期償債能力，流動資產足以覆蓋流動負債。財報摘要中未提供應收帳款和存貨的詳細周轉情況，但對於服務型公司而言，存貨風險通常較低。應收帳款的回收效率是關鍵，但目前沒有足夠數據進行深入分析。

**負債與償債能力**
*   **流動性**：如前所述，若流動比率和速動比率維持在1.84，則流動性狀況良好。
*   **長期風險**：提供的基本面數據顯示，債務對權益比 (Debt/Equity) 為0.25，長期債務對權益比 (LT Debt/Eq) 為0.22。這些比率相對較低，表明公司的財務槓桿不高，長期償債風險可控。
*   **淨現金狀況**：截至2023年12月31日，公司已動用信貸額度1.55億美元。截至2024年3月31日，已動用信貸額度降至1.05億美元，但在2024年6月30日又增至1.25億美元，並在2024年9月30日進一步增至1.65億美元。雖然有信貸額度使用，但考慮到其現金及短期投資水平，淨現金狀況應仍為正，表明公司有能力應對債務。

**資本配置 (Capital Allocation)**
從現金及短期投資的變化和信貸額度的使用情況來看，Globant的資金主要投向了平台業務的投資、新地理區域的擴張、新工作室的增加以及併購活動。例如，2024年第一季度現金減少8580萬美元，主要用於部分償還信貸額度及多項併購或有對價支付。公司在AI領域的持續投資也屬於資本配置的一部分，旨在推動未來的成長。2026年5月14日，董事會批准了一項新的股份回購計劃，授權每季度最高5000萬美元的回購額度。這表明公司在產生足夠現金流後，也開始考慮通過股權回購來回饋股東。
