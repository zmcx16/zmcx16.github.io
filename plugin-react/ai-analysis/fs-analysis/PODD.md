### 1. 損益表分析 (Income Statement Analysis)

*   **營收成長動能**：
    Insulet Corporation展現出強勁且持續的營收成長動能。根據最新財報，2026年第三季營收達到8.42億美元，較2025年同期（7.063億美元）增長19.2%。若以固定匯率計算，增長率為19.6%。回顧過去幾年，公司在2025財年實現了27.1億美元的營收，同比增長31%。值得注意的是，Insulet已連續十年實現20%或更高的固定匯率營收增長。這種成長主要來自於其Omnipod胰島素管理系統的銷量增加，特別是Omnipod 5自動胰島素輸送系統的強勁採用，推動了美國和國際市場的客戶群擴大。公司預計未來三年營收複合年增長率約為20%。

*   **獲利能力與利潤率**：
    Insulet的獲利能力顯著提升，利潤率呈現擴張趨勢。
    *   **毛利率 (Gross Margin)**：2026年第三季毛利率為75.1%，較2025年同期的72.2%有所提升。2025財年毛利率為71.6%，較前一年增長180個基點。這表明公司在產品定價和成本控制方面表現良好，且可能存在規模經濟效應。
    *   **營業利益率 (Operating Margin)**：2026年第三季營業利益率為22.5%（營業利益1.898億美元），較去年同期增長590個基點。2025財年營業利益率為17.5%，較前一年增長260個基點。營業利益率的持續擴張顯示公司在營收增長的同時，有效控制了營運費用，並從規模擴張中受益。
    *   **純益率 (Net Margin)**：2026年第三季淨利潤為1.411億美元，純益率約為16.76%（141.1M / 842.0M）。2025財年淨利潤為2.471億美元，純益率約為9.12%（247.1M / 2708M）。淨利潤的顯著增長和純益率的提升，反映了公司整體獲利能力的增強。

*   **費用控制**：
    雖然具體的研發費用 (R&D) 和行銷費用 (S&A) 佔比未在摘要中直接提供，但從營業利益率的擴張可以看出，公司在營收增長的同時，對營運費用（包括R&D和S&A）進行了有效管理。營業利益率的提升表明費用增長速度慢於營收增長速度，這與公司實現規模經濟和擴大獲利能力的策略相符。
