### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Albemarle的營收在近期呈現波動。根據最新數據，公司在2026年第二季度的淨銷售額為17.4億美元，較2025年同期的13.3億美元增長了30.8%。2026年第一季度的淨銷售額為14.3億美元，較去年同期增長33%。2026年上半年，淨銷售額合計為31.7億美元。
然而，若回溯至2024年，由於鋰市場價格下跌，公司營收面臨顯著壓力。2024年第一季度淨銷售額為14億美元，較去年同期下降47%。2024年第二季度淨銷售額同樣為14億美元，較去年同期下降40%。這表明營收成長主要受到鋰市場價格波動的影響，儘管能源儲存業務的銷量有所增長，但價格下跌的影響更大。2023年全年淨銷售額達到96億美元，創歷史新高，較2022年增長31%，其中21%來自銷量增長。這顯示在鋰價高漲時期，公司營收成長強勁，主要來自銷量和價格的雙重推動。

**獲利能力與利潤率**
Albemarle的獲利能力在近期有所改善，但仍受市場價格波動影響。2026年第二季度，公司歸屬於Albemarle的淨利潤為4.799億美元，遠高於2025年同期的2290萬美元。2026年第一季度，毛利率擴大至35.1%，顯著高於之前的14.5%。
相比之下，2024年第一季度淨利潤僅為200萬美元，稀釋後每股虧損0.08美元。2024年第二季度更是錄得淨虧損1.88億美元，稀釋後每股虧損1.96美元，其中包括與Kemerton 4資本項目資產沖銷相關的2.15億美元稅後費用。2023年全年淨利潤為16億美元。
毛利率、營業利益率和純益率的變化反映了鋰市場的劇烈波動。在鋰價高點時，利潤率擴張，但在價格下跌時則受到嚴重壓縮。2023年第三季度，調整後EBITDA為4.533億美元，較去年同期下降7.367億美元，主要由於鋰市場價格下跌和鋰輝石成本上升。這表明公司在成本控制方面面臨挑戰，尤其是在原材料價格波動時。

**費用控制**
財報摘要中未直接提供研發費用 (R&D) 和行銷費用 (S&A) 的具體佔比。然而，公司在2024年第一季度實現了超過9000萬美元的生產力與重組成本節約，並預計2024年將實現超過2.8億美元的生產力效益。這表明公司正積極採取措施控制費用，以應對市場變化並提升效率。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
Albemarle的營業現金流在近期表現強勁。2026年上半年，營運現金流增至10.6億美元。2023年前九個月的營運現金流為14億美元，較去年同期增加了4.679億美元。然而，在鋰市場低迷的2024年第一季度，營運現金流降至9800萬美元，較去年同期減少了6.23億美元。這表明公司的營運現金流與淨利潤的波動趨勢一致，受到市場價格的顯著影響。當市場環境有利時，OCF能與淨利潤同步增長，甚至表現更佳；但在市場下行時，OCF也會大幅縮水。

**自由現金流 (FCF)**
*   **計算**：
    *   2024年第一季度：OCF 9800萬美元 - CapEx 5.79億美元 = -4.81億美元。
    *   2023年全年：OCF (未直接提供，但前九個月為14億美元) - CapEx 21億美元。若假設全年OCF略高於14億美元，FCF仍可能為負。
    *   2026年上半年：OCF 10.6億美元 - CapEx (未直接提供，但2024年預計為16-18億美元，2023年為21億美元)。如果資本支出保持較高水平，FCF可能仍承壓。
*   **分析**：在鋰市場價格下跌期間，Albemarle的自由現金流為負，這表明公司營運產生的現金不足以覆蓋其資本支出。這限制了公司用於擴張、派息或回購股票的現金能力。公司在2024年第一季度資本支出增加，主要由於項目支出的時機。

**資本配置 (Capital Allocation)**
公司在過去幾年將大量資金投入資本支出以擴大產能，特別是在能源儲存領域。2023年資本支出約為21億美元。然而，面對市場變化，公司已宣布採取積極措施，預計2024年資本支出將降至16億至18億美元，重點放在已顯著進展、接近完成和啟動的項目。此外，公司通過發行強制性可轉換優先股來強化資產負債表和資金增長投資。公司也維持派發季度普通股息，並在2026年第二季度將普通股息提高至每股0.41美元。這表明公司在成長投資、償債和股東回報之間進行平衡，但近期更側重於強化財務靈活性和優化資本支出。
