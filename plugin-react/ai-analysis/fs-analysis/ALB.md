# Albemarle Corp (ALB) 財務狀況全面拆解

作為一名資深美股分析師，我將針對Albemarle Corp (ALB) 的財務狀況進行全面拆解，並根據最新的財報數據進行分析。

---

### 1. 損益表分析 (Income Statement Analysis)

-   **營收成長動能**：
    Albemarle在2025年的淨銷售額為51.427億美元，較2024年下降4%，主要原因是其能源儲存部門的碳酸鋰和氫氧化鋰市場價格下跌所致。然而，公司在最新季度（2026年第二季度）展現了強勁的復甦，淨銷售額達到17億美元，同比大幅增長31%。此增長主要由能源儲存部門更高的定價（增長73%）以及特種化學品部門更高的定價（增長11%）和銷量（增長8%）所驅動。這表明儘管2025年面臨挑戰，但2026年上半年市場條件改善和公司執行力提升，帶動了顯著的營收增長。

-   **獲利能力與利潤率**：
    2025年，Albemarle的毛利率為13.0%，並錄得淨虧損5.106億美元。然而，在2026年第二季度，公司的獲利能力顯著改善，調整後EBITDA達到8.58億美元，同比增長155%。調整後EBITDA利潤率從去年同期的25%擴大至49%。淨利潤歸屬於Albemarle普通股股東為4.80億美元，較去年同期增長近2000%。利潤率的顯著擴張表明公司在鋰價回升和成本控制方面取得了規模經濟效應。

-   **費用控制**：
    2025年10-K報告指出，Albemarle持續投資於研發，以開發創新化學品和技術，並專注於綠色化學。2026年第二季度財報中，公司強調其專注於成本和生產力改進，這有助於抵消通脹和供應鏈中斷的影響。儘管缺乏具體的研發費用和銷售與管理費用佔比數據，但利潤率的顯著提升表明公司在費用控制或營收增長對利潤的貢獻方面表現良好。

### 2. 資產負債表分析 (Balance Sheet Analysis)

    -   **長期風險**：債務對權益比 (Debt/Eq) 為0.19，長期債務對權益比 (LT Debt/Eq) 為0.18（根據提供數據）。這些比率相對較低，表明公司的財務槓桿不高，長期償債風險較小。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

-   **營業現金流 (OCF)**：
    2026年第二季度，Albemarle的經營活動現金流為7.10億美元。同期淨利潤為4.80億美元。經營現金流顯著高於淨利潤，表明公司盈餘品質良好，現金產生能力強勁。經營現金流轉換率為83%，主要受Talison合資企業股息增加和非經常性營運資金效益的影響。

-   **自由現金流 (FCF)**：
    2026年第二季度，Albemarle的自由現金流為6.38億美元。強勁的自由現金流表明公司有足夠的現金用於擴張、派息或回購，是公司財務健康的積極信號。

-   **資本配置 (Capital Allocation)**：
    2025年資本支出為5.90億美元，較前一年減少11億美元，反映了停止或減緩支出以及能源儲存和特種化學品產能擴張完成的影響。公司預計2026年資本支出將與2025年大致持平，約在5.5億至6億美元之間。2026年第二季度財報中提到公司正在優化資本支出，並專注於長期增長機會，如能源轉型和電網儲能需求。強勁的自由現金流和優化的資本支出策略表明公司在平衡增長投資和股東回報方面具有靈活性。
