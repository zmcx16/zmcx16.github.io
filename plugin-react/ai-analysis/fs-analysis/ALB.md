# Albemarle Corp (ALB) 財務狀況全面拆解

作為一名資深美股分析師，我將對Albemarle Corp (ALB) 的財務狀況進行全面拆解，並結合其最新財報數據與基本面指標，評估其獲利能力、償債安全性、現金流品質及資本效率。

### 1. 損益表分析 (Income Statement Analysis)

**營收成長動能**
Albemarle Corp 在最近的季度展現出強勁的營收成長動能。根據2026年第二季財報，公司淨銷售額達到17.4億美元，較去年同期增長31%。此成長主要來自於能源儲存(Energy Storage)部門的鋰產品價格上漲，該部門淨銷售額增長了78%。特種化學品(Specialties)部門的淨銷售額也增長了20%，這得益於銷量增加8%和價格上漲11%。這表明ALB的營收成長是價格和銷量雙重驅動的結果，尤其是在鋰市場價格高漲的背景下，其能源儲存業務表現突出。

**獲利能力與利潤率**
ALB的獲利能力在近期顯著改善。2026年第二季的淨利潤為4.8億美元，相較去年同期大幅增長。調整後的稀釋每股盈餘(EPS)為3.75美元，超出分析師預期。
*   **毛利率 (Gross Margin)**：2026年第一季的毛利率擴張至35.1%，遠高於去年同期的14.5%。這顯示公司在成本控制和定價能力上有所提升，尤其是在高價鋰的推動下。
*   **營業利益率 (Operating Margin)**：雖然最新季報未直接提供營業利益率，但調整後的EBITDA在2026年第二季達到8.58億美元，同比增長155%，這強烈暗示營業利益率有顯著擴張。
*   **純益率 (Net Margin)**：根據2026年第二季的數據，淨利潤4.8億美元對應17.4億美元的淨銷售額，計算得出淨益率約為27.6%。這與提供的基本面數據中0.97%的利潤率存在巨大差異，表明基本面數據中的利潤率可能基於較舊或包含較弱表現的期間。以最新財報為準，ALB的利潤率正在顯著擴張，並展現出規模經濟的潛力。

**費用控制**
財報中未提供詳細的研發費用(R&D)與行銷費用(S&A)佔比。然而，公司在2026年第二季的調整後EBITDA大幅增長，部分原因歸因於「持續的成本和生產力改進」，這暗示公司在費用控制方面取得了一定成效。

### 2. 資產負債表分析 (Balance Sheet Analysis)

**資產品質與結構**
截至2026年6月30日，Albemarle擁有約16億美元的現金及現金等價物。這筆充裕的現金提供了良好的流動性。財報中未提供應收帳款(AR)與存貨(Inventory)的具體周轉情況，但通常對於大宗商品相關企業，存貨管理和應收帳款回收效率是關鍵。

**負債與償債能力**
ALB的償債能力在近期得到顯著改善。
*   **流動性**：提供的基本面數據顯示，流動比率(Current Ratio)為2.09，速動比率(Quick Ratio)為1.35。這些比率均高於1，表明公司擁有足夠的流動資產來覆蓋短期負債，流動性健康。
*   **長期風險**：截至2026年6月30日，公司總債務為19億美元，或長期債務為18.8億美元。相較於2025年底的31.9億美元長期債務，公司債務已大幅減少。債務對權益比(Debt/Equity)為0.19，長期債務對權益比(LT Debt/Eq)為0.18，這些比率非常低，顯示公司財務槓桿使用保守，長期償債風險較低。淨債務對調整後EBITDA比率約為0.5，這是一個非常健康的水平，遠低於一般認為的3倍安全線。
*   **淨現金 (Net Cash)**：公司擁有16億美元現金，總債務19億美元，淨債務約為3億美元，處於非常低的水平，顯示其財務狀況穩健。

**無形資產與商譽**
最新財報中未提供商譽(Goodwill)的具體金額及減損風險評估。然而，鑑於公司近期強勁的獲利表現和資產出售（如煉油催化劑業務的出售），若有商譽，其減損風險可能有所降低。

### 3. 現金流量表分析 (Cash Flow Statement Analysis)

**營業現金流 (OCF)**
Albemarle的營運現金流表現強勁。2026年上半年，營運現金流達到11億美元，或10.6億美元，較去年同期增長5.18億美元。這表明公司的核心業務產生了大量的現金，且與淨利潤同步增長，甚至可能更高，顯示其盈餘品質優良。

**自由現金流 (FCF)**
2026年上半年，資本支出(CapEx)為1.7億美元。
自由現金流 (FCF) = 營業現金流 (OCF) - 資本支出 (CapEx)
FCF (2026上半年) = 11億美元 - 1.7億美元 = 9.3億美元。
公司產生了大量的自由現金流，這意味著ALB有充足的現金用於業務擴張、償債、派息或股份回購。提供的P/FCF為8.39，顯示其自由現金流估值相對合理。

**資本配置 (Capital Allocation)**
*   **償債**：公司在2026年上半年將長期債務從2025年底的31.9億美元大幅削減至18.8億美元，顯示其優先償還債務，改善財務結構。
*   **資本支出**：2026年上半年資本支出為1.7億美元，較去年同期減少1.32億美元。預計2026年全年資本支出約為5億美元，較2025年下降15%，這歸因於「持續的資本效率改進」。這表明公司在擴張的同時，注重資本支出的效率。
*   **派息**：公司已將季度普通股股息提高至每股0.41美元，自2026年10月1日起支付。這反映了公司對未來現金流的信心以及回饋股東的意願。
*   **資產出售**：公司出售了Ketjen煉油催化劑解決方案業務的控股權，產生了5.252億美元的現金，並出售了Eurecat S.A. 50%的股權，產生了4230萬美元的收益。這些資產出售進一步強化了其現金狀況並優化了業務組合。
整體而言，ALB的資本配置策略穩健，優先償債、優化資本支出並回饋股東。

### 4. 核心財務指標與杜邦分析 (Key Ratios & DuPont Analysis)

**回報率指標**

    *   **杜邦分析拆解 (利潤率 x 周轉率 x 財務槓桿)**：
        *   **利潤率**：如前所述，最新淨益率約27.6%，遠高於提供的0.97%。
        *   **資產周轉率**：提供的P/S為1.91，意味著銷售額約為市值的一半。若以17.4億美元季度銷售額年化，資產周轉率應會不錯。
        *   **財務槓桿**：Debt/Eq為0.19，顯示財務槓桿使用非常低，這會限制ROE的提升，但也降低了財務風險。
*   **ROIC (投入資本回報率)**：提供的ROI為0.0184 (1.84%)。鑑於公司強勁的獲利能力和資本效率的提升，實際ROIC應會更高。公司在資本支出方面的效率改進，有助於提升ROIC。雖然沒有WACC的具體數據，但以其低負債成本和穩健的業務，其ROIC很可能超過WACC。

**效率指標**

*   **存貨周轉天數 (DIO) 與應收帳款周轉天數 (DSO)**：未提供具體數據，但對於大宗商品公司，有效的存貨和應收帳款管理對現金流至關重要。
