# Global Payments (GPN) 定量分析報告

作為量化投資分析師，針對 **Global Payments (GPN)** 的當前估值與未來 12 個月的預期表現，我將透過機率思考與期望值模型進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **業務簡化與資產剝離**：GPN 正在進行戰略轉型，計畫剝離非核心資產（如 AdvancedMD），專注於核心收單與軟體整合業務。這將提升營運利潤率並引發市場對其估值的重新發現。
2.  **大規模資本回報計畫**：公司近期宣布了高達 60 億美元的股票回購授權（約佔市值 25%）。在 Forward P/E 僅約 5-6 倍的背景下，回購對 EPS 的增厚效應極其顯著。
3.  **利率環境改善**：作為高槓桿（Debt/Eq 1.02）且與消費支出高度相關的支付公司，降息循環將降低其債務利息支出，並刺激終端消費交易量。

#### **主要風險點 (Risks)**
1.  **宏觀經濟衰退**：若美國消費支出大幅放緩，將直接衝擊其交易手續費收入（Merchant Solutions 佔比高）。
2.  **競爭格局惡化**：來自 Adyen、Stripe 等雲端原生支付服務商以及 Block (SQ) 的競爭，可能導致 GPN 的市佔率流失或定價權受損。
3.  **執行風險**：轉型過程中的資產處置進度若慢於預期，或整合新收購業務出現減值，將壓抑股價表現。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前 $85.62 的股價與 5.27 倍的遠期本益比，我設定以下三種互斥且窮盡的情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：成功出售非核心資產且溢價，60 億美元回購執行進度超前，EPS 增長超過 20%，市場給予估值修復至 9-10 倍 Forward P/E。
*   **預估機率**：25%
*   **目標價格與預期回報**：$125.00 (+46.0%)

#### **基準情境 (Base Case)**
*   **發生條件**：業務轉型穩步推進，達成分析師預期的 18.9% EPS 增長，回購按計畫進行，估值修復至 7-8 倍 Forward P/E（仍低於歷史均值）。
*   **預估機率**：50%
*   **目標價格與預期回報**：$109.00 (+27.3%)

#### **悲觀情境 (Bear Case)**
*   **發生條件**：美國經濟進入衰退，消費支出萎縮，競爭導致利潤率下滑，股價回測 52 週低點並維持低估值陷阱（5 倍 P/E 以下）。
*   **預估機率**：25%
*   **目標價格與預期回報**：$65.00 (-24.1%)

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
GPN 投資決策 (現價 $85.62)
├── [25%] 樂觀情境: 轉型成功 + 估值修復 -> $125.00 (+46.0%)
├── [50%] 基準情境: 符合預期 + 穩健回購 -> $109.00 (+27.3%)
└── [25%] 悲觀情境: 宏觀衰退 + 競爭加劇 -> $65.00 (-24.1%)
```

#### **總期望值計算**
*   `EV = (0.25 * 46.0%) + (0.50 * 27.3%) + (0.25 * -24.1%)`
*   `EV = 11.5% + 13.65% - 6.025%`
*   **`EV = 19.125%`**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：平均約 +33.5% (樂觀與基準加權)
*   **下行空間 (Downside)**：-24.1%
*   **風險回報比 (Risk/Reward Ratio)**：1 : 1.39。雖然比例非極端不對稱，但考慮到 Forward P/E 處於歷史極低分位數，下行空間受 P/B (0.98) 與回購計畫強力支撐。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | +46.0% | 資產高價剝離、回購加速、估值倍數修復 |
| **基準 (Base)** | 50% | +27.3% | 達成 EPS 增長目標、宏觀環境平穩 |
| **悲觀 (Bear)** | 25% | -24.1% | 經濟衰退、支付市場競爭失利、利潤率萎縮 |
| **整體期望值** | **100%** | **+19.13%** | **加權平均預期回報** |

**最終結論：**
1.  **投資建議**：**買入 (Buy)**
2.  **核心逻辑**：GPN 目前處於「極低估值 + 高資本回報」的典型價值陷阱反轉模型中。Forward P/E 僅 5.27 倍，遠低於行業均值，且 PEG 0.33 顯示市場嚴重低估其增長潛力。19.13% 的期望值在當前高位美股市場中具備極高的安全邊際與吸引力。
3.  **風控建議**：若股價跌破 $75（技術面支撐位）或 Forward P/E 降至 4.5 倍以下，需重新評估基本面是否惡化；若連續兩個季度營收增長低於市場預期，應視為悲觀情境觸發訊號，執行減碼或止損。
