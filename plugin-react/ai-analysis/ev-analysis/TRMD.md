# TRMD (Torm Plc) 量化投資分析報告

作為量化投資分析師，針對成品油輪（Product Tanker）巨頭 **Torm Plc (TRMD)**，我將結合當前宏觀地緣政治、航運週期數據及財務指標，進行期望值決策分析。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **地緣政治導致的噸海里（Ton-Mile）需求增加**：紅海危機迫使油輪繞行好望角，顯著拉長航程，變相減少了市場有效運力供給。只要中東局勢未見實質性降溫，運費（Spot Rates）將維持高位。
2.  **極低的成品油輪訂單量（Orderbook）**：目前全球成品油輪的新船訂單佔現有船隊比例仍處於歷史低位，且新船交付需 2-3 年。供給端的結構性緊缺是未來 12 個月股價的最強支撐。
3.  **高額股息發放政策**：TRMD 擁有極具吸引力的分紅政策（殖利率約 12.5%），在當前高利率環境進入尾聲時，其「類債券」的高現金流屬性將吸引收益型資金流入。

#### **主要風險點 (Risks)**
1.  **地緣政治突然降溫**：若紅海航道恢復正常或俄烏衝突達成停火，噸海里需求將迅速萎縮，導致運費均值回歸。
2.  **全球經濟衰退導致需求下滑**：成品油（汽油、柴油、航空燃油）需求與經濟活動高度相關。若美歐進入深度衰退，將直接打擊運費。
3.  **OPEC+ 減產延長**：原油產量減少會間接影響成品油的貿易總量，進而壓制油輪租金。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於未來 12 個月的展望，設定以下三種互斥情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：紅海危機持續整個 2025 年；全球經濟軟著陸帶動成品油需求增長；TRMD 運費維持在 $45,000/天以上。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$53.00 (總回報 +50%)**
    *   估值邏輯：P/E 回升至 8x（行業高峰），加上約 15% 的年度股息回報。

#### **基準情境 (Base Case)**
*   **發生條件**：地緣政治維持現狀；運費受季節性波動影響但均值高於歷史水平；公司維持現有分紅比例。
*   **預估機率**：50%
*   **目標價格與預期回報**：**$44.00 (總回報 +25%)**
    *   估值邏輯：接近分析師平均目標價 $39.57，加上約 12% 的股息回報。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：中東局勢迅速和平解決；全球經濟衰退導致油耗下降；運費跌破公司盈虧平衡點。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$26.50 (總回報 -25%)**
    *   估值邏輯：股價回落至 P/B 1.0x 附近（安全邊際），股息因利潤下滑而減半。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
TRMD Investment Decision
├── [25%] Bull Case: +50% Return (Price Appr. + Dividends)
├── [50%] Base Case: +25% Return (Price Appr. + Dividends)
└── [25%] Bear Case: -25% Return (Price Drop + Reduced Div)
```

#### **總期望值計算**
$EV = (0.25 \times 0.50) + (0.50 \times 0.25) + (0.25 \times -0.25)$
$EV = 0.125 + 0.125 - 0.0625 = 0.1875$
**總期望報酬率 = 18.75%**

#### **風險回報比分析**
*   **上行潛力**：在基準與樂觀情境下，預期回報介於 25% 至 50%。
*   **下行空間**：悲觀情境下損失約 25%。
*   **不對稱性**：期望值為正（18.75%），且勝率（樂觀+基準）達 75%。目前的低 P/E (5.82) 提供了良好的估值保護。

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |

| **整體期望值** | **100%** | **+18.75%** | **具備高度吸引力的風險溢價** |

**最終結論：**
1.  **投資建議**：**買入 (Buy)**
2.  **核心逻辑**：TRMD 目前處於「低估值、高現金流、供給受限」的黃金三角。5.82 倍的 P/E 顯示市場已部分定價了週期見頂的風險，但忽視了地緣政治對噸海里需求的長期重塑。18.75% 的期望值遠高於市場平均水平，且 12% 以上的殖利率提供了極強的下行緩衝。
3.  **風控建議**：監控「蘇伊士運河通行量」與「MR 型油輪即期運費」。若運費連續兩個季度低於 $25,000/天，或紅海局勢徹底和平化，應觸發減碼或出場訊號。此外，跌破 SMA200 ($28.5 附近) 可視為技術面轉弱的止損參考。
