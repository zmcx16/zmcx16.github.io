# AstraZeneca (AZN) 投資價值量化分析報告

作為量化投資分析師，我將結合您提供的基本面數據與當前市場動態（特別是近期中國區監管風波與 2030 年營收目標），透過期望值模型評估 AZN 的投資贏面。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **2030 年營收目標與利潤率擴張**：AZN 目標在 2030 年實現 800 億美元營收，這意味著需維持約 8% 的年複合增長率。隨著高毛利的腫瘤藥物（如 Enhertu, Tagrisso）佔比提升，營運利潤率有望從目前的 23.3% 向 30% 以上邁進。
2.  **ADC 與 GLP-1 管線突破**：AZN 在抗體藥物偶聯物 (ADC) 領域處於領先地位，且其口服 GLP-1 藥物 (ECC1883) 的臨床數據若優於預期，將使其切入利潤極高的減重/代謝市場，引發估值倍數 (P/E) 的重新定義。
3.  **腫瘤藥物適應症擴展**：Tagrisso 作為一線治療的滲透率持續增加，且多項臨床試驗（如肺癌、乳腺癌）將在未來 12 個月內公佈關鍵數據。

#### **主要風險點 (Risks)**
1.  **中國區監管與法律風險**：近期 AZN 中國區總裁王磊被拘留調查，涉及醫保詐欺及非法進口藥物指控。中國市場貢獻 AZN 約 13% 的營收，此事件可能導致罰款、市場份額流失或品牌受損。
2.  **美國《通膨削減法案》(IRA) 價格談判**：AZN 的核心產品（如 Farxiga）面臨 Medicare 價格談判壓力，可能壓縮長期利潤空間。
3.  **研發管線挫敗**：特別是與第一三共合作的 Dato-DXd 在某些適應症上的 FDA 審核進度若受阻，將直接打擊市場對其 2030 目標的信心。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $182.27 與分析師平均目標價 $228.71，設定以下三種情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：中國監管調查僅限於個人行為，公司層面未受重大處罰；口服 GLP-1 數據驚艷；2025 年指引超預期。
*   **預估機率**：20%
*   **目標價格與預期回報**：**$246 (+35%)**。基於 Forward P/E 擴張至 20x（目前 16x），反映其在減重藥市場的潛力。

#### **基準情境 (Base Case)**
*   **發生條件**：腫瘤業務維持雙位數增長；中國業務短期受壓但長期穩健；ADC 管線按計畫推進。
*   **預估機率**：55%
*   **目標價格與預期回報**：**$228 (+25%)**。基於分析師共識目標價，反映 1.43 的 PEG 估值合理性。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：中國區面臨結構性制裁或巨額罰款；核心藥物專利挑戰失敗；市場進入避險模式。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$146 (-20%)**。回測至 52 週低點附近，並跌破 SMA200 支撐位，反映市場對其增長故事的懷疑。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[AZN Investment]
├── 樂觀 (20%): +35% Return -> EV Contribution: 7.0%
├── 基準 (55%): +25% Return -> EV Contribution: 13.75%
└── 悲觀 (25%): -20% Return -> EV Contribution: -5.0%
```

#### **總期望值計算**
`EV = (0.20 * 35%) + (0.55 * 25%) + (0.25 * -20%)`
`EV = 7.0% + 13.75% - 5.0% = 15.75%`

#### **風險回報比分析**
*   **上行潛力 (Upside)**：+25% ~ +35%
*   **下行空間 (Downside)**：-20%
*   **風險回報比 (R/R Ratio)**：約 **1.44** (以基準情境計)。這顯示每承擔 1 單位的風險，預期可獲得 1.44 單位的回報，具備正向不對稱性。
