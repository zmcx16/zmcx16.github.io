# Progressive Corp (PGR) 量化投資分析報告

作為量化投資分析師，我將透過機率思考框架，結合 Progressive (PGR) 的財務數據與市場動態，進行期望值（Expected Value, EV）建模分析。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **承保利潤率（Combined Ratio）持續優化**：Progressive 在數據分析與遠程信息處理（Snapshot）具備領先優勢。若其綜合成本率能持續維持在 90% 以下（優於行業平均的 96% 以上），將驅動 EPS 超預期增長。
2.  **市場份額擴張**：當競爭對手（如 GEICO 或 State Farm）因通膨壓力調整定價較慢時，PGR 憑藉精準定價能力能快速獲取高質量客戶。
3.  **投資收益增長**：在高利率環境持續（Higher for Longer）的背景下，PGR 龐大的固定收益投資組合將持續產生更高的利息收入，增強獲利墊片。

#### **主要風險點 (Risks)**
1.  **氣候與災難損失 (CAT Losses)**：極端天氣事件（如颶風、冰雹）頻率增加，可能導致短期賠付支出激增，衝擊季度利潤。
2.  **社會通膨 (Social Inflation)**：法律訴訟成本上升與賠償金額增加，可能導致儲備金提撥不足，影響未來利潤率。
3.  **監管定價限制**：若關鍵州（如加州、佛州）監管機構限制保費調漲速度，將導致保費增長無法覆蓋賠付成本。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $211.42 與 12 個月目標價 $232.95，設定以下三種互斥情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：通膨降溫快於預期，車輛維修成本下降；承保利潤率維持在 88% 以下；市佔率因競爭對手撤出特定市場而大幅提升。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$265 (+25.3%)**。基於 Forward P/E 回升至 18x（歷史高位區間）及 EPS 增長超預期。

#### **基準情境 (Base Case)**
*   **發生條件**：保費調漲成功抵銷賠付通膨；業務增長穩定，綜合成本率維持在 91-93% 的目標區間；投資收益符合預期。
*   **預估機率**：55%
*   **目標價格與預期回報**：**$235 (+11.1%)**。接近分析師平均目標價，反映穩健的 ROE (37.9%) 表現。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：發生重大自然災害；監管機構嚴格限制費率上調；或經濟衰退導致新車投保量大幅下滑。
*   **預估機率**：20%
*   **目標價格與預期回報**：**$180 (-14.9%)**。回測 52 週低點附近，P/E 壓縮至 10x 以下的安全邊際位置。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[PGR 投資決策]
├── 樂觀 (25%): 回報 +25.3%  => 貢獻 +6.33%
├── 基準 (55%): 回報 +11.1%  => 貢獻 +6.11%
└── 悲觀 (20%): 回報 -14.9%  => 貢獻 -2.98%
```

#### **總期望值計算**
*   **EV** = (0.25 * 25.3%) + (0.55 * 11.1%) + (0.20 * -14.9%)
*   **EV** = 6.33% + 6.11% - 2.98% = **9.46%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：平均約 +18.2% (樂觀與基準加權)
*   **下行空間 (Downside)**：-14.9%
*   **風險回報比**：1 : 1.22。雖然不具備極端不對稱性，但正向期望值接近 10%，在保險防禦型板塊中具備吸引力。
