# Morningstar Inc (MORN) 投資價值量化分析報告

作為量化投資分析師，針對 Morningstar Inc (MORN) 的當前基本面與市場動態，我將透過機率思考框架，拆解其未來 12 個月的期望值（Expected Value, EV）。

---

## 1. 核心驅動因素與風險 (Drivers & Risks)

### 關鍵催化劑 (Catalysts)
1.  **利潤率持續擴張 (Margin Expansion)**：Morningstar 近期致力於營運槓桿的優化。隨著高利潤率的授權產品（如 Morningstar Data, Direct 及 PitchBook）營收佔比提升，其營運利潤率（Oper. Margin 24.13%）具備進一步上行空間。
2.  **PitchBook 的強勁增長**：私募市場數據需求依然旺盛。PitchBook 作為該領域的領導者，其訂閱收入的穩定增長是抵禦公開市場波動的護城河。
3.  **資本市場復甦帶動 DBRS 業務**：若 2024-2025 年利率環境趨穩或進入降息週期，債券發行量回升將直接利好 DBRS Morningstar 的信用評等業務。

### 主要風險點 (Risks)
1.  **高槓桿財務壓力**：目前總負債權益比（Debt/Eq）高達 1.81，在長期高利率環境下，利息支出可能侵蝕淨利。
2.  **資產管理規模 (AUM) 敏感性**：財富管理業務收入與市場表現掛鉤。若美股進入深度回調，管理費收入將直接萎縮。
3.  **競爭加劇**：在 ESG 數據與私募數據領域，面臨來自 MSCI、S&P Global 等巨頭的激烈競爭，可能導致定價權受損。

---

## 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前 Forward P/E 15.53x 與 PEG 0.78 的低估值狀態，設定以下三種情境：

### 樂觀情境 (Bull Case)
*   **發生條件**：PitchBook 營收增速維持 20% 以上；營運利潤率突破 28%；聯準會降息帶動債券發行潮。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$302 (+30%)**。基於 20x Forward P/E（回歸歷史均值）與 EPS 超預期增長。

### 基準情境 (Base Case)
*   **發生條件**：數據訂閱業務穩健增長 10-12%；利潤率小幅改善；市場情緒中性。
*   **預估機率**：55%
*   **目標價格與預期回報**：**$265 (+14%)**。接近分析師平均目標價 $254.33，反映 PEG 修正至 1.0 附近的估值。

### 悲觀情境 (Bear Case)
*   **發生條件**：全球經濟衰退導致 AUM 大幅下降；債務違約風險上升導致融資成本激增；PitchBook 客戶流失。
*   **預估機率**：20%
*   **目標價格與預期回報**：**$181 (-22%)**。回測 52 週低點與 SMA200 支撐位，反映估值收縮。

## 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

### 決策樹結構
```text
[MORN Investment Decision]
├── (25%) 樂觀情境: +30% Return
├── (55%) 基準情境: +14% Return
└── (20%) 悲觀情境: -22% Return
```

### 總期望值計算
*   **EV** = (0.25 * 0.30) + (0.55 * 0.14) + (0.20 * -0.22)
*   **EV** = 0.075 + 0.077 - 0.044 = **0.108 (10.8%)**

### 風險回報比分析
*   **上行潛力 (Upside)**：+14% ~ +30%
*   **下行空間 (Downside)**：-22%
*   **不對稱性評估**：期望值為正（10.8%），且基準情境的勝率（55%）配合樂觀情境共計 80% 的機率獲得正回報。目前 PEG < 1 提供了良好的安全邊際。
