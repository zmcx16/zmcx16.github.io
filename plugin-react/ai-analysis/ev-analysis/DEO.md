# DEO (Diageo plc ADR) 投資價值量化分析報告

作為量化投資分析師，針對 **DEO** 的當前估值與未來 6-12 個月的預期走勢，我將透過機率思考與期望值模型進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **拉美與加勒比地區 (LAC) 庫存去化完成**：DEO 近期股價受挫主因是 LAC 地區庫存積壓導致銷售暴跌。若未來兩季財報顯示該區庫存回歸正常水平並恢復增長，將引發強勁的估值修復。
2.  **成本節約與生產力提升計畫**：公司目標在 2027 年前實現 20 億美元的成本節約。若 2025 財年的利潤率改善優於預期（目前營業利益率 28.2%），將直接推升 EPS。
3.  **降息循環利多**：DEO 債務比例較高（Debt/Eq 2.03），且作為高股息防禦股，全球降息環境將降低其財務成本，並提升其 3.9% 殖利率的吸引力。

#### **主要風險點 (Risks)**
1.  **全球消費降級 (Down-trading)**：通膨壓力若持續，消費者可能從高端烈酒（Premiumization）轉向平價品牌，直接打擊 DEO 的核心利潤區。
2.  **地緣政治與貿易關稅**：烈酒常成為貿易爭端的報復對象（如中歐、美歐貿易摩擦），潛在的關稅成本將侵蝕毛利。
3.  **高槓桿財務壓力**：長期債務與權益比（LT Debt/Eq 1.74）偏高，若業績恢復不如預期，信用評等下調風險將增加融資成本。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前 Forward P/E 13.45x（遠低於歷史均值 20-22x）與市場共識，設定以下情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：LAC 地區強勁復甦，美國市場高端化趨勢重啟，成本節約計畫超前達成。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$112 (+31.5%)**。基於 P/E 回升至 18x 的歷史中值。

#### **基準情境 (Base Case)**
*   **發生條件**：庫存問題緩慢解決，有機營收增長回歸 3-5% 的中低個位數，利潤率持平。
*   **預估機率**：50%
*   **目標價格與預期回報**：**$98 (+15.1%)**。基於分析師平均目標價 $102.64 的保守修正。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：全球經濟衰退導致烈酒需求萎縮，庫存問題蔓延至北美，債務壓力迫使削減資本支出。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$73 (-14.3%)**。回測 52 週低點並尋求強大支撐位。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
DEO 投資決策 (12個月)
├── [25%] 樂觀情境: 估值修復 + 增長加速 -> 回報 +31.5%
├── [50%] 基準情境: 業務穩定 + 庫存正常化 -> 回報 +15.1%
└── [25%] 悲觀情境: 消費衰退 + 債務風險 -> 回報 -14.3%
```

#### **總期望值計算**
*   `EV = (0.25 * 31.5%) + (0.50 * 15.1%) + (0.25 * -14.3%)`
*   `EV = 7.875% + 7.55% - 3.575%`
*   **`EV = 11.85%`**

#### **風險回報比分析**
*   **上行潛力**：+15.1% ~ +31.5%
*   **下行空間**：-14.3%
*   **不對稱性**：目前股價處於 52 週區間的低位（靠近 $72.45），下行空間受限於 3.9% 的股息收益率與極低的 Forward P/E，風險回報比約為 **1 : 2.2**，具備投資吸引力。

**最終結論：**

2.  **核心邏輯**：DEO 目前處於「估值窪地」，Forward P/E 僅 13.45x，遠低於其全球烈酒龍頭的歷史地位。11.85% 的期望值尚未計入約 4% 的股息收益，總預期回報接近 16%。市場已過度反應 LAC 地區的短期利空，提供了極佳的安全邊際。
