# TGT (Target Corp) 量化投資分析報告

作為量化投資分析師，針對 Target (TGT) 目前的市場表現與基本面數據，我將透過機率模型與期望值（Expected Value, EV）框架進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **利潤率修復與供應鏈優化**：Target 持續推動「效率提升計劃」，目標是將營業利潤率（Oper. Margin）恢復至疫情前的 6% 水準。若物流成本進一步下降且庫存管理精準，將直接帶動 EPS 超預期增長。
2.  **自有品牌（Private Labels）滲透率提升**：Target 的自有品牌（如 All in Motion, Dealworthy）毛利較高。在消費者預算緊縮環境下，高性價比的自有品牌若能成功吸引流量，將改善其毛利結構（目前 Gross Margin 為 26.83%）。
3.  **降息循環帶動非必需消費品回溫**：Target 約 50% 以上的營收來自非必需消費品（家居、服飾、電子產品）。隨著聯準會進入降息週期，消費者對大額支出與非必需品的購買意願有望在未來 6-12 個月內反彈。

#### **主要風險點 (Risks)**
1.  **消費兩極化與競爭加劇**：Walmart (WMT) 在民生必需品（雜貨）的市佔率持續擴大，而 Amazon 則在物流速度上領先。Target 處於中間地帶，若無法有效區隔市場，流量將持續流失。
2.  **非必需消費疲軟持續**：最新財報顯示消費者對高單價、非必需品仍持謹慎態度。若通膨降溫速度不如預期，Target 的營收增長（Sales Q/Q 僅 5.27%）可能進一步放緩。
3.  **庫存損耗（Shrinkage）與治安問題**：零售盜竊對利潤的侵蝕仍是隱憂，雖然公司已採取措施，但若社會治安環境未改善，將持續拖累營業利潤。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $158.43 與 Forward P/E 16.52x，設定未來 12 個月的三種情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：假日購物季表現強勁，非必需消費品需求大幅反彈，營業利潤率回升至 6.5% 以上，EPS 增長超預期。
*   **預估機率**：20%
*   **目標價格與預期回報**：$195 (基於 18x Forward P/E)。預期回報：**+23.1%**。

#### **基準情境 (Base Case)**
*   **發生條件**：業務平穩增長，自有品牌抵銷了部分流量下滑，利潤率維持在 5.5%-5.8% 區間，符合市場共識。
*   **預估機率**：45%
*   **目標價格與預期回報**：$165 (基於 16x Forward P/E)。預期回報：**+4.1%**。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：宏觀經濟衰退導致非必需品需求崩盤，競爭對手發動價格戰，庫存積壓導致毛利受損。
*   **預估機率**：35%
*   **目標價格與預期回報**：$120 (基於 13x Forward P/E，回測至 52 週低點附近)。預期回報：**-24.3%**。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[投資 TGT @ $158.43]
    |
    |---- 樂觀 (20%): 回報 +23.1%  => 貢獻 +4.62%
    |
    |---- 基準 (45%): 回報 +4.1%   => 貢獻 +1.85%
    |
    |---- 悲觀 (35%): 回報 -24.3%  => 貢獻 -8.51%
```

#### **總期望值計算**
`EV = (0.20 * 23.1%) + (0.45 * 4.1%) + (0.35 * -24.3%)`
`EV = 4.62% + 1.85% - 8.51% = -2.04%`

#### **風險回報比分析**
*   **上行潛力 (Upside)**：$195 - $158.43 = $36.57
*   **下行空間 (Downside)**：$158.43 - $120 = $38.43
*   **風險回報比**：1 : 1.05 (每承擔 1 元風險，僅換取 0.95 元潛利)。
*   **分析**：目前期望值為負值，且風險回報比不具備不對稱性（Asymmetry），顯示在 $158 價位附近，市場已充分定價了利多，但對潛在的下行風險（如近期財報指引下修）防禦不足。

**最終結論：**
1.  **投資建議**：**避開 (Avoid) / 觀望**
2.  **核心逻辑**：從期望值模型來看，TGT 目前的數學贏面為負（-2.04%）。雖然公司基本面穩健（ROE 26%），但其高度依賴「非必需消費」的業務結構在當前高通膨殘留與競爭加劇的環境下極具脆弱性。近期市場情緒轉向悲觀，且技術面上 SMA20 已跌破，顯示短期動能轉弱，目前價格缺乏足夠的安全邊際。
3.  **風控建議**：若已持倉，建議將 **$148**（近期支撐位）設為硬性止損點。若股價跌破此位，顯示悲觀情境正在兌現，應立即減碼。若欲買入，應等待股價回落至 **$130-$135** 區間，屆時期望值將轉為正向。
