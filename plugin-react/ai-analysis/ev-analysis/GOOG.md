# Alphabet Inc (GOOG) 投資價值量化分析報告

作為量化投資分析師，針對 Alphabet Inc (GOOG) 目前的市場表現與基本面數據，我將透過機率思考框架，拆解其未來 12 個月的期望值（Expected Value, EV）。

## 1. 核心驅動因素與風險 (Drivers & Risks)

### 關鍵催化劑 (Catalysts)
1.  **AI 貨幣化與 Gemini 整合**：Google 將 Gemini 模型深度整合至 Search 與 Workspace，若能證明 AI Overviews 不僅未侵蝕廣告點擊，反而提升了用戶留存與轉化率，將引發估值修復。
2.  **Google Cloud 獲利能力爆發**：雲端業務已轉虧為盈且增長強勁（Sales Q/Q 24.2%）。隨著企業對 AI 算力需求增加，Cloud 部門的利潤率改善將成為 EPS 增長的新引擎。
3.  **資本回饋政策**：目前 P/E 僅 13.78 倍，處於歷史極低水位。公司強大的現金流（P/C 12.21）可能支撐更大規模的股份回購或股息增長，提供股價下行支撐。

### 主要風險點 (Risks)
1.  **反壟斷法案（DOJ）裁決**：美國司法部提議拆分 Chrome 或 Android，以及限制其作為預設搜尋引擎的協議。這是目前壓制股價的核心「政治折扣」。
2.  **AI 搜尋競爭與流量侵蝕**：OpenAI (SearchGPT) 與 Perplexity 等競爭對手可能改變用戶搜尋習慣，導致 Google 核心廣告收入（Search Ads）市場份額萎縮。
3.  **盈餘預期下修**：數據顯示 EPS next Y 為 -23.72%，反映市場對未來一年獲利能力的極大擔憂，若財報未能證實這僅是保守估計，股價將面臨二次探底。

## 2. 情境設定與機率賦予 (Scenario Modeling)

基於目前股價 $264.0（低於 52 週低點 $270.72），我們設定以下三種互斥情境：

### 樂觀情境 (Bull Case)
*   **發生條件**：DOJ 最終裁決僅限於罰款或輕微行為限制（非拆分）；Gemini 帶動廣告單價（CPC）上升；Cloud 業務利潤率突破 20%。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$380 (+43.9%)**。基於 Forward P/E 回歸至歷史均值 22x。

### 基準情境 (Base Case)
*   **發生條件**：法律訴訟進入漫長上訴期，短期無拆分風險；搜尋業務份額小幅波動但維持領先；AI 投入與產出達成平衡。
*   **預估機率**：50%
*   **目標價格與預期回報**：**$310 (+17.4%)**。基於 Forward P/E 17.5x（目前市場共識）。

### 悲觀情境 (Bear Case)
*   **發生條件**：法院強制拆分 Chrome；AI 競爭導致搜尋流量下滑超過 10%；EPS 確實如預期萎縮 23%。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$220 (-16.7%)**。基於 P/E 12x 的極端壓力測試（安全邊際水位）。

## 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

### 決策樹結構
```text
GOOG 投資決策 ($264.0)
├── [25%] 樂觀情境: 法律利多 + AI 爆發 -> $380 (Return: +43.9%)
├── [50%] 基準情境: 業務穩健 + 訴訟拖延 -> $310 (Return: +17.4%)
└── [25%] 悲觀情境: 強制拆分 + 盈餘衰退 -> $220 (Return: -16.7%)
```

### 總期望值計算
*   **EV = (0.25 * 43.9%) + (0.50 * 17.4%) + (0.25 * -16.7%)**
*   **EV = 10.975% + 8.7% - 4.175% = 15.5%**

### 風險回報比分析
*   **上行潛力 (Upside)**：$380 - $264 = $116
*   **下行空間 (Downside)**：$264 - $220 = $44
*   **風險回報比 (Risk/Reward Ratio)**：**1 : 2.64**。這顯示每承擔 1 元風險，預期可獲得 2.64 元回報，具備高度不對稱性。

**最終結論：**
1.  **投資建議**：**買入 (Buy)**
2.  **核心逻辑**：目前 GOOG 的 P/E (13.78) 已反映了極度悲觀的預期（包括 EPS 衰退與拆分風險）。15.5% 的期望值在大型科技股中極具吸引力，且風險回報比高達 1:2.64。市場目前的恐慌提供了進入「護城河企業」的廉價機會，即便在悲觀情境下，其強大的資產負債表（Debt/Eq 0.22）也提供了極高的容錯率。
3.  **風控建議**：若股價跌破 $220（悲觀情境目標價），或 DOJ 最終裁決確定強制拆分且不允許上訴，則需重新評估核心商業模式的完整性，屆時應考慮減倉或止損。
