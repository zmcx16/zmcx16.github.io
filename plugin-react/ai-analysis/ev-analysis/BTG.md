### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **Goose Project (加拿大) 投產進度**：這是 BTG 轉型為多元化地理佈局的關鍵。預計 2025 年第二季首度產金，這將顯著降低公司對馬利（Mali）單一地區的依賴，並帶來高利潤的產量增長。
2.  **馬利 Fekola 礦區協議達成**：近期 BTG 與馬利政府就新礦業法達成協議，解決了長期懸而未決的稅務與股權爭議。這消除了市場最大的不確定性，有利於估值修復（P/E 從目前的 9.6x 向行業平均 12-15x 靠攏）。
3.  **金價高位運行與 EPS 爆發**：目前金價維持在 $2,600/oz 以上。數據顯示 BTG 明年 EPS 預期增長率高達 76.96%，且 PEG 僅 0.13，顯示市場尚未完全定價其增長潛力。

#### **主要風險點 (Risks)**
1.  **地緣政治風險**：儘管達成協議，但馬利政局依然動盪，任何政策反覆都可能影響佔比重大的 Fekola 產出。
2.  **資本支出與通膨壓力**：Goose Project 位於北極圈，物流與建設成本極高。若通膨導致資本支出進一步超支，將壓縮自由現金流（目前 P/FCF 為 42.54，偏高）。
3.  **金價回撤風險**：若聯準會降息節奏慢於預期或美元走強，金價回落將直接打擊其營運利潤率。

### 2. 情境設定與機率賦予 (Scenario Modeling)

#### **基準情境 (Base Case)**
*   **發生條件**：金價維持在 $2,400-$2,600/oz；Goose Project 按計畫於 2025 Q2 投產；馬利協議執行平穩。
*   **預估機率**：55%
*   **目標價格與預期回報**：**$6.80 (+29.5%)**。接近分析師平均目標價 $6.82，反映基本面正常修復。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：金價跌破 $2,200/oz；Goose Project 遭遇重大建設延誤或成本嚴重超支；馬利政府再度要求重新談判。
*   **預估機率**：20%
*   **目標價格與預期回報**：**$3.80 (-27.6%)**。回測 52 週低點附近，作為安全邊際支撐位。
