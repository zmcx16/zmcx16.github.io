# LLY (Eli Lilly & Co) 量化投資分析報告

作為量化投資分析師，針對 Eli Lilly (LLY) 的當前估值與未來 6-12 個月的預期，我將透過機率模型與期望值 (EV) 框架進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **產能擴張與供應鏈解封**：LLY 正在印第安納州、北卡羅來納州及愛爾蘭大規模擴建工廠。若 2025 年產能釋放速度高於市場預期，將直接轉化為 Zepbound 與 Mounjaro 的營收超預期增長。
2.  **適應症擴展 (Label Expansion)**：Tirzepatide 在阻塞性睡眠呼吸中止症 (OSA)、代謝相關脂肪性肝炎 (MASH) 及心臟衰竭 (HFpEF) 的臨床數據與監管批准，將使其市場滲透率從糖尿病/減重擴展至更廣泛的慢性病領域。
3.  **口服 GLP-1 (Orforglipron) 進展**：作為下一代減重藥物，口服劑型的 Phase 3 數據若表現優異，將大幅降低物流成本並提高患者依從性，鞏固其與 Novo Nordisk 競爭中的護城河。

#### **主要風險點 (Risks)**
1.  **定價壓力與政策監管**：美國聯邦醫療保險 (Medicare) 的價格談判（IRA 法案）以及對高價減重藥物的報銷限制，可能壓低毛利率。
2.  **競爭加劇**：Viking Therapeutics (VKTX) 的強勁臨床數據以及 Roche、Amgen 的追趕，可能導致 LLY 的市場份額預期被下修。
3.  **估值溢價回歸**：目前 P/E 超過 44 倍，儘管 PEG 僅 0.79，但若 EPS 增長稍有放緩，市場情緒可能迅速轉向，導致估值倍數壓縮。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $1347.11 與分析師平均目標價 $1507.96，設定以下三種互斥情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：產能提前達標，Zepbound 季度營收連續大幅超預期；Donanemab (阿茲海默症) 商業化進展極其順利；口服藥數據亮眼。
*   **預估機率**：**25%**
*   **目標價格與預期回報**：**$1750 (+30%)**。基於 Forward P/E 35x 與 EPS 增長加速。

#### **基準情境 (Base Case)**
*   **發生條件**：GLP-1 藥物需求持續強勁，供應穩步提升；適應症擴展符合預期；宏觀環境穩定。
*   **預估機率**：**55%**
*   **目標價格與預期回報**：**$1510 (+12%)**。符合目前市場共識與 PEG 估值邏輯。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：監管機構對定價實施嚴格限制；競爭對手推出更具優勢的口服藥；出現罕見副作用導致法律訴訟或標籤警告。
*   **預估機率**：**20%**
*   **目標價格與預期回報**：**$1050 (-22%)**。回測至 SMA200 支撐位附近，估值倍數回歸至歷史均值。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[LLY Investment]
    |
    |-- 樂觀 (25%): +30% Return --> EV Contribution: 7.5%
    |
    |-- 基準 (55%): +12% Return --> EV Contribution: 6.6%
    |
    |-- 悲觀 (20%): -22% Return --> EV Contribution: -4.4%
```

#### **總期望值計算**
*   **EV** = (0.25 * 0.30) + (0.55 * 0.12) + (0.20 * -0.22)
*   **EV** = 0.075 + 0.066 - 0.044 = **9.7%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**: 30% (樂觀)
*   **下行空間 (Downside)**: 22% (悲觀)
*   **風險回報比**: 1 : 1.36
*   **分析**：期望值為正（9.7%），顯示在統計學上具備贏面。雖然目前股價處於高位，但 PEG 0.79 顯示其增長速度足以支撐高溢價，不對稱性偏向多頭。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | +30% | 產能超預期釋放、口服藥 Phase 3 數據大勝 |
| **基準 (Base)** | 55% | +12% | GLP-1 需求穩健、適應症順利擴展至 OSA/MASH |
| **悲觀 (Bear)** | 20% | -22% | 藥價談判利空、競爭對手突破、安全性疑慮 |
| **整體期望值** | **100%** | **+9.7%** | **加權平均預期回報** |

**最終結論：**
1.  **投資建議**：**買入 (Buy)**
2.  **核心逻辑**：LLY 目前處於「增長溢價期」，雖然 P/E 較高，但 9.7% 的期望值在當前高估值市場中仍具吸引力。PEG < 1 是核心量化支撐，顯示市場尚未完全 Price-in 其在慢性病領域（非僅減重）的長期壟斷潛力。
3.  **風控建議**：若股價跌破 **$1250** (SMA50 附近) 且伴隨成交量放大，需重新評估基準情境的機率；若跌破 **$1100** 或出現重大監管利空，應執行止損以保護資本，防止進入悲觀情境的深度回撤。
