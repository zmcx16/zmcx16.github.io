# Exxon Mobil Corp (XOM) 量化投資分析報告

作為量化投資分析師，針對 Exxon Mobil (XOM) 的當前估值與未來 6-12 個月的走勢，我將結合基本面數據、市場動態及機率模型進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **Pioneer Natural Resources 併購協同效應**：XOM 已完成對 Pioneer 的收購，未來 12 個月在二疊紀盆地（Permian Basin）的產量整合與成本削減若優於預期，將顯著提升自由現金流（FCF）。
2.  **蓋亞那（Guyana）產量超預期**：Stabroek 區塊的開採效率持續提升，若產量提前達到下一個里程碑（如 65 萬桶/日以上），將成為盈餘增長的強大引擎。
3.  **地緣政治溢價與供應緊縮**：中東局勢不穩或 OPEC+ 延長減產，可能導致油價維持在 $80-$90 區間，直接推升 XOM 的利潤率。

#### **主要風險點 (Risks)**
1.  **全球經濟放緩導致需求疲軟**：若美國或中國經濟增長低於預期，原油需求下滑將壓制油價，XOM 作為週期股將首當其衝。
2.  **監管與法律風險**：氣候變遷相關訴訟以及各國政府可能徵收的「超額利潤稅」（Windfall Tax），可能侵蝕淨利。
3.  **OPEC+ 增產風險**：若 OPEC+ 決定放棄價格支撐轉而爭奪市場份額，油價可能出現斷崖式下跌。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $155.44 與分析師平均目標價 $167.14，設定以下三種互斥情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：油價維持在 $90 以上；Pioneer 整合進度超前；蓋亞那產量大幅超標；公司加大回購力度。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$195** (基於 Forward P/E 17x)。預期總回報：**+28.0%** (含股息)。

#### **基準情境 (Base Case)**
*   **發生條件**：油價在 $75-$85 震盪；業務整合符合預期；全球需求平穩增長。
*   **預估機率**：50%
*   **目標價格與預期回報**：**$168** (接近分析師目標價，Forward P/E 14.5x)。預期總回報：**+10.7%** (含股息)。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：全球經濟衰退；油價跌破 $65；發生重大環保事故或法律重罰。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$120** (回測 200 日均線下方支撐，P/B 接近 1.8x)。預期總回報：**-20.2%** (含股息)。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[投資 XOM @ $155.44]
    |
    |---- 樂觀 (25%): 回報 +28.0%  => 貢獻 +7.00%
    |
    |---- 基準 (50%): 回報 +10.7%  => 貢獻 +5.35%
    |
    |---- 悲觀 (25%): 回報 -20.2%  => 貢獻 -5.05%
```

#### **總期望值計算**
*   **EV** = (0.25 * 28.0%) + (0.50 * 10.7%) + (0.25 * -20.2%)
*   **EV** = 7.00% + 5.35% - 5.05% = **7.3%**

#### **風險回報比分析**
*   **上行潛力**：$195 - $155.44 = $39.56
*   **下行空間**：$155.44 - $120 = $35.44
*   **風險回報比 (Risk/Reward Ratio)**：1 : 1.12。這顯示目前價位的盈虧比相對中性，並非極端不對稱的獲利機會。
