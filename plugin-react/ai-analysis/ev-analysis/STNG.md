# Scorpio Tankers Inc (STNG) 投資價值量化分析報告

作為量化投資分析師，針對 Scorpio Tankers Inc (STNG) 的當前基本面與市場動態，我將透過機率思考框架，拆解其未來 12 個月的期望值（Expected Value, EV）。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **噸海里需求持續擴張 (Ton-Mile Growth)**：紅海危機導致的繞道好望角效應尚未緩解，加上俄烏戰爭引發的貿易流向改變（從遠距離進口成品油），顯著拉長了航程，有效供給被變相壓縮。
2.  **極致的資產負債表優化與資本回饋**：STNG 的 Debt/Eq 僅 0.14，處於歷史極低位。隨著債務壓力解除，公司已轉向激進的股份回購與股息發放。在 P/B 僅 1.01 的情況下，回購對每股淨值（NAV）的增厚效應極強。
3.  **成品油輪供給斷層**：未來兩年成品油輪新船交付量仍處於歷史低點，且全球船隊高齡化嚴重，環保法規（EEXI/CII）迫使舊船減速，進一步收緊供給。

#### **主要風險點 (Risks)**
1.  **全球經濟衰退導致需求萎縮**：若美歐經濟陷入深度衰退，成品油（汽油、柴油、航空燃油）消費下降將直接衝擊運費（Spot Rates）。
2.  **地緣政治溢價消退**：若紅海局勢突然和平解決或蘇伊士運河恢復正常通行，噸海里需求將迅速回落，運費可能出現斷崖式下跌。
3.  **OPEC+ 減產延長**：原油產量減少會間接影響成品油的貿易總量，限制運費上行空間。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $78.06 與分析師平均目標價 $109.54，設定以下三種互斥情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：地緣政治緊張持續全年，全球經濟軟著陸帶動燃油需求超預期，運費維持在 $50,000/日以上；公司利用強大現金流回購超過 10% 的流通股。
*   **預估機率**：30%
*   **目標價格與預期回報**：$125 (基於 P/E 6.5x 或 P/NAV 1.2x)；**回報率：+60%**

#### **基準情境 (Base Case)**
*   **發生條件**：運費維持在目前盈利水平（約 $30,000-$40,000/日），紅海局勢維持現狀，公司按計畫進行去槓桿與穩定派息。
*   **預估機率**：50%
*   **目標價格與預期回報**：$102 (接近分析師目標價，基於 P/E 5.5x)；**回報率：+31%**

#### **悲觀情境 (Bear Case)**
*   **發生條件**：全球經濟衰退，地緣政治衝突快速平息，運費跌破盈虧平衡點；市場情緒轉向避險，航運板塊估值遭殺。
*   **預估機率**：20%
*   **目標價格與預期回報**：$55 (安全邊際參考：P/B 0.7x)；**回報率：-30%**

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[STNG 投資決策]
├── 樂觀 (30%): +60% 回報 -> 貢獻 18.0%
├── 基準 (50%): +31% 回報 -> 貢獻 15.5%
└── 悲觀 (20%): -30% 回報 -> 貢獻 -6.0%
```

#### **總期望值計算**
*   **EV** = (0.30 * 0.60) + (0.50 * 0.31) + (0.20 * -0.30)
*   **EV** = 0.18 + 0.155 - 0.06 = **27.5%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：(0.3 * 60%) + (0.5 * 31%) = 33.5%
*   **下行風險 (Downside)**：6.0%
*   **不對稱性**：目前期望值為正（27.5%），且上行空間與下行空間的比例約為 **5.6 : 1**，顯示這是一筆具備高度統計學贏面的交易。
