# AMZN 量化投資分析報告：基於期望值決策模型

作為量化投資分析師，針對 **Amazon.com Inc (AMZN)** 的當前市場定價與未來 12 個月的發展路徑，我將透過概率思考框架進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **AWS 與生成式 AI 的協同效應**：AWS 營收增長已重新加速（Q1 達 17%）。隨著企業將生成式 AI 工作負載遷移至雲端，加上 Amazon 自研晶片（Trainium/Inferentia）降低成本，AWS 的營業利潤率有望進一步擴張。
2.  **廣告業務與零售利潤率優化**：Prime Video 廣告的全面導入為高毛利收入提供新動能。同時，物流網絡的「區域化」改造持續降低履約成本（Cost to Serve），帶動北美零售業務利潤率向雙位數邁進。
3.  **資本支出效率提升**：雖然 AI 投資增加，但 Amazon 展現了極強的資本配置能力，自由現金流（FCF）正處於爆發式增長階段。

#### **主要風險點 (Risks)**
1.  **反壟斷監管壓力**：美國聯邦貿易委員會（FTC）對 Amazon 的反壟斷訴訟仍是長期懸念，可能導致業務拆分預期或營運限制。
2.  **宏觀消費疲軟**：高利率環境若持續更久，可能壓抑消費者非必要性支出，影響電商 GMV 增速。
3.  **雲端競爭加劇**：Microsoft Azure 與 Google Cloud 在 AI 領域的先發優勢可能對 AWS 的市佔率構成壓力。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

以當前股價約 **$188** 為基準，評估未來 12 個月目標價：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：AWS 營收增速回升至 20% 以上；AI 貢獻顯著超預期；零售利潤率因自動化技術大幅提升。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$245 (+30%)**。基於 45x P/E 或 25x EV/EBITDA。

#### **基準情境 (Base Case)**
*   **發生條件**：AWS 穩定在 17-18% 增長；廣告業務保持 20% 增速；宏觀經濟軟著陸，消費支出平穩。
*   **預估機率**：55%
*   **目標價格與預期回報**：**$215 (+14%)**。基於市場共識的 40x P/E。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：美國進入經濟衰退；AWS 增速跌破 12%；FTC 訴訟取得實質性不利進展。
*   **預估機率**：20%
*   **目標價格與預期回報**：**$150 (-20%)**。回測至長期支撐位，反映估值倍數壓縮。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[AMZN 投資決策]
├── 樂觀 (25%): 報酬 +30%  => 貢獻 +7.5%
├── 基準 (55%): 報酬 +14%  => 貢獻 +7.7%
└── 悲觀 (20%): 報酬 -20%  => 貢獻 -4.0%
```

#### **總期望值計算**
*   **EV** = (0.25 * 0.30) + (0.55 * 0.14) + (0.20 * -0.20)
*   **EV** = 0.075 + 0.077 - 0.04 = **11.2%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：+14% 至 +30%
*   **下行空間 (Downside)**：-20%
*   **不對稱性評估**：期望值為正（11.2%），且基準情境具備高度確定性。雖然下行空間達 20%，但發生機率較低，風險回報比（Risk/Reward Ratio）約為 1:1.5，具備投資吸引力。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | +30% | AWS AI 營收爆發、零售利潤率創歷史新高 |
| **基準 (Base)** | 55% | +14% | 雲端業務穩健、廣告收入持續增長、FCF 強勁 |
| **悲觀 (Bear)** | 20% | -20% | 宏觀衰退、監管重擊、雲端市佔流失 |
| **整體期望值** | **100%** | **+11.2%** | **加權平均預期回報** |

**最終結論：**
1. **投資建議**：**買入 (Buy)**
2. **核心邏輯**：AMZN 目前正處於「利潤釋放期」。AWS 的重新加速與廣告業務的高毛利特性，抵銷了資本支出的擔憂。11.2% 的期望回報率在大型科技股中表現穩健，且基準情境（Base Case）的勝率超過 50%，顯示目前股價尚未完全反映其 FCF 增長潛力。
3. **風控建議**：若 AWS 季度增速連續兩季低於 13%，或零售業務營業利潤率意外轉負，視為進入悲觀情境的訊號，應考慮減碼或利用價外看跌期權（Put Options）進行對沖。
