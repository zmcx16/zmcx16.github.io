# Wendy's Co (WEN) 量化投資分析報告

作為量化投資分析師，針對 Wendy's (WEN) 的當前數據與市場動態，我將透過期望值模型（Expected Value Model）評估其投資價值。目前 WEN 展現出高股息、高空頭部位與高槓桿的特徵，這是不對稱交易的典型溫床。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **數位化與早餐時段增長**：Wendy's 持續擴大其數位訂單佔比（目前約 15%）與早餐市場份額。若數位忠誠計畫能有效提升客單價與回購率，將顯著改善其營運利潤率（Oper. Margin 11.55%）。
2.  **潛在的空頭擠壓 (Short Squeeze)**：目前 Short Float 高達 **28.36%**。在技術面站上 SMA20/50/200 的情況下，任何優於預期的財報或利多消息，都可能引發空頭回補，推動股價非線性上漲。
3.  **資本回報與估值修復**：高達 **5.81%** 的股息率在餐飲板塊具備極強吸引力。隨著聯準會進入降息週期，高股息債券替代股的估值（P/E 16.63）有回升至歷史均值（約 20-22x）的空間。

#### **主要風險點 (Risks)**
1.  **極高的財務槓桿**：Debt/Eq 高達 32.57，這反映了公司高度依賴債務進行資本運作。在長期高利率環境下，利息支出將嚴重侵蝕淨利。
2.  **低收入消費者支出疲軟**：速食產業競爭加劇（如麥當勞的 $5 超值套餐），若 Wendy's 無法在價格戰中維持利潤率，其 EPS Q/Q 下滑（-65.99%）的趨勢可能延續。
3.  **負增長預期**：分析師預期明年 EPS 增長為 -3.57%，顯示市場對其短期成長動能存疑。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

#### **樂觀情境 (Bull Case)**
*   **發生條件**：早餐業務超預期增長，數位轉型帶動利潤率回升至 15% 以上，且引發空頭擠壓。
*   **預估機率**：25%
*   **目標價格與預期回報**：$11.50 (+34.7%)。基於 20x Forward P/E 與空頭回補溢價。

#### **基準情境 (Base Case)**
*   **發生條件**：同店銷售額持平或微增，股息維持發放，債務壓力隨降息緩解。
*   **預估機率**：50%
*   **目標價格與預期回報**：$9.20 (+7.7%)。基於市場共識與 17x P/E 估值修復。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：經濟硬著陸導致消費崩潰，高槓桿引發信用評等下調，被迫削減股息。
*   **預估機率**：25%
*   **目標價格與預期回報**：$6.50 (-23.9%)。回測 52 週低點並跌破安全邊際。

---

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
*   **WEN 投資決策**
    *   [0.25] **樂觀** -> 回報 +34.7%
    *   [0.50] **基準** -> 回報 +7.7%
    *   [0.25] **悲觀** -> 回報 -23.9%

#### **總期望值計算**
`EV = (0.25 * 34.7%) + (0.50 * 7.7%) + (0.25 * -23.9%)`
`EV = 8.675% + 3.85% - 5.975% = 6.55%`

*加上 **5.81%** 的股息收益率，總預期年度回報率 (Total EV) 約為 **12.36%**。*

#### **風險回報比分析**
*   **上行潛力**：$11.50 - $8.54 = $2.96
*   **下行空間**：$8.54 - $6.50 = $2.04
*   **風險回報比**：1 : 1.45。雖然不是極端不對稱，但配合高股息提供的下行保護，贏面（Win Rate）與期望值均為正向。

2. **核心逻辑**：WEN 目前處於技術面多頭排列（SMA20/50/200 以上），且擁有極高的空頭部位，這提供了強大的向上彈性。5.8% 的股息率為投資者提供了良好的現金流與安全墊。儘管債務水平高，但 P/FCF 僅 7.28，顯示現金流足以支撐營運，期望值 12.36% 在當前市場具備吸引力。
