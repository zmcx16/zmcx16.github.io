# CALM (Cal-Maine Foods, Inc.) 量化投資分析報告

作為量化投資分析師，針對 CALM 的分析核心在於「蛋價週期」與「生物安全風險」的機率博弈。CALM 擁有極強的資產負債表（零負債），但其獲利極度依賴高波動的商品價格。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **禽流感 (HPAI) 導致的供給衝擊**：若美國再次爆發大規模高致病性禽流感，將導致蛋雞存欄量下降。身為產業龍頭，CALM 若能憑藉優於同業的生物安全防護維持產能，將受益於蛋價飆升帶來的超額利潤。
2.  **飼料成本下降**：玉米與大豆佔生產成本約 60-70%。目前全球糧食供應趨於穩定，若飼料價格進一步回落，即使蛋價持平，CALM 的毛利率（目前 23.08%）仍有擴張空間。
3.  **非籠養 (Cage-Free) 轉型加速**：隨著各州法規生效，高毛利的特殊蛋（Specialty Eggs）需求增加，CALM 持續擴大此類產能，有助於提升平均售價 (ASP)。

#### **主要風險點 (Risks)**
1.  **蛋價回歸常態化**：2023 年的高蛋價基期導致目前 Sales Q/Q 下跌近 50%。若市場供給過剩，蛋價可能跌破生產成本線。
2.  **自身產線染疫**：雖然 CALM 規模大，但若核心產區爆發禽流感，將面臨大規模撲殺與營收中斷風險。
3.  **通膨壓抑消費**：雖然雞蛋是廉價蛋白質，但極端通膨可能導致消費者轉向更低價的品牌或減少購買量。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於目前股價 $71.73 接近 52 週低點，且 Forward P/E (24.81) 遠高於 Trailing P/E (11.16)，顯示市場已預期短期獲利將大幅修正。

*   **樂觀情境 (Bull Case)**
    *   **發生條件**：禽流感導致全美供給減少 10% 以上，蛋價重回歷史高位；同時飼料成本維持低檔。
    *   **預估機率**：25%
    *   **目標價格與預期回報**：$95.00 (+32.4%)。基於 EPS 回升至 $6.0 以上，給予 15x P/E。
*   **基準情境 (Base Case)**
    *   **發生條件**：蛋價維持在歷史平均水平，特殊蛋銷量穩步增長，公司維持穩定的季度派息。
    *   **預估機率**：50%
    *   **目標價格與預期回報**：$82.00 (+14.3%)。接近分析師平均目標價 $86，反映基本面修復。
*   **悲觀情境 (Bear Case)**
    *   **發生條件**：蛋價因產能過剩崩盤，或 CALM 自身主要農場爆發禽流感導致產量銳減。
    *   **預估機率**：25%
    *   **目標價格與預期回報**：$60.00 (-16.4%)。回測 P/B 1.1x 的價值支撐區。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[CALM 投資決策]
├── 樂觀 (25%): 供給短缺 + 成本下降 -> 回報 +32.4%
├── 基準 (50%): 供需平衡 + 穩健經營 -> 回報 +14.3%
└── 悲觀 (25%): 蛋價崩盤 + 染疫風險 -> 回報 -16.4%
```

#### **總期望值計算**
*   `EV = (0.25 * 32.4%) + (0.50 * 14.3%) + (0.25 * -16.4%)`
*   `EV = 8.1% + 7.15% - 4.1% = 11.15%`

#### **風險回報比分析**
*   **上行潛力**：$95.00 - $71.73 = $23.27
*   **下行空間**：$71.73 - $60.00 = $11.73
*   **風險回報比 (Risk/Reward Ratio)**：1 : 1.98。這顯示每承擔 1 元風險，預期可獲得約 2 元回報，具備正向不對稱性。

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |

| **整體期望值** | **100%** | **+11.15%** | **加權平均預期回報** |

**最終結論：**
1. **投資建議**：**買入 (Buy)**
2. **核心逻辑**：CALM 目前股價已反映了大部分蛋價回落的利空（過去一年跌幅 26%），且處於 52 週低點附近。11.15% 的期望值在當前高波動市場中具備吸引力，特別是公司擁有「零負債」的極強防禦力與 3.36% 的股息支撐，下行空間受限於淨資產價值。
3. **風控建議**：若股價跌破 $65.00（跌破 52 週低點支撐），或公司公告主要產區發生禽流感疫情，應立即啟動減碼或停損程序，以防進入極端悲觀情境。
