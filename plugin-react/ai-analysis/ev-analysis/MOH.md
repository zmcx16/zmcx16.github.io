# MOH (Molina Healthcare Inc) 量化投資分析報告

作為量化投資分析師，針對 **Molina Healthcare (MOH)** 的當前數據與市場動態，我將透過機率模型與期望值（Expected Value, EV）框架進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **Medicaid 再認證週期結束與利潤修復**：隨著各州 Medicaid 重新審核（Redeterminations）接近尾聲，會員結構將趨於穩定。若 MOH 能有效管理醫療成本率 (MLR)，其利潤率將在 2025 年迎來顯著修復，支撐 EPS next Y 達 86.5% 的高增長預期。
2.  **併購整合效益 (M&A Synergy)**：MOH 近期完成對 ConnectiCare 的收購及 Bright Health 資產的整合。若這些新業務的整合速度優於預期，將直接貢獻非線性增長的現金流與營收。
3.  **大選後的政策明朗化**：市場目前對 Medicaid 撥款縮減存有疑慮，若選後政策確認維持現狀或僅微調，將引發估值倍數 (P/E Multiples) 的均值回歸。

#### **主要風險點 (Risks)**
1.  **醫療成本趨勢 (Medical Cost Trend) 超標**：GLP-1 藥物支出增加及住院手術量上升，可能導致 MLR 超出預期，壓縮利潤空間。
2.  **監管與費率壓力**：CMS (聯邦醫療保險和聯邦醫療補助服務中心) 若進一步下調 2025-2026 年的支付費率，將直接衝擊 MOH 的核心營收來源。
3.  **競爭加劇與合約流失**：在關鍵州的 Medicaid 招標中若輸給大型競爭對手（如 UNH 或 ELV），將導致市場份額永久性損失。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $194.54 與分析師目標價 $209.24，設定以下 12 個月情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：MLR 低於 88%，併購整合產生顯著協同效應，EPS 增長兌現 80% 以上，市場給予 Forward P/E 15x。
*   **預估機率**：25%
*   **目標價格**：$250.00
*   **預期回報**：+28.5%

#### **基準情境 (Base Case)**
*   **發生條件**：業務發展符合預期，Medicaid 會員數穩定，達成分析師平均目標價。
*   **預估機率**：50%
*   **目標價格**：$210.00
*   **預期回報**：+8.0%

#### **悲觀情境 (Bear Case)**
*   **發生條件**：醫療成本失控，關鍵州合約丟失，或政策出現極端不利變化，股價回測 52 週低點支撐。
*   **預估機率**：25%
*   **目標價格**：$155.00
*   **預期回報**：-20.3%

---

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
MOH Investment Decision
├── [25%] Bull Case: +28.5% Return ($250)
├── [50%] Base Case: +8.0% Return ($210)
└── [25%] Bear Case: -20.3% Return ($155)
```

#### **總期望值計算**
*   `EV = (0.25 * 0.285) + (0.50 * 0.08) + (0.25 * -0.203)`
*   `EV = 0.07125 + 0.04 - 0.05075`
*   `EV = 0.0605` 或 **6.05%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：$250 - $194.54 = $55.46
*   **下行空間 (Downside)**：$194.54 - $155 = $39.54
*   **風險回報比 (R/R Ratio)**：1.40
*   **分析**：期望值為正（6.05%），但風險回報比僅為 1.4，顯示目前價格並未提供極端的不對稱優勢，屬於「合理但非廉價」的區間。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | +28.5% | MLR 管理卓越、併購超預期貢獻、政策利多 |
| **基準 (Base)** | 50% | +8.0% | 符合市場共識、Medicaid 規模穩定 |
| **悲觀 (Bear)** | 25% | -20.3% | 醫療成本通膨、CMS 費率大幅削減、合約流失 |
| **整體期望值** | **100%** | **6.05%** | **加權平均預期回報** |

**最終結論：**
1.  **投資建議**：**持有 (Hold) / 區間操作**
2.  **核心逻辑**：MOH 目前的期望值為 6.05%，略高於無風險利率，但考慮到其高波動性（Perf Month -18.14%），吸引力中等。市場已部分消化了 Medicaid 再認證的負面影響，但 2025 年的高增長預期（EPS +86.5%）仍需財報驗證。目前股價處於 SMA200 之上但短期均線受壓，建議等待 MLR 數據改善的明確訊號。
3.  **風控建議**：若股價跌破 **$175**（近期支撐位且進入悲觀情境路徑），應考慮減碼；若 MLR 連續兩個季度上升，則視為基本面惡化，應執行止損。
