### 1. 核心驅動因素與風險 (Drivers & Risks)

**關鍵催化劑**：
*   **AI諮詢服務需求強勁與IT支出增長**：Gartner在2026年第一季度財報中顯示，AI諮詢需求強勁，且公司預計全球IT支出將在2025年增長7.9%，主要由AI和生成式AI (GenAI) 數位化倡議推動。這可能推動其洞察(Insights)業務的增長。
*   **持續的股票回購計劃**：Gartner在2026年第一季度回購了5.35億美元的股票，並在2026年4月將股票回購授權增加了6億美元。這表明管理層對公司長期現金流產生能力有信心，並有助於提升每股收益。
*   **合約價值(CV)增長加速與訂閱收入穩定**：儘管近期合約價值增長面臨壓力，但2026年第一季度合約價值有所加速。若公司能成功穩定並加速其核心訂閱業務的合約價值增長，將是股價上漲的重要催化劑。

**主要風險點**：
*   **AI顛覆核心研究訂閱模式**：市場普遍擔憂AI工具的普及可能顛覆Gartner的核心研究訂閱模式，導致客戶對其諮詢服務的需求減弱，進而影響其定價能力和合約價值增長。
*   **合約價值增長疲軟與客戶流失**：儘管Q1 CV有所加速，但仍存在美國聯邦業務留存率較弱、受關稅影響行業的CV增長放緩，以及企業客戶座位基礎流失率上升等問題，可能導致負面的非續約合約價值(NCVI)表現。
*   **宏觀經濟逆風與IT預算緊縮**：全球經濟不確定性和地緣政治風險可能導致企業IT預算緊縮，影響Gartner的銷售和留存工作，特別是可自由支配的IT支出。
*   **證券詐欺集體訴訟**：Gartner面臨一項涵蓋2025年2月至2026年2月期間的證券詐欺集體訴訟，指控公司高管淡化業務放緩風險。這可能導致法律成本和潛在的財務賠償。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

```

├── 樂觀情境 (機率: 30%) ──> 目標價格: $203.00 (回報: +60.31%)
│
├── 基準情境 (機率: 50%) ──> 目標價格: $170.00 (回報: +34.25%)
│
└── 悲觀情境 (機率: 20%) ──> 目標價格: $100.00 (回報: -21.03%)
```

**總期望值計算**：
`EV = (機率_樂觀 * 回報_樂觀) + (機率_基準 * 回報_基準) + (機率_悲觀 * 回報_悲觀)`
`EV = (0.30 * 0.6031) + (0.50 * 0.3425) + (0.20 * -0.2103)`
`EV = 0.18093 + 0.17125 - 0.04206`
`EV = 0.31012`
**總期望值 (EV) = 31.01%**

**風險回報比分析**：
Gartner的期望值分析顯示出顯著的正向回報潛力。上行潛力（樂觀情境60.31%，基準情境34.25%）遠大於下行空間（悲觀情境-21.03%）。這表明投資Gartner具有不對稱的風險回報比，即潛在收益遠超潛在損失。儘管存在AI顛覆和合約價值增長放緩的風險，但公司在AI諮詢領域的強勁表現和積極的資本配置策略（股票回購）為其提供了支撐。
