# Hafnia Ltd (HAFN) 投資價值定量分析報告

作為量化投資分析師，針對 Hafnia Ltd (HAFN) 的當前基本面與市場動態，我將透過機率思考框架，拆解其未來 12 個月的期望值（Expected Value, EV）。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **地緣政治溢價與噸海里數增加**：紅海危機導致蘇伊士運河航行受阻，成品油輪被迫繞道好望角，顯著拉長航程（噸海里數增加），直接推升成品油輪運費（Spot Rates）。只要中東局勢維持現狀，運力供給將持續緊張。
2.  **全球煉油格局錯位**：歐美煉油產能關閉，而中東與亞洲（如印度、中國）新增產能投產。這種「產銷分離」的結構性變化，使得成品油長途運輸需求具備長期支撐。
3.  **高額股息與資本回報**：HAFN 目前股息率高達 13.15%，且資產負債表穩健（Debt/Eq 0.33）。公司承諾高比例盈餘分配，在當前高利率環境下，具備極強的下行防禦性與現金流吸引力。

#### **主要風險點 (Risks)**
1.  **地緣政治降溫（蘇伊士運河重啟）**：若紅海局勢意外迅速和平解決，繞道需求消失，運費可能面臨斷崖式下跌。
2.  **全球經濟衰退導致需求萎縮**：成品油（汽油、柴油、航空煤油）需求與經濟活動高度相關。若 2025 年全球經濟超預期放緩，將直接打擊運費。
3.  **新船交付壓力**：雖然目前成品油輪手持訂單（Orderbook）處於歷史相對低位，但 2025 年後新船交付量將逐步增加，可能稀釋市場份額與利潤。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前市場共識與量化數據，設定未來 12 個月的總回報（股價變動 + 股息）情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：紅海封鎖持續全年；冬季能源需求超預期；公司維持 80% 以上派息率。
*   **預估機率**：25%
*   **目標價格與預期回報**：目標價 $11.50（基於 P/E 8x）。
*   **預期總回報**：+29% (股價) + 13% (股息) = **+42%**

#### **基準情境 (Base Case)**
*   **發生條件**：運費維持在高於歷史平均水平震盪；地緣政治維持現狀；全球經濟軟著陸。
*   **預估機率**：50%
*   **目標價格與預期回報**：目標價 $9.82（分析師平均目標價）。
*   **預期總回報**：+10% (股價) + 13% (股息) = **+23%**

#### **悲觀情境 (Bear Case)**
*   **發生條件**：中東達成全面停火，蘇伊士運河恢復通行；全球經濟進入衰退，成品油需求下滑。
*   **預估機率**：25%
*   **目標價格與預期回報**：目標價 $7.00（回到 P/B 1.2x 的安全邊際）。
*   **預期總回報**：-21% (股價) + 6% (股息減半) = **-15%**

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
HAFN 投資決策 (現價 $8.92)
├── [25%] 樂觀情境: 運費持續高漲 + 高派息 -> 回報 +42%
├── [50%] 基準情境: 運費高位震盪 + 穩定派息 -> 回報 +23%
└── [25%] 悲觀情境: 局勢緩和 + 需求衰退 -> 回報 -15%
```

#### **總期望值計算**
*   `EV = (0.25 * 0.42) + (0.50 * 0.23) + (0.25 * -0.15)`
*   `EV = 0.105 + 0.115 - 0.0375 = 0.1825`
*   **總期望回報率：18.25%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：+23% ~ +42%
*   **下行空間 (Downside)**：-15%
*   **不對稱性**：期望值為正且顯著（18.25%），風險回報比約為 1:1.5（以基準情境計）至 1:2.8（以樂觀情境計）。
