# Bio-Techne Corp (TECH) 投資價值定量分析報告

作為量化投資分析師，針對 **Bio-Techne Corp (TECH)** 的當前數據與市場動態，我將透過機率思維拆解其未來 12 個月的期望值（Expected Value, EV）。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **生物製藥研發支出回升**：隨著利率環境趨於穩定及降息預期，早期生物技術公司的融資環境改善，將直接帶動對 TECH 試劑與蛋白質組學工具的需求。
2.  **空間生物學與自動化平台增長**：收購 Lunaphore 後的整合效應顯現，加上其自動化蛋白質印跡系統（Simple Western）在細胞與基因治療（CGT）流程中的滲透率提升，有望推動利潤率擴張。
3.  **診斷業務的突破**：ExoDx 前列腺癌檢測等液體活檢產品在臨床應用中的普及，以及納入更多醫保覆蓋範圍，將提供非週期性的增長動能。

#### **主要風險點 (Risks)**
1.  **中國市場復甦緩慢**：TECH 在中國市場有顯著曝險，若當地科研經費縮減或國產替代加速，將嚴重拖累營收增速（近期 Sales Q/Q 為 -1.51% 已反映此壓力）。
2.  **估值溢價壓縮**：目前 P/E 高達 103 倍，即便 Forward P/E 為 35 倍，在成長性若未能如期回歸雙位數的情況下，市場可能下修其估值倍數。
3.  **競爭加劇**：在空間生物學領域面臨 10x Genomics 等強大對手，研發投入若無法轉化為市佔率，將壓低 ROI（目前僅 4.64%）。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $72.09 與市場共識，設定以下三種互斥情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：生物製藥融資全面復甦，中國市場需求反彈 >10%，Lunaphore 貢獻顯著營收，EPS 增長超預期。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$95 (+32%)**。基於 Forward P/E 45x（歷史高位區間）與 EPS 成長加速。

#### **基準情境 (Base Case)**
*   **發生條件**：終端市場溫和復甦，營收維持中個位數增長，利潤率因效率提升而改善，符合分析師預期。
*   **預估機率**：50%
*   **目標價格與預期回報**：**$78 (+8%)**。基於 Forward P/E 37x，反映穩健但非爆發性的增長。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：中國市場持續萎縮，研發支出因宏觀壓力再度凍結，估值回歸至行業平均水平。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$55 (-24%)**。基於 Forward P/E 26x，尋求 SMA200 下方的長期支撐位（安全邊際）。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[投資 TECH @ $72.09]
├── 樂觀 (25%): 回報 +32%  => 貢獻 +8.0%
├── 基準 (50%): 回報 +8%   => 貢獻 +4.0%
└── 悲觀 (25%): 回報 -24%  => 貢獻 -6.0%
```

#### **總期望值計算**
*   **EV** = (0.25 * 0.32) + (0.50 * 0.08) + (0.25 * -0.24)
*   **EV** = 0.08 + 0.04 - 0.06 = **0.06 (6.0%)**

#### **風險回報比分析**
*   **上行潛力**：$22.91 ($95 - $72.09)
*   **下行空間**：$17.09 ($72.09 - $55)
*   **風險回報比 (Risk/Reward Ratio)**：**1.34**。這顯示每承擔 1 單位的風險，預期可獲得 1.34 單位的回報，屬於「正向但不對稱性不夠極端」的標的。

1. **投資建議**：**持有 (Hold) / 逢低買入 (Buy on Dips)**
