# Ford Motor Co (F) 投資價值量化分析報告

作為量化投資分析師，針對 Ford (F) 的評估不僅看其傳統造車底蘊，更需聚焦其業務拆分（Ford Blue, Ford Pro, Model e）後的盈利結構與宏觀利率環境的交互作用。

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **Ford Pro 獲利能力持續超預期**：商用車部門（Ford Pro）目前是公司的利潤引擎，其高利潤率與軟體訂閱服務的增長，若能抵銷電動車部門的虧損，將帶動估值修復。
2.  **聯準會降息週期啟動**：汽車業對利率極度敏感。降息不僅降低消費者的融資成本（刺激需求），也能減輕 Ford 龐大債務（Debt/Eq: 4.26）的利息支出壓力。
3.  **資本配置優化與特別股息**：Ford 近期展現出更積極的股東回饋政策，若能維持高額常規股息（4.09%）並輔以特別股息，將吸引收益型資金流入。

#### **主要風險點 (Risks)**
1.  **Model e (EV) 虧損擴大與價格戰**：電動車需求放緩及 Tesla 引發的價格戰，可能導致 Ford 電動車部門虧損超過預期，拖累整體利潤率。
2.  **宏觀經濟衰退風險**：汽車屬於週期性消費，若美國經濟進入硬著陸，高單價的皮卡（F-150）需求將首當其衝。
3.  **高負債比率的財務壓力**：高達 4.26 的總負債權益比在信用環境收緊時，會增加財務脆弱性。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $14.68 與 Forward P/E 8.04，設定未來 12 個月情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：Ford Pro 增長強勁且利潤率突破 18%；Model e 虧損因成本削減顯著收窄；美國經濟軟著陸且降息 3 碼以上。
*   **預估機率**：25%
*   **目標價格與預期回報**：$20.00 (預期回報：+36%)。基於 Forward P/E 回升至 10x 歷史高位區間。

#### **基準情境 (Base Case)**
*   **發生條件**：Ford Pro 維持穩定利潤；燃油車（Ford Blue）銷量持平；電動車策略轉向混合動力（Hybrid）獲得市場認可。
*   **預估機率**：50%
*   **目標價格與預期回報**：$16.00 (預期回報：+9%)。接近分析師平均目標價 $15.16，加上約 4% 的股息回報。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：經濟衰退導致皮卡銷量下滑；電動車庫存積壓被迫大幅降價；工會成本上升侵蝕利潤。
*   **預估機率**：25%
*   **目標價格與預期回報**：$11.00 (預期回報：-25%)。回測 52 週低點，安全邊際建立在 P/B 1.0x 附近。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[投資 Ford (F) @ $14.68]
├── 樂觀 (25%): 回報 +36% (目標 $20.00)
├── 基準 (50%): 回報 +9%  (目標 $16.00)
└── 悲觀 (25%): 回報 -25% (目標 $11.00)
```

#### **總期望值計算**
*   `EV = (0.25 * 0.36) + (0.50 * 0.09) + (0.25 * -0.25)`
*   `EV = 0.09 + 0.045 - 0.0625 = 0.0725`
*   **總期望報酬率：7.25%**

#### **風險回報比分析**
*   **上行潛力**：$20.00 - $14.68 = $5.32
*   **下行空間**：$14.68 - $11.00 = $3.68
*   **風險回報比 (Risk/Reward Ratio)**：1 : 1.45。這顯示每承擔 1 元風險，預期可獲得 1.45 元回報，具備正向不對稱性，但優勢不算極端顯著。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | +36% | Ford Pro 爆發、降息超預期、EV 虧損大幅收窄 |
| **基準 (Base)** | 50% | +9% | 混合動力車型熱銷、維持現有股息政策 |
| **悲觀 (Bear)** | 25% | -25% | 經濟衰退、皮卡需求萎縮、高負債利息壓力 |
| **整體期望值** | **100%** | **7.25%** | **加權平均預期回報 (含股息)** |

**最終結論：**
1.  **投資建議**：**持有 (Hold) / 區間操作**
2.  **核心邏輯**：期望值 7.25% 略高於市場長期平均，但考慮到 Ford 的高槓桿（Debt/Eq 4.26）與汽車業的週期性風險，目前的贏面主要建立在 Ford Pro 的護城河與高股息支撐。當前股價已部分反映轉型預期，缺乏極具吸引力的安全邊際，適合尋求現金流的投資者，而非追求爆發性成長。
3.  **風控建議**：若股價跌破 $12.50（SMA200 支撐位附近）或 Ford Pro 營運利潤率連續兩季下滑，應視為悲觀情境觸發訊號，建議減碼或執行停損。
