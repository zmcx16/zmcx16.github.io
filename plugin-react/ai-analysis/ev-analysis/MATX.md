# MATX (Matson Inc) 投資價值量化分析報告

作為量化投資分析師，針對 Matson Inc (MATX) 的當前數據與市場動態，我將透過機率模型與期望值 (EV) 框架進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **紅海危機與供應鏈中斷持續**：地緣政治導致繞道航行，消耗全球運力，支撐運費維持在高位。Matson 的 CLX 和 CLX+ 快船服務在供應鏈不穩定時具備極高的溢價能力。
2.  **強勁的資本回報政策**：公司持續進行大規模股份回購（Insider Trans 顯示內部變動，但公司層面回購力道強）。在低 P/E (11.32) 背景下，回購能顯著提升 EPS。
3.  **中國電商出口需求**：Temu、Shein 等跨境電商對中美快船服務需求強勁，Matson 作為該領域的領導者，其季節性旺季表現可能超預期。

#### **主要風險點 (Risks)**
1.  **全球經濟增速放緩**：若美國消費需求大幅萎縮，將直接打擊太平洋航線的貨運量。
2.  **運費正常化速度快於預期**：隨著新船下水增加全球運力，若紅海局勢緩解，運費可能面臨劇烈回調。
3.  **燃油價格波動**：雖然有附加費機制，但短期油價飆升仍會對利潤率 (Oper. Margin 16.05%) 造成壓力。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $200.05 與分析師目標價 $292.5，設定未來 12 個月的三種情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：紅海局勢全年未解，中美貿易需求因電商爆發而超預期，公司 EPS 增長超過 20%，市場給予 P/E 估值修復至 14x。
*   **預估機率**：25%
*   **目標價格與預期回報**：$290 (+45%)

#### **基準情境 (Base Case)**
*   **發生條件**：運費維持在歷史均值上方，夏威夷與阿拉斯加業務穩定，公司按計畫回購股份。EPS 保持平穩或微增。
*   **預估機率**：55%
*   **目標價格與預期回報**：$230 (+15%)

#### **悲觀情境 (Bear Case)**
*   **發生條件**：全球經濟衰退，運費跌回 2019 年水平，且面臨競爭對手價格戰。股價回測 SMA200 或更低支撐。
*   **預估機率**：20%
*   **目標價格與預期回報**：$150 (-25%)

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[MATX 投資決策]
├── 樂觀 (25%): 回報 +45%  => 貢獻 +11.25%
├── 基準 (55%): 回報 +15%  => 貢獻 +8.25%
└── 悲觀 (20%): 回報 -25%  => 貢獻 -5.00%
```

#### **總期望值計算**
`EV = (0.25 * 0.45) + (0.55 * 0.15) + (0.20 * -0.25) = 0.1125 + 0.0825 - 0.05 = 0.145`
**總期望報酬率：14.5%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：+45% (至目標價)
*   **下行空間 (Downside)**：-25% (至安全邊際)
*   **風險回報比 (Risk/Reward Ratio)**：1 : 1.8
*   **分析**：期望值為正且高於無風險利率，顯示目前價位具備數學上的贏面。雖然近期股價回檔 (Perf Month -12%)，但這反而拉高了期望值。

**最終結論：**
1. **投資建議**：**買入 (Buy)**
2. **核心逻辑**：MATX 目前 P/E 僅 11.3 倍，遠低於其歷史高點與行業平均，且 ROE 高達 19.17%，財務結構穩健 (Debt/Eq 0.24)。14.5% 的期望回報率在當前高波動市場中具備吸引力，近期 12% 的回調提供了良好的介入點。
3. **風控建議**：若股價跌破 $180 (跌破 SMA200 且放量)，說明悲觀情境發生機率上升，應考慮減碼；若運費指數 (如 SCFI/FBX) 出現連續 4 週 10% 以上跌幅，為核心出場訊號。
