# 量化投資分析報告：Companhia Siderurgica Nacional ADR (SID)

## 角色設定
本報告由一位精通概率思考與期望值決策的量化投資分析師撰寫，旨在將複雜的市場變數拆解為具體的機率情境，並透過期望值模型判斷投資標的 SID 的數學贏面與風險回報比。

## 分析標的
美股公司：**SID**
公司名稱：**Companhia Siderurgica Nacional ADR**

## 基本面數據概覽
SID 目前股價為 $1.03。公司面臨高負債（Debt/Eq: 4.01, LT Debt/Eq: 3.28）、負盈利能力（ROE: -0.1567, ROA: -0.0204, ROI: -0.0353）以及負的自由現金流。儘管如此，其P/B比率較低（0.56），且分析師目標價（$1.64）顯示潛在的上行空間。然而，過去一年的股價表現持續疲軟，且分析師普遍給予「賣出」評級。

## 1. 核心驅動因素與風險 (Drivers & Risks)

### 關鍵催化劑 (Catalysts)
1.  **成功去槓桿化與資產出售**: 公司若能成功執行大規模資產出售計畫，將顯著降低其高額債務負擔，改善財務結構，減少利息支出，並提升市場對其償債能力的信心。
2.  **多元化業務板塊表現超預期**: 鋼鐵以外的礦業、水泥、能源和物流等多元化業務在2026年第一季度已展現出營運韌性與EBITDA增長。若這些板塊能持續強勁增長，將有效抵銷鋼鐵市場的波動，並成為集團新的盈利增長引擎。
3.  **巴西經濟復甦與基礎設施投資加速**: 巴西國內經濟活動的顯著回升，特別是建築與工業領域對鋼鐵產品需求的增加，以及政府加大基礎設施建設投入，將為公司提供穩定的市場需求，推動業績增長。

### 主要風險點 (Risks)
1.  **高額債務與再融資風險**: SID 擁有龐大的債務負擔，且2026年第一季度自由現金流為負。若公司無法有效去槓桿或面臨再融資困難，高額利息支出將持續侵蝕盈利，甚至可能引發流動性危機。
2.  **全球鋼鐵需求疲軟與鐵礦石價格下跌**: 由於中國鋼鐵需求放緩、全球供應過剩以及鐵礦石價格預計在2026年下半年跌破每噸100美元，將直接衝擊公司主要鋼鐵和礦業業務的營收與利潤率。
3.  **巴西國內市場競爭加劇與進口壓力**: 巴西國內粗鋼產量在2026年前五個月下降1.9%，而同期軋製鋼材進口量預計將增長10%，達到歷史新高。這將導致國內市場競爭白熱化，對 SID 的定價權和市場份額構成壓力。

## 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $1.03。

### 樂觀情境 (Bull Case)
*   **發生條件**: 公司成功執行大規模資產出售計畫，顯著降低債務水平，同時巴西經濟強勁復甦，基礎設施投資超預期，帶動國內鋼鐵需求大幅增長。此外，鐵礦石價格意外反彈，多元化業務板塊持續強勁增長。
*   **預估機率**: 15%
*   **目標價格與預期回報**: 參考52週高點($2.20)及基本面數據中較高的分析師目標價($1.64)，設定目標價為 **$1.80**。
    *   預期回報 = ($1.80 - $1.03) / $1.03 = 74.76%

### 基準情境 (Base Case)
*   **發生條件**: 公司在去槓桿方面取得有限進展，但多元化業務（如水泥、物流、礦業）表現穩健，部分抵銷鋼鐵業務的疲軟。巴西經濟溫和增長，但鋼鐵市場仍面臨進口競爭和鐵礦石價格壓力。公司營運維持韌性，但整體盈利能力受限。
*   **預估機率**: 50%
*   **目標價格與預期回報**: 參考分析師平均目標價($1.23 - $1.40)以及當前股價與52週低點($1.02)的區間，設定目標價為 **$1.25**。
    *   預期回報 = ($1.25 - $1.03) / $1.03 = 21.36%

### 悲觀情境 (Bear Case)
*   **發生條件**: 公司去槓桿計畫受挫，高額債務問題惡化，自由現金流持續為負。全球經濟放緩導致鋼鐵和鐵礦石價格進一步大幅下跌，巴西國內市場競爭加劇，進口鋼材大量湧入，嚴重擠壓公司利潤空間，導致盈利能力持續惡化甚至虧損擴大。
*   **預估機率**: 35%
*   **目標價格與預期回報**: 考慮到當前股價已接近52週低點($1.02)，且有分析師預測年底可能跌至$0.8963，設定目標價為 **$0.70**。
    *   預期回報 = ($0.70 - $1.03) / $1.03 = -32.04%

## 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

### 決策樹繪製
```
投資 SID (當前價格: $1.03)
├── 樂觀情境 (機率: 15%)
│   └── 預期回報: +74.76% (目標價: $1.80)
├── 基準情境 (機率: 50%)
│   └── 預期回報: +21.36% (目標價: $1.25)
└── 悲觀情境 (機率: 35%)
    └── 預期回報: -32.04% (目標價: $0.70)
```

### 總期望值計算
`EV = (機率_樂觀 * 回報_樂觀) + (機率_基準 * 回報_基準) + (機率_悲觀 * 回報_悲觀)`
EV = (0.15 * 0.7476) + (0.50 * 0.2136) + (0.35 * -0.3204)
EV = 0.11214 + 0.1068 - 0.11214
EV = 0.1068
**總期望值 = 10.68%**

### 風險回報比分析
*   **上行潛力 (Upside)**: 在樂觀情境下，潛在回報為 74.76%；在基準情境下，潛在回報為 21.36%。
*   **下行空間 (Downside)**: 在悲觀情境下，潛在損失為 32.04%。

總期望值為正 10.68%，表明在考慮所有情境及其機率後，投資 SID 具有正向的數學贏面。然而，下行風險（-32.04%）與基準情境的上行潛力（+21.36%）之間存在不對稱性，下行風險略大於基準情境的上行潛力。正的期望值主要由樂觀情境的高回報貢獻，但其發生機率相對較低。

**最終結論：**
1.  **投資建議**：持有
2.  **核心邏輯**：儘管SID的整體期望值為正10.68%，顯示長期存在上行潛力，但其高額債務、持續的負自由現金流以及分析師普遍的「賣出」評級構成重大風險。當前商品市場逆風和巴西國內鋼鐵市場的挑戰，使得基準情境下的回報相對有限，而悲觀情境的下行空間不容忽視。因此，在等待公司去槓桿化取得實質性進展，並觀察宏觀經濟及商品價格走勢明朗化之前，建議「持有」觀望。
3.  **風控建議**：若SID股價跌破$0.95（約為當前價格下跌8%），或公司未能按計畫執行資產出售，或鐵礦石價格持續跌破$90/噸，應視為出場訊號。投資者可考慮設定止損點，並密切關注公司債務重組進度及各業務板塊的盈利能力報告。
