# OMF (OneMain Holdings Inc) 量化投資分析報告

作為量化投資分析師，針對 **OneMain Holdings Inc (OMF)** 的分析將聚焦於其作為「非次級貸款（Non-prime Lending）」龍頭在當前宏觀週期下的風險溢價。OMF 目前交易於 8.65 倍 P/E，且具備超過 7% 的股息殖利率，顯示市場對其信用風險已進行相當程度的定價。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **聯準會降息週期啟動**：OMF 的資金成本（Funding Cost）與基準利率高度相關。隨著降息預期升溫，其淨利差（NIM）有望擴大。同時，降息能減輕借款人的還款壓力，降低違約率。
2.  **信貸品質正常化 (Credit Normalization)**：若未來 6-12 個月失業率維持低位，OMF 的淨銷帳率（Net Charge-offs, NCOs）若能從高點回落或趨於穩定，市場將對其 ROE（目前高達 23.28%）進行估值修復。
3.  **高資本回報政策**：公司持續發放高額股息（7.32%）並進行股份回購。在 Forward P/E 僅 6.71 倍的情況下，資本回報對股價形成強大支撐。

#### **主要風險點 (Risks)**
1.  **宏觀經濟衰退與失業率飆升**：OMF 的客戶群對經濟波動極為敏感。若失業率顯著上升，違約率將侵蝕利潤，甚至威脅其高槓桿（Debt/Eq 6.73）的資產負債表。
2.  **監管壓力 (Regulatory Risk)**：美國消費者金融保護局 (CFPB) 對高利貸利率上限或滯納金（Late Fees）的限制政策，可能直接衝擊其營收結構。
3.  **融資成本滯後性**：雖然利率下降利多，但若通膨反彈導致利率「Higher for Longer」，OMF 的利息支出壓力將持續壓抑利潤增長。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前市場數據與宏觀預測，設定未來 12 個月的三種情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：美國經濟實現「軟著陸」，降息超過 100 個基點，失業率低於 4.2%，信貸損失低於預期。
*   **預估機率**：25%
*   **目標價格與預期回報**：P/E 回升至歷史均值 10x，EPS 增長至 $8.5。目標價 **$85**。
*   **預期總回報**：+48% (股價) + 7.3% (股息) = **55.3%**

#### **基準情境 (Base Case)**
*   **發生條件**：經濟緩慢增長，降息 50-75 個基點，信貸品質維持現狀，公司達成 EPS next Y 22.29% 的增長預期。
*   **預估機率**：50%
*   **目標價格與預期回報**：維持目前約 8.5x P/E，目標價接近分析師共識 **$70**。
*   **預期總回報**：+22% (股價) + 7.3% (股息) = **29.3%**

#### **悲觀情境 (Bear Case)**
*   **發生條件**：美國進入輕度衰退，失業率升破 5%，淨銷帳率（NCO）大幅攀升，公司被迫削減股息以保全資本。
*   **預估機率**：25%
*   **目標價格與預期回報**：股價回測 52 週低點支撐區，P/E 壓縮至 6x。目標價 **$45**。
*   **預期總回報**：-21.5% (股價) + 3.5% (假設股息減半) = **-18.0%**

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```
[OMF 投資決策]
    |
    |-- 樂觀 (25%): 軟著陸 + 降息加速 -> 回報 +55.3%
    |
    |-- 基準 (50%): 經濟平穩 + 正常增長 -> 回報 +29.3%
    |
    |-- 悲觀 (25%): 經濟衰退 + 違約激增 -> 回報 -18.0%
```

#### **總期望值計算**
`EV = (0.25 * 0.553) + (0.50 * 0.293) + (0.25 * -0.180)`
`EV = 0.13825 + 0.1465 - 0.045 = 0.23975`
**總期望報酬率：23.98%**

#### **風險回報比分析**
*   **上行潛力**：基準與樂觀情境下的加權回報約 28.5%。
*   **下行風險**：悲觀情境下的損失約 18%。
*   **不對稱性**：期望值為正且高達 24%，顯示目前股價已過度反應悲觀預期，具備極佳的風險補償。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |

**最終結論：**
1.  **投資建議**：**買入 (Buy)**
2.  **核心逻辑**：OMF 目前處於估值窪地（Forward P/E 6.7x），PEG 僅 0.51 顯示增長被嚴重低估。24% 的期望報酬率遠高於市場平均，且 7.3% 的股息提供了強大的下行緩衝。只要美國不進入深度衰退，該標的具備極高的贏面。
3.  **風控建議**：監控「失業率」與「淨銷帳率 (NCO)」指標。若失業率連續三個月上升且 NCO 超過 8.5%，應視為進入悲觀情境的訊號，建議執行止損或減碼，保護本金。
