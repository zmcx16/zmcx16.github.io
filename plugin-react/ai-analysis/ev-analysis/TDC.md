# TDC (Teradata Corp) 量化投資分析報告

作為量化投資分析師，針對 Teradata (TDC) 的評估核心在於其**從傳統地端資料倉儲向雲端訂閱制 (SaaS) 轉型的進度**，以及其極低估值（P/FCF 3.6x）與高空單比例（Short Float 17.1%）所形成的不對稱博弈機會。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **雲端 ARR 增長超預期**：Teradata 的轉型核心在於 VantageCloud。若雲端年度經常性收入 (Cloud ARR) 增長率能維持在 30% 以上，將引發市場對其估值倍數的重新定義（Re-rating）。
2.  **AI 整合與 ClearScape Analytics 落地**：企業對生成式 AI 的需求帶動了對高品質數據底座的需求。若 TDC 能證明其在處理大規模 AI 數據集上的成本優勢，將吸引新客戶流入。
3.  **潛在的空頭擠壓 (Short Squeeze)**：目前高達 17.13% 的空單比例，一旦財報出現利多或雲端轉型數據亮眼，空頭回補將推動股價快速反彈。

#### **主要風險點 (Risks)**
1.  **地端客戶流失 (Churn)**：傳統地端業務的萎縮速度若快於雲端業務的增長速度，將導致總營收持續停滯。
2.  **雲端原生對手的競爭**：面對 Snowflake、Databricks 以及雲端巨頭（AWS Redshift, Google BigQuery）的直接競爭，TDC 的市場份額可能被侵蝕。
3.  **宏觀 IT 支出放緩**：企業在經濟不確定性下可能推遲大型數據遷移項目，影響其轉型進度。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $28.55，設定未來 12 個月的三種情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：Cloud ARR 增長 > 35%，AI 相關合約顯著貢獻營收，且公司利用強勁現金流進行大規模回購。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$42.00 (+47%)**。基於 P/FCF 回升至 6x（仍低於行業平均）及空頭擠壓效應。

#### **基準情境 (Base Case)**
*   **發生條件**：雲端轉型符合預期，Cloud ARR 穩定增長，總營收微幅增長，利潤率保持穩定。
*   **預估機率**：50%
*   **目標價格與預期回報**：**$34.00 (+19%)**。接近分析師平均目標價，反映轉型初具成效。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：雲端增長失速，地端客戶加速流向 Snowflake，自由現金流因競爭加劇而萎縮。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$20.00 (-30%)**。回測 52 週低點，市場對其轉型徹底失去信心。

---

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[投資 TDC ($28.55)]
    |
    |-- 樂觀 (25%): 回報 +47%  --> 貢獻 EV: +11.75%
    |
    |-- 基準 (50%): 回報 +19%  --> 貢獻 EV: +9.50%
    |
    |-- 悲觀 (25%): 回報 -30%  --> 貢獻 EV: -7.50%
```

#### **總期望值計算**
*   **EV** = (0.25 * 47%) + (0.50 * 19%) + (0.25 * -30%)
*   **EV** = 11.75% + 9.5% - 7.5% = **13.75%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：+47% (樂觀)
*   **下行空間 (Downside)**：-30% (悲觀)
*   **風險回報比**：1 : 1.57。雖然不是極端不對稱，但考慮到 P/FCF 僅 3.6x，下行空間受強勁現金流支撐，具備較高的安全邊際。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | +47% | Cloud ARR 爆發、AI 應用落地、空頭擠壓 |
| **基準 (Base)** | 50% | +19% | 轉型進度符合預期、穩定回購、估值修復 |
| **悲觀 (Bear)** | 25% | -30% | 競爭加劇導致客戶流失、雲端增長停滯 |
| **整體期望值** | **100%** | **+13.75%** | **加權平均預期回報** |

**最終結論：**
1. **投資建議**：**買入 (Buy)**
2. **核心逻辑**：TDC 目前處於「極度低估」狀態，P/FCF 僅 3.6 倍，這在科技股中極為罕見。13.75% 的期望值顯示，即便考慮到轉型失敗的風險，目前的價格已提供了足夠的補償。高空單比例為股價提供了潛在的爆發力，而強勁的現金流則為股價提供了底部支撐。
3. **風控建議**：若 Cloud ARR 增長率連續兩個季度低於 20%，或股價跌破 $24（跌破近期支撐位），應視為轉型失敗的訊號，建議執行止損。
