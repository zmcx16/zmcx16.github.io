# TDC (Teradata Corp) 投資價值量化分析報告

作為量化投資分析師，針對 Teradata (TDC) 的當前基本面與市場動態，我將透過機率模型與期望值決策框架進行深度拆解。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **雲端 ARR 增長加速與 AI 整合**：Teradata 轉型為雲端優先（VantageCloud）已進入收割期。若其 AI Unlimited 與微軟 Azure、AWS 的深度整合能帶動雲端年度經常性收入 (Cloud ARR) 超預期增長（目前市場預期約 20-25%），將引發估值修復。
2.  **強勁的自由現金流與資本回報**：P/FCF 僅 4.42 倍，顯示公司具備極強的現金產生能力。公司持續進行大規模股份回購（Insider Trans 雖微減，但整體回購力道強），這在低估值時期能有效提升 EPS。
3.  **空頭擠壓 (Short Squeeze) 潛力**：目前 Short Float 高達 15.31%。一旦財報利多觸發股價突破 SMA200 ($41.47 附近)，高空頭佔比可能演變成助漲動力。

#### **主要風險點 (Risks)**
1.  **競爭壓力加劇**：面對 Snowflake、Databricks 以及雲端巨頭（如 Google BigQuery）的直接競爭，Teradata 的存量客戶遷移速度若慢於預期，或面臨定價壓力，將導致毛利萎縮。
2.  **傳統業務萎縮過快**：雖然雲端業務增長，但傳統地端 (On-premise) 收入的下滑若超過雲端增補的速度，會導致總營收 Q/Q 持續負成長（目前 Sales Q/Q 為 -4.09%）。
3.  **宏觀支出放緩**：企業 IT 預算若因經濟不確定性而縮減，對於 Teradata 這種高客單價的數據倉庫服務將產生負面衝擊。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於未來 12 個月的展望，設定以下互斥且窮盡的情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：Cloud ARR 增長 > 30%，AI 相關訂單貢獻顯著，且成功維持 60% 以上的高毛利。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$50.00 (+41%)**。基於 Forward P/E 回升至 15x（接近行業平均）及空頭回補壓力。

#### **基準情境 (Base Case)**
*   **發生條件**：雲端轉型穩健，符合公司指引；回購抵消了營收微跌的衝擊，EPS 保持小幅增長。
*   **預估機率**：50%
*   **目標價格與預期回報**：**$39.00 (+10%)**。基於 Forward P/E 12x，反映市場對其轉型成功的初步認可。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：客戶流失至 Snowflake 等競爭對手，營收連續兩季低於預期，自由現金流惡化。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$26.00 (-27%)**。回測 52 週低點支撐位，反映市場對其長期競爭力的質疑。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
TDC 投資決策 ($35.45)
├── [25%] 樂觀情境: 雲端 AI 爆發 -> 目標 $50.00 (報酬 +41%)
├── [50%] 基準情境: 穩健轉型回購 -> 目標 $39.00 (報酬 +10%)
└── [25%] 悲觀情境: 競爭加劇流失 -> 目標 $26.00 (報酬 -27%)
```

#### **總期望值計算**
*   `EV = (0.25 * 0.41) + (0.50 * 0.10) + (0.25 * -0.27)`
*   `EV = 0.1025 + 0.05 - 0.0675 = 0.085`
*   **預期報酬率 = 8.5%**

#### **風險回報比分析**
*   **上行潛力**：$50.00 - $35.45 = $14.55
*   **下行空間**：$35.45 - $26.00 = $9.45
*   **風險回報比 (Risk/Reward Ratio)**：1 : 1.54。雖然不是極端不對稱，但考慮到 P/FCF 僅 4.4 倍，下行空間受價值支撐較強。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | +41% | Cloud ARR 增速 > 30%，空頭擠壓發生 |
| **基準 (Base)** | 50% | +10% | 雲端轉型符合預期，持續股份回購 |
| **悲觀 (Bear)** | 25% | -27% | 競爭對手蠶食市佔，地端收入崩跌 |
| **整體期望值** | **100%** | **+8.5%** | **具備正向期望值，價值底層支撐強** |

**最終結論：**
1. **投資建議**：**買入 (持有為主，逢低加碼)**
2. **核心逻辑**：TDC 目前處於極低估值區間（P/FCF < 5, P/E 7.5），市場已過度定價其競爭風險。8.5% 的期望值雖不驚人，但其高達 15% 的空頭佔比提供了潛在的爆發性上行空間。在基準情境下，僅靠回購與穩健轉型即可獲得優於大盤的風險調整後收益。
3. **風控建議**：若股價跌破 **$31.50**（SMA50 附近且跌破近期支撐），需重新評估基本面是否惡化；若跌破 **$26.00** 則應果斷止損，此時可能代表雲端轉型邏輯徹底失效。
