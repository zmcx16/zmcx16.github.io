# Abbott Laboratories (ABT) 投資價值定量分析報告

作為量化投資分析師，我將透過機率思考框架，將 Abbott (ABT) 的基本面數據與市場動態整合，評估其未來 12 個月的期望值 (Expected Value)。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **醫療器械的高速增長 (FreeStyle Libre & Lingo)**：Abbott 的連續血糖監測 (CGM) 系統 FreeStyle Libre 持續保持強勁增長（年營收已突破 50 億美元）。隨著 Lingo 和 Libre Rio（非處方 OTC 版本）在美國獲批並推向大眾市場，預計將觸及非糖尿病人群，開啟新的增長曲線。
2.  **營養業務的利潤率修復**：隨著美國嬰兒配方奶粉供應鏈問題完全解決，Abbott 已奪回大部分市場份額。利潤率較高的成人營養品（如 Ensure）在老齡化趨勢下展現出強大的定價權。
3.  **管線產品獲批與滲透**：TriClip（經導管三尖瓣修復）與 Avelir（無導線起搏器）等高毛利產品的市場滲透率提升，將有效抵消 COVID-19 檢測業務萎縮帶來的缺口。

#### **主要風險點 (Risks)**
1.  **NEC 法律訴訟風險**：針對早產兒配方奶粉引發壞死性小腸結腸炎 (NEC) 的訴訟是目前最大的下行壓力。雖然近期部分判決對公司有利，但法律賠償金額的不確定性仍會壓制估值倍數。
2.  **GLP-1 藥物的心理衝擊**：市場擔心減肥藥（GLP-1）會減少糖尿病併發症，進而影響 CGM 需求。雖然數據顯示 GLP-1 與 CGM 具備協同效應，但市場情緒波動仍可能導致股價短期承壓。
3.  **匯率與宏觀壓力**：Abbott 超過 40% 的營收來自海外，美元走強將直接侵蝕淨利潤。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前 Forward P/E 17.51x（低於歷史均值）與分析師目標價 $120.21，設定以下情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：NEC 訴訟達成和解且金額遠低於預期；FreeStyle Libre 營收增長超 25%；聯準會降息帶動醫療保健板塊估值修復。
*   **預估機率**：25%
*   **目標價格與預期回報**：$135 (+30.0%)。基於 22x Forward P/E。

#### **基準情境 (Base Case)**
*   **發生條件**：核心醫療器械業務保持 8-10% 有機增長；法律訴訟進展緩慢但無重大負面判決；EPS 達成分析師預期的 $4.6-$4.7。
*   **預估機率**：55%
*   **目標價格與預期回報**：$120 (+15.5%)。基於 19x Forward P/E（接近分析師共識）。

#### **悲觀情境 (Bear Case)**
*   **發生條件**：NEC 訴訟出現巨額懲罰性賠償判決；GLP-1 普及導致 CGM 銷量增速大幅放緩；全球經濟衰退導致選擇性手術量下降。
*   **預估機率**：20%
*   **目標價格與預期回報**：$85 (-18.2%)。基於 14x Forward P/E，回測至 52 週低點附近。

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
[ABT 投資決策]
├── 樂觀 (25%): 回報 +30.0%  => 貢獻 +7.50%
├── 基準 (55%): 回報 +15.5%  => 貢獻 +8.53%
└── 悲觀 (20%): 回報 -18.2%  => 貢獻 -3.64%
```

#### **總期望值計算**
*   **EV** = (0.25 * 0.30) + (0.55 * 0.155) + (0.20 * -0.182)
*   **EV** = 0.075 + 0.08525 - 0.0364 = **12.385%**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：+15.5% ~ +30.0%
*   **下行空間 (Downside)**：-18.2%
*   **風險回報比 (R/R Ratio)**：1 : 1.25 (以基準情境計)。雖然不對稱性不算極端，但正向期望值超過 12%，顯著優於無風險利率。
