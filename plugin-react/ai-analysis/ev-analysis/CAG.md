# Conagra Brands Inc (CAG) 量化投資分析報告

作為量化投資分析師，針對 **CAG (Conagra Brands Inc)** 的當前數據與市場環境，我將透過機率思考框架，拆解其未來 12 個月的期望值（Expected Value, EV）。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

#### **關鍵催化劑 (Catalysts)**
1.  **銷量回升與組合優化**：在經歷長期的通膨壓力後，若消費者對品牌冷凍食品（如 Healthy Choice, Birds Eye）的價格敏感度降低，且公司成功透過促銷活動恢復銷量增長，將帶動營收動能。
2.  **供應鏈效率提升與成本節約**：Conagra 持續推動供應鏈轉型計劃。若利潤率（Oper. Margin 目前為 11.49%）能因自動化與物流優化回升至歷史高位，將顯著改善 EPS。
3.  **高股息吸引力與估值修復**：目前股息率高達 9%，在利率進入下行週期時，具備極強的債券替代屬性，可能引發防禦性資金流入。

#### **主要風險點 (Risks)**
1.  **GLP-1 藥物長期衝擊**：減肥藥（如 Ozempic）的普及可能結構性改變美國人的零食與冷凍食品消費習慣，這對 CAG 的核心產品線構成長期威脅。
2.  **高槓桿與債務壓力**：Debt/Eq 為 1.18，且 ROE 為負（-25.06%）。在利息支出高企的環境下，若現金流無法覆蓋債務，可能面臨信用評級下調或股息削減風險。
3.  **自有品牌（Private Label）競爭**：通膨雖放緩但物價仍高，消費者轉向超市自有品牌的趨勢若持續，CAG 的市場份額將被進一步侵蝕。

---

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於目前股價 **$15.43** 與分析師目標價 **$13.79**（顯示市場共識偏悲觀），設定以下情境：

#### **樂觀情境 (Bull Case)**
*   **發生條件**：銷量增長轉正，GLP-1 影響被證明過度反應，利潤率因成本控制超預期改善。
*   **預估機率**：20%
*   **目標價格與預期回報**：**$19.50** (回歸 52W 高點附近，Forward P/E 回升至 13x)。
*   **預期總回報**：+26.4% (股價) + 9% (股息) = **+35.4%**

#### **基準情境 (Base Case)**
*   **發生條件**：業務表現平穩，銷量微幅下滑但被價格上漲抵消，股息維持現狀。
*   **預估機率**：55%
*   **目標價格與預期回報**：**$14.50** (接近分析師目標價，反映當前負面基本面)。
*   **預期總回報**：-6.0% (股價) + 9% (股息) = **+3.0%**

#### **悲觀情境 (Bear Case)**
*   **發生條件**：銷量持續萎縮，債務壓力迫使公司削減股息，市場下修估值倍數。
*   **預估機率**：25%
*   **目標價格與預期回報**：**$11.50** (跌破 52W 低點，安全邊際失效)。
*   **預期總回報**：-25.5% (股價) + 4.5% (假設股息減半) = **-21.0%**

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

#### **決策樹結構**
```text
投資 CAG ($15.43)
├── [20%] 樂觀情境: 銷量復甦 + 估值修復 -> 回報 +35.4%
├── [55%] 基準情境: 增長停滯 + 股息支撐 -> 回報 +3.0%
└── [25%] 悲觀情境: 結構性衰退 + 削減股息 -> 回報 -21.0%
```

#### **總期望值計算**
*   `EV = (0.20 * 35.4%) + (0.55 * 3.0%) + (0.25 * -21.0%)`
*   `EV = 7.08% + 1.65% - 5.25%`
*   **`EV = 3.48%`**

#### **風險回報比分析**
*   **上行潛力 (Upside)**：20.0% (相對於基準的增量)
*   **下行空間 (Downside)**：24.0% (相對於基準的減量)
*   **分析**：目前期望值僅為 **3.48%**，遠低於標普 500 的歷史平均回報。雖然 9% 的股息看似誘人，但股價下行的風險（-25.5%）在數學上抵消了大部分收益，風險回報比並不具備不對稱的優勢。

### 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 20% | +35.4% | 銷量轉正、供應鏈節流超預期、GLP-1 憂慮消退 |
| **基準 (Base)** | 55% | +3.0% | 銷量持平、維持高股息、符合分析師目標價 |
| **悲觀 (Bear)** | 25% | -21.0% | 股息削減、債務違約風險增加、消費習慣永久改變 |
| **整體期望值** | **100%** | **3.48%** | **加權平均預期回報 (含股息)** |

**最終結論：**
1. **投資建議**：**避開 (Avoid) / 觀望**
2. **核心逻辑**：CAG 目前處於高度不確定性中，ROE 為負且債務負擔重。雖然 9% 的股息率在表面上極具吸引力，但經過機率加權後，整體的期望回報僅為 3.48%，這尚未考慮到股息稅與資本侵蝕的風險。市場共識目標價（$13.79）低於現價，顯示下行引力強勁，缺乏足夠的安全邊際。
3. **風控建議**：若已持股，應將 **$12.50 (52W Low)** 設為強制止損線。若公司宣佈削減股息或季度銷量（Sales Q/Q）連續兩季低於市場預期，應立即清倉出場。
