## 1. 核心驅動因素與風險 (Drivers & Risks)

### 關鍵催化劑 (Catalysts)
1.  **成功執行「Win Now」轉型策略與產品創新：** Nike正積極重建批發關係、重新聚焦高性能跑鞋市場，並計劃在2027財年下半年推出多款運動休閒鞋，以及在2027年春季推出由重組後運動團隊開發的產品。這些舉措有望帶動營收增長和市場份額回升。
2.  **毛利率擴張與成本控制：** 隨著供應鏈問題的解決、庫存清理的完成以及重組措施帶來的成本節約，管理層預計Nike的毛利率將在2027財年開始擴張，從而改善盈利能力。
3.  **全球大型體育賽事效應：** 2026年FIFA世界盃和冬季奧運會等全球性體育賽事，將為Nike提供巨大的品牌曝光和產品銷售機會，特別是其在跑步和全球足球領域的強勁勢頭。

### 主要風險點 (Risks)
1.  **大中華區市場持續疲軟與競爭加劇：** Nike在大中華區的營收已連續多季下滑，面臨安踏、李寧等本土品牌的激烈競爭及「國潮」趨勢。此外，2027年1月起限制線上批發銷售的策略調整，可能在短期內進一步對營收造成壓力。
2.  **消費者需求疲軟與品牌疲勞：** 由於通膨和高利率導致的消費者可支配支出壓力，以及市場對Nike經典款式的「品牌疲勞」，可能導致公司需要持續進行折扣活動，進而侵蝕利潤。
3.  **轉型執行不及預期與競爭對手侵蝕市場份額：** 若「Win Now」策略的執行未能有效解決產品創新不足、批發渠道重建緩慢等問題，Adidas、On Holding、Hoka、Lululemon等競爭對手將繼續搶佔市場份額，導致Nike的營收和盈利恢復期拉長。

## 2. 情境設定與機率賦予 (Scenario Modeling)

**當前股價 (Current Price):** $36.80

### 樂觀情境 (Bull Case)
*   **發生條件**：Nike的「Win Now」轉型策略取得顯著成功，新產品線（特別是2027財年下半年的運動休閒鞋和2027年春季的運動團隊產品）受到市場熱烈歡迎，大中華區市場開始觸底反彈並恢復增長。同時，全球體育賽事效應最大化，消費者信心回升，且毛利率擴張速度超預期。
*   **預估機率**：30%
*   **目標價格與預期回報**：基於強勁的增長前景和品牌溢價，市場可能給予更高的估值倍數，例如25倍的預期市盈率 (Forward P/E)。假設2027財年每股收益 (EPS) 達到$2.50 (考慮到Zacks預計2027財年EPS增長34.3% 及當前TTM EPS約$2.09)。
    *   目標價格 = 25 (P/E) * $2.50 (EPS) = $62.50。
    *   預期回報 = (($62.50 - $36.80) / $36.80) * 100% = **69.84%**。

### 基準情境 (Base Case)
*   **發生條件**：Nike的轉型策略穩步推進，但進展緩慢。新產品表現平穩，大中華區市場壓力有所緩解但未見強勁復甦。毛利率如預期般小幅擴張，但整體營收增長仍受宏觀經濟和競爭影響。市場情緒保持中性，分析師共識目標價得以實現。
*   **預估機率**：50%
*   **目標價格與預期回報**：基於分析師共識的平均目標價，例如Ticker Nerd的$46 或24/7 Wall St.的$51.48。我們取一個中間值，例如$49.00。此目標價也與當前預期市盈率 (Forward P/E) 17.07 乘以一個略微改善的2027財年EPS (約$2.81，基於Zacks預計的34.3%增長) 相符 (17.07 * 2.81 ≈ $47.99)。
    *   目標價格 = $49.00。
    *   預期回報 = (($49.00 - $36.80) / $36.80) * 100% = **33.15%**。

### 悲觀情境 (Bear Case)
*   **發生條件**：Nike的轉型策略遭遇重大挫折，新產品未能扭轉品牌疲勞，大中華區市場持續惡化，競爭壓力進一步加劇。宏觀經濟下行導致消費者支出大幅減少，公司盈利能力持續受損，毛利率承壓，甚至可能出現負面盈利修正。公司被S&P 100移除進一步打擊市場信心。
*   **預估機率**：20%
*   **目標價格與預期回報**：基於分析師的悲觀預期，例如Morgan Stanley的$31 或BMO Capital的$30，以及Ticker Nerd的最低預期$23。考慮到當前股價已接近52週低點，且公司仍有品牌價值和股息，我們取一個相對保守的下行目標，例如$28.00。
    *   目標價格 = $28.00。
    *   預期回報 = (($28.00 - $36.80) / $36.80) * 100% = **-23.91%**。

## 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

### 決策樹繪製 (Decision Tree)

```
當前股價: $36.80
├── 樂觀情境 (機率: 30%)
│   └── 預期目標價: $62.50 (回報: +69.84%)
├── 基準情境 (機率: 50%)
│   └── 預期目標價: $49.00 (回報: +33.15%)
└── 悲觀情境 (機率: 20%)
    └── 預期目標價: $28.00 (回報: -23.91%)
```

### 總期望值計算 (Total Expected Value Calculation)

`EV = (機率_樂觀 * 回報_樂觀) + (機率_基準 * 回報_基準) + (機率_悲觀 * 回報_悲觀)`
`EV = (0.30 * 0.6984) + (0.50 * 0.3315) + (0.20 * -0.2391)`
`EV = 0.20952 + 0.16575 - 0.04782`
`EV = 0.32745`

總期望值回報率約為 **32.75%**。

### 風險回報比分析 (Risk-Reward Ratio Analysis)
*   **上行潛力 (Upside Potential):** 在樂觀情境下，潛在回報為69.84%。在基準情境下，潛在回報為33.15%。
*   **下行空間 (Downside Potential):** 在悲觀情境下，潛在損失為23.91%。

從期望值角度看，潛在的上行空間 (加權平均約37.53%) 遠大於潛在的下行空間 (加權平均約4.78%)，顯示出明顯的不對稱風險回報特性。若以樂觀情境與悲觀情境的絕對值回報率相比，風險回報比約為 2.92:1 (69.84% / 23.91%)。

**最終結論：**
1.  **投資建議**：**買入**
2.  **核心邏輯**：儘管Nike目前面臨多重挑戰，包括中國市場疲軟、競爭加劇和品牌疲勞，但其高達32.75%的整體期望值回報率顯示出顯著的數學贏面。公司正積極進行戰略轉型，重建批發渠道、聚焦核心運動品類並推出新產品，這些努力有望在未來6-12個月內逐步顯現成效。當前股價已接近多年低點，市場已充分反映大部分負面因素，而潛在的上行空間遠大於下行風險，提供了一個具吸引力的風險回報比。
3.  **風控建議**：若進入悲觀情境，具體的出場訊號包括：大中華區營收連續兩季加速下滑、毛利率持續收縮而非擴張、或管理層對「Win Now」策略的執行進度發出重大預警。一旦股價跌破$28，且上述基本面惡化跡象明顯，應考慮減倉或止損，以保護資本。
