# NKE 投資分析：基於概率思考與期望值決策

作為一位精通概率思考與期望值決策的量化投資分析師，本報告將針對美股公司 Nike, Inc. (NKE) 進行多情境分析，評估其未來 6-12 個月的投資數學贏面。

## 1. 核心驅動因素與風險 (Drivers & Risks)

Nike 目前正處於轉型期，面臨多重挑戰與潛在機遇。

**關鍵催化劑 (Catalysts):**
1.  **Pace Program 執行成效顯現：** Nike 的「Pace」轉型計畫旨在簡化營運、提高生產力並加速「Sport Offense」策略。若該計畫能有效實現預期的 25 億美元成本節約，並在未來 6-12 個月內展現出超出預期的營運效率提升，將有助於改善利潤率和自由現金流，提振投資者信心。
2.  **2026 年投資者日公布明確的長期增長策略：** 預計於 2026 年 11 月 16-17 日舉行的投資者日，是 Nike 九年來的首次。若管理層能在此次活動中提出清晰、可信且具體的多年期增長策略，特別是在產品創新、數位轉型和市場拓展方面，並能有效解決大中華區和生活時尚產品線的挑戰，將可能重新點燃市場對其長期增長潛力的信心。
3.  **核心運動表現業務持續強勁增長：** Nike 的跑步、足球、訓練和籃球等核心運動表現業務在 Q1 FY27 呈現高個位數增長，並持續推出創新產品。若此趨勢能持續並擴展至其他地區，有效抵銷生活時尚產品線的疲軟，將證明其「Sport Offense」策略的成功，並為整體營收帶來正向貢獻。

**主要風險點 (Risks):**
1.  **大中華區市場持續疲軟與競爭加劇：** 大中華區銷售額在 Q1 FY27 大幅下滑 26%，主要受本土品牌競爭、消費支出疲軟及消費者偏好轉變影響。若此趨勢未能有效逆轉，且 Nike 未能成功調整其在該地區的策略，將對其整體營收和盈利能力構成重大下行壓力。
2.  **生活時尚產品線（Sportswear, Jordan）復甦緩慢：** 佔 Nike 約一半營收的生活時尚產品線持續面臨挑戰，管理層預計 FY27 仍將呈現負增長。若這些關鍵業務未能有效復甦，且新興競爭者（如 On、Hoka）持續侵蝕市場份額，將導致整體營收持續下滑，並可能影響其品牌吸引力。
3.  **宏觀經濟逆風與消費者支出緊縮：** 全球經濟放緩、通脹壓力以及消費者可支配支出緊縮，可能導致對非必需品（如運動鞋服）的需求進一步下降。若宏觀經濟環境惡化，將直接衝擊 Nike 的銷售額和盈利能力，尤其是在其轉型期間。

## 2. 情境設定與機率賦予 (Scenario Modeling)

**當前股價 (Current Price):** $34.74

**樂觀情境 (Bull Case)**：
*   **發生條件**：Pace 轉型計畫的成本節約效果顯著且快於預期，同時 2026 年投資者日公布的長期策略獲得市場高度認可，特別是在大中華區和生活時尚產品線展現出明確的復甦跡象。核心運動表現業務持續強勁增長，並成功推出多款受歡迎的新產品，有效抵禦競爭。宏觀經濟環境意外改善，提振消費者信心。
*   **預估機率**：25%
*   **目標價格與預期回報**：基於市場對其轉型成功和未來增長潛力的重新評估，P/E 倍數有望回升至歷史平均水平。若 FY27 EPS 能達到預期上限 $1.35，並考慮到 2028 年 EPS 預計增長 30.7% 至 $2.17，我們以 FY28 EPS $2.17 乘以保守的 25 倍 P/E (低於其 5 年中位數 30.34x，但高於目前水平)，得出目標價約為 $54.25。綜合考量部分分析師給出的高目標價 $50-$51 以及 GuruFocus 的 GF Value $69-$72，設定目標價格為 $55。
    *   預期回報：(($55 - $34.74) / $34.74) = 58.3%

**基準情境 (Base Case)**：
*   **發生條件**：Pace 計畫按部就班進行，成本節約效果符合預期但進度緩慢。投資者日提供了一些策略方向，但市場對其執行能力仍持謹慎態度。大中華區和生活時尚產品線的下滑趨勢有所放緩，但尚未實現顯著復甦。核心運動表現業務保持穩定增長，但不足以完全抵銷其他業務的疲軟。宏觀經濟環境保持現狀，無重大惡化或改善。
*   **預估機率**：50%
*   **目標價格與預期回報**：基於分析師的共識「持有」評級和平均目標價。目前分析師平均目標價約為 $40.96 - $46.33。我們取中間值 $42。
    *   預期回報：(($42 - $34.74) / $34.74) = 20.9%

**悲觀情境 (Bear Case)**：
*   **發生條件**：Pace 計畫執行不力，成本節約效果不及預期，甚至因重組產生額外費用。投資者日未能提出令人信服的轉型策略，導致市場信心進一步受挫。大中華區和生活時尚產品線持續惡化，市場份額被競爭對手大幅侵蝕。宏觀經濟環境進一步惡化，消費者支出大幅緊縮，導致整體營收和盈利能力加速下滑。股息可能面臨削減風險。
*   **預估機率**：25%
*   **目標價格與預期回報**：基於最悲觀的分析師預期，例如 Morgan Stanley 的 $20-$27 或 BofA Securities 的 $24。考慮到當前股價已接近 52 週低點 $31.97，以及公司仍有強大的品牌和現金儲備，但面臨結構性問題，我們設定目標價格為 $25。
    *   預期回報：(($25 - $34.74) / $34.74) = -28.1%

## 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

**決策樹繪製 (Decision Tree):**

```
當前股價: $34.74
├── 樂觀情境 (機率: 25%)
│   └── 條件: Pace計畫成功, 投資者日策略清晰, 核心業務強勁, 宏觀改善
│       └── 目標價格: $55 (回報: +58.3%)
├── 基準情境 (機率: 50%)
│   └── 條件: Pace計畫符合預期, 策略方向明確但執行謹慎, 大中華區/生活時尚趨穩
│       └── 目標價格: $42 (回報: +20.9%)
└── 悲觀情境 (機率: 25%)
    └── 條件: Pace計畫不力, 策略不明, 大中華區/生活時尚惡化, 宏觀惡化
        └── 目標價格: $25 (回報: -28.1%)
```

**總期望值計算 (Total Expected Value Calculation):**

EV = (機率_樂觀 * 回報_樂觀) + (機率_基準 * 回報_基準) + (機率_悲觀 * 回報_悲觀)
EV = (0.25 * 0.583) + (0.50 * 0.209) + (0.25 * -0.281)
EV = 0.14575 + 0.1045 - 0.07025
EV = 0.180

**總期望值 (Expected Value) = 18.0%**

**風險回報比分析 (Risk-Reward Ratio Analysis):**

*   **上行潛力 (Upside Potential):** 58.3% (樂觀情境)
*   **下行空間 (Downside Potential):** -28.1% (悲觀情境)

風險回報比 (Upside/Downside Ratio) = 58.3% / 28.1% ≈ 2.07

這表示每承擔 1 單位下行風險，有機會獲得約 2.07 單位的上行回報。從數學期望值來看，NKE 具有正向的期望回報，且上行潛力大於下行風險。

## 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | 58.3% | Pace計畫超預期、投資者日策略清晰、核心業務強勁、宏觀改善 |
| **基準 (Base)** | 50% | 20.9% | Pace計畫符合預期、策略方向明確但執行謹慎、大中華區/生活時尚趨穩 |
| **悲觀 (Bear)** | 25% | -28.1% | Pace計畫不力、策略不明、大中華區/生活時尚惡化、宏觀惡化 |
| **整體期望值** | **100%** | **18.0%** | **加權平均預期回報** |

**最終結論：**
1.  **投資建議**：持有
2.  **核心逻辑**：儘管 Nike 面臨大中華區疲軟、生活時尚產品線掙扎以及激烈競爭等多重挑戰，導致營收預期下滑，但其核心運動表現業務仍具韌性，且「Pace」轉型計畫有望帶來長期成本效益。當前股價已大幅下跌，部分分析師認為其被低估，且股息收益率具吸引力。綜合考量，18.0% 的正向期望值顯示其在當前價位具備一定的數學贏面，但鑑於轉型過程的長期性和不確定性，以及市場情緒的謹慎，建議「持有」以觀察後續催化劑的實際成效。
3.  **風控建議**：若進入悲觀情境，具體的出場訊號包括：大中華區銷售額持續加速下滑且無改善跡象；「Pace」計畫未能如期產生效益，或管理層進一步下調 FY27/FY28 營收及 EPS 指引；以及股息政策面臨削減的明確信號。此時應考慮減持或清倉，以保護資本。
