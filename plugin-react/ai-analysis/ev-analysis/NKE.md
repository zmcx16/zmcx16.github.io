# NKE 投資決策分析：基於概率思考與期望值模型

作為一位精通概率思考與期望值決策的量化投資分析師，我將針對美股公司 Nike, Inc. (NKE) 進行多情境分析，評估其當前投資的數學贏面。

## 1. 核心驅動因素與風險 (Drivers & Risks)

### 關鍵催化劑 (Catalysts)
1.  **新產品發布與「運動攻勢」策略成功**：Nike 專注於高端定位和高性能產品類別的增長，特別是在跑步等領域。未來 6-12 個月被視為「催化劑豐富」的時期，預計到 2027 年春季，隨著全套運動攻勢產品的推出，將迎來真正的轉折點。
2.  **營運效率提升與利潤率改善**：公司正在實施成本削減措施，預計將改善利潤率。此外，預計未來一年每股收益 (EPS) 將增長 35.06%，顯示盈利能力有望回升。
3.  **中國市場及核心生活時尚產品線復甦**：儘管目前中國市場和生活時尚產品線（如 Sportswear 和 Jordan Streetwear）面臨挑戰，但任何超出預期的銷售反彈或改善都將成為股價上漲的強勁催化劑。

### 主要風險點 (Risks)
1.  **全球經濟放緩與消費者支出疲軟**：全球經濟波動和消費者信心下降可能導致非必需品支出減少，特別是影響 Nike 較大的生活時尚產品線，這些產品線目前已面臨挑戰。
2.  **中國市場持續疲軟與競爭加劇**：Nike 在中國市場面臨持續的逆風和銷售下滑，同時來自其他品牌的競爭日益激烈，可能導致市場份額流失。
3.  **供應鏈中斷與關稅風險**：Nike 的製造高度依賴外包（主要在越南、印尼和中國），任何供應鏈中斷、地緣政治緊張或潛在的更高關稅都可能增加生產成本並影響產品供應。

## 2. 情境設定與機率賦予 (Scenario Modeling)

當前 NKE 股價為 $41.71，接近其 52 週低點 $40.00。分析師平均目標價約為 $50.62 至 $53.74。

### 樂觀情境 (Bull Case)
*   **發生條件**：Nike 的「運動攻勢」策略取得顯著成功，新產品線廣受市場歡迎，尤其在跑步等高性能領域實現超預期增長。同時，中國市場銷售強勁反彈，且全球消費者信心回升，帶動生活時尚產品線意外復甦。公司成本控制措施效果顯著，利潤率大幅提升，並實現強勁的 EPS 增長。
*   **預估機率**：30%
*   **目標價格與預期回報**：若成功實現轉型和市場復甦，股價有望回升至接近 52 週高點的一半或更高，甚至達到部分分析師的樂觀目標。考慮到其歷史高點和品牌價值，以及預期 EPS 增長，P/E 倍數有望擴張。
    *   目標價格：$70.00 (約為 52 週高點 $80.17 的 87%，或接近分析師高目標的下限)
    *   預期回報：($70.00 - $41.71) / $41.71 = 67.82%

### 基準情境 (Base Case)
*   **發生條件**：Nike 的轉型進展符合或略優於市場預期。高性能產品線持續增長，但生活時尚產品線的復甦緩慢且不穩定。中國市場表現持平或略有改善，但不足以抵消其他地區的挑戰。公司盈利能力逐步改善，但宏觀經濟環境仍存在不確定性，導致股價溫和上漲。
*   **預估機率**：50%
*   **目標價格與預期回報**：基於分析師的平均目標價。
    *   目標價格：$50.00 (接近提供的 Target Price $49.93 和分析師平均目標價 $50.62-$53.74)
    *   預期回報：($50.00 - $41.71) / $41.71 = 19.87%

### 悲觀情境 (Bear Case)
*   **發生條件**：全球經濟進一步惡化，消費者支出大幅縮減，尤其對非必需品造成衝擊。Nike 在中國市場的銷售持續下滑，且生活時尚產品線的困境加劇，未能實現預期的復甦。競爭加劇導致市場份額流失，供應鏈問題或關稅風險顯現，導致利潤率承壓，公司未能達到盈利預期。
*   **預估機率**：20%
*   **目標價格與預期回報**：股價可能跌破 52 週低點，甚至觸及分析師的最低目標價。
    *   目標價格：$30.00 (低於 52 週低點 $40.00，接近分析師最低目標價 $23.00-$40.00 的區間)
    *   預期回報：($30.00 - $41.71) / $41.71 = -28.07%

## 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

### 決策樹繪製
```
投資 NKE (當前價格 $41.71)
├── 樂觀情境 (機率 30%)
│   └── 預期回報 +67.82% (目標價格 $70.00)
├── 基準情境 (機率 50%)
│   └── 預期回報 +19.87% (目標價格 $50.00)
└── 悲觀情境 (機率 20%)
    └── 預期回報 -28.07% (目標價格 $30.00)
```

### 總期望值計算
EV = (機率_樂觀 * 回報_樂觀) + (機率_基準 * 回報_基準) + (機率_悲觀 * 回報_悲觀)
EV = (0.30 * 0.6782) + (0.50 * 0.1987) + (0.20 * -0.2807)
EV = 0.20346 + 0.09935 - 0.05614
**EV = 0.24667 (即 24.67%)**

### 風險回報比分析
*   **上行潛力 (Upside):** 樂觀情境下有 67.82% 的潛在回報。
*   **下行空間 (Downside):** 悲觀情境下有 -28.07% 的潛在損失。

從期望值來看，NKE 具有正向的預期回報 (24.67%)。上行潛力顯著大於下行空間，風險回報比約為 67.82% / 28.07% ≈ 2.42:1。這表明每承擔 1 單位下行風險，潛在的上行回報約為 2.42 單位。儘管存在顯著的下行風險，但其潛在的收益不對稱性使其在數學上具有吸引力。

| :--- | :--- | :--- | :--- |

**最終結論：**
1.  **投資建議**：買入
2.  **核心逻辑**：NKE 目前股價接近 52 週低點，市場已充分反映其面臨的挑戰。儘管存在不確定性，但透過期望值模型分析，其加權平均預期回報率為 24.67%，且上行潛力 (67.82%) 顯著大於下行空間 (-28.07%)，風險回報比約為 2.42:1。公司在高性能產品線和成本控制方面展現出積極信號，未來 6-12 個月存在多個潛在催化劑，有望推動股價反彈。
3.  **風控建議**：若 NKE 股價跌破 $38.00（約為當前價格下跌 9%），且伴隨中國市場銷售數據進一步惡化、核心生活時尚產品線未見任何復甦跡象，或宏觀經濟數據顯示全球消費支出加速萎縮，則應考慮減倉或出場。此價格點可作為初步止損位，以保護資本並重新評估悲觀情境發生的可能性。
