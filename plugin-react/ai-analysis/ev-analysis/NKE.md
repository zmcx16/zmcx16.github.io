# NKE 投資分析：基於概率思考與期望值決策

作為一名量化投資分析師，我將運用概率思考與期望值決策模型，對美股公司 Nike, Inc. (NKE) 進行多情境分析，以評估其當前投資的數學贏面。

## 1. 核心驅動因素與風險 (Drivers & Risks)

Nike目前正處於轉型期，面臨挑戰的同時也蘊藏機會。

*   **關鍵催化劑 (Catalysts)**：
    1.  **2026年投資者日 (Investor Day 2026) 的新策略發布：** 預計在2026年11月16-17日舉行，新任CEO Elliott Hill將闡述未來多年的增長戰略，特別是聚焦於高性能運動產品、恢復批發渠道關係以及潛在的創新產品線。這有望重塑市場對Nike未來增長路徑的信心。
    2.  **「運動攻勢」(Sport Offense) 策略的成功與新產品發布：** Nike在跑步、足球、訓練和籃球等高性能運動類別已展現增長勢頭，並計劃推出十多款新鞋款。若這些產品能有效抓住消費者需求並提升品牌吸引力，將推動銷售增長。
    3.  **庫存正常化與利潤率改善：** 透過清理過剩庫存、減少折扣以及「Pace」重組計劃，有望改善毛利率和營運效率，進而提升盈利能力。

*   **主要風險點 (Risks)**：
    1.  **大中華區市場持續疲軟：** 大中華區銷售額在2027財年第一季度大幅下滑26%，已連續九個季度下降，主要受當地競爭加劇和需求疲軟影響。管理層預計這種壓力將持續存在。
    2.  **消費者需求疲軟與宏觀經濟逆風：** 佔Nike營收約一半的休閒生活類產品（如Sportswear和Jordan Brand）表現不佳，因消費者減少非必需品支出。管理層預計2027財年營收將出現高個位數下降。
    3.  **競爭加劇與市場份額流失：** 運動服飾市場競爭激烈，Adidas、Puma、On Holding以及中國本土品牌（如安踏、李寧）等競爭對手正在搶佔市場份額，對Nike的市場主導地位構成挑戰。

## 2. 情境設定與機率賦予 (Scenario Modeling)

當前股價 (Close): $38.32

*   **樂觀情境 (Bull Case)**：
    *   **發生條件**：2026年投資者日發布的策略獲得市場高度認可，新產品線表現強勁，尤其是在高性能運動領域取得突破。大中華區市場出現初步穩定跡象，庫存問題得到有效解決，毛利率顯著改善。宏觀經濟環境優於預期，消費者信心回升。
    *   **預估機率**：25%
    *   **目標價格與預期回報**：基於分析師最高目標價 $60-$75 的中位數 $67.50。
        *   預期回報率 = (($67.50 - $38.32) / $38.32) * 100% = 76.15%

*   **基準情境 (Base Case)**：
    *   **發生條件**：Nike的轉型策略逐步推進，但進展緩慢且非線性。營收如管理層預期般在2027財年呈現高個位數下降，但盈利能力因成本控制和庫存管理改善而略好於預期。大中華區市場壓力持續，但未進一步惡化。市場對其長期前景保持「持有」觀望態度。
    *   **預估機率**：55%
    *   **目標價格與預期回報**：基於分析師平均目標價 $36.32 - $40.93 的中位數 $38.62。
        *   預期回報率 = (($38.62 - $38.32) / $38.32) * 100% = 0.78%

*   **悲觀情境 (Bear Case)**：
    *   **發生條件**：2026年投資者日未能提出令人信服的轉型方案，或新策略執行不力。大中華區銷售持續惡化，競爭加劇導致市場份額進一步流失。全球消費者需求持續疲軟，庫存問題未能有效解決，導致持續的折扣和利潤率壓力。宏觀經濟惡化，甚至出現衰退。
    *   **預估機率**：20%
    *   **目標價格與預期回報**：基於分析師最低目標價 $19-$24 的中位數 $21.50。
        *   預期回報率 = (($21.50 - $38.32) / $38.32) * 100% = -43.90%

## 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

**決策樹繪製 (Decision Tree)**：

```
當前股價: $38.32
├── 樂觀情境 (機率: 25%)
│   └── 目標價格: $67.50 (回報: +76.15%)
├── 基準情境 (機率: 55%)
│   └── 目標價格: $38.62 (回報: +0.78%)
└── 悲觀情境 (機率: 20%)
    └── 目標價格: $21.50 (回報: -43.90%)
```

**總期望值計算 (Total Expected Value Calculation)**：

EV = (機率_樂觀 * 回報_樂觀) + (機率_基準 * 回報_基準) + (機率_悲觀 * 回報_悲觀)
EV = (0.25 * 76.15%) + (0.55 * 0.78%) + (0.20 * -43.90%)
EV = 19.0375% + 0.429% - 8.78%
EV = 10.6865%

**風險回報比分析 (Risk-Reward Ratio Analysis)**：

*   **上行潛力 (Upside Potential):** 在樂觀情境下，潛在回報為 76.15%。
*   **下行空間 (Downside Potential):** 在悲觀情境下，潛在損失為 -43.90%。

從期望值來看，NKE的加權平均預期回報為正10.69%。上行潛力顯著大於下行空間的絕對值，顯示出不對稱的風險回報特性。儘管悲觀情境下的損失較大，但其發生機率相對較低，而基準情境和樂觀情境的綜合機率較高，且樂觀情境提供了可觀的回報。

## 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | 76.15% | 投資者日新策略成功、新產品強勁、中國市場穩定、庫存改善 |
| **基準 (Base)** | 55% | 0.78% | 轉型緩慢但穩定、營收符合預期下降、盈利略好於預期 |
| **悲觀 (Bear)** | 20% | -43.90% | 策略失敗、中國市場惡化、需求持續疲軟、競爭加劇 |
| **整體期望值** | **100%** | **10.69%** | **加權平均預期回報** |

**最終結論：**
1.  **投資建議**：持有
2.  **核心邏輯**：儘管Nike面臨多重挑戰，特別是大中華區市場的持續疲軟和宏觀經濟逆風，但其強大的品牌力、積極的轉型策略（如「運動攻勢」和「Pace」重組計劃）以及即將到來的投資者日，為未來提供了潛在的催化劑。目前的股價已反映了大部分負面因素，且分析師平均目標價與現價接近，顯示市場共識為「持有」。期望值分析顯示，儘管存在顯著的下行風險，但其上行潛力在機率加權後仍帶來正向的預期回報，呈現出不對稱的風險回報比。
3.  **風控建議**：若NKE股價跌破分析師最低目標價 $21.50，或大中華區營收跌幅進一步擴大且管理層未能提出有效應對措施，則應考慮出場。此外，密切關注即將到來的財報和投資者日，若未能提供清晰的轉型路徑或業績指引持續惡化，也應作為減倉或出場的訊號。
