作為一位精通概率思考與期望值決策的量化投資分析師，我將對美股公司 Nike, Inc. (NKE) 進行多情境分析，評估其未來 6-12 個月的投資贏面。

### 1. 核心驅動因素與風險 (Drivers & Risks)

根據提供的基本面數據及最新市場資訊，NKE 目前股價接近 52 週低點，市場情緒偏向謹慎，分析師共識為「持有」或「中性」。

-   **關鍵催化劑 (Catalysts)**：
    1.  **2026 年投資者日 (Investor Day 2026) 的策略清晰度**：預計在 11 月舉行的投資者日，CEO Elliott Hill 將闡述公司未來數年的多年度增長策略。若能提出清晰且具說服力的轉型計畫，將顯著提振投資者信心。
    2.  **新產品週期成功與創新驅動**：Nike 持續推出新鞋款系列（例如 2025 年跑鞋系列、SNKRS Showcase 預覽），若這些新產品能獲得市場熱烈迴響，並在跑步等核心性能類別中展現強勁銷售，將推動營收增長和市佔率提升。
    3.  **中國市場復甦超預期與庫存正常化**：若大中華區銷售能較預期更快地止跌回升，且公司能有效清理過剩庫存，將大幅緩解市場主要擔憂，並改善毛利率。

-   **主要風險點 (Risks)**：
    1.  **中國市場持續疲軟與庫存壓力**：大中華區銷售持續顯著下滑，且未能有效解決庫存過剩問題，將導致營收和毛利率面臨更大壓力。
    2.  **競爭加劇與市佔率流失**：來自本地品牌及其他運動服飾競爭者的壓力日益增加，可能進一步侵蝕 Nike 的市佔率和定價能力。
    3.  **宏觀經濟逆風與消費需求疲弱**：全球經濟環境惡化或消費者支出持續低迷，可能對所有地區的銷售產生負面影響。
    4.  **2027 財年第一季財報不及預期**：即將於 10 月 1 日公佈的財報若營收或每股盈餘不及預期，或進一步下調未來財測，可能引發股價新一輪下跌。

### 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 (35.75 美元) 和市場資訊，以下為未來 12 個月的三種情境分析：

-   **樂觀情境 (Bull Case)**：
    -   **發生條件**：2026 年投資者日成功發布令人振奮的長期增長策略，新產品週期表現強勁，尤其在關鍵性能類別中實現顯著增長。同時，中國市場展現出明確的復甦跡象，庫存問題得到有效解決，推動毛利率擴張。
    -   **預估機率**：20%
    -   **目標價格與預期回報**：基於市場對轉型成功的信心，P/E 倍數回歸歷史平均水平，或達到分析師高目標區間。預計目標價格為 60.00 美元。
        -   預期回報：($60.00 - $35.75) / $35.75 = +67.8%

-   **基準情境 (Base Case)**：
    -   **發生條件**：公司業績符合分析師普遍預期，轉型策略逐步推進但進展緩慢。中國市場銷售趨於穩定但未見強勁反彈，庫存管理持續改善但仍面臨一定壓力。新產品表現平穩，但不足以完全抵消宏觀逆風和競爭壓力。
    -   **預估機率**：50%
    -   **目標價格與預期回報**：基於分析師共識的平均目標價。預計目標價格為 45.00 美元。
        -   預期回報：($45.00 - $35.75) / $35.75 = +25.9%

-   **悲觀情境 (Bear Case)**：
    -   **發生條件**：即將公佈的 Q1 財報不及預期，並進一步下調全年財測。中國市場銷售持續大幅下滑，庫存問題惡化導致更嚴重的折扣促銷，嚴重侵蝕毛利率。宏觀經濟環境惡化，消費者需求進一步疲軟，競爭壓力顯著加劇。
    -   **預估機率**：30%
    -   **目標價格與預期回報**：基於分析師最低目標價，或考慮到營收和盈利能力持續惡化下的估值收縮。預計目標價格為 30.00 美元。
        -   預期回報：($30.00 - $35.75) / $35.75 = -16.1%

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

**決策樹繪製 (文字結構)**：

```
當前股價: $35.75
├── 樂觀情境 (機率: 20%)
│   └── 預期回報: +67.8% (目標價: $60.00)
├── 基準情境 (機率: 50%)
│   └── 預期回報: +25.9% (目標價: $45.00)
└── 悲觀情境 (機率: 30%)
    └── 預期回報: -16.1% (目標價: $30.00)
```

**總期望值計算 (Total Expected Value Calculation)**：

`EV = (機率_樂觀 * 回報_樂觀) + (機率_基準 * 回報_基準) + (機率_悲觀 * 回報_悲觀)`
`EV = (0.20 * 0.678) + (0.50 * 0.259) + (0.30 * -0.161)`
`EV = 0.1356 + 0.1295 - 0.0483`
`EV = 0.2168`
`總期望值 = +21.68%`

**風險回報比分析 (Risk-Reward Ratio Analysis)**：

NKE 的期望值為正 21.68%，顯示出在未來 12 個月內，根據當前情境假設，投資該股票具有正向的數學贏面。上行潛力 (Bull Case +67.8%) 遠大於下行空間 (Bear Case -16.1%)，呈現出不對稱的風險回報比。這表明即使悲觀情境發生的機率不低 (30%)，其潛在損失也相對有限，而樂觀情境下的潛在收益則非常可觀。目前股價接近 52 週低點，且 P/E 倍數處於十年低位，為潛在的上行提供了較大的安全邊際。

2.  **核心邏輯**：儘管 Nike 面臨中國市場疲軟和庫存調整的短期挑戰，但其目前股價已反映了大部分負面因素，交易在歷史 P/E 低點附近，提供了顯著的安全邊際。 結合即將到來的投資者日可能帶來的策略清晰度，以及持續的產品創新能力，其上行潛力遠大於下行風險，期望值分析顯示出具吸引力的正向回報。
