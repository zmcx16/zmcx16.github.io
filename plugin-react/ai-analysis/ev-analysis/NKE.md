# NKE 投資決策分析：基於概率思考與期望值模型

作為一位量化投資分析師，我將運用概率思考與期望值決策模型，對美股公司 Nike, Inc. (NKE) 進行多情境分析，以評估其當前的投資數學贏面。

## 1. 核心驅動因素與風險 (Drivers & Risks)

Nike 正處於轉型期，其未來 6-12 個月的股價走勢將主要受以下關鍵因素影響：

*   **關鍵催化劑**：
    1.  **Pace 轉型計畫成效顯現**：Nike 的 Pace 成本節約計畫預計在 FY31 前實現 25 億美元的累積節省，並立即改善毛利率和盈利能力。若該計畫能加速執行並在未來 6-12 個月內展現優於預期的效益，將顯著提振股價。
    2.  **2026 投資者日 (11/16-11/17)**：這是 Nike 九年來首次舉辦投資者日，預計新任 CEO Elliott Hill 將闡述未來五年的多年度增長戰略和財務目標。若能提出清晰、具說服力的增長路徑和盈利能力恢復時間表，將有效重塑市場信心。
    3.  **新產品週期與運動品類復甦**：預計到 2027 年春季將推出完整的「運動攻勢」產品系列。若新產品能成功吸引消費者，並在北美等關鍵市場實現強勁增長，將抵消其他地區的疲軟。

*   **主要風險點**：
    1.  **大中華區市場持續疲軟與競爭加劇**：大中華區營收在 Q1 FY27 下降 26%，面臨本土品牌（如安踏、李寧）的激烈競爭，以及分銷模式重組帶來的短期壓力。若該地區的銷售下滑未能止血，將嚴重拖累整體業績。
    2.  **生活時尚產品需求不振與庫存問題**：管理層指出生活時尚市場缺乏活力，產品同質化嚴重，導致需求疲軟和庫存積壓。若庫存清理進度緩慢且促銷活動侵蝕利潤，將對毛利率構成壓力。
    3.  **FY27 營收與盈利指引下調**：公司預計 FY27 營收將出現高個位數下滑，且 EBIT 降幅將大於營收降幅。若實際業績表現甚至低於已下調的指引，或管理層進一步下調預期，將引發市場恐慌。
    4.  **股息可持續性風險**：根據 FY27 的 EPS 預期，Nike 的股息支付率可能超過 100%，這引發了市場對其股息可持續性的擔憂。若公司被迫削減股息，將對股價造成負面影響。

## 2. 情境設定與機率賦予 (Scenario Modeling)

基於當前股價 $39.12，以及對未來 12 個月市場動態的評估，設定以下三種情境：

*   **樂觀情境 (Bull Case)**：
    *   **發生條件**：Pace 轉型計畫超預期加速，2026 投資者日提出清晰且具吸引力的長期增長戰略，新產品成功引爆市場需求，尤其在北美市場表現強勁，且大中華區市場的下滑趨勢顯著放緩。FY27 盈利指引被上調，市場對 FY28 復甦信心大增。
    *   **預估機率**：25%
    *   **目標價格與預期回報**：基於 FY28 預期 EPS $2.17 且市場給予 27 倍 P/E 倍數 (反映強勁復甦預期)。
        *   目標價格 = $2.17 * 27 = $58.59
        *   預期回報 = ($58.59 - $39.12) / $39.12 = 49.78%

*   **基準情境 (Base Case)**：
    *   **發生條件**：Pace 計畫按部就班推進，但短期效益有限。2026 投資者日提供合理但缺乏驚喜的戰略，大中華區和生活時尚產品線的挑戰持續存在，但未進一步惡化。公司業績符合 FY27 下調後的指引，FY28 預期增長緩慢。分析師共識維持「持有」評級。
    *   **預估機率**：50%
    *   **目標價格與預期回報**：基於 FY27 調整後 EPS 指引中點 $1.25 且市場給予 28 倍 P/E 倍數 (反映對未來復甦的謹慎樂觀)。
        *   目標價格 = $1.25 * 28 = $35.00
        *   預期回報 = ($35.00 - $39.12) / $39.12 = -10.53%

*   **悲觀情境 (Bear Case)**：
    *   **發生條件**：大中華區市場加速惡化，競爭壓力導致市佔率進一步流失。生活時尚產品庫存問題嚴重，導致大幅降價促銷，嚴重侵蝕毛利率。FY27 業績大幅不及預期，管理層再次下調指引，甚至宣布削減股息。市場對公司轉型失去信心。
    *   **預估機率**：25%
    *   **目標價格與預期回報**：基於 FY27 調整後 EPS 指引低點 $1.15 且市場給予 25 倍 P/E 倍數 (反映盈利能力受損和增長前景黯淡)。
        *   目標價格 = $1.15 * 25 = $28.75
        *   預期回報 = ($28.75 - $39.12) / $39.12 = -26.51%

## 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

**決策樹繪製**：

```
當前投資 NKE ($39.12)
├── 樂觀情境 (機率: 25%)
│   └── 預期目標價: $58.59 (回報: +49.78%)
├── 基準情境 (機率: 50%)
│   └── 預期目標價: $35.00 (回報: -10.53%)
└── 悲觀情境 (機率: 25%)
    └── 預期目標價: $28.75 (回報: -26.51%)
```

**總期望值計算**：
`EV = (機率_樂觀 * 回報_樂觀) + (機率_基準 * 回報_基準) + (機率_悲觀 * 回報_悲觀)`
`EV = (0.25 * 49.78%) + (0.50 * -10.53%) + (0.25 * -26.51%)`
`EV = 12.445% - 5.265% - 6.6275%`
`EV = 0.5525%`

**風險回報比分析**：
*   **上行潛力 (Upside)**：在樂觀情境下，預期回報為 +49.78%。
*   **下行空間 (Downside)**：在悲觀情境下，預期回報為 -26.51%。
*   **風險回報比 (Upside/Downside Ratio)**：49.78% / 26.51% ≈ 1.88 : 1。

儘管上行潛力大於下行空間，但基準情境為負回報，且整體期望值僅為微幅正值，顯示投資 NKE 在當前價格下，數學贏面較為有限，風險與回報之間的不對稱性並不明顯具吸引力。

## 4. 決策總結 (Decision Summary)

| 情境 | 發生機率 (%) | 預期報酬率 (%) | 關鍵驅動/觸發因素 |
| :--- | :--- | :--- | :--- |
| **樂觀 (Bull)** | 25% | 49.78% | Pace計畫超預期、投資者日戰略清晰、新產品成功、大中華區改善 |
| **基準 (Base)** | 50% | -10.53% | Pace計畫按部就班、戰略缺乏驚喜、大中華區與生活時尚挑戰持續、符合下調指引 |
| **悲觀 (Bear)** | 25% | -26.51% | 大中華區惡化、庫存問題嚴重、業績大幅不及預期、削減股息 |
| **整體期望值** | **100%** | **0.55%** | **加權平均預期回報** |

**最終結論：**
1.  **投資建議**：持有
2.  **核心逻辑**：NKE 目前的整體期望值僅為微幅正值 0.55%，顯示在當前股價下，投資的數學贏面並不顯著。儘管存在如 Pace 轉型計畫和即將到來的投資者日等潛在催化劑，但公司面臨大中華區市場疲軟、生活時尚產品需求不振以及 FY27 營收和盈利指引下調等重大逆風。基準情境預期為負回報，反映了市場對其短期業績的謹慎態度。因此，在明確的復甦信號出現之前，建議觀望。
3.  **風控建議**：若 NKE 股價跌破 $31.97 (52 週低點)，或公司在 Q2 FY27 財報中再次下調全年指引，或宣布削減股息，應視為明確的出場訊號。投資者可考慮設定止損點於 $30.00，以限制下行風險。
