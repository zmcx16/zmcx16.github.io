作為一位精通概率思考與期望值決策的量化投資分析師，我將對Nike (NKE) 進行多情境分析，評估其未來12個月的投資數學贏面。

---

### 1. 核心驅動因素與風險 (Drivers & Risks)

**關鍵催化劑 (Catalysts)**：
*   **2026世界盃與奧運週期帶動新產品發布與品牌行銷**：Nike歷史上善於利用大型體育賽事重塑品牌定位並推動產品發布。2026年世界盃和持續的奧運週期預計將為其足球和田徑市場帶來行銷催化劑，特別是性能類產品（如跑步、訓練、籃球和ACG）預計將在2027財年實現增長。
*   **「運動攻勢」(Sport Offense) 策略推動產品創新與市場份額提升**：Nike正透過「運動攻勢」策略，將約8,000名員工重新分配到垂直運動團隊，旨在加速決策、提升產品品質並強化品牌故事敘述，以期透過執行力和運動真實性而非廣泛促銷來重建增長。
*   **毛利率改善與庫存健康化**：公司預計毛利率將透過效率提升、產品成本降低以及減少促銷活動而擴張。2026財年第四季度毛利率因一次性關稅回收收益而顯著提升，管理層預計毛利率擴張將從2027財年第一季度開始。

**主要風險點 (Risks)**：
*   **大中華區市場持續疲軟與競爭加劇**：大中華區市場在2026財年第四季度營收持續下滑，且面臨安踏、李寧等本土品牌的激烈競爭，消費者情緒謹慎，對Nike的整體業績構成重大拖累。
*   **生活時尚類產品（Sportswear, Jordan Streetwear）創新不足或需求不振**：儘管性能類產品表現良好，但佔Nike約一半營收的生活時尚類產品（Sportswear和Jordan Streetwear）銷售依然疲軟，產品滲透率受挑戰，折扣活動頻繁，影響未來訂單。
*   **全球宏觀經濟不確定性及消費者支出壓力**：管理層承認消費者面臨壓力，零售銷售趨勢自4月中旬開始減速，導致營收展望下調。宏觀經濟不確定性可能持續影響消費者支出，進而影響Nike的銷售表現。

### 2. 情境設定與機率賦予 (Scenario Modeling)

**當前股價 (Current Price)**: $44.37

*   **樂觀情境 (Bull Case)**：
    *   **發生條件**：2026世界盃與奧運週期行銷活動取得巨大成功，新發布的性能與生活時尚類產品廣受市場歡迎，大中華區市場意外實現穩定甚至溫和復甦，同時毛利率因營運效率提升和關稅利好而顯著擴張。
    *   **預估機率**：25%
    *   **目標價格與預期回報**：基於強勁的產品週期和市場復甦，P/E倍數有望擴張至30-35倍，推動股價達到$70。
    *   **預期回報**：((70 - 44.37) / 44.37) * 100% = 57.79%

*   **基準情境 (Base Case)**：
    *   **發生條件**：Nike的「運動攻勢」策略逐步見效，性能類產品持續增長，但生活時尚類產品和中國市場的復甦緩慢且不均衡。毛利率溫和改善，營收符合管理層低至中個位數下滑的指引，市場共識的分析師預期得以實現。
    *   **預估機率**：50%
    *   **目標價格與預期回報**：基於分析師共識平均目標價約$53.5，反映當前市場對其轉型進度的預期。
    *   **預期回報**：((53.5 - 44.37) / 44.37) * 100% = 20.58%

*   **悲觀情境 (Bear Case)**：
    *   **發生條件**：大中華區市場進一步惡化，新產品未能有效刺激需求，競爭壓力持續加大，全球宏觀經濟下行導致消費者支出大幅減少，促銷活動持續侵蝕毛利率，且可能面臨新的法律訴訟或營運挑戰。
    *   **預估機率**：25%
    *   **目標價格與預期回報**：股價可能跌至分析師最低目標價附近，反映市場對其轉型失敗的擔憂，P/E倍數可能收縮至15-20倍。目標價$28。
    *   **預期回報**：((28 - 44.37) / 44.37) * 100% = -36.89%

### 3. 期望值計算與決策樹 (EV Calculation & Decision Tree)

**決策樹繪製 (Decision Tree)**：

```
當前股價 ($44.37)
├── 樂觀情境 (機率: 25%) ──> 目標價 $70 (回報: +57.79%)
│
├── 基準情境 (機率: 50%) ──> 目標價 $53.5 (回報: +20.58%)
│
└── 悲觀情境 (機率: 25%) ──> 目標價 $28 (回報: -36.89%)
```

**總期望值計算 (Total Expected Value Calculation)**：
`EV = (0.25 * 0.5779) + (0.50 * 0.2058) + (0.25 * -0.3689)`
`EV = 0.144475 + 0.1029 + (-0.092225)`
`EV = 0.15515`
**總期望值 (EV) = 15.52%**

**風險回報比分析 (Risk-Reward Ratio Analysis)**：
*   上行潛力 (Upside Potential) = $70 (樂觀目標價) - $44.37 (當前股價) = $25.63
*   下行空間 (Downside Potential) = $44.37 (當前股價) - $28 (悲觀目標價) = $16.37
*   風險回報比 (Upside:Downside) = $25.63 : $16.37 ≈ 1.57 : 1

儘管期望值為正，但上行潛力與下行空間的比例並非極度不對稱偏向上行，顯示投資仍存在顯著風險。

**最終結論：**
1.  **投資建議**：持有
2.  **核心邏輯**：Nike的整體期望值為正15.52%，顯示長期而言具備一定的上行潛力。然而，公司正處於轉型期，面臨大中華區市場疲軟、生活時尚類產品需求不振以及宏觀經濟不確定性等多重挑戰。儘管有2026世界盃和奧運週期等潛在催化劑，但其效果仍需觀察，且轉型進度存在不確定性。目前的風險回報比約為1.57:1，雖然為正，但下行風險不容忽視。在轉型成果尚未明確顯現之前，建議「持有」觀望，等待更清晰的復甦信號。
3.  **風控建議**：若進入悲觀情境，具體的出場訊號包括：大中華區營收連續兩季加速下滑，或生活時尚類產品（Sportswear, Jordan Streetwear）銷售數據持續惡化且管理層未能提出有效應對策略。此外，若股價跌破$38（約為當前股價下跌14%），可考慮部分減倉以保護資本，因為這可能預示著市場對其轉型前景的信心大幅動搖，並可能進一步測試$28的悲觀目標價。
