# American Eagle Outfitters (AEO) 投資價值分析報告

#### 估值地位分析
- **折價狀態**：相對於 ANF 的高成長溢價，AEO 目前處於明顯的**折價 (Discount)** 狀態。其 P/E (9.18x) 低於產業平均值 (~12x)。
- **獲利能力**：AEO 的營業利潤率 (9.34%) 優於 GPS 與 URBN，顯示其成本控制與 Aerie 品牌的高毛利貢獻顯著。
- **結論**：市場目前對 AEO 的定價較為保守，主要擔憂 AE 主品牌的成長天花板，但忽略了 Aerie 持續的雙位數增長潛力與公司強勁的自由現金流生成能力。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### 預測假設
1.  **預測期間**：5 年 (2025-2029)。
2.  **營收增長率**：預計未來 3 年複合增長率 (CAGR) 為 4.5%。其中 Aerie 預計增長 8-10%，AE 品牌持平或微增 1-2%。
3.  **自由現金流 (FCF) 利潤率**：假設維持在 6.5% - 7.5% 區間，考量到資本支出 (CapEx) 將集中於店面翻新與供應鏈數位化。
4.  **稅率**：26%。

#### 折現率與終值
- **WACC 計算**：
  - 無風險利率 (Risk-free Rate)：4.2% (參考美債 10Y)。
  - 貝塔值 (Beta)：1.5 (反映零售業高波動性)。
  - 股權風險溢價 (ERP)：5.5%。
  - **WACC 估算結果：10.8%**。
- **終值增長率 (Terminal Growth Rate)**：2.0% (符合長期通膨與成熟零售業預期)。

#### 估值結果
- **企業價值 (EV)**：約 $3.85B。
- **扣除淨負債後股權價值**：約 $3.42B。
- **DCF 內在價值**：**$22.45**。
- **合理價位區間**：$20.5 - $24.5。

### 3. 多維度估值法

#### 相對估值法 (Relative Valuation)
參考同業平均 Forward P/E 11.5x，給予 AEO 稍微保守的 10.5x 倍數（考量其債務權益比 1.09 略高於部分同業）。
- **目標價 = 2025 EPS 預估 ($2.15) × 10.5 = $22.58**。

#### 股息折現模型 (DDM)
AEO 目前配息 $0.50/年，殖利率 2.79%。
- 假設股息增長率 (g) 為 3%，股權成本 (Ke) 為 11.5%。
- **DDM 價值 = 0.50 / (0.115 - 0.03) = $5.88**。
- *註：DDM 對 AEO 參考價值較低，因其目前處於資本擴張期而非純收成期。*

#### 企業價值倍數法 (EV/EBITDA)
給予 6.5x EV/EBITDA (產業中位數)。
- **推算股價：$21.20**。
