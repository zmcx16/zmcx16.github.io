### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估算公司未來自由現金流的現值，以得出其內在價值。

**預測假設**：
*   **預測期間 (Explicit Forecast Period)**：5年 (2026-2030)。
*   **營收增長率預期 (Revenue Growth Rate)**：
    *   2026年：5.5% (基於 2026 年全年指引中位數 4.5%-7.5%)
    *   2027年：6.0%
    *   2028年：5.0%
    *   2029年：4.0%
    *   2030年：3.0% (逐步趨近終值增長率)
*   **營業利潤率 (Operating Margin)**：EPAM Q1 2026 非 GAAP 營業利潤率為 14.3%，TTM 為 10.91%。考慮到公司對 AI 的投資和成本優化計劃，預計未來幾年將逐步改善。
    *   2026年：13.0%
    *   2027年：13.5%
    *   2028年：14.0%
    *   2029年：14.5%
    *   2030年：15.0%
*   **稅率 (Tax Rate)**：採用 2025 年非 GAAP 有效稅率 23.5%。
*   **資本支出 (Capital Expenditure, CapEx)**：假設為營收的 2.0%。
*   **折舊與攤銷 (Depreciation & Amortization, D&A)**：假設為營收的 2.5%。
*   **營運資本變動 (Change in Net Working Capital, NWC)**：假設為營收增長的 10%。

**折現率與終值**：
*   **加權平均資本成本 (Weighted Average Cost of Capital, WACC)**：
    *   **股權成本 (Cost of Equity, Ke)**：使用資本資產定價模型 (CAPM)。
        *   無風險利率 (Risk-Free Rate, Rf)：採用美國 10 年期國債收益率 4.557%。
        *   Beta (β)：採用 1.2282。
        *   市場風險溢酬 (Market Risk Premium, ERP)：採用 6.0%。
        *   Ke = 4.557% + 1.2282 * 6.0% = 11.93%。
    *   **債務成本 (Cost of Debt, Kd)**：考慮到 EPAM 的低債務水平和市場利率，採用 7.0%。
    *   **稅率 (Tax Rate, t)**：23.5%。
    *   **債務市值 (Market Value of Debt, D)**：$287.94M。
    *   **股權市值 (Market Value of Equity, E)**：$4.5B。
    *   **WACC** = (E/V) * Ke + (D/V) * Kd * (1 - t) = (4.5B / 4.78794B) * 11.93% + (0.28794B / 4.78794B) * 7.0% * (1 - 0.235) = 11.53%。
*   **終值增長率 (Terminal Growth Rate, g)**：假設為 2.5% (略低於長期 GDP 增長率)。

**估值結果**：
基於上述假設，通過 DCF 模型計算，EPAM Systems Inc. 的企業價值約為 $10B - $12B。考慮到公司持有的現金 $1.04B 和債務 $287.94M，股權價值約為 $10.75B - $12.75B。
以約 51.33M 的流通股數計算 (市值 $4.5B / 股價 $87.67)，
**DCF 模型下的內在價值區間為：$200 - $250。**

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**：
我們將使用同業的平均估值倍數來推算 EPAM 的目標價位。
*   **同業平均 P/E (不含虧損的 Endava)**: (12.57 + 10.8 + 13.32) / 3 = 12.23。
    *   EPAM TTM EPS: $7.01。
    *   目標價 = 12.23 * $7.01 = $85.72。
*   **同業平均 P/S (不含 Endava)**: (0.57 + 1.16 + 1.39) / 3 = 1.04。
    *   EPAM FY2025 Revenue: $5.46B。
    *   目標市值 = 1.04 * $5.46B = $5.68B。
    *   目標價 = $5.68B / 51.33M 股 = $110.66。
*   **同業平均 EV/EBITDA (不含 Endava)**: (8.83 + 6.3 + 7.44) / 3 = 7.52。
    *   EPAM TTM EBITDA: $686.88M。
    *   目標企業價值 = 7.52 * $0.68688B = $5.16B。
    *   目標股權價值 = $5.16B + $1.04B (現金) - $0.288B (債務) = $5.912B。
    *   目標價 = $5.912B / 51.33M 股 = $115.18。

綜合相對估值法，目標價位區間約為 **$85 - $115**。
