### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF模型旨在估計公司未來自由現金流的現值，以得出其內在價值。

**預測假設**

*   **預測期間：** 5年 (2026-2030)。
*   **營收增長率預期：**
    *   2026年：根據公司指引，預計營收增長率為3.7% (取3.2%至4.2%的中點)。
    *   2027-2028年：考慮到AI轉型帶來的潛力以及市場競爭，預計增長率將逐步提升，但仍需謹慎。假設為5.0%和6.0%。
    *   2029-2030年：隨著AI業務的成熟和市場份額的穩定，增長率將趨於平穩，假設為5.0%和4.0%。
*   **營業利潤率 (Operating Margin)：** 根據公司2026年非GAAP營業利潤率指引15.5%至16%，我們假設未來五年營業利潤率穩定在15.8%。
*   **稅率：** 根據公司Q3 2026非GAAP有效稅率預期約24%，我們假設未來稅率為24%。
*   **資本支出 (Capital Expenditure, CapEx)：** 假設為營收的2.0% (與歷史趨勢和行業特性一致)。
*   **折舊與攤銷 (D&A)：** 假設為營收的2.5% (與歷史趨勢一致)。
*   **營運資本變動 (Change in Working Capital)：** 假設為營收變動的5% (反映營收增長對營運資金的需求)。

**折現率與終值**

*   **無風險利率 (Risk-Free Rate)：** 採用美國10年期國債收益率，目前約為4.65%。
*   **市場風險溢酬 (Market Risk Premium, MRP)：** 採用Kroll推薦的美國股票風險溢酬，為5.0%。
*   **Beta (β)：** EPAM的Beta值為1.39。
*   **股權成本 (Cost of Equity, Ke)：** 根據CAPM模型計算：
    Ke = 無風險利率 + Beta × 市場風險溢酬
    Ke = 4.65% + 1.39 × 5.0% = 4.65% + 6.95% = 11.60%

*   **債務成本 (Cost of Debt, Kd)：** 考慮到EPAM的低負債率 (Debt/Eq: 0.04)，假設其稅前債務成本為6.0%。
*   **稅後債務成本：** Kd (1 - 稅率) = 6.0% × (1 - 24%) = 4.56%
*   **權重：** 根據EPAM的低負債率，我們假設股權權重為95%，債務權重為5%。
*   **加權平均資本成本 (WACC)：**
    WACC = (股權權重 × Ke) + (債務權重 × 稅後債務成本)
    WACC = (0.95 × 11.60%) + (0.05 × 4.56%) = 11.02% + 0.23% = 11.25%

*   **終值增長率 (Terminal Growth Rate, g)：** 假設為2.5%，略高於長期通脹率，反映公司在成熟階段的永續增長。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**

我們將使用同業的平均估值倍數來推算EPAM的目標價位。

*   **P/E Ratio (Trailing):**
    同業平均 P/E (ACN, GLOB, CTSH) = (14.84 + 14.32 + 11.84) / 3 = 13.67
    EPAM 2026年預期EPS (非GAAP) = $13.08 - $13.24 (取中點 $13.16)
    目標價 = 13.67 × 13.16 = 180.00 美元。

*   **Forward P/E Ratio:**
    同業平均 Forward P/E (ACN, GLOB, CTSH) = (11.67 + 6.01 + 9.80) / 3 = 9.16
    EPAM 2027年預期EPS (假設增長7.55% [用戶提供]) = 13.16 * (1 + 0.0755) = 14.15 美元
    目標價 = 9.16 × 14.15 = 129.61 美元。
    (此處EPAM的Forward P/E 6.9與同業平均9.16有較大差距，若直接使用EPAM的Forward P/E 6.9，則目標價為 6.9 * 14.15 = 97.63 美元，這與當前股價接近，可能反映市場對其未來增長預期較為保守。)

*   **P/S Ratio:**
    同業平均 P/S (ACN, GLOB, CTSH) = (1.58 + 0.62 + 1.14) / 3 = 1.11
    EPAM 2026年預期營收 = 5,870 百萬美元
    EPAM 2026年預期每股營收 = 5,870 / 51.4 = 114.20 美元
    目標價 = 1.11 × 114.20 = 126.76 美元。

*   **EV/EBITDA Ratio:**
    同業平均 EV/EBITDA (ACN, GLOB, CTSH, DAVA) = (8.84 + 10.25 + 7.44 + 9.8) / 4 = 9.08
    EPAM 2026年預期EBITDA (基於營業利潤率15.8%和D&A 2.5%) = 5,870 * (0.158 + 0.025) = 1,070 百萬美元
    企業價值 = 9.08 × 1,070 = 9,716 百萬美元
    股權價值 = 9,716 + 500 (淨現金) = 10,216 百萬美元
    目標價 = 10,216 / 51.4 = 198.75 美元。

綜合相對估值法，目標價位區間約在 **130 - 200 美元**。

EPAM Systems Inc 的基本面數據顯示其「Dividend %」為 "-"，表示公司目前不支付股息。因此，股息折現模型 (DDM) 不適用於EPAM的估值。

**其他方法**
資產基礎估值 (Asset-based Valuation) 或 SOTP (Sum-of-the-parts Valuation) 通常適用於擁有大量有形資產或多元化業務部門的公司。EPAM作為一家IT服務公司，其主要價值在於人力資本、技術專長和客戶關係，這些無形資產難以通過資產基礎法準確衡量。因此，這些方法不適用於EPAM的估值。
