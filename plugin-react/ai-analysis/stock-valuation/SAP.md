# SAP SE (SAP) 深度估值分析報告

作為資深投資分析師，針對 SAP 目前從傳統地端軟體轉型為雲端領先企業的關鍵階段，以下是基於 2024 年第三季財報及市場最新數據的完整估值分析。

---

### 1. 同業比較分析 (Industry Peer Comparison)

SAP 的主要競爭對手集中在企業資源規劃 (ERP)、客戶關係管理 (CRM) 及人力資本管理 (HCM) 領域。

| :--- | :--- | :--- | :--- | :--- |
| **市值 (Market Cap)** | ~$270B | ~$520B | ~$310B | ~$70B |
| **前瞻本益比 (Forward P/E)** | 36.5x | 28.2x | 30.5x | 35.2x |

| **EV/EBITDA** | 24.5x | 21.0x | 22.5x | 28.0x |
| **營收增長率 (YoY)** | 10% (雲端 25%) | 8% | 11% | 17% |
| **營業利潤率 (Non-IFRS)** | ~30% | ~43% | ~33% | ~25% |
| **淨利潤率 (Net Margin)** | ~15% | ~20% | ~16% | ~18% |

**估值地位分析：**
SAP 目前相對於 Oracle 處於**溢價 (Premium)** 狀態，主要反映了市場對其「雲端轉型加速」與「Business AI」整合的高度預期。SAP 的雲端未履約訂單 (Cloud Backlog) 增長強勁（約 25%），這使其在成長性上優於傳統的 Oracle。雖然其利潤率暫低於 Oracle 與 Salesforce，但隨著 2024-2025 年重組計劃完成，利潤率具備擴張潛力。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

**預測假設：**
- **預測期間**：2025 - 2029 (5年)。
- **營收增長率**：預計未來 3 年複合增長率 (CAGR) 為 10-12%，主要由雲端業務 (Cloud Revenue) 20%+ 的增長驅動。
- **自由現金流 (FCF) 利潤率**：預計從目前的 18% 逐步提升至 2025 年的 22% (目標 75-80 億歐元)，並在 2029 年達到 25%。
- **稅率**：24%。

**折現率與終值：**
- **WACC (加權平均資本成本)**：**8.8%**。
    - 無風險利率 (Risk-free Rate): 4.2% (美債 10Y)。
    - 貝塔值 (Beta): 1.05。
    - 股權風險溢價 (ERP): 5.0%。
    - 債務成本 (Pre-tax Cost of Debt): 4.5%。
- **終值增長率 (Terminal Growth Rate)**：**2.5%** (符合全球 GDP 長期增長預期)。

**估值結果：**
- **企業價值 (EV)**：約 $2,850 億美元。
- **股權價值 (Equity Value)**：扣除淨負債後，約 $2,780 億美元。
- **內在價值 (Intrinsic Value)**：**$238.50 / ADR**。
- **合理價位區間**：**$220 - $255**。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)：**
參考同業平均 Forward P/E 約 32x，給予 SAP 2025 年預估 EPS ($6.80) 約 35x 的倍數（考量其雲端轉型溢價），推算目標價為 **$238**。

**股息折現模型 (DDM)：**
SAP 2023 年配息 €2.20，預計未來股息增長率為 8-10%。
- 假設 $D_1 = \$2.55$, $r = 8.8\%$, $g = 7.5\%$。
- 推算價值：$2.55 / (0.088 - 0.075) = \mathbf{\$196.15}$。
*(註：DDM 通常低估成長型科技股，僅供下行支撐參考)*。

**SOTP (分部加總估值)：**
- 雲端業務 (高倍數 10x P/S) + 地端授權 (低倍數 3x P/S) + 服務。
- 估算總價值約 **$245**。

**最終結論：**
1. **合理價位區間**：**$230 - $245**
2. **目前股價位階**：**合理 (Fairly Valued)** (參考目前市價約 $230 左右)
3. **投資核心論點**：SAP 正處於雲端轉型的收割期，其 Cloud Backlog 的高能見度提供了極強的抗週期性。Business AI 的整合（如 Joule 助手）提升了客單價 (ARPU)。雖然目前估值倍數處於歷史高位，但考慮到 2025 年營運利潤目標的實現以及強勁的 FCF 增長，目前的股價已充分反映預期，建議在回調至 $215-$220 區間時分批佈局。主要風險在於宏觀經濟放緩導致企業 IT 支出縮減。
