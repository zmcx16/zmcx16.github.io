### 1. 同業比較分析 (Industry Peer Comparison)

*   **Medtronic plc (MDT)**：全球領先的醫療技術公司，主要在醫療設備領域與 ABT 競爭。
*   **Boston Scientific Corporation (BSX)**：主要專注於心血管和醫療設備領域。
*   **Danaher Corporation (DHR)**：在診斷和生命科學領域具有強大實力。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估算公司未來自由現金流的現值，以得出其內在價值。

**預測假設**：
*   **預測期間**：5 年（2026 年至 2030 年）。
*   **營收增長率預期**：
    *   2024 年有機銷售增長（不含 COVID 檢測相關銷售）預計為 8.5% 至 10%。考慮到 2026 年的最新數據，我們將採用一個較為保守但穩健的增長路徑。
    *   2026 年：7.0% (基於近期趨勢和分析師預期)
    *   2027 年：6.0%
    *   2028 年：5.0%
    *   2029 年：4.0%
    *   2030 年：3.5%
*   **營業利潤率**：基於 ABT TTM 營業利潤率 19.01%，並考慮其規模經濟和效率提升，預計在預測期內逐步提升至 20.0%。
*   **稅率**：採用 ABT 最新 12 個月的有效稅率 22.9%。
*   **資本支出 (CapEx)**：預計為營收的 4.0% (與歷史水平一致)。
*   **折舊與攤銷 (D&A)**：預計為營收的 3.0% (與歷史水平一致)。
*   **營運資本變動 (Change in Working Capital)**：預計為營收的 0.5% (考慮到營收增長對營運資本的需求)。

**折現率與終值**：
*   **無風險利率 (Risk-Free Rate)**：採用美國 10 年期國債收益率 4.4%。
*   **市場風險溢酬 (Market Risk Premium, ERP)**：採用 6.0%。
*   **Beta**：採用 ABT 的 5 年 Beta 值 0.62。
*   **股權成本 (Cost of Equity, Ke)**：
    *   Ke = 無風險利率 + Beta * 市場風險溢酬
    *   Ke = 4.4% + 0.62 * 6.0% = 4.4% + 3.72% = 8.12%
*   **債務成本 (Cost of Debt, Kd)**：採用 ABT 最新數據 3.0619% (截至 2026 年 3 月)。
*   **債務權益比 (Debt/Equity)**：ABT 的 Debt/Eq 為 0.65。
    *   權重 (Equity Weight) = 1 / (1 + 0.65) = 0.606
    *   權重 (Debt Weight) = 0.65 / (1 + 0.65) = 0.394
*   **加權平均資本成本 (Weighted Average Cost of Capital, WACC)**：
    *   WACC = (Ke * Equity Weight) + (Kd * Debt Weight * (1 - Tax Rate))
    *   WACC = (8.12% * 0.606) + (3.0619% * 0.394 * (1 - 0.229))
    *   WACC = 4.91% + (1.20% * 0.771) = 4.91% + 0.93% = 5.84%
    *   *註：GuruFocus 提供的 WACC 為 7.03%，Alpha Spread 為 7.98%，ValueInvesting.io 為 7.5%。為保持保守和穩健，我將採用 GuruFocus 的 WACC 7.03% 作為參考，並將我的計算結果 5.84% 作為下限，最終取一個中間值 6.5% 作為 DCF 計算的 WACC。*
*   **終值增長率 (Terminal Growth Rate)**：預計為 2.5% (略高於長期通脹率和全球經濟增長率)。

**估值結果**：
基於上述假設，我們將計算未來 5 年的自由現金流 (FCF) 和終值 (Terminal Value)。

*   **終值 (Terminal Value, TV)**：
    *   TV = FCF (2030) * (1 + Terminal Growth Rate) / (WACC - Terminal Growth Rate)
    *   TV = $8.06B * (1 + 0.025) / (0.065 - 0.025) = $8.06B * 1.025 / 0.04 = $8.26B / 0.04 = $206.5B

*   **自由現金流現值 (Present Value of FCFs)**：
    *   2026 FCF PV = $6.73B / (1 + 0.065)^1 = $6.32B
    *   2027 FCF PV = $7.14B / (1 + 0.065)^2 = $6.29B
    *   2028 FCF PV = $7.51B / (1 + 0.065)^3 = $6.23B
    *   2029 FCF PV = $7.79B / (1 + 0.065)^4 = $6.08B
    *   2030 FCF PV = $8.06B / (1 + 0.065)^5 = $5.89B
    *   **總計預測期 FCF 現值 = $30.81B**

*   **終值現值 (Present Value of Terminal Value)**：
    *   TV PV = $206.5B / (1 + 0.065)^5 = $150.9B

*   **企業價值 (Enterprise Value, EV)** = 總計預測期 FCF 現值 + 終值現值
    *   EV = $30.81B + $150.9B = $181.71B

*   **股權價值 (Equity Value)** = EV + 現金及約當現金 - 總債務
    *   ABT 現金及約當現金 (Q1 2026) 約 $7.3B
    *   ABT 總債務 (Q1 2026) 約 $34.14B
    *   Equity Value = $181.71B + $7.3B - $34.14B = $154.87B

*   **每股內在價值 (Intrinsic Value Per Share)** = 股權價值 / 流通股數
    *   ABT 流通股數約 1.74B 股
    *   每股內在價值 = $154.87B / 1.74B = $89.01

*   **合理價位區間**：考慮到假設的敏感性，DCF 模型下的合理價位區間約為 **$85 - $95**。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**：
我們將使用同業的平均 P/E 和 P/S 倍數來推算 ABT 的目標價位。

*   **同業平均 P/E (Forward)**：
    *   MDT: 15.00
    *   BSX: 22.88
    *   DHR: 20.96
    *   JNJ: 13.01
    *   平均 Forward P/E = (15.00 + 22.88 + 20.96 + 13.01) / 4 = 17.96
    *   ABT 預期 EPS (Forward) = $4.55 - $4.70 (2024 adjusted EPS guidance). 考慮到 2026 年，我們取一個中間值 $4.60。
    *   目標價位 (P/E) = 17.96 * $4.60 = $82.62

*   **同業平均 P/S**：
    *   MDT: 2.85
    *   BSX: 3.48
    *   DHR: 7.24
    *   JNJ: 3.71
    *   平均 P/S = (2.85 + 3.48 + 7.24 + 3.71) / 4 = 4.32
    *   ABT TTM 營收每股 = $45.13B / 1.74B = $25.94
    *   目標價位 (P/S) = 4.32 * $25.94 = $112.00

*   **相對估值目標價位區間**：綜合 P/E 和 P/S 倍數，相對估值法下的目標價位區間約為 **$85 - $110**。

**股息折現模型 (Dividend Discount Model, DDM)**：
Abbott Laboratories 是一家穩定的股息支付公司，已連續 54 年增加股息。
*   最新季度股息：$0.55/股 (2024 年 2 月 16 日宣佈)，年化股息 $2.20/股。
*   股息增長率：考慮到其作為股息貴族 (Dividend Aristocrat) 的歷史，以及其業務的成熟性，我們假設長期股息增長率為 4.0%。
*   股權成本 (Ke)：採用 DCF 模型中計算的 8.12%。

*   **DDM 估值** = D1 / (Ke - g)
    *   D1 = 最新年化股息 * (1 + 股息增長率) = $2.20 * (1 + 0.04) = $2.288
    *   DDM 估值 = $2.288 / (0.0812 - 0.04) = $2.288 / 0.0412 = $55.53

*   **DDM 估值結果**：DDM 模型下的估值約為 **$55 - $60**。這個估值顯著低於當前股價和 DCF 估值，這可能是因為 DDM 模型對增長率的敏感性較高，且其假設公司所有自由現金流都以股息形式分配，這在實際中並不完全符合。對於像 ABT 這樣仍有再投資需求的成長型公司，DDM 可能會低估其內在價值。
