### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估算公司未來自由現金流的現值，以得出其內在價值。

**預測假設**
*   **預測期間 (Explicit Forecast Period)**：5 年 (2027-2031)。
*   **營收增長率 (Revenue Growth Rate)**：
    *   PAGS 2026 年毛利潤增長指引為 3%-5%。考慮到巴西宏觀經濟壓力及公司近期增長放緩，我們將採用保守的增長率。
    *   2027年：4.0%
    *   2028年：3.5%
    *   2029年：3.0%
    *   2030年：2.5%
    *   2031年：2.0%
*   **營業利潤率 (Operating Margin)**：用戶提供的數據為 37.54%。然而，Q1 2026 營業利潤率壓縮至 9.3%。這是一個顯著的差異。考慮到近期壓力，我們將假設營業利潤率在預測期內逐步恢復，但不會達到歷史高點。
    *   2027年：15.0%
    *   2028年：17.0%
    *   2029年：19.0%
    *   2030年：20.0%
    *   2031年：21.0%
*   **稅率 (Tax Rate)**：PAGS TTM 有效稅率為 17.30%。我們將採用此稅率。
*   **資本支出 (Capital Expenditures, CapEx)**：2026 年 CapEx 指引為 BRL 1.8B - BRL 2B。假設為 BRL 1.9B，約為 $0.365B (1.9B / 5.2)。PAGS TTM 營收為 $3.75B。CapEx 佔營收比約為 9.7%。我們將假設 CapEx 佔營收的 8% 並逐步下降至 6%。
*   **營運資本變動 (Change in Net Working Capital, NWC)**：假設為營收的 2% 且穩定。

**折現率與終值**
*   **加權平均資本成本 (Weighted Average Cost of Capital, WACC)**：
    *   **無風險利率 (Risk-Free Rate)**：採用美國 10 年期國債收益率，假設為 4.5%。
    *   **市場風險溢價 (Market Risk Premium)**：假設為 5.5%。
    *   **Beta 值 (Beta)**：PAGS 的 Beta 值為 1.36。
    *   **股權成本 (Cost of Equity, Ke)**：使用資本資產定價模型 (CAPM)：Ke = 無風險利率 + Beta * 市場風險溢價 = 4.5% + 1.36 * 5.5% = 11.98%。
    *   **債務成本 (Cost of Debt, Kd)**：PAGS 的利息覆蓋率 (TTM) 為 1.53x，表明其債務成本相對較高。考慮到巴西的高利率環境，我們假設稅前債務成本為 10.0%。
    *   **稅率 (Tax Rate)**：17.30%。稅後債務成本 = 10.0% * (1 - 0.1730) = 8.27%。
    *   **債務權益比 (Debt-to-Equity Ratio)**：用戶提供為 3.07。
    *   **WACC 計算**：WACC = (E/(D+E)) * Ke + (D/(D+E)) * Kd * (1 - Tax Rate)。
        *   E/(D+E) = 1 / (3.07 + 1) = 1 / 4.07 = 0.2457
        *   D/(D+E) = 3.07 / (3.07 + 1) = 3.07 / 4.07 = 0.7543
        *   WACC = 0.2457 * 11.98% + 0.7543 * 8.27% = 2.94% + 6.24% = 9.18%。
*   **終值增長率 (Terminal Growth Rate)**：假設為 2.5%，略高於長期通脹率，反映公司在成熟市場的長期溫和增長。

**估值結果**
由於缺乏詳細的財務報表數據來精確預測每一項自由現金流組成部分，我們將基於上述假設進行簡化估算。

*   **簡化自由現金流 (FCF) 預測 (單位：百萬美元)**
    *   假設 2026 年營收為 $3.75B (TTM)。
    *   2027 年營收：$3.75B * 1.04 = $3.90B
    *   2028 年營收：$3.90B * 1.035 = $4.036B
    *   2029 年營收：$4.036B * 1.03 = $4.157B
    *   2030 年營收：$4.157B * 1.025 = $4.261B
    *   2031 年營收：$4.261B * 1.02 = $4.346B

    *   **EBIT (營業利潤)** = 營收 * 營業利潤率
    *   **稅後 EBIT** = EBIT * (1 - 稅率)
    *   **自由現金流 (FCF)** = 稅後 EBIT + 折舊與攤銷 (D&A) - 資本支出 (CapEx) - 營運資本變動 (ΔNWC)
        *   假設 D&A 約為營收的 3%。
        *   CapEx 佔營收比：2027: 8%, 2028: 7.5%, 2029: 7%, 2030: 6.5%, 2031: 6%。
        *   ΔNWC 佔營收比：2%。

*   **終值 (Terminal Value, TV)**：
    *   2031 年 FCF = $0.537B
    *   TV = FCF_2032 / (WACC - Terminal Growth Rate) = (FCF_2031 * (1 + Terminal Growth Rate)) / (WACC - Terminal Growth Rate)
    *   TV = ($0.537B * (1 + 0.025)) / (0.0918 - 0.025) = ($0.537B * 1.025) / 0.0668 = $0.550B / 0.0668 = $8.233B
    *   終值現值 = $8.233B / (1 + 0.0918)^5 = $8.233B / 1.551 = $5.308B

*   **公司內在價值 (Intrinsic Value)**：
    *   總現值 = 預測期 FCF 現值總和 + 終值現值
    *   總現值 = $0.191B + $0.252B + $0.309B + $0.330B + $0.344B + $5.308B = $6.734B

*   **每股內在價值 (Intrinsic Value Per Share)**：
    *   流通股數：約 274.74 百萬股。
    *   每股內在價值 = $6.734B / 274.74M = $24.51

*   **合理價位區間**：考慮到假設的敏感性，DCF 模型下的合理價位區間約為 **$22.00 - $27.00**。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**
我們將使用同業的平均估值倍數來推算 PAGS 的目標價位。

*   **P/E 倍數法**：
    *   同業平均 P/E (不含 Cielo，因其數據不完整且增長為負)：
        *   STNE: 2.88
        *   NU: 14.91
        *   MELI: 36.36
        *   平均 P/E = (2.88 + 14.91 + 36.36) / 3 = 18.05
    *   PAGS 預期 EPS (EPS next Y_%)：用戶數據為 0.0488，但 Q3 2026 稀釋非 GAAP EPS 增長 13% 至 BRL 2.90。2026 年稀釋 EPS 增長指引為 9%-13%。假設 2026 年 EPS 為 $1.48 (TTM)，2027 年 EPS 增長 10%，則 2027 年 EPS = $1.48 * 1.10 = $1.628。
    *   目標價 = 平均 P/E * 預期 EPS = 18.05 * $1.628 = $29.39

*   **P/S 倍數法**：
    *   同業平均 P/S (不含 Cielo)：
        *   STNE: 0.69
        *   NU: 2.60 (計算值)
        *   MELI: 1.78 (計算值)
        *   平均 P/S = (0.69 + 2.60 + 1.78) / 3 = 1.69
    *   PAGS TTM 營收 $3.75B。
    *   目標價 = 平均 P/S * (PAGS TTM 營收 / 流通股數) = 1.69 * ($3.75B / 274.74M) = 1.69 * $13.65 = $23.06

*   **EV/EBITDA 倍數法**：
    *   同業平均 EV/EBITDA (不含 NU 和 Cielo，因 NU 數據不完整，Cielo 數據不完整且增長為負)：
        *   STNE: 2.14 (計算值)
        *   MELI: 17.63
        *   平均 EV/EBITDA = (2.14 + 17.63) / 2 = 9.89
    *   PAGS TTM EBITDA = $1.77B。
    *   PAGS 企業價值 (EV) = 平均 EV/EBITDA * PAGS TTM EBITDA = 9.89 * $1.77B = $17.50B。
    *   PAGS 股權價值 = EV - 總債務 + 現金 = $17.50B - $9.07B (計算值) = $8.43B。
    *   目標價 = 股權價值 / 流通股數 = $8.43B / 274.74M = $30.68

*   **相對估值法目標價區間**：綜合 P/E、P/S 和 EV/EBITDA 倍數法，目標價區間約為 **$23.00 - $31.00**。

**股息折現模型 (Dividend Discount Model, DDM)**
PAGS 是一家穩定派息的公司。公司預計 2026 年 12 月派發約 BRL 400M 股息，並在 2027 年和 2028 年合計派發至少 BRL 2B (即每年 BRL 1B)。

*   **預期股息 (Dividend Per Share, DPS)**：
    *   2027 年預期股息 = BRL 1B / 5.2 BRL/USD / 274.74M 股 = $0.70/股。
    *   2028 年預期股息 = $0.70/股。
*   **股息增長率 (Dividend Growth Rate)**：考慮到公司增長放緩，我們假設長期股息增長率為 2.0%。
*   **股權成本 (Cost of Equity, Ke)**：沿用 DCF 模型中的 11.98%。

*   **DDM 估值**：
    *   假設 2026 年底股價為 $7.31。
    *   2027 年股息現值 = $0.70 / (1 + 0.1198)^1 = $0.625
    *   2028 年股息現值 = $0.70 / (1 + 0.1198)^2 = $0.558
    *   終端股息價值 (從 2029 年開始) = D_2029 / (Ke - g) = ($0.70 * (1 + 0.02)) / (0.1198 - 0.02) = $0.714 / 0.0998 = $7.154
    *   終端股息價值現值 = $7.154 / (1 + 0.1198)^2 = $7.154 / 1.254 = $5.705
    *   DDM 內在價值 = $0.625 + $0.558 + $5.705 = $6.89

*   **DDM 模型下的內在價值**：約為 **$6.89**。

**最終結論：**
1.  **合理價位區間**：綜合考量不同估值模型，並給予 DCF 和相對估值較高權重，PAGS 的合理價位區間預計在 **$18.00 - $25.00** 之間。DCF 和相對估值結果顯著高於 DDM，這可能是因為 DDM 對於增長型公司（即使增長放緩）的估值通常較為保守，且對股息增長率敏感。

2.  **目前股價位階**：PAGS 目前股價為 $7.31。相較於上述合理價位區間，目前股價處於**低估**狀態。

3.  **投資核心論點**：PAGS 目前的估值顯著低於其內在價值，主要原因在於市場對其增長前景的擔憂以及巴西高利率環境的壓力。然而，公司在 Q3 2026 仍實現了淨收入和 EPS 的增長，並維持了 EPS 增長指引。其穩定的盈利能力、較高的利潤率以及承諾的未來股息分派 顯示出被市場低估的潛力。若巴西宏觀經濟環境改善，利率下降，PAGS 有望實現估值修復。主要風險在於持續的宏觀經濟逆風和來自高增長同業的激烈競爭。
