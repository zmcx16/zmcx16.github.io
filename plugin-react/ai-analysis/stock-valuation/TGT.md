# Target Corp (TGT) 深度估值分析報告

作為資深投資分析師，針對 Target Corporation (TGT) 的當前財務狀況、產業競爭格局及未來現金流預測，本報告提供全方位的估值評估。

### 1. 同業比較分析 (Industry Peer Comparison)

Target 的業務模式介於「折扣零售」與「百貨公司」之間，其產品組合中非必需消費品（Discretionary Goods）佔比較高。我們選取 Walmart (WMT)、Costco (COST)、Dollar General (DG) 及 Amazon (AMZN) 作為主要對手。

#### 估值地位分析
- **折價狀態**：相對於 Walmart 與 Costco，Target 目前處於明顯的**折價 (Discount)** 狀態。這反映了市場對其「非必需品」佔比較高的擔憂，在通膨壓力下，消費者更傾向於 WMT 的食品雜貨。
- **合理性評估**：雖然 TGT 的 P/E 遠低於 WMT，但其 **ROE (26.41%)** 與 **營業利潤率 (5.74%)** 均優於 WMT。這顯示 TGT 具備更強的獲利效率。目前的低倍數主要源於市場對其營收成長動能（Sales Q/Q 5.27%）能否持續的觀望。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### 預測假設
- **預測期間**：2024 - 2028 (5年)。
- **營收增長率**：預計未來 3 年為 3.0% - 4.5%，隨後進入 2.5% 的穩定增長。這考量了其電商轉型與門市翻新的成效。
- **EBIT Margin**：假設穩定在 6.0% - 6.5%（公司長期目標為 6% 以上）。
- **有效稅率**：22.0%。
- **資本支出 (CapEx)**：佔營收的 3.5%，主要用於供應鏈自動化。

#### 折現率與終值
- **WACC 計算**：
  - 無風險利率 (10Y Treasury): 4.2%
  - Beta: 1.1
  - 股權風險溢價 (ERP): 5.0%
  - 權益成本 (Ke): 9.7%
  - 稅後債務成本: 4.0%
  - **WACC: 8.2%**
- **終值增長率 (g)**：2.5% (符合美國長期通膨與零售增長預期)。

#### 估值結果
- **企業價值 (EV)**：約 $88.5 Billion。
- **股權價值**：扣除淨負債後，得出內在價值。
- **DCF 推算單股價值**：**$174.50**。

### 3. 多維度估值法

#### 相對估值法 (Relative Valuation)
參考歷史平均 P/E (約 17x-18x) 與同業中位數。
- 若給予 17.5x Forward P/E，以預期 EPS $9.50 計算：**$166.25**。
- 若以 EV/EBITDA 11x 計算：**$162.00**。

#### 股息折現模型 (DDM)
Target 為「股息貴族」，連續 50 年以上增加配息。
- 當前年化股息：$4.48。
- 預期股息增長率 (g)：4.0%。
- 股權成本 (Ke)：9.7%。
- **DDM 推算價值**：$4.48 * (1.04) / (0.097 - 0.04) = **$81.77** (註：DDM 通常低估成長型零售商，僅供下行支撐參考)。

**最終結論：**
1. **合理價位區間**：**$165.00 - $172.00**
2. **目前股價位階**：**低估 (Undervalued)**
3. **投資核心論點**：Target 目前交易於 15.7x P/E，顯著低於歷史均值與同業 WMT。隨著庫存壓力緩解及利潤率回升至 6% 目標，其獲利能力已展現韌性。雖然非必需品需求受宏觀環境壓抑，但其強大的全通路（Omnichannel）能力與高 ROE 提供了安全邊際。目前股價尚未完全反映其營運效率的改善，具備估值修復（Re-rating）空間。
