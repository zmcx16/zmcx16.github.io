# Gilead Sciences (GILD) 深度估值分析報告

作為資深投資分析師，針對 Gilead Sciences (GILD) 的當前財務數據與市場表現，本報告將結合產業橫向對比、折現現金流模型 (DCF) 及多維度估值法，全面評估其內在價值。

---

#### 估值地位分析
- **溢價狀態**：相對於同業，GILD 在 **P/S (6.33x)** 上呈現溢價，這反映了市場對其 HIV 核心業務（Biktarvy）的高利潤率以及腫瘤藥物（Trodelvy）增長潛力的認可。
- **合理性**：其 **Forward P/E (15.59x)** 與 AbbVie 和 Amgen 基本持平，顯示市場已消化其短期因併購導致的 EPS 壓力，並看好明年 25.16% 的 EPS 增長預期。
- **技術壁壘**：GILD 擁有極高的 **Gross Margin (79.66%)**，顯著高於產業平均，這為其在研發投入與債務償還上提供了強大的緩衝空間。

### 2. 折現現金流模型 (DCF)

#### 預測假設
1.  **預測期間**：2024-2028 (5年)。
2.  **營收增長率**：預計未來 3 年受 HIV 藥物穩定貢獻與 Oncology 業務 20%+ 的增速帶動，複合年增長率 (CAGR) 設定為 **4.5%**。
3.  **自由現金流 (FCF) 利潤率**：參考 P/FCF 14.95x，隱含 FCF Yield 約 6.7%。假設 FCF Margin 穩定在 **35%**。
4.  **稅率**：有效稅率設定為 **19%**。

#### 折現率與終值
- **WACC 計算**：
  - 無風險利率 (Rf)：4.3% (10Y Treasury)
  - 貝塔值 (Beta)：0.5 (低波動防禦屬性)
  - 股權風險溢價 (ERP)：5.5%
  - 權益成本 (Ke)：7.05%
  - 債務成本 (Kd)：5.0% (考量 Debt/Eq 2.22 較高，信用風險溢價略升)
  - **最終 WACC：約 7.5%**。
- **終值增長率 (g)**：設定為 **2.0%**（符合生物醫藥產業長期通膨預期）。

#### 估值結果
- **企業價值 (EV)**：約 $215.6 Billion
- **股權價值**：扣除淨債務後，推算內在價值約 **$168.40**。
- **合理價位區間**：**$158.00 - $178.00**。

### 3. 多維度估值法

#### 相對估值法 (Relative Valuation)
- **Forward P/E 估值**：給予產業平均 16x 倍數，結合明年預期 EPS，目標價約 **$164.00**。
- **P/S 估值**：考量其高於同業的營業利潤率 (39%)，給予 6.5x P/S，目標價約 **$160.00**。

#### 股息折現模型 (DDM)
- **假設**：當前年化股息約 $3.24 (基於 2.08% 殖利率與 $156 股價)，預計未來股息增長率 (g) 為 **5.5%**，要求回報率 (r) 為 **7.5%**。
- **計算**：$3.24 * (1+0.055) / (0.075 - 0.055) = **$170.91**。
- **分析**：GILD 具備穩定的現金流產生能力，DDM 顯示其在當前利率環境下對收益型投資者極具吸引力。
