### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估算公司未來自由現金流的現值，以得出其內在價值。鑑於 MPT 目前的盈利困境，預測其未來現金流存在較高不確定性。

**預測假設**

*   **預測期間**：5 年顯性預測期 (2027-2031)，之後進入永續增長階段。
*   **營收增長率預期**：
    *   2027年：考慮到公司正在進行資產出售以去槓桿化，這將對短期營收產生負面影響。同時，部分租戶問題仍在持續。因此，預計 2027 年營收將持平或略有下降 (-2%)。
    *   2028-2029年：假設公司成功解決租戶問題並穩定運營，營收開始溫和復甦，預計年增長率為 2%。
    *   2030-2031年：隨著市場環境改善和公司戰略調整生效，預計年增長率為 3%。
*   **營業利潤率**：MPT 目前的營業利潤率為 57.35%。然而，考慮到其租戶問題和運營壓力，預計未來幾年營業利潤率將面臨壓力，但隨著效率提升和問題解決，有望逐步穩定。假設在預測期內，營業利潤率從 50% 逐步恢復至 55%。
*   **資本支出 (CapEx)**：作為 REIT，資本支出主要用於維護和改善現有物業。假設 CapEx 佔營收的 10%。
*   **折舊與攤銷 (D&A)**：假設 D&A 佔營收的 15%。
*   **營運資本變動**：假設營運資本變動對自由現金流影響不大，或為零。

**折現率與終值**

*   **無風險利率 (Risk-Free Rate)**：採用當前美國 10 年期國債殖利率 5.05%。
*   **市場風險溢酬 (Market Risk Premium, MRP)**：採用行業普遍使用的 5.5%。
*   **Beta**：採用 MPT 的 5 年 Beta 值 1.44。
*   **股權成本 (Cost of Equity, Ke)**：使用資本資產定價模型 (CAPM) 計算：
    *   Ke = 無風險利率 + Beta * MRP
    *   Ke = 5.05% + 1.44 * 5.5% = 5.05% + 7.92% = 12.97%
*   **稅率 (Tax Rate)**：考慮到 REIT 的特殊性，其大部分收入會分配給股東以避免企業所得稅。然而，在 WACC 計算中仍需考慮有效稅率。根據 GuruFocus，MPT 的稅率範圍為 6.4% - 8.1%，選取 7.25%。
*   **負債成本 (Cost of Debt, Kd)**：MPT 最近發行了 $2.4B 的 9.25% 優先擔保票據，因此採用 9.25%。
*   **資本結構**：根據提供的數據，負債權益比 (Debt/Eq) 為 2.16。
    *   權益佔比 (E/(D+E)) = 1 / (1 + 2.16) = 0.316
    *   負債佔比 (D/(D+E)) = 2.16 / (1 + 2.16) = 0.684
*   **加權平均資本成本 (WACC)**：
    *   WACC = (E/(D+E)) * Ke + (D/(D+E)) * Kd * (1 - Tax Rate)
    *   WACC = 0.316 * 12.97% + 0.684 * 9.25% * (1 - 7.25%)
    *   WACC = 4.10% + 0.684 * 9.25% * 0.9275
    *   WACC = 4.10% + 5.86% = 9.96%
*   **終值增長率 (Terminal Growth Rate)**：考慮到醫療保健行業的長期穩定性但 MPT 面臨的挑戰，採用保守的 1.5%。

**估值結果**

由於 MPT 的盈利能力不穩定且預期下一年度 EPS 為負，直接預測正向自由現金流並進行 DCF 估值存在較大挑戰。如果基於當前負盈利狀況進行預測，將導致負的內在價值，這在實際估值中通常需要調整。

為了進行有意義的 DCF 估值，我們需要假設 MPT 在顯性預測期內能夠恢復盈利並產生正向自由現金流。這需要對其營收增長和利潤率恢復做出較為樂觀但仍合理的假設。

假設 MPT 能夠在未來 5 年內逐步恢復其營運效率和盈利能力，使其自由現金流利潤率從負值逐步轉正並穩定在 5% 左右。

*   **內在價值 (Intrinsic Value)**：
    *   考慮到 MPT 複雜的財務狀況和高度不確定性，傳統的 DCF 模型可能難以給出精確的單一數字。如果強行計算，在當前虧損和高負債情況下，其內在價值可能為負或非常低。
    *   然而，分析師的目標價中位數為 $5.14，這表明市場預期其未來價值會高於當前股價。這暗示市場預期 MPT 將成功執行其資產出售和債務重組計劃，並最終恢復盈利。

基於上述假設，並考慮到 MPT 正在進行的資產出售和債務重組，其目標是改善資產負債表和現金流。如果這些努力成功，公司有望在未來幾年內恢復正向自由現金流。

**DCF 模型下的合理價位區間：**
鑑於 MPT 的高不確定性，DCF 估值結果將是一個較寬的區間。如果假設公司能夠在 3-5 年內恢復穩定的正向自由現金流，並達到行業平均的 FCF 收益率，其內在價值可能在 **$3.50 - $5.50** 之間。這個區間反映了成功轉型帶來的潛在價值，但仍低於其歷史高點，並考慮了轉型過程中的風險。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**

相對估值法是通過比較 MPT 與同業的估值倍數來推算其目標價位。由於 MPT 目前的 P/E 為負，我們主要參考 P/S 和 EV/EBITDA。

*   **P/S 倍數**：
    *   同業平均 P/S (WELL, VTR, PEAK, OHI)：(13.40 + 7.03 + 5.43 + 11.21) / 4 = 9.27。
    *   考慮到 MPT 的盈利能力較弱，給予其同業平均 P/S 的 50% 折扣作為目標倍數：9.27 * 0.5 = 4.64。
    *   MPT 過去 12 個月營收約為 $1B (根據 Q3 2026 營收 $250.14M 年化估算)。
    *   目標市值 = 4.64 * $1B = $4.64B。
    *   目標股價 = $4.64B / 597.2M (流通股數) = **$7.77**。

*   **EV/EBITDA 倍數**：
    *   同業平均 EV/EBITDA (WELL, VTR, PEAK, OHI)：(58.7 + 24.30 + 10.5 + 14.4) / 4 = 26.98。
    *   考慮到 MPT 的盈利能力和負債風險，給予其同業平均 EV/EBITDA 的 50% 折扣作為目標倍數：26.98 * 0.5 = 13.49。
    *   MPT TTM EBITDA 約為 $857.76M。
    *   目標企業價值 = 13.49 * $0.85776B = $11.57B。
    *   目標市值 = 目標企業價值 - 淨負債 = $11.57B - $3.48B (估算淨負債) = $8.09B。
    *   目標股價 = $8.09B / 597.2M = **$13.55**。

*   **分析師目標價**：分析師對 MPT 的中位數目標價為 $5.14，區間為 $3.80 至 $9.00。

綜合相對估值法，考慮到 MPT 的基本面挑戰，採用較為保守的 P/S 倍數估值結果，並參考分析師目標價。

**相對估值法下的合理價位區間：$5.00 - $8.00**

**股息折現模型 (Dividend Discount Model, DDM)**

MPT 目前的年化股息為 $0.36/股 ($0.09/季度)。然而，其盈利為負，導致派息率為負，這意味著股息並非來自持續盈利，而是可能通過借款或資產出售來維持。市場已對其股息可持續性表示擔憂。

因此，對於 MPT 而言，DDM 模型並不適用，因為其股息增長率無法合理預測，且當前股息不可持續。如果強行使用 DDM，需要假設股息在未來會大幅削減並在長期內恢復增長，這會引入過多主觀假設。

**其他方法**

目前 MPT 的主要問題在於其運營和財務結構，而非資產本身。雖然公司正在出售資產以去槓桿化，但資產基礎估值 (Asset-based Valuation) 在當前階段可能無法完全反映其運營風險和未來潛在的盈利恢復。SOTP (Sum-of-the-parts) 估值可能適用於具有多個獨立業務部門的公司，但 MPT 主要專注於醫療保健房地產，因此 SOTP 的適用性有限。
