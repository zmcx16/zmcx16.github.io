### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估算 MPT 未來自由現金流的現值，以推導其內在價值。

#### 預測假設

*   **預測期間 (Explicit Forecast Period)**：5 年 (2027-2031)。
*   **營收增長率預期**：
    *   MPT 2026 年第三季度營收同比增長 5.3%。公司預計 2026 年和 2027 年的年度現金租金收入將超過 10 億美元。然而，考慮到租戶問題 (HSA 租金支付不確定性、Priory 租金削減) 和資產出售對未來營收的潛在影響，我們採取較為保守的增長假設。
    *   2027-2028 年：3.0% (反映初期挑戰與資產組合調整)
    *   2029-2031 年：2.0% (趨於穩定增長)
*   **營業利潤率 (Operating Margin)**：基於提供的基本面數據 58.3% [cite: user data] 和 TTM 59.70%，我們假設未來 5 年維持在 58.5%。
*   **資本支出 (Capital Expenditures)**：作為 REIT，MPT 需要持續的資本支出來維護和擴展其物業組合。我們假設資本支出佔營收的 15% (基於 REIT 產業平均水平及公司投資活動)。
*   **折舊與攤銷 (Depreciation & Amortization, D&A)**：假設 D&A 佔營收的 28% (與歷史數據和 REIT 產業特性保持一致)。
*   **營運資本變動 (Change in Working Capital)**：對於 REIT 而言，營運資本變動通常較小且穩定，我們假設其對自由現金流的影響可忽略不計。
*   **有效稅率 (Effective Tax Rate)**：由於 MPT 作為 REIT 的特殊稅務結構，其有效稅率通常較低。我們採用 TTM 2.83%。

#### 折現率與終值

*   **加權平均資本成本 (WACC)**：

    *   市場風險溢酬 (Market Risk Premium, MRP)：5.10%

    *   股權成本 (Cost of Equity, Ke) = Rf + β * MRP = 4.15% + 1.55 * 5.10% = 12.055%

    *   股權市值 (Market Value of Equity, E)：$1.08B
    *   債務市值 (Market Value of Debt, D)：$9.26B
    *   WACC = (E/V * Ke) + (D/V * Kd * (1 - t))
    *   WACC = (1.08 / (1.08 + 9.26)) * 12.055% + (9.26 / (1.08 + 9.26)) * 8.0% * (1 - 0.0283)

#### 股息折現模型 (Dividend Discount Model, DDM)

MPT 目前的年化股息為每股 $0.36。然而，公司近期經歷了股息削減 (從每股 $0.29 降至 $0.09)，且市場對其股息可持續性存在擔憂。因此，採用單一穩定增長率的 DDM 模型可能不適用。

若假設股息在未來幾年保持穩定，然後以極低的永續增長率增長，則：

*   當前股息 (D0)：$0.36
*   預期股息增長率 (g)：0% (短期內，考慮到不確定性)
*   所需報酬率 (r)：我們使用股權成本 12.055%

DDM 估值 = D0 * (1 + g) / (r - g) = $0.36 * (1 + 0%) / (0.12055 - 0%) = $0.36 / 0.12055 = **$2.99**

如果考慮到未來股息可能會有小幅增長 (例如 0.5%)，則：
DDM 估值 = $0.36 * (1 + 0.005) / (0.12055 - 0.005) = $0.3618 / 0.11555 = **$3.13**

DDM 模型結果顯示，在當前股息水平和高所需報酬率下，MPT 的估值約為 **$2.99 - $3.13**。這反映了市場對其股息增長前景的悲觀預期。
