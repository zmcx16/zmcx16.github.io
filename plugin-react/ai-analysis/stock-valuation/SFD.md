# Smithfield Foods, Inc. (SFD) 深度估值分析報告

作為資深投資分析師，針對 **Smithfield Foods (SFD)** 的估值分析需考量其在全球豬肉供應鏈的龍頭地位，以及當前生鮮肉品市場的週期性波動。雖然 SFD 目前為萬洲國際（WH Group, 0288.HK）之子公司，但基於市場傳聞其擬於美股重新上市及您提供的獨立財務數據，本報告將其視為獨立實體進行橫向與縱向估值。

- **財務穩健性**：SFD 的 Debt/Eq (0.34) 遠低於同業，顯示其財務槓桿極低，具備較強的抗風險能力與潛在的併購擴張空間。
- **獲利能力**：其營業利潤率 (8.56%) 優於 Tyson 與 Pilgrim's，顯示其在垂直整合（從養殖到加工）上的成本控制優勢。

### 3. 多維度估值法

#### A. 相對估值法 (Relative Valuation)
參考同業平均 Forward P/E 12.0x。
- 若給予 SFD 較保守的 10.5x P/E（考量其品類集中度），以預估 EPS $2.42 計算：
- **目標價 = 2.42 * 10.5 = $25.41**。

#### B. 股息折現模型 (DDM)
SFD 目前提供 5.34% 的高殖利率，這在食品加工業中極具吸引力。
- 當前股息 (D0) = $1.17 (21.97 * 5.34%)。
- 假設股息增長率 (g) = 3%。
- 股權成本 (Ke) = 8.2%。
- **DDM 價值 = 1.17 * (1.03) / (0.082 - 0.03) = $23.17**。
