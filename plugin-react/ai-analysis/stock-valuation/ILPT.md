## 股權評價報告：Industrial Logistics Properties Trust (ILPT)

### 角色設定

作為一位資深股權評價分析師，我將運用多種估值模型，對美股公司 Industrial Logistics Properties Trust (ILPT) 進行深入分析，並特別加強與同業競爭對手的橫向比較，以推算其內在價值。

### 1. 同業比較分析 (Industry Peer Comparison)

Industrial Logistics Properties Trust (ILPT) 是一家專注於美國本土及夏威夷工業與物流地產的房地產投資信託 (REIT)，其業務模式主要透過租賃倉庫、配送中心及工業用地來產生經常性收入。為進行全面的同業比較，我們選取了以下五家主要工業 REITs 作為競爭對手：

*   **Prologis (PLD)**：全球最大的工業 REIT，作為行業領導者進行基準比較。
*   **STAG Industrial (STAG)**：專注於單一租戶工業物業，與 ILPT 部分資產類型相似。
*   **EastGroup Properties (EGP)**：主要投資於美國南部和西部高增長市場的多租戶工業物業。
*   **First Industrial Realty Trust (FR)**：另一家領先的綜合型工業地產所有者、營運商和開發商。
*   **Terreno Realty Corp (TRNO)**：專注於美國六大沿海市場的工業地產。

**估值地位分析：**

從市值來看，ILPT (約 6.19 億美元) 相較於其主要競爭對手 (Prologis 1347.6 億美元，EastGroup Properties 111.4 億美元等) 規模顯著較小，屬於小型工業 REIT。

*   **本益比 (P/E Ratio)**：由於 REITs 的會計處理中折舊費用較高，導致淨利潤可能為負或較低，因此 P/E 比率對於 REITs 的估值參考意義有限，ILPT 的 P/E 為負值。
*   **股價營收比 (P/S Ratio)**：ILPT 的 P/S 比率為 1.36，遠低於同業平均水平 (Prologis 14.5x, EastGroup 15.26x, First Industrial 11.74x, Terreno 13.7x, STAG 8.79x)。這表明市場對 ILPT 的營收估值顯著折價。
*   **企業價值倍數 (EV/EBITDA)**：ILPT 的 EV/EBITDA 為 17.12x，介於同業區間內，但略低於 Prologis (27.0x)、EastGroup (20.06x) 和 First Industrial (21.9x)，高於 Terreno (13.38x) 和 STAG (15.72x)。考慮到 ILPT 較高的負債權益比 (8.76)，其企業價值 (EV) 相對於市值 (Market Cap) 顯著放大。
*   **營收增長率**：ILPT Q1 2026 的營收年增長率為 4.0%，低於大多數同業的增長率 (例如 EastGroup 11.63%, Terreno 12.70%)。這可能解釋了其較低的 P/S 比率。
*   **營業利潤率與淨利潤率**：ILPT 的營業利潤率 (34.36%) 接近同業平均水平，但其淨利潤率為負 (-8.08%)，而同業普遍為正且較高。這表明 ILPT 在扣除利息和稅費後，盈利能力較弱，這與其高負債和利息支出有關。
*   **股息殖利率**：ILPT 的股息殖利率為 2.19%，低於同業平均水平 (約 2.9%-3.9%)。儘管公司近期大幅提高了股息，但相較於其他工業 REITs，其股息吸引力仍有提升空間。

**總結估值地位**：ILPT 相對於同業處於**折價 (Discount)** 狀態，尤其體現在 P/S 比率和淨利潤率上。其較低的營收增長率和負的淨利潤率是導致市場給予折價估值的主要原因。然而，其營業利潤率與 EV/EBITDA 顯示其核心營運效率尚可，但高負債和利息成本嚴重侵蝕了淨利潤。其獨特的夏威夷資產組合 可能提供長期價值，但目前尚未完全體現在估值中。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估算公司未來自由現金流的現值，以得出其內在價值。

**預測假設 (基於 2026 年 Q1 數據及市場趨勢)：**

*   **預測期間 (Explicit Forecast Period)**：5 年 (2026-2030)。
*   **營收增長率預期 (Revenue Growth Rate)**：
    *   2026 年：4.0% (基於 Q1 2026 年增長率)
    *   2027 年：3.5% (考慮到工業地產市場的穩定增長和 ILPT 的資產組合)
    *   2028 年：3.0%
    *   2029-2030 年：2.5% (逐步趨近長期增長率)
*   **營業利潤率 (Operating Margin)**：
    *   2026 年：34.36% (基於 Q1 2026)
    *   2027-2030 年：假設在管理層努力下，略微提升至 35.0% (考慮到租金上調和成本控制)。
*   **稅率 (Tax Rate)**：REITs 通常將大部分應稅收入分配給股東以避免企業所得稅。然而，為計算稅後營業利潤 (NOPAT) 並考慮潛在的非 REIT 收入或稅盾效應，我們假設一個名義有效稅率為 5%。
*   **資本支出 (Capital Expenditures, CapEx)**：REITs 的 CapEx 較高。根據 ILPT 的業務性質，我們假設 CapEx 佔營收的 20% (用於維護、租戶改善和少量開發)。
*   **折舊與攤銷 (Depreciation & Amortization, D&A)**：假設 D&A 佔營收的 25% (REITs 通常有較高的非現金折舊)。
*   **營運資本變動 (Changes in Working Capital)**：假設為營收的 0.5% (穩定 REITs 通常變動不大)。

**折現率與終值 (Discount Rate & Terminal Value)：**

*   **加權平均資本成本 (Weighted Average Cost of Capital, WACC)**：
    *   **無風險利率 (Risk-Free Rate)**：採用美國 10 年期國債收益率。目前約為 4.25%。
    *   **股權風險溢價 (Equity Risk Premium, ERP)**：採用行業標準 5.5%。
    *   **Beta (β)**：由於用戶未提供，且 REITs 的 Beta 可能受其槓桿影響。我們將使用行業平均 Beta，假設為 0.9。
    *   **股權成本 (Cost of Equity, Ke)** = 無風險利率 + Beta \* ERP = 4.25% + 0.9 \* 5.5% = 4.25% + 4.95% = 9.20%。
    *   **債務成本 (Cost of Debt, Kd)**：ILPT 最近的再融資利率低於 5.5%。我們採用 5.5%。
    *   **市場價值權重 (Market Value Weights)**：
        *   股權市值 (E) = 618.66 百萬美元。
        *   債務市值 (D) = 8.76 (債務/股權比) \* 618.66 百萬美元 = 5,414.9 百萬美元。
        *   總資本 (V) = E + D = 618.66 + 5,414.9 = 6,033.56 百萬美元。
        *   股權權重 (E/V) = 618.66 / 6,033.56 = 10.25%。
        *   債務權重 (D/V) = 5,414.9 / 6,033.56 = 89.75%。
    *   **企業稅率 (Corporate Tax Rate)**：雖然 REITs 通常免稅，但在計算債務稅盾時，我們使用一個名義企業稅率 21% (美國聯邦稅率) 來反映債務融資的潛在稅務優勢，即使實際支付的企業稅可能很低。
    *   **WACC** = (E/V) \* Ke + (D/V) \* Kd \* (1 - 稅率)
        = 0.1025 \* 9.20% + 0.8975 \* 5.5% \* (1 - 0.21)
        = 0.00943 + 0.8975 \* 5.5% \* 0.79
        = 0.00943 + 0.03906
        = 4.85%

*   **終值增長率 (Terminal Growth Rate, g)**：假設長期穩定增長率為 1.8% (略低於長期通脹和經濟增長)。

**DCF 估值結果 (簡化計算，僅供參考)：**

由於缺乏完整的歷史財務報表細項，此處將提供一個簡化的 DCF 框架和估算結果。

1.  **計算預測期內的自由現金流 (FCFF)**：
    *   營收 (Revenue)
    *   營業利潤 (Operating Income) = Revenue \* Operating Margin
    *   稅後營業利潤 (NOPAT) = Operating Income \* (1 - Tax Rate)
    *   加回折舊與攤銷 (Add back D&A)
    *   減去資本支出 (Subtract CapEx)
    *   減去營運資本變動 (Subtract Change in Working Capital)
    *   得出 FCFF

2.  **計算終值 (Terminal Value, TV)**：
    *   TV = FCFF (Terminal Year) \* (1 + g) / (WACC - g)

3.  **計算內在價值 (Intrinsic Value)**：
    *   將預測期內的 FCFF 和終值折現回現值，加總得出企業價值 (Enterprise Value)。
    *   股權價值 (Equity Value) = Enterprise Value - 淨債務 (Net Debt)。
    *   每股內在價值 (Intrinsic Value Per Share) = Equity Value / 流通股數。

**簡化 DCF 估算 (基於上述假設)：**

假設 2025 年營收約為 4.5 億美元 (基於 Q1 2026 營收 $116.4M * 4 = $465.6M，與 Q4 2025 營收 $113.91M 接近)。

| 年度 | 2026 | 2027 | 2028 | 2029 | 2030 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 營收增長率 | 4.0% | 3.5% | 3.0% | 2.5% | 2.5% |
| 營收 (百萬美元) | 468.0 | 484.4 | 499.9 | 512.4 | 525.2 |
| 營業利潤率 | 34.36% | 35.0% | 35.0% | 35.0% | 35.0% |
| 營業利潤 (百萬美元) | 160.8 | 169.5 | 175.0 | 179.3 | 183.8 |

| CapEx (百萬美元) | 93.6 | 96.9 | 100.0 | 102.5 | 105.0 |

*   **終值 (Terminal Value)**：
    *   FCFF (2030) = 198.3 百萬美元
    *   TV = 198.3 \* (1 + 0.018) / (0.0485 - 0.018) = 198.3 \* 1.018 / 0.0305 = 6,617.6 百萬美元

*   **企業價值 (Enterprise Value)**：
    *   折現 FCFF (2026-2030) + 折現 TV
    *   PV(FCFF) = 173.9/(1.0485) + 182.8/(1.0485)^2 + 188.8/(1.0485)^3 + 193.3/(1.0485)^4 + 198.3/(1.0485)^5 = 165.8 + 165.7 + 163.0 + 159.6 + 156.0 = 810.1 百萬美元
    *   PV(TV) = 6,617.6 / (1.0485)^5 = 5,200.0 百萬美元
    *   Enterprise Value = 810.1 + 5,200.0 = 6,010.1 百萬美元

*   **股權價值 (Equity Value)**：
    *   淨債務 = 總債務 - 現金 = 5,414.9 百萬美元 - 100 百萬美元 = 5,314.9 百萬美元
    *   Equity Value = Enterprise Value - 淨債務 = 6,010.1 - 5,314.9 = 695.2 百萬美元

*   **每股內在價值 (Intrinsic Value Per Share)**：
    *   流通股數：根據用戶提供數據，市值 $618.66M / 股價 $9.28 = ~66.67 百萬股。
    *   每股內在價值 = 695.2 百萬美元 / 66.67 百萬股 = **10.43 美元/股**

**合理價位區間 (DCF)**：基於上述假設，DCF 模型推算的 ILPT 合理價位區間約為 **9.50 - 11.50 美元/股**。

### 3. 多維度估值法 (Other Valuation Methods)

#### 相對估值法 (Relative Valuation)

我們將使用同業的估值倍數來推算 ILPT 的目標價位。由於 ILPT 的淨利潤為負，P/E 倍數不適用。我們將主要參考 P/S 和 EV/EBITDA 倍數。

1.  **基於 P/S Ratio**：
    *   同業平均 P/S (不含 PLD，因其規模過大可能扭曲平均值)：(8.79 + 15.26 + 11.74 + 13.7) / 4 = 12.37x。
    *   ILPT 2025 年營收約為 4.5 億美元 (基於 Q1 2026 營收 $116.4M * 4 = $465.6M)。
    *   若 ILPT 達到同業平均 P/S 12.37x，則其市值應為 4.5 億美元 \* 12.37 = 55.665 億美元。
    *   這與 ILPT 目前的市值 6.1866 億美元相去甚遠，表明 ILPT 在 P/S 方面存在巨大折價。
    *   如果我們考慮 ILPT 自身的 P/S 1.36，並假設其應向同業平均靠攏，但考慮其較低的增長和負的淨利潤，給予一個折價的 P/S 倍數，例如 5x。
    *   目標市值 = 4.5 億美元 \* 5 = 22.5 億美元。
    *   每股目標價 = 22.5 億美元 / 66.67 百萬股 = **33.75 美元/股** (此估算顯然過高，反映了 ILPT 與同業在盈利能力上的巨大差異，單純 P/S 比較可能不適用)。

    *   **調整後的 P/S 考量**：由於 ILPT 的淨利潤為負，其 P/S 遠低於盈利的同業是合理的。如果我們考慮其營業利潤率與同業接近，但淨利潤為負，則其 P/S 應顯著低於同業。目前 1.36 的 P/S 已經反映了市場的悲觀情緒。

2.  **基於 EV/EBITDA 倍數**：
    *   同業平均 EV/EBITDA (不含 PLD)：(15.72 + 20.06 + 21.9 + 13.38) / 4 = 17.77x。
    *   ILPT 預計 2026 年 EBITDA 為 346.5 百萬美元。
    *   目標企業價值 = 346.5 百萬美元 \* 17.77 = 6,158.5 百萬美元。
    *   目標股權價值 = 目標企業價值 - 淨債務 = 6,158.5 - 5,314.9 = 843.6 百萬美元。
    *   每股目標價 = 843.6 百萬美元 / 66.67 百萬股 = **12.65 美元/股**。

**相對估值法推算目標價位**：基於 EV/EBITDA 倍數，合理價位約為 **12.65 美元/股**。

#### 股息折現模型 (Dividend Discount Model, DDM)

ILPT 於 2025 年大幅提高了年度股息，從 $0.04 提高到 $0.20。目前股息殖利率為 2.19%。由於股息近期有大幅調整，且未來增長率難以穩定預測，單階段 DDM 可能不適用。若採用兩階段 DDM，需要假設一個高增長階段和一個穩定增長階段。

*   **當前年度股息 (D0)** = $0.20/股
*   **股息增長率 (g)**：考慮到公司近期再融資降低了利息成本，以及租金上調的潛力，假設未來幾年股息能以較低速度增長。
    *   假設第一階段 (3 年) 股息增長率為 5%。
    *   假設第二階段 (永續) 股息增長率為 2%。
*   **股權成本 (Ke)**：9.20% (來自 DCF 模型)。

**DDM 估算 (兩階段)：**

*   D1 = 0.20 \* (1 + 0.05) = 0.21
*   D2 = 0.21 \* (1 + 0.05) = 0.2205
*   D3 = 0.2205 \* (1 + 0.05) = 0.2315
*   P3 (終值) = D3 \* (1 + g_永續) / (Ke - g_永續) = 0.2315 \* (1 + 0.02) / (0.0920 - 0.02) = 0.2315 \* 1.02 / 0.072 = 3.27 美元

*   **每股內在價值** = D1/(1+Ke) + D2/(1+Ke)^2 + (D3 + P3)/(1+Ke)^3
    = 0.21/(1.092) + 0.2205/(1.092)^2 + (0.2315 + 3.27)/(1.092)^3
    = 0.1923 + 0.1849 + 2.7015
    = **3.08 美元/股**

DDM 模型給出的估值顯著低於當前股價和 DCF 估值。這可能反映了市場對 ILPT 股息增長可持續性的擔憂，或者 DDM 模型對於高槓桿且近期股息政策變動較大的 REITs 適用性較低。

#### 其他方法 (Other Methods)

*   **資產基礎估值 (Asset-based Valuation)**：對於 REITs 而言，資產基礎估值 (如 NAV, Net Asset Value) 是一個重要的參考。由於缺乏詳細的物業估值數據，我們無法直接計算 NAV。然而，ILPT 的 P/B 比率為 1.29，表明其股價略高於賬面價值。同業的 P/B 則差異較大 (Prologis 2.51, STAG 2.0, EastGroup 未直接找到但 P/E 較高可能 P/B 也較高, First Industrial 3.06, Terreno 20.90)。Terreno 的高 P/B 可能與其沿海高價值市場的資產有關。ILPT 的 P/B 處於中低水平，可能暗示其資產價值尚未被充分認可，或其資產質量/增長潛力被市場認為不如部分同業。
