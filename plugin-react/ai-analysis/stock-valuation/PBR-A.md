# Petrobras (PBR-A) 股權評價分析報告

#### **估值地位分析**
- **折價狀態 (Discount)**：相較於美系同行（XOM, CVX），PBR-A 處於極度折價狀態（P/E 僅 5.74x vs 14x）。這反映了市場對巴西政治干預風險、資本支出計畫變動以及匯率波動的風險溢價要求。
- **合理性評估**：PBR-A 的營業利潤率（34.8%）顯著高於美歐同行，主要得益於其鹽下油田（Pre-salt）極低的開採成本（Lifting Cost）。儘管存在政治折價，但其 **PEG 僅 0.74**，顯示其成長性相對於目前的低本益比仍具備極高吸引力。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### **預測假設**
- **預測期間**：2024 - 2028 (5年)。
- **營收增長率**：預計 2024-2025 年受油價波動影響，營收增長放緩至 2-3%，隨後隨產量提升穩定在 1.5%。
- **自由現金流 (FCF) 利潤率**：假設維持在 18%-22% 區間，考量到公司 2024-2028 戰略計畫中增加的資本支出（Capex）。
- **稅率**：34% (巴西法定稅率)。

#### **折現率與終值**
- **WACC 計算**：
  - 無風險利率 (US 10Y)：4.2%
  - 股權風險溢價 (ERP)：5.0%
  - **國家風險溢價 (Brazil CRP)**：3.5%
  - Beta：1.25
  - 權益成本 (Ke)：4.2% + 1.25 * (5.0% + 3.5%) = 14.8%
  - 債務成本 (Kd)：7.5% (稅後約 4.95%)
  - **WACC 最終設定：12.5%** (反映高風險環境)。
- **終值增長率 (g)**：2.0%。

#### **估值結果**
- **企業價值 (EV)**：約 1,450 億美元。
- **淨負債**：約 580 億美元。
- **股權價值**：約 870 億美元。
- **DCF 推算內在價值**：**$28.50 / ADR**。

### 3. 多維度估值法 (Other Valuation Methods)

#### **相對估值法 (Relative Valuation)**
參考歐洲同行與新興市場國家石油公司平均 7.5x Forward P/E。
- 目標價 = 2025 EPS (預估 $4.10) * 6.5x (保守給予政治折價) = **$26.65**。

#### **股息折現模型 (DDM)**
Petrobras 執行固定比例配息政策（45% FCF）。
- 預期年度股息：$2.20 - $2.50 (含特別股息)。
- 要求的報酬率：15%。
- DDM 推算價值：$2.35 / (0.15 - 0.02) = **$18.08** (此模型對配息穩定性敏感，因政治因素波動較大，權重調低)。

#### **資產基礎估值 (Asset-based)**
考慮到其鹽下油田儲量價值，P/B 僅 1.63x，遠低於歷史高點，顯示資產價值尚未被完全定價。

**最終結論：**
1. **合理價位區間**：**$24.50 - $27.80**
2. **目前股價位階**：**低估 (Undervalued)** (當前股價 $23.53 低於合理區間下限)
3. **投資核心論點**：PBR-A 目前估值極具安全邊際，其 5.95x 的本益比已充分計入巴西政治風險。核心競爭力在於其鹽下油田的低成本優勢與強勁的現金流產生能力。儘管政府可能干預燃料定價或增加資本支出，但其高達 30% 以上的 ROE 與穩健的去槓桿表現，使其在油價維持在 70 美元以上時具備極高的投資價值。潛在風險為巴西財政政策轉向導致的匯率貶值及股息政策收緊。
