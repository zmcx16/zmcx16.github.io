# PBR-A (Petrobras) 深度估值分析報告

作為資深投資分析師，針對巴西石油公司（Petrobras, PBR-A）的估值，我們必須同時考量其卓越的資產質量（鹽下油田低開採成本）與顯著的政治風險溢價。以下是基於最新財報數據與市場環境的完整分析。

#### 估值地位分析
- **深度折價 (Deep Discount)**：PBR-A 的 Forward P/E (4.73x) 遠低於全球同業平均（約 8-10x）。
- **盈利能力冠絕同業**：其營業利潤率 (34.79%) 與 ROE (30.69%) 顯著高於 XOM 與 SHEL，主要得益於其鹽下油田 (Pre-salt) 極低的盈虧平衡點（約每桶 35-40 美元）。
- **結論**：市場對 PBR-A 給予了極高的「巴西國家風險折價」與「政治干預溢價」。儘管基本面強勁，但估值倍數受限於巴西政府的資本支出政策與派息不確定性。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### 預測假設
1.  **預測期間**：2025 - 2029 (5年)。
2.  **營收增長率**：預計未來 3 年維持 2-3% 的低速增長，反映產量增加（預計 2028 年達到 3.2 million boed）與油價波動的抵銷。
3.  **自由現金流 (FCF) 利潤率**：假設維持在 18-22% 區間，考量到資本支出 (CAPEX) 將因 2024-2028 戰略計劃（1020 億美元）而上升。
4.  **WACC (加權平均資本成本)**：**13.5%**。
    - 無風險利率 (US 10Y): 4.2%
    - 股權風險溢價 (ERP): 5.5%
    - 巴西國家風險溢價 (CRP): 3.5%
    - Beta: 1.25
5.  **終值增長率 (Terminal Growth Rate)**：**1.5%**。

#### 估值結果
- **企業價值 (EV)**：約 1,450 億美元。
- **扣除淨負債**：約 550 億美元。
- **股權價值**：約 900 億美元。
- **每股 ADR 內在價值**：**$23.45**。
- **合理價位區間**：**$21.00 - $25.00**。

### 3. 多維度估值法 (Other Valuation Methods)

#### 相對估值法 (Relative Valuation)
若給予 PBR-A 較為保守的 6.0x Forward P/E（仍低於同業，但反映其盈利能力），對應 EPS 預測，目標價約為 **$21.50**。

#### 股息折現模型 (DDM)
Petrobras 採用固定比例派息政策（45% 的自由現金流）。
- 假設未來每股派息 (DPS) 為 $2.20（含特別股息）。
- 股權成本 (Ke) = 15% (考量政治風險)。
- 永續增長率 = 2%。
- **推算價值 = $2.20 / (0.15 - 0.02) = $16.92**。
*註：DDM 結果較低，反映了市場對派息持續性的擔憂。*

**最終結論：**

2. **目前股價位階**：**低估 (Undervalued)**
3. **投資核心論點**：PBR-A 目前交易於極低的倍數（P/E 4.36x），其強大的現金流產生能力與鹽下油田的成本優勢提供了極高的安全邊際。儘管巴西政府對燃料定價與資本支出的干預構成主要下行風險，但目前的股價已過度反應悲觀預期。若油價維持在 $70 以上且公司維持現行派息框架，該股具備顯著的估值修復潛力與優異的總回報空間。
