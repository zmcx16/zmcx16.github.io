# Ubiquiti Inc. (UI) 深度股權評價分析報告

作為資深投資分析師，針對 **Ubiquiti Inc. (UI)** 的估值分析需考慮其獨特的商業模式：極低的銷售與行銷支出、高度依賴社群的研發模式，以及創辦人 Robert Pera 高度集中的持股（約 90%），這導致其市場流通量（Float）極低，估值往往帶有顯著的稀缺性溢價。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### **預測假設**
- **預測期間**：2025 - 2029 (5年)。
- **營收增長率**：預計未來 3 年維持 15%-18% 增長（受惠於 WiFi 7 升級週期與 Enterprise 產品線擴張），隨後放緩至 10%。
- **自由現金流 (FCF) 利潤率**：假設維持在 28% - 30%（基於其穩定的 30% 淨利率與低資本支出需求）。
- **稅率**：有效稅率假設為 18%。

#### **折現率與終值**
- **WACC 計算**：
  - 無風險利率 (10Y Treasury): 4.3%
  - Beta: 1.25 (考量低流通量帶來的波動性)
  - 股權風險溢價: 5.0%
  - **WACC 估算：約 10.2%** (考量其極低的債務比 Debt/Eq 0.05)。
- **終值增長率 (Terminal Growth Rate)**：3.0%。

#### **估值結果**
- **企業價值 (EV)**：約 $38.5B - $42.0B。
- **每股內在價值**：**$635.00 - $695.00**。
- **分析**：目前股價 $685.94 處於 DCF 估值區間的上緣，顯示市場已充分計入未來 5 年的成長預期。

### 3. 多維度估值法 (Other Valuation Methods)

#### **相對估值法 (Relative Valuation)**
- **Forward P/E 乘數法**：參考同業高成長期平均倍數 30x - 35x。
  - 預估明年 EPS (基於 EPS next Y 5.27% 增長與當前 Forward P/E)：約 $21.47。
  - 目標價 = $21.47 * 33x = **$708.51**。
- **P/S 乘數法**：UI 歷史 P/S 中位數約 8x-10x，目前 11.63x 處於歷史高位，顯示估值偏熱。

#### **股息折現模型 (DDM)**
- UI 雖有配息（Dividend 0.5%），但其主要資本配置在於股票回購而非股息增長。DDM 對於此類高成長、高回購公司參考價值較低，僅作為下行支撐參考，推算價值約為 $320 (假設 8% 股息增長率)，遠低於市價。

3. **投資核心論點**：Ubiquiti 憑藉極高的營運效率與 UniFi 生態黏性，在企業級網路市場維持強大競爭力。目前 $685 的股價已反映了 WiFi 7 帶來的成長預期。高達 85% 的 ROE 與強勁的現金流是其估值支撐，但考慮到 P/E 已達 38 倍且內部人持股極高導致的流動性風險，短期上行空間受限於 $750 壓力位。建議在回調至 $630 以下時再行佈局，需警惕宏觀支出放緩對硬體更新週期的影響。
