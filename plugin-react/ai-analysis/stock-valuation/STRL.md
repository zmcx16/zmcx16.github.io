# 股票估值分析：Sterling Infrastructure Inc (STRL)

作為一位資深投資分析師，我將對美股公司 Sterling Infrastructure Inc (STRL) 進行全面的股權估值分析，並著重於與同業競爭對手的橫向比較，以推算其內在價值。

## 1. 同業比較分析 (Industry Peer Comparison)

### 識別競爭對手
根據市場搜尋結果，Sterling Infrastructure Inc (STRL) 的主要業務涵蓋 E-Infrastructure (數據中心、半導體製造、倉儲等)、Transportation Solutions (公路、機場、橋樑、鐵路) 和 Building Solutions (住宅與商業混凝土基礎)。其 E-Infrastructure 業務是主要的成長驅動力，且公司正將資源轉向高利潤的 E-Infrastructure 項目。

基於此業務特性，我選取以下 4 家公司作為主要同業競爭對手進行比較：
*   **MasTec (MTZ)**：提供通訊、清潔能源與基礎設施、電力傳輸和管道基礎設施等服務。
*   **Granite Construction (GVA)**：主要從事重型民用建設和建築材料生產。
*   **Primoris Services (PRIM)**：專業承包商，提供公用事業、能源和可再生能源市場的關鍵基礎設施服務。
*   **Quanta Services (PWR)**：提供電力、通訊、管道和基礎設施服務。

### 估值地位分析
從同業比較來看，STRL 展現出幾個顯著特點：
*   **成長性領先**：STRL 在最近一季的營收增長率高達 127%，遠超所有同業，這主要得益於其 E-Infrastructure 解決方案（特別是數據中心和半導體製造）的強勁需求。Quanta Services (PWR) 也展現出強勁的營收增長 (57%)，但仍不及 STRL。
*   **盈利能力優異**：STRL 的營業利潤率 (18.73%) 和淨利潤率 (12.85%) 在同業中處於領先地位。特別是其 E-Infrastructure 部門的調整後營業利潤率在 2026 年第三季度達到 23%，顯示其業務結構轉型至高利潤領域的成效。相比之下，Granite Construction (GVA) 和 Primoris Services (PRIM) 的淨利潤率較低，甚至 GVA 在最近一季出現負值。
*   **估值倍數**：
    *   **P/E (Trailing)**：STRL 的 13.59 遠低於同業平均，尤其低於 PWR (55.11) 和 GVA (34.71)。這可能暗示市場尚未完全反映其近期爆炸性增長帶來的盈利能力提升。
    *   **P/E (Forward)**：STRL 的 8.66 也是同業中最低的，這表明分析師預期其未來盈利將大幅增長，使其遠期估值更具吸引力。
    *   **P/S**：STRL 的 1.71 介於同業之間，低於 PWR (2.32)，但高於 MTZ (0.89)、GVA (0.73) 和 PRIM (0.42)。考慮到其卓越的利潤率，較高的 P/S 可能是合理的。
    *   **EV/EBITDA**：STRL 的 8.89 顯著低於 PWR (24.52) 和 PRIM (13.73)，也低於 GVA (11.30)。這進一步支持了 STRL 相對於其盈利能力和成長性可能被低估的觀點。

**總結**：STRL 相對於其同業而言，在成長性和盈利能力方面表現突出，尤其是在 E-Infrastructure 領域的強勁勢頭。然而，其目前的本益比和企業價值倍數卻顯著低於同業平均，這表明市場可能尚未完全消化其轉型帶來的價值，或者存在對其高增長可持續性的疑慮。從估值角度看，STRL 目前可能處於**折價 (Discount)** 狀態，其估值倍數相對於其基本面表現而言顯得較為合理，甚至可能被低估。

## 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估算公司未來自由現金流的現值，以得出其內在價值。

### 預測假設
*   **預測期間**：5 年 (2027-2031)。
*   **起始營收 (2026E)**：根據公司 2026 年全年營收指引中點 $4.68 億美元 (($4.63B + $4.73B) / 2)。
*   **營收增長率預期**：
    *   2026 年營收增長率約 88% (基於 2025 年 $2.49B 營收和 2026 年指引中點)。
    *   考慮到 E-Infrastructure 業務的強勁需求和公司戰略轉型，預計初期仍將保持高增長，但會逐步放緩至更可持續的水平。
        *   2027 年：35%
        *   2028 年：25%
        *   2029 年：15%
        *   2030 年：10%
        *   2031 年：8%
*   **營業利潤率 (Operating Margin)**：公司 2026 年第三季度 E-Infrastructure 調整後營業利潤率為 23%，整體營業利潤率為 18.73%。預計隨著高利潤業務佔比提升，營業利潤率將略有改善並趨於穩定。
    *   2027-2028 年：19.5%
    *   2029-2031 年：20.0%
*   **稅率 (Tax Rate)**：採用公司 2026 年指引的有效稅率 23.8%，簡化為 24%。
*   **資本支出 (Capital Expenditures, CapEx)**：2026 年指引約 $1.4 億美元。假設未來 CapEx 佔營收的比例穩定在 3.0% 左右。
*   **折舊與攤銷 (Depreciation & Amortization, D&A)**：2026 年指引約 $1.12 億美元。假設 D&A 佔營收的比例穩定在 2.4% 左右。
*   **營運資本變動 (Change in Net Working Capital, NWC)**：假設為營收變動的 5%。

### 折現率與終值
*   **無風險利率 (Risk-Free Rate)**：採用美國 10 年期國債收益率 4.81%。
*   **Beta**：STRL 的 Beta 值為 1.97。
*   **市場風險溢酬 (Market Risk Premium, MRP)**：假設為 5.5%。
*   **股權成本 (Cost of Equity, Ke)**：Ke = 無風險利率 + Beta * 市場風險溢酬 = 4.81% + 1.97 * 5.5% = 15.645%。
*   **稅前債務成本 (Pre-tax Cost of Debt, Kd)**：假設為 6.0%。
*   **股權市值 (Market Value of Equity, E)**：$7.39 億美元 (公司市值)。
*   **債務市值 (Market Value of Debt, D)**：根據 Debt/Equity 0.11，D = 0.11 * E = 0.11 * $7.39B = $0.8129B。
*   **加權平均資本成本 (Weighted Average Cost of Capital, WACC)**：
    *   WACC = (E/(E+D)) * Ke + (D/(E+D)) * Kd * (1 - 稅率)
    *   WACC = (7.39 / (7.39 + 0.8129)) * 15.645% + (0.8129 / (7.39 + 0.8129)) * 6.0% * (1 - 0.24)
    *   WACC = 0.9009 * 15.645% + 0.0991 * 6.0% * 0.76 = 14.094% + 0.452% = **14.55%**。
*   **終值增長率 (Terminal Growth Rate, g)**：假設為 2.5% (長期可持續增長率，低於名義 GDP 增長)。

**終值 (Terminal Value, TV)**：
*   2031 年 FCF = $1,535 百萬美元
*   永續增長率 (g) = 2.5%
*   TV = FCF_2031 * (1 + g) / (WACC - g) = $1,535 * (1 + 0.025) / (0.1455 - 0.025) = $1,573.375 / 0.1205 = $13,057 百萬美元
*   終值現值 = $13,057 * 0.506 = $6,609 百萬美元

**總內在價值 (Total Intrinsic Value)**：
*   預測期 FCF 現值總和 = $712 + $795 + $843 + $819 + $776 = $3,945 百萬美元
*   總內在價值 = 預測期 FCF 現值總和 + 終值現值 = $3,945 + $6,609 = $10,554 百萬美元

**每股內在價值 (Intrinsic Value Per Share)**：
*   流通股數：約 31.1 百萬股 (2026 年指引)。
*   每股內在價值 = $10,554 百萬美元 / 31.1 百萬股 = **$339.36**

**合理價位區間 (DCF)**：考慮到假設的敏感性，合理價位區間約為 **$300 - $380**。

## 3. 多維度估值法 (Other Valuation Methods)

### 相對估值法 (Relative Valuation)
基於同業比較分析，STRL 的估值倍數普遍低於同業，尤其是在考慮其高成長性和盈利能力的情況下。

*   **P/E 倍數法**：
    *   同業平均 P/E (Trailing) (不含 GVA 負值)：(23.64 + 31.79 + 55.11) / 3 = 36.85
    *   同業平均 P/E (Forward)：(13.22 + 26.83 + 10.55 + 28.96) / 4 = 19.89
    *   STRL 2026 年調整後稀釋 EPS 指引中點：$21.83 (($21.70 + $21.96) / 2)。
    *   若採用同業平均 Forward P/E (19.89) 估算：$21.83 * 19.89 = $434.21
    *   若考慮 STRL 自身較低的 P/E (Forward 8.66)，市場可能對其高增長的可持續性持謹慎態度。但若其能持續高增長，則應享有更高的倍數。
    *   保守估計，給予 STRL 15x 的 Forward P/E：$21.83 * 15 = $327.45

*   **EV/EBITDA 倍數法**：
    *   同業平均 EV/EBITDA (不含 MTZ N/A)：(11.30 + 13.73 + 24.52) / 3 = 16.52
    *   STRL 2026 年調整後 EBITDA 指引中點：$975.5 百萬美元 (($970M + $981M) / 2)。
    *   若採用同業平均 EV/EBITDA (16.52) 估算：$975.5M * 16.52 = $16,116 百萬美元 (企業價值)
    *   減去淨債務 (假設 2026 年底淨現金 $122M 保持不變，即負淨債務)：$16,116M - (-$122M) = $16,238 百萬美元 (股權價值)
    *   每股價值 = $16,238 百萬美元 / 31.1 百萬股 = $522.12

**相對估值法推算價位區間**：考慮到 STRL 的高成長性和盈利能力，但同時也存在市場對其可持續性的潛在疑慮，我將給予其介於保守 P/E 估值和同業平均 EV/EBITDA 估值之間的區間，約為 **$320 - $450**。

### 股息折現模型 (DDM)
根據搜尋結果，Sterling Infrastructure Inc (STRL) 不支付股息。因此，股息折現模型不適用於本公司的估值。

### 其他方法
目前來看，資產基礎估值 (Asset-based) 或 SOTP (Sum-of-the-parts) 模型對於 STRL 這種以服務和項目為主的基礎設施公司而言，並非最直接或最合適的估值方法，除非有明確的非核心資產剝離或分部估值需求。因此，本次分析不採用這些方法。
