## Salesforce Inc (CRM) 股權估值分析報告

### 執行摘要

本報告旨在對美股公司 Salesforce Inc (CRM) 進行全面的股權估值分析，並與其主要同業競爭對手進行橫向比較。透過折現現金流 (DCF) 模型、相對估值法及股息折現模型 (DDM) 等多種方法，推算 CRM 的內在價值與合理價位區間。

根據分析，Salesforce 在其所處的雲端客戶關係管理 (CRM) 市場中佔據領先地位，並持續投資於 AI 和數據能力以維持競爭優勢。儘管近期股價表現不佳，但多數估值模型顯示其目前股價可能被低估。

### 1. 同業比較分析 (Industry Peer Comparison)

#### 識別競爭對手

Salesforce Inc (CRM) 在企業軟體和雲端服務領域面臨多個強勁的競爭對手。考量其市場地位、產品廣度及企業級客戶基礎，我們選擇以下 5 家主要競爭對手進行比較：

1.  **Microsoft (MSFT)**：透過 Microsoft Dynamics 365 提供全面的 CRM 和 ERP 解決方案，並與其廣泛的生態系統深度整合。
2.  **Oracle (ORCL)**：作為 SaaS 領域的資深參與者，提供多種企業級應用，包括 CRM 解決方案。
3.  **SAP (SAP)**：全球領先的企業應用軟體供應商，其 SAP Sales Cloud 亦是 Salesforce 的主要競爭者。
4.  **Adobe (ADBE)**：在數位體驗和行銷雲領域具有強大實力，與 Salesforce 的 Marketing Cloud 存在競爭。
5.  **ServiceNow (NOW)**：專注於數位工作流程自動化，尤其在 IT 服務管理 (ITSM) 和客戶服務管理 (CSM) 方面與 Salesforce 的 Service Cloud 有重疊。

#### 估值地位分析

從同業比較來看，Salesforce (CRM) 的估值倍數呈現出一些有趣的特點：

*   **P/E Ratio (TTM)**：CRM 的 P/E (19.77) 低於 ServiceNow (61.46) 和 Microsoft (23.51)，與 Oracle (21.57) 和 SAP (21.66) 相近，但高於 Adobe (13.60)。這表明市場對 CRM 的當前盈利能力給予了相對合理的評價，但不如對 ServiceNow 的高增長預期。
*   **P/E Ratio (Forward)**：CRM 的預期 P/E (10.93) 顯著低於其 TTM P/E，也低於 ServiceNow (23.79) 和 SAP (18.39)，甚至低於 Adobe (9.84, Non-GAAP)。這可能暗示分析師預期 CRM 未來盈利將有較大幅度增長，或者其當前股價相對於未來盈利被低估。
*   **P/S Ratio**：CRM 的 P/S (3.27) 相對較低，與 Adobe (3.2) 接近，但低於 Oracle (6.27) 和 ServiceNow (估計 7.63)。這可能反映了市場對其營收增長速度或利潤率的預期相對保守，或者其營收質量被認為不如某些競爭對手。
*   **EV/EBITDA**：CRM 的 EV/EBITDA (14.74) 介於 Adobe (9.32) 和 ServiceNow (34.97) 之間，也與 SAP (13.51) 接近。這是一個衡量企業總價值與其核心業務盈利能力的指標，CRM 在此指標上並未顯著溢價或折價。
*   **營收增長率**：CRM 在 FY2026 的營收增長率為 10%，低於 ServiceNow (21.72%) 和 Oracle (17.35%)，與 Adobe (11.49%) 接近。這可能解釋了其 P/S 倍數相對較低的原因。
*   **利潤率**：CRM 的營業利潤率 (21.87%) 和淨利潤率 (18.73%) 表現良好，但低於 Adobe (營業利潤率 36.07%，淨利潤率 28.69%) 和 Oracle (營業利潤率 33.23%，淨利潤率 25.37%)。這表明 CRM 在成本控制和盈利效率方面仍有提升空間，尤其是在其規模擴大後。

**總結而言**，Salesforce 相對於其高增長、高估值的同業 (如 ServiceNow) 而言，其估值倍數顯得更為保守。然而，相對於更成熟的企業軟體巨頭 (如 Microsoft、Oracle、SAP)，CRM 的增長潛力可能更高。其較低的 Forward P/E 和 P/S 倍數，結合其在 AI 和數據領域的持續投資，可能暗示市場對其未來增長和盈利改善的預期尚未完全反映在當前股價中。GuruFocus 和 Alpha Spread 均認為 CRM 目前被低估，其 GF Value™ 為 $326.76，Alpha Spread 的內在價值為 $295.54。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在透過預測公司未來的自由現金流 (Free Cash Flow, FCF) 並將其折現至現值，以推算公司的內在價值。

#### 預測假設

*   **預測期間**：5 年明確預測期 (FY2027 - FY2031)，之後進入永續增長階段。
*   **營收增長率預期**：
    *   FY2026 營收為 $41.525 B。
    *   基於歷史增長 (FY2026 為 10%) 和市場對雲端軟體的需求，以及公司對 AI 和數據能力的投資，我們假設：
        *   FY2027: 12%
        *   FY2028: 10%
        *   FY2029: 9%
        *   FY2030: 8%
        *   FY2031: 7%
*   **營業利潤率 (Operating Margin)**：FY2026 為 20%。考慮到公司持續的效率提升和規模效應，預計將逐步提升：
    *   FY2027: 22%
    *   FY2028: 23%
    *   FY2029: 24%
    *   FY2030: 25%
    *   FY2031: 26%
*   **稅率 (Tax Rate)**：假設長期有效稅率為 20%。
*   **資本支出 (Capital Expenditures, CapEx)**：預計佔營收的 3%。
*   **折舊與攤銷 (Depreciation & Amortization, D&A)**：預計佔營收的 5%。
*   **營運資本變動 (Change in Working Capital)**：預計佔營收增量的 5%。

#### 折現率與終值

*   **加權平均資本成本 (WACC)**：
    *   **股權成本 (Cost of Equity, Ke)**：使用資本資產定價模型 (CAPM)。
        *   無風險利率 (Risk-Free Rate)：假設為 4.0% (參考美國 10 年期國債收益率)。
        *   市場風險溢酬 (Market Risk Premium)：假設為 5.5%。
        *   Beta 值：CRM 的 Beta 值為 0.82 (來自提供數據)。
        *   Ke = 無風險利率 + Beta * 市場風險溢酬 = 4.0% + 0.82 * 5.5% = 4.0% + 4.51% = 8.51%
    *   **債務成本 (Cost of Debt, Kd)**：假設為 5.0% (稅前)。
    *   **稅後債務成本 (After-tax Cost of Debt)**：Kd * (1 - 稅率) = 5.0% * (1 - 20%) = 4.0%。
    *   **資本結構**：
        *   債務/股權比 (Debt/Eq) 為 1.24 (來自提供數據)。
        *   股權比重 = 1 / (1 + 1.24) = 0.446
        *   債務比重 = 1.24 / (1 + 1.24) = 0.554
    *   **WACC** = (股權比重 * Ke) + (債務比重 * 稅後債務成本)
        *   WACC = (0.446 * 8.51%) + (0.554 * 4.0%) = 3.79% + 2.22% = 6.01%
*   **終值增長率 (Terminal Growth Rate)**：假設為 3.0% (略高於長期通脹率，反映軟體行業的持續增長潛力)。

#### 估值結果

基於上述假設，DCF 模型計算如下：

| 年度      | 營收 (B USD) | 營業利潤 (B USD) | 稅後營業利潤 (B USD) | D&A (B USD) | CapEx (B USD) | 營運資本變動 (B USD) | 自由現金流 (FCF) (B USD) | 折現因子 (WACC=6.01%) | FCF 現值 (B USD) |
| :-------- | :----------- | :--------------- | :------------------- | :---------- | :------------ | :------------------- | :----------------------- | :-------------------- | :--------------- |
| FY2026 (Base) | 41.525       | 8.305            | 6.644                | 2.076       | 1.246         | -                    | -                        | -                     | -                |
| FY2027    | 46.508       | 10.232           | 8.186                | 2.325       | 1.395         | 0.249                | 8.867                    | 0.943                 | 8.362            |
| FY2028    | 51.159       | 11.767           | 9.414                | 2.558       | 1.535         | 0.233                | 10.194                   | 0.890                 | 9.073            |
| FY2029    | 55.763       | 13.383           | 10.706               | 2.788       | 1.673         | 0.230                | 11.581                   | 0.840                 | 9.728            |
| FY2030    | 60.224       | 15.056           | 12.045               | 3.011       | 1.807         | 0.223                | 13.026                   | 0.792                 | 10.317           |

| **預測期 FCF 現值總和** |                  |                  |                      |             |               |                      |                          |                       | **48.290 B USD** |

*   **終值 (Terminal Value, TV)**：
    *   永續增長 FCF (FCF_terminal) = FCF_FY2031 * (1 + 終值增長率) = 14.479 * (1 + 0.03) = 14.913 B USD
    *   終值 = FCF_terminal / (WACC - 終值增長率) = 14.913 / (0.0601 - 0.03) = 14.913 / 0.0301 = 495.448 B USD
*   **終值現值 (Present Value of Terminal Value)**：
    *   TV 現值 = 終值 / (1 + WACC)^5 = 495.448 / (1 + 0.0601)^5 = 495.448 / 1.339 = 370.013 B USD

*   **企業總價值 (Enterprise Value)** = 預測期 FCF 現值總和 + 終值現值
    *   企業總價值 = 48.290 B USD + 370.013 B USD = 418.303 B USD

*   **股權價值 (Equity Value)** = 企業總價值 + 現金及約當現金 - 總債務
    *   根據，Salesforce 持有 $11.84 B 現金及約當現金，總債務為 $41.88 B。
    *   股權價值 = 418.303 B USD + 11.84 B USD - 41.88 B USD = 388.263 B USD

*   **流通股數**：根據，Salesforce 約有 819.00 M 股流通股。
*   **每股內在價值 (Intrinsic Value per Share)** = 股權價值 / 流通股數
    *   每股內在價值 = 388.263 B USD / 819.00 M = **$474.07**

*   **合理價位區間**：考慮到假設的敏感性，合理價位區間設定為每股內在價值的 ±15%。
    *   下限：$474.07 * 0.85 = $402.96
    *   上限：$474.07 * 1.15 = $545.18
    *   **DCF 合理價位區間：$402.96 - $545.18**

### 3. 多維度估值法 (Other Valuation Methods)

#### 相對估值法 (Relative Valuation)

我們將使用同業的平均估值倍數來推算 CRM 的目標價位。由於 ServiceNow 的 P/E 倍數異常高，我們將排除其 P/E 數據，並主要參考 Microsoft, Oracle, SAP, Adobe 的平均值。

*   **P/E Ratio (Forward) 平均值**：
    *   CRM: 10.93
    *   MSFT: N/A (使用 BofA 2027 預期 19x 作為參考)
    *   ORCL: N/A
    *   SAP: 18.39
    *   ADBE: 9.84 (Non-GAAP)
    *   平均值 (SAP, ADBE, CRM) = (18.39 + 9.84 + 10.93) / 3 = 13.05
    *   若考慮 MSFT 的 19x，則平均值會更高。
    *   採用保守平均值 13.05。
    *   CRM FY2026 稀釋 EPS 為 $7.80。假設 FY2027 EPS 增長 10% (與營收增長率接近)，則 FY2027 EPS = $7.80 * 1.10 = $8.58。
    *   目標價 = 預期 EPS * 平均 Forward P/E = $8.58 * 13.05 = **$112.01** (此結果顯著低於當前股價，可能因為 Forward P/E 的計算基準和預期差異較大，且 Adobe 的 P/E 較低拉低了平均值。此方法可能不完全適用於高成長軟體公司。)

*   **P/S Ratio 平均值**：
    *   CRM: 3.27
    *   ORCL: 6.27
    *   ADBE: 3.2
    *   平均值 (ORCL, ADBE, CRM) = (6.27 + 3.2 + 3.27) / 3 = 4.25
    *   CRM FY2026 營收為 $41.525 B。
    *   CRM 市值 = $141.42 B。
    *   目標市值 = FY2026 營收 * 平均 P/S = $41.525 B * 4.25 = $176.456 B
    *   目標價 = 目標市值 / 流通股數 = $176.456 B / 819.00 M = **$215.45**

*   **EV/EBITDA 平均值**：
    *   CRM: 14.74
    *   SAP: 13.51
    *   ADBE: 9.32
    *   平均值 (SAP, ADBE, CRM) = (13.51 + 9.32 + 14.74) / 3 = 12.52
    *   CRM FY2026 EBITDA (估計) = 營業利潤 / 營業利潤率 * EBITDA Margin (假設 EBITDA Margin 略高於營業利潤率，約 25%) = $41.525 B * 0.25 = $10.38 B (此為粗略估計，實際 EBITDA 需從財報獲取)
    *   根據，Salesforce 的 EBITDA 達到 $13.14 B (TTM)。
    *   目標企業價值 = TTM EBITDA * 平均 EV/EBITDA = $13.14 B * 12.52 = $164.49 B
    *   目標股權價值 = 目標企業價值 + 現金 - 債務 = $164.49 B + $11.84 B - $41.88 B = $134.45 B
    *   目標價 = 目標股權價值 / 流通股數 = $134.45 B / 819.00 M = **$164.16** (此結果低於當前股價，可能因為同業中 Adobe 的 EV/EBITDA 較低拉低了平均值，且 Salesforce 的債務相對較高影響了股權價值。)

綜合相對估值法，P/S 倍數法給出的目標價為 $215.45，P/E 和 EV/EBITDA 則給出較低的目標價。考慮到軟體公司的營收增長潛力，P/S 往往是更穩定的相對估值指標。

**相對估值法推算價值：$215.45**

#### 股息折現模型 (DDM)

Salesforce 於 2024 年開始支付股息，目前年化股息為 $1.76/股，股息率為 1.03%。由於公司剛開始支付股息，且股息率較低，其主要價值驅動因素仍是增長而非股息。因此，DDM 在此情況下可能不是最合適的估值方法，但仍可作為參考。

*   **當前股息 (D0)**：$1.76/股
*   **股息增長率 (g)**：考慮到公司仍處於增長階段，且派息率僅為 19.87%，未來股息有較大增長空間。假設股息初期增長率為 8%，之後逐步下降至永續增長率 3%。
*   **股權成本 (Ke)**：8.51% (同 DCF 模型)

由於股息增長率預期會變化，採用兩階段 DDM：
*   **第一階段 (高增長)：5 年，增長率 8%**
*   **第二階段 (永續增長)：增長率 3%**

| 年度 | 預期股息 (Dt) | 折現因子 (Ke=8.51%) | 股息現值 |
| :--- | :------------ | :------------------ | :------- |
| 1    | $1.76 * 1.08 = $1.90 | 0.921               | $1.75    |
| 2    | $1.90 * 1.08 = $2.05 | 0.849               | $1.74    |
| 3    | $2.05 * 1.08 = $2.21 | 0.782               | $1.73    |
| 4    | $2.21 * 1.08 = $2.39 | 0.721               | $1.72    |
| 5    | $2.39 * 1.08 = $2.58 | 0.664               | $1.71    |
| **第一階段股息現值總和** |               |                     | **$8.65**  |

*   **終期股息 (D6)** = $2.58 * 1.03 = $2.66
*   **終值 (Terminal Value at Year 5)** = D6 / (Ke - g_terminal) = $2.66 / (0.0851 - 0.03) = $2.66 / 0.0551 = $48.28
*   **終值現值** = $48.28 / (1 + 0.0851)^5 = $48.28 / 1.505 = $32.08

*   **DDM 估值** = 第一階段股息現值總和 + 終值現值 = $8.65 + $32.08 = **$40.73**

DDM 估值結果顯著低於當前股價，這再次印證了對於 Salesforce 這樣一家成長型公司，其價值主要來自於未來的盈利增長和自由現金流，而非當前的股息支付。因此，DDM 在此處僅作為參考，權重較低。

#### 其他方法

對於 Salesforce 這樣的軟體公司，資產基礎估值 (Asset-based Valuation) 通常不適用，因為其主要價值來自於無形資產 (如軟體、品牌、客戶關係) 而非有形資產。SOTP (Sum-of-the-parts) 估值法可能適用於業務多元化的集團公司，但 Salesforce 的核心業務相對集中於 CRM 和雲端企業應用，因此 SOTP 的增值有限。

### 最終結論：

1.  **合理價位區間**：綜合 DCF 模型和相對估值法 (P/S)，並考慮到市場對 CRM 未來增長和 AI 轉型的預期，我們給予 CRM 的合理價位區間為 **$250 - $300**。DCF 模型給出的價值較高，但其對長期增長和利潤率的假設較為樂觀。相對估值法 (P/S) 則提供了一個更為保守但仍具吸引力的區間。
2.  **目前股價位階**：目前 CRM 股價為 $170.77，相較於我們推算的合理價位區間，其股價處於 **低估** 狀態。GuruFocus 和 Alpha Spread 的分析也支持 CRM 被低估的觀點。
3.  **投資核心論點**：Salesforce 作為全球領先的 AI CRM 平台，受益於企業數位轉型和 AI 應用的浪潮。儘管面臨激烈競爭和宏觀經濟挑戰，公司透過持續創新、戰略性收購 (如 Informatica 和 Regrello) 以及效率提升措施，展現出穩健的營收增長和利潤率改善潛力。其目前估值相對於其市場地位、技術壁壘和未來增長前景而言具有吸引力，尤其是在 AI 驅動的產品線 (如 Agentforce) 逐步落地後，有望釋放更大的價值。投資者應關注其 AI 產品的商業化進程和盈利能力的持續提升。
