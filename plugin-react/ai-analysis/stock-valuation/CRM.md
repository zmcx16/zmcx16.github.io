## Salesforce Inc (CRM) 股權估值分析報告

作為一名資深投資分析師，我將對美股公司 Salesforce Inc (CRM) 進行全面的股權估值分析，並特別加強與同業競爭對手的橫向比較。

### 1. 同業比較分析 (Industry Peer Comparison)

Salesforce (CRM) 是客戶關係管理 (CRM) 軟體領域的領導者，其業務涵蓋銷售、服務、行銷、商務、數據和 AI 解決方案。為進行有效的同業比較，我們識別了以下 4 家主要競爭對手：

*   **Microsoft (MSFT)**：憑藉其 Dynamics 365 和 Azure 雲服務，在企業軟體和雲計算領域與 Salesforce 競爭。
*   **Oracle (ORCL)**：作為傳統資料庫巨頭，正積極轉型雲端應用和基礎設施，與 Salesforce 在企業級應用市場有所重疊。
*   **SAP SE (SAP)**：歐洲最大的企業軟體公司，提供 ERP 和 CRM 等多種企業解決方案。
*   **ServiceNow (NOW)**：專注於 IT 服務管理和數位工作流程自動化，在企業雲服務市場與 Salesforce 形成競爭。

以下是 Salesforce 及其主要競爭對手的關鍵財務與估值指標對照表：

**估值地位分析：**

從同業比較來看，Salesforce (CRM) 的估值倍數相對於其成長性和盈利能力，呈現出一些值得關注的特點：

*   **P/E Ratio (Trailing & Forward):** CRM 的本益比 (23.63 / 16.09) 介於 Oracle (26.73 / 17.6) 和 Microsoft (27.87 / 25.30) 之間，但顯著低於 ServiceNow (88.26 / 31.18)。這表明市場對 CRM 未來盈利增長的預期相對合理，並未像 ServiceNow 那樣給予極高的成長溢價。
*   **P/S Ratio:** CRM 的股價營收比 (4.86) 低於所有主要競爭對手 (MSFT 11.09, ORCL 6.74, SAP 6.64, NOW 10.4)。這可能暗示 CRM 的營收估值相對較低，或者其利潤率不如某些競爭對手。
*   **EV/EBITDA:** CRM 的企業價值倍數 (13.29) 也低於 Microsoft (17.64), Oracle (17.41) 和 SAP (18.44)，但遠低於 ServiceNow (44.80)。這進一步支持了 CRM 相對於其營運現金流而言，估值可能處於折價狀態。
*   **盈利能力與成長性：**
    *   CRM 的營收增長率 (LTM 22.93%) 表現強勁，與 ServiceNow (24.0%) 相當，並高於 Microsoft (17.8%), Oracle (17%) 和 SAP (11%)。這顯示 CRM 仍具備較高的成長動能。
    *   然而，在營業利潤率 (21.52%) 和淨利潤率 (21.99%) 方面，CRM 落後於 Microsoft (46.8% / 40.3%) 和 Oracle (33.23% / 25.37%)，但高於 ServiceNow (29.5% / 11.34%)。這可能解釋了其 P/S 和 EV/EBITDA 倍數較低的原因，市場可能對其盈利效率有所顧慮。

總體而言，Salesforce 相對於其高成長性而言，其估值倍數（尤其是 P/S 和 EV/EBITDA）似乎處於折價狀態。這可能反映了市場對其盈利能力提升空間的潛在擔憂，或者其在某些細分市場面臨的競爭壓力。然而，考慮到其在 CRM 市場的領導地位和持續的營收增長，目前的估值可能具有吸引力。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估算公司未來自由現金流的現值，以得出其內在價值。

**預測假設：**

*   **預測期間：** 5 年 (2027 - 2031 財年)。
*   **起始營收 (FY2026):** $41.53 億美元。
*   **營收增長率預期：**
    *   FY2027: 10% (基於近期營收增長趨勢和市場預期，略低於 LTM 增長率以反映規模效應)。
    *   FY2028-FY2029: 8% (逐步趨緩)。
    *   FY2030-FY2031: 6% (進一步趨緩，但仍高於行業平均水平，反映其市場領導地位)。
*   **自由現金流利潤率 (FCF Margin):**
    *   Salesforce 最近 12 個月的自由現金流為 $15.15 億美元，營收為 $43.94 億美元，計算得出 FCF Margin 約為 34.48%。考慮到營運資本變動和再投資需求，我們將採用較為保守的假設。
    *   FY2027: 30%
    *   FY2028-FY2031: 逐步提升至 32%，反映規模經濟和營運效率的提升。
*   **稅率：** 22% (參考其有效稅率)。

**折現率與終值：**

*   **加權平均資本成本 (WACC):**
    *   我們參考了多個來源，WACC 介於 7.9% 至 10.52% 之間。為保守起見，我們採用 **9.0%** 作為基準 WACC。
    *   計算邏輯：WACC = (E/V) \* Re + (D/V) \* Rd \* (1 - Tc)
        *   Re (股權成本): 8.76% (Alpha Spread)
        *   Rd (債務成本): 5.08% (Alpha Spread)
        *   Tc (稅率): 22%
        *   E/V (股權權重): 84%
        *   D/V (債務權重): 16%
        *   WACC = (0.84 \* 0.0876) + (0.16 \* 0.0508 \* (1 - 0.22)) = 0.073584 + 0.00635 = 0.0800 ≈ 8.0% (此處與 Alpha Spread 的 8.18% 接近，但為簡化模型，我們將使用 9.0% 作為基準，並在敏感性分析中考慮範圍)。
*   **終值增長率 (Terminal Growth Rate):** 3% (假設公司在預測期後以穩定的速度增長，略高於長期通脹率，符合大型成熟科技公司的特徵)。

**估值結果 (DCF 模型)：**

| 年度 (財年) | 預測營收 (B USD) | FCF Margin | 自由現金流 (B USD) | 折現因子 (9.0%) | 自由現金流現值 (B USD) |
| :---------- | :--------------- | :--------- | :----------------- | :-------------- | :--------------------- |
| FY2027      | 45.68            | 30.0%      | 13.70              | 0.917           | 12.56                  |
| FY2028      | 49.33            | 30.5%      | 15.04              | 0.842           | 12.66                  |
| FY2029      | 53.28            | 31.0%      | 16.52              | 0.772           | 12.75                  |
| FY2030      | 56.48            | 31.5%      | 17.79              | 0.708           | 12.60                  |
| FY2031      | 59.87            | 32.0%      | 19.16              | 0.650           | 12.45                  |
| **預測期自由現金流現值總和** | | | | | **63.02** |

*   **終值 (Terminal Value):**
    *   終值自由現金流 (FY2032) = FY2031 FCF \* (1 + Terminal Growth Rate) = 19.16 \* (1 + 0.03) = 19.73 B USD
    *   終值 = 終值自由現金流 / (WACC - Terminal Growth Rate) = 19.73 / (0.09 - 0.03) = 19.73 / 0.06 = 328.83 B USD
    *   終值現值 = 328.83 / (1 + 0.09)^5 = 328.83 / 1.5386 = 213.72 B USD

*   **企業價值 (Enterprise Value):** 預測期自由現金流現值總和 + 終值現值 = 63.02 + 213.72 = 276.74 B USD
*   **股權價值 (Equity Value):** 企業價值 + 現金及約當現金 - 總債務
    *   Salesforce 現金及約當現金：$11.40 億美元
    *   Salesforce 總債務：$42.38 億美元
    *   股權價值 = 276.74 + 11.40 - 42.38 = 245.76 B USD
*   **流通股數：** 約 8.19 億股
*   **每股內在價值 (Intrinsic Value Per Share):** 245.76 B / 0.819 B = **$300.07**

**合理價位區間 (DCF):**
考慮 WACC 和終值增長率的敏感性分析：
*   WACC 8.5%, Terminal Growth 3.0% -> $325 - $335
*   WACC 9.0%, Terminal Growth 3.0% -> **$290 - $310**
*   WACC 9.5%, Terminal Growth 3.0% -> $260 - $270

因此，DCF 模型下的合理價位區間約為 **$290 - $310**。

### 3. 多維度估值法 (Other Valuation Methods)

#### 相對估值法 (Relative Valuation)

我們將使用同業的平均估值倍數來推算 Salesforce 的目標價位。

| 指標                 | CRM (Salesforce) | 同業平均 (MSFT, ORCL, SAP, NOW) |
| :------------------- | :--------------- | :------------------------------ |
| P/E Trailing         | 23.63            | (27.87+26.73+27.96+88.26)/4 = 42.71 |
| P/E Forward          | 16.09            | (25.30+17.6+24.06+31.18)/4 = 24.54 |
| P/S                  | 4.86             | (11.09+6.74+6.64+10.4)/4 = 8.72 |
| EV/EBITDA            | 13.29 | (17.64+17.41+18.44+44.80)/4 = 24.57 |

*   **基於 P/E (Trailing) 的估值：**
    *   CRM EPS (TTM) = 營收 / P/S = 43.94B / 4.86 = 9.04 (這不是實際 EPS，而是反推的，實際 EPS TTM 為 $10.79)。
    *   使用實際 EPS (TTM) $10.79。
    *   目標價 = EPS (TTM) \* 同業平均 P/E (Trailing) = $10.79 \* 42.71 = **$460.90** (此結果因 ServiceNow 的高 P/E 而被拉高，可能不具代表性)。
    *   若排除 ServiceNow (P/E 88.26)，同業平均 P/E (Trailing) = (27.87+26.73+27.96)/3 = 27.52。
    *   目標價 = $10.79 \* 27.52 = **$296.95**

*   **基於 P/E (Forward) 的估值：**
    *   CRM Forward EPS = 259.23 / 16.09 = $16.11 (此為反推，實際 EPS next Y_% 為 -0.0291，EPS this Y 為 0.3253，所以 Forward EPS 應為 0.3253 * (1-0.0291) = 0.3158。這與 P/E 16.09 不符，可能數據來源有差異。我們將使用分析師目標價的 Forward P/E 16.09 和其對應的 EPS。)
    *   若使用同業平均 Forward P/E 24.54，則需要預估 CRM 的 Forward EPS。假設 CRM 的 Forward EPS 為 $16.11 (從當前股價和 Forward P/E 反推)。
    *   目標價 = $16.11 \* 24.54 = **$395.35** (同樣受 ServiceNow 影響較大)
    *   若排除 ServiceNow，同業平均 Forward P/E = (25.30+17.6+24.06)/3 = 22.32。
    *   目標價 = $16.11 \* 22.32 = **$359.58**

*   **基於 P/S 的估值：**
    *   CRM 營收 (TTM) = $43.94 億美元
    *   同業平均 P/S = 8.72
    *   目標市值 = 營收 (TTM) \* 同業平均 P/S = $43.94 B \* 8.72 = 383.27 B USD
    *   目標價 = 383.27 B / 0.819 B = **$467.97** (同樣受 Microsoft 和 ServiceNow 的高 P/S 影響)
    *   若排除 ServiceNow 和 Microsoft，同業平均 P/S = (6.74+6.64)/2 = 6.69。
    *   目標市值 = $43.94 B \* 6.69 = 293.95 B USD
    *   目標價 = 293.95 B / 0.819 B = **$358.91**

*   **基於 EV/EBITDA 的估值：**
    *   CRM EBITDA (TTM) = $12.90 億美元
    *   同業平均 EV/EBITDA = 24.57
    *   目標企業價值 = EBITDA (TTM) \* 同業平均 EV/EBITDA = $12.90 B \* 24.57 = 317.97 B USD
    *   目標股權價值 = 目標企業價值 - 總債務 + 現金 = 317.97 - 42.38 + 11.40 = 286.99 B USD
    *   目標價 = 286.99 B / 0.819 B = **$350.41**
    *   若排除 ServiceNow，同業平均 EV/EBITDA = (17.64+17.41+18.44)/3 = 17.83。
    *   目標企業價值 = $12.90 B \* 17.83 = 229.95 B USD
    *   目標股權價值 = 229.95 - 42.38 + 11.40 = 198.97 B USD
    *   目標價 = 198.97 B / 0.819 B = **$242.94**

考慮到 ServiceNow 的估值倍數異常高，且 Microsoft 的規模和業務廣度與 CRM 仍有差異，我們更傾向於參考 Oracle 和 SAP 的倍數。綜合來看，排除極端值後，相對估值法給出的目標價位區間約為 **$290 - $360**。

#### 股息折現模型 (Dividend Discount Model, DDM)

Salesforce 於 2024 年首次宣布派發股息，年股息為 $1.76，股息收益率約 0.68%。其 1 年股息增長率約為 4.0% 至 5.34%。由於股息歷史較短且收益率較低，DDM 對於 Salesforce 的估值權重較低，但仍可作為參考。

假設股息增長率為 5.0%，並在未來 5 年後穩定在 3.0% (與終值增長率一致)，股權成本 (Re) 採用 8.76%。

*   D0 = $1.76
*   D1 = 1.76 \* (1 + 0.05) = $1.85
*   D2 = 1.85 \* (1 + 0.05) = $1.94
*   D3 = 1.94 \* (1 + 0.05) = $2.04
*   D4 = 2.04 \* (1 + 0.05) = $2.14
*   D5 = 2.14 \* (1 + 0.05) = $2.25
*   D6 = 2.25 \* (1 + 0.03) = $2.32

*   DDM 終值 (P5) = D6 / (Re - g) = 2.32 / (0.0876 - 0.03) = 2.32 / 0.0576 = $40.28

*   每股價值 = D1/(1+Re)^1 + D2/(1+Re)^2 + D3/(1+Re)^3 + D4/(1+Re)^4 + D5/(1+Re)^5 + P5/(1+Re)^5
    *   = 1.85/(1.0876)^1 + 1.94/(1.0876)^2 + 2.04/(1.0876)^3 + 2.14/(1.0876)^4 + 2.25/(1.0876)^5 + 40.28/(1.0876)^5
    *   = 1.70 + 1.64 + 1.58 + 1.52 + 1.46 + 26.10 = **$34.00**

DDM 模型給出的估值顯著低於當前股價，這主要是因為 Salesforce 的股息收益率非常低，且其價值主要來自於未來的成長而非當前股息。因此，DDM 在此案例中僅作為參考，不作為主要估值依據。

**最終結論：**

綜合 DCF 模型和同業相對估值法的結果，我們認為 Salesforce (CRM) 的合理價位區間約為 **$280 - $320**。

目前股價 $259.23，處於合理偏低估的位階。

**投資核心論點：**

Salesforce 在全球 CRM 市場的領導地位穩固，並透過持續的產品創新和策略性收購，不斷強化其在雲端應用和 AI 領域的競爭力。儘管面臨來自 Microsoft、Oracle 等巨頭的激烈競爭，但其強勁的營收增長勢頭和不斷改善的盈利能力，為其內在價值提供了堅實支撐。相較於同業，CRM 的估值倍數（特別是 P/S 和 EV/EBITDA）處於相對合理的水平，甚至略有折價，這為長期投資者提供了潛在的價值空間。然而，投資者需關注其相對較高的負債水平以及市場對其未來盈利效率持續提升的預期。若公司能有效整合 AI 技術並持續擴大市場份額，其估值有望進一步提升。
