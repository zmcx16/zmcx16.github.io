# Medtronic Plc (MDT) 深度估值分析報告

#### **估值地位分析**
- **折價狀態**：相對於 BSX 與 SYK，MDT 目前處於明顯的**估值折價 (Discount)**。其 Forward P/E 僅 14.9x，遠低於同業平均的 25x 以上。
- **原因分析**：市場對 MDT 的折價主要源於其營收增長率（低個位數）低於 BSX 與 SYK（雙位數）。然而，MDT 的營業利潤率與淨利潤率仍維持在產業領先水準，顯示其成本控制與規模經濟依然強大。
- **合理性**：考慮到 MDT 正在進行業務剝離（如患者監護與呼吸干預業務）並轉向高增長的 AI 手術機器人與糖尿病管理領域，目前的折價程度顯得過度，具備價值回歸空間。

- **預測期間**：2025 - 2029 (5年)。
- **營收增長率**：預計未來 5 年複合年增長率 (CAGR) 為 **4.5%**。考量到新產品（如 Hugo 機器人系統、Simplera 血糖監測儀）的放量。
- **自由現金流 (FCF) 利潤率**：假設維持在 **18% - 20%**。MDT 具備強大的現金轉換能力。
- **稅率**：有效稅率假設為 14.5%（參考公司指引）。

#### **折現率與終值**
- **WACC 計算**：
  - 無風險利率 (Risk-free Rate): 4.0% (10Y Treasury)
  - 貝塔係數 (Beta): 0.72 (低波動特性)
  - 股權風險溢價 (ERP): 5.0%
  - 權益成本 (Ke): 7.6%
  - 稅後債務成本: 4.2%
  - **最終 WACC: 7.2%**
- **終值增長率 (g)**：**2.5%** (符合醫療產業長期通膨與人口老化趨勢)。

#### **估值結果**

- **淨負債**：約 $145 億。
- **內在價值 (Intrinsic Value)**：**$108.40**。
- **合理價位區間**：**$102 - $115**。

### 3. 多維度估值法

#### **相對估值法 (Relative Valuation)**
- 參考 MDT 過去五年的平均 Forward P/E 約為 17.5x。
- 預計 FY2025 EPS 為 $5.45。
- **目標價 = 17.5 * $5.45 = $95.38**。
- 若給予產業平均 20x 的保守溢價（考量其龍頭地位回歸），目標價可達 **$109**。

#### **股息折現模型 (DDM)**
- MDT 是著名的「股息貴族」，已連續 47 年調升股息。
- 當前年化股息：$2.80。
- 預期股息增長率：4.0%。
- 股權成本 (Ke)：7.6%。
- **DDM 價值 = $2.80 * (1 + 4%) / (7.6% - 4%) = $80.88**。
- *註：DDM 通常會低估 MDT，因為該公司投入大量資金於研發與併購，而非僅發放股息。*
