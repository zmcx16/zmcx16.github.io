- **結論**：SD 處於「資產防禦型」溢價狀態，其 6.46x 的 P/E 在同業中屬中高位，但考量到其現金佔市值約 20% 以上，剔除現金後的企業價值倍數 (EV/EBITDA) 其實與同業持平，估值尚屬合理。

### 2. 折現現金流模型 (DCF)

SD 的現金流特徵是「前期高、後期隨產量遞減」。

#### 預測假設
1.  **預測期間**：5 年 (2025-2029)。
2.  **營收增長率**：預計 2025 年因大宗商品價格波動及產量自然遞減，營收下滑 5%-8%，隨後每年維持 -3% 的自然衰減。
3.  **自由現金流 (FCF) 利潤率**：維持在 25%-30% 高位，因資本支出 (CapEx) 僅用於維持性生產。
4.  **稅率**：21% (考慮公司仍有部分 NOLs 稅收抵免，實際稅率可能較低)。

#### 折現率與終值
- **WACC 計算**：
  - 無風險利率 (10Y Treasury): 4.3%
  - Beta: 1.2
  - 股權風險溢價: 6.0%
  - **WACC = 11.5%** (因無債務，WACC 即為股權成本)。
- **終值增長率 (g)**：-2% (考量油氣田枯竭風險，採用負增長假設)。

#### 估值結果
- **預計未來 5 年 FCF 總現值**：約 $285M。
- **終值現值**：約 $210M。
- **加回淨現金**：約 $115M。
- **內在價值**：$610M。
- **每股合理價位**：**$16.50**。

### 3. 多維度估值法

#### 相對估值法 (Relative Valuation)
參考同業平均 EV/EBITDA 3.5x。
- 預估 2025 EBITDA: $135M。
- 企業價值 (EV) = 135 * 3.5 = $472.5M。
- 市值 = EV + 現金 ($115M) = $587.5M。
- 推算股價：**$15.90**。

#### 股息折現模型 (DDM)
SD 採取固定加特別股息政策。
- 預期年度總配息：$0.44 (基礎) + $0.60 (預期特別股息) = $1.04。
- 假設股息增長率：0% (成熟期)。
- 股權成本：11.5%。
- 推算股價：1.04 / 0.115 = **$9.04** (註：DDM 對於此類高現金儲備公司會嚴重低估，僅供參考)。

#### 資產基礎估值 (NAV)
根據最新 10-K 披露的 PV-10 (折現 10% 的稅前未來淨現金流) 價值，結合當前油價調整。
- 估計 PV-10 價值約 $450M - $500M。
- 加上帳面現金與流動資產，扣除負債。
- 推算價值區間：**$14.50 - $15.50**。
