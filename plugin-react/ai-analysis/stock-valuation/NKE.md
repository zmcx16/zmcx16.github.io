## Nike (NKE) 股權估值分析報告

作為一名資深投資分析師，我將對美股公司 Nike, Inc. (NKE) 進行全面的股權估值分析，並著重與其主要同業競爭對手進行橫向比較。

### 1. 同業比較分析 (Industry Peer Comparison)

#### 識別競爭對手
Nike 在全球運動服飾與鞋類市場中佔據領導地位。其主要競爭對手包括：
1.  **Adidas AG (ADDYY)**：德國跨國運動用品製造商，Nike 的主要全球競爭對手。
2.  **Lululemon Athletica Inc. (LULU)**：專注於瑜伽和運動休閒服飾，近年來成長迅速，市場定位高端。
3.  **Under Armour, Inc. (UAA)**：美國運動服飾和配件公司，在北美市場與 Nike 競爭。

#### 估值地位分析
從同業比較來看，Nike 的估值倍數（P/E、P/S、EV/EBITDA）普遍高於 Adidas 和 Under Armour，但低於 Lululemon 在某些盈利指標上的表現。

*   **相對於 Adidas**：Nike 的 P/E 略低於 Adidas (20.32 vs 20.97)，但 P/S 略高 (1.34 vs 1.13)。EV/EBITDA 方面，Nike 的 13.5x 高於 Adidas 的 11.5x。這可能反映市場對 Nike 的品牌溢價和更穩定的市場地位有較高認可。然而，Nike 近期的營收增長率 (0.19%) 顯著低於 Adidas (5%)，這可能對其估值溢價構成壓力。
*   **相對於 Lululemon**：Lululemon 展現出更高的盈利能力（營業利潤率 11.2% 和淨利潤率 13.0%），且其 P/E (9.99) 和 EV/EBITDA (5.6x) 顯著低於 Nike。這可能是由於 Lululemon 的市場規模較小，且其高成長性可能導致其盈利倍數波動較大，或者市場對其未來成長的可持續性有不同看法。值得注意的是，Lululemon 的 P/E 數據顯得異常低，可能需要進一步核實或考慮其成長性因素。
*   **相對於 Under Armour**：Under Armour 目前處於虧損狀態（P/E 為負，淨利潤率為負），營收也呈現負增長。儘管其 P/S (0.56) 較低，但其 EV/EBITDA (15.0x) 卻相對較高，這通常發生在 EBITDA 較低或為負的公司，表明其企業價值相對於營運收益而言較高，反映了其較差的盈利能力和較高的風險。Nike 相對於 Under Armour 而言，無論在盈利能力、成長性還是估值穩定性上都處於明顯的溢價地位，這是合理的。

總體而言，Nike 的估值倍數處於行業中上水平。其品牌實力、全球佈局和穩定的現金流是支撐其估值的重要因素。然而，其近期較低的營收增長率，特別是與 Adidas 和 Lululemon 相比，可能需要市場重新評估其成長前景，這也解釋了其股價在過去一年中的大幅下跌。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估計公司未來自由現金流的現值，以推算其內在價值。

#### 預測假設
*   **預測期間**：5 年 (2027-2031 財年)。
*   **營收增長率預期**：
    *   考慮到 Nike 近期營收增長放緩 (FY2026 YoY 0.19%) 以及全球經濟不確定性，我們預計未來幾年將呈現溫和增長。
    *   2027-2028 財年：3.0% (預期溫和復甦)
    *   2029-2030 財年：2.0% (增長趨於穩定)
    *   2031 財年：1.5% (接近長期增長率)
*   **自由現金流利潤率 (FCF Margin)**：
    *   Nike 的 FCF Margin 波動較大，最新一季為 13.66%，LTM 為 2.3%。考慮到其歷史平均和營運效率，我們假設 FCF Margin 在預測期內逐步穩定在 8.0% 的水平。
    *   2027 財年：7.0%
    *   2028 財年：7.5%
    *   2029-2031 財年：8.0%

#### 折現率與終值
*   **加權平均資本成本 (WACC)**：
    *   我們參考多個來源，Nike 的 WACC 估計值介於 7.75% 至 9.26% 之間。
    *   採用保守估計，我們將 WACC 設定為 **8.5%**。
    *   計算邏輯：
        *   股權成本 (Cost of Equity, Re)：約 9.5% (參考 CAPM 模型，Beta 0.77，無風險利率約 4.65%，股權風險溢價約 4.3%)。
        *   債務成本 (Cost of Debt, Rd)：稅後約 4.5% (參考稅前債務成本和 38% 稅率)。
        *   資本結構：債務/股權比 (Debt/Eq) 為 0.74。
        *   股權權重 (E/(E+D)) = 1 / (1 + 0.74) = 0.575。
        *   債務權重 (D/(E+D)) = 0.74 / (1 + 0.74) = 0.425。
        *   WACC = (0.575 * 9.5%) + (0.425 * 4.5%) = 5.46% + 1.91% = 7.37%。
        *   由於計算結果與市場普遍估計的 WACC 存在差異，為保持分析的穩健性，我們直接採用市場上較為普遍且保守的 WACC 估計值 **8.5%**。
*   **終值增長率 (Terminal Growth Rate)**：
    *   我們假設 Nike 在預測期後進入穩定增長階段，終值增長率設定為 **1.5%**，略低於長期通脹和全球經濟增長率。

### 3. 多維度估值法 (Other Valuation Methods)

#### 相對估值法 (Relative Valuation)
我們將使用同業的估值倍數來推算 Nike 的目標價位。

*   **P/E Ratio (Trailing)**：
    *   NKE P/E: 20.32
    *   Adidas P/E: 20.97
    *   Lululemon P/E: 9.99
    *   同業平均 P/E (不含虧損的 UAA)：(20.97 + 9.99) / 2 = 15.48。
    *   若以同業平均 P/E 15.48 估值，NKE 的合理股價 = EPS (TTM) * 15.48。NKE 的 EPS (TTM) 為 $2.10。
    *   合理股價 = $2.10 * 15.48 = **$32.51**。
    *   若考慮 Nike 的市場領導地位，給予其與 Adidas 相近的 P/E (20.97)，合理股價 = $2.10 * 20.97 = **$44.04**。

*   **P/S Ratio**：
    *   NKE P/S: 1.34
    *   Adidas P/S: 1.13
    *   Lululemon P/S: 1.21
    *   同業平均 P/S (不含 UAA)：(1.13 + 1.21) / 2 = 1.17。
    *   若以同業平均 P/S 1.17 估值，NKE 的合理股價 = 營收/股 * 1.17。NKE 的 TTM 營收為 $46.40B，市值 $62.31B，股價 $41.70。每股營收約 $46.40B / (62.31B / 41.70) = $31.08 (估計流通股數約 1.49B)。
    *   合理股價 = ($46.40B / 1.49B) * 1.17 = $31.14 * 1.17 = **$36.43**。

*   **EV/EBITDA**：
    *   NKE EV/EBITDA: ~13.5x
    *   Adidas EV/EBITDA: ~11.5x
    *   Lululemon EV/EBITDA: ~5.6x
    *   同業平均 EV/EBITDA (不含 UAA)：(11.5 + 5.6) / 2 = 8.55x。
    *   若以同業平均 EV/EBITDA 8.55x 估值，NKE 的合理企業價值 = EBITDA * 8.55。NKE 的 TTM EBITDA 為 $4,594 Mil。
    *   合理企業價值 = $4,594 Mil * 8.55 = $39,278.7 Mil。
    *   合理股權價值 = 合理企業價值 - 淨債務。假設淨債務約為總債務減去現金。
    *   由於缺乏詳細的淨債務數據，此處僅作參考，並以 P/E 和 P/S 為主。

綜合相對估值法，考慮到 Nike 的品牌溢價和市場地位，其合理價位可能落在 **$36 - $44** 之間。

#### 股息折現模型 (DDM)
Nike 是一家穩定派息的公司，年股息為 $1.64，股息收益率為 3.93%。其三年平均股息增長率為 9.68%。

*   **假設**：
    *   當前股息 (D0) = $1.64
    *   短期股息增長率 (g1)：未來 3 年為 6.0% (考慮歷史增長但趨於保守)。
    *   長期股息增長率 (g2)：3 年後穩定在 2.5% (低於 WACC)。
    *   股權成本 (Ke)：採用 9.5%。

*   **計算**：
    *   D1 = $1.64 * (1 + 0.06) = $1.74
    *   D2 = $1.74 * (1 + 0.06) = $1.85
    *   D3 = $1.85 * (1 + 0.06) = $1.96
    *   P3 (終值) = D3 * (1 + g2) / (Ke - g2) = $1.96 * (1 + 0.025) / (0.095 - 0.025) = $1.96 * 1.025 / 0.07 = $2.009 / 0.07 = $28.70
    *   DDM 估值 = D1/(1+Ke)^1 + D2/(1+Ke)^2 + D3/(1+Ke)^3 + P3/(1+Ke)^3
    *   DDM 估值 = $1.74/(1.095)^1 + $1.85/(1.095)^2 + $1.96/(1.095)^3 + $28.70/(1.095)^3
    *   DDM 估值 = $1.59 + $1.54 + $1.49 + $21.86 = **$26.48**

DDM 模型給出的估值顯著低於當前股價和 DCF 估值，這可能表明市場對 Nike 未來的股息增長預期更高，或者 DDM 模型對於成長型公司（即使是穩定派息的）的適用性有限，因為它高度依賴於股息增長率的假設。
