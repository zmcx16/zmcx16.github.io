作為一位資深投資分析師，我將對美股公司 Autodesk Inc (ADSK) 進行全面的股權估值分析，並特別強調與同業競爭對手的橫向比較。

### 1. 同業比較分析 (Industry Peer Comparison)

**識別競爭對手**
Autodesk (ADSK) 主要提供設計、工程和娛樂軟體，其競爭對手主要來自應用軟體產業。根據市場資訊，以下是 ADSK 的 4 家主要競爭對手：
*   **Adobe Inc. (ADBE)**：在創意和數位媒體軟體領域的領導者。
*   **Dassault Systèmes SE (DSY.PA)**：一家法國跨國軟體公司，專注於 3D 產品設計、模擬和製造。
*   **PTC Inc. (PTC)**：提供產品生命週期管理 (PLM)、物聯網 (IoT) 和擴增實境 (AR) 軟體。
*   **ANSYS Inc. (ANSS)**：專注於工程模擬軟體。

**估值地位分析**
從同業比較來看，Autodesk (ADSK) 的估值倍數呈現以下特點：
*   **本益比 (P/E)**：ADSK 的追蹤本益比 (36.39) 顯著高於 Adobe (15.17)、Dassault Systèmes (21.98) 和 PTC (13.73)，但低於 ANSYS (55.57)。然而，其預期本益比 (17.57) 則與 PTC (16.86) 接近，並高於 Adobe (10.23) 和 Dassault Systèmes (15.63)，但仍低於 ANSYS (31.49)。這表明市場對 ADSK 未來盈利增長有較高預期，但其當前盈利能力尚未完全支撐其追蹤 P/E。
*   **股價營收比 (P/S)**：ADSK 的 P/S (6.99) 介於同業之間，高於 Adobe (4.16)、Dassault Systèmes (4.56) 和 PTC (5.20)，但遠低於 ANSYS (12.75)。這可能反映了 ADSK 相對於部分同業在營收規模上的優勢，但其利潤率可能不如 Adobe 或 PTC。
*   **企業價值倍數 (EV/EBITDA)**：ADSK 的 EV/EBITDA (34.44) 遠高於 Adobe (7.84)、Dassault Systèmes (12.20) 和 PTC (13.29)，但與 ANSYS (30.38) 接近。這表明市場對 ADSK 的企業價值給予了較高的溢價，可能與其強勁的營收增長預期和市場地位有關。
*   **營收增長率**：ADSK 最近一季的營收增長率 (18%) 表現強勁，高於 Adobe (10.5%) 和 Dassault Systèmes (4%)，與 PTC (19.2%) 和 ANSYS (16.0%) 相當。這支持了市場對其較高估值的合理性。
*   **利潤率**：ADSK 的營業利潤率 (39% Non-GAAP) 和淨利潤率 (19.5%) 雖然表現良好，但略低於 Adobe (營業利潤率 36.63%，淨利潤率 29.00%) 和 PTC (營業利潤率 35.9%，淨利潤率 35%)。這可能解釋了其 P/E 倍數相對於這些公司較高的部分原因，即市場可能預期其利潤率有提升空間。

總體而言，ADSK 相對於其主要競爭對手 Adobe、Dassault Systèmes 和 PTC 而言，在 P/E 和 EV/EBITDA 等估值倍數上處於**溢價**狀態。這種溢價可能歸因於其強勁的近期營收增長勢頭、在建築、工程和製造等核心市場的領導地位，以及對 AI 和雲端平台的持續投資所帶來的未來增長潛力。然而，其利潤率略低於部分同業，這也提示了未來提升效率的重要性。與 ANSYS 相比，ADSK 的估值倍數更為合理，且營收增長率相似。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估計公司未來自由現金流的現值，以得出其內在價值。

**預測假設**
*   **預測期間**：5 年（2027 財年 - 2031 財年），之後進入永續增長階段。
*   **營收增長率預期**：
    *   **2027 財年**：根據 ADSK Q1 FY2027 財報，公司上調了 FY2027 的營收指引至 $8.155B - $8.215B。以中位數 $8.185B 計算，相較於 FY2026 的 $7.21B 營收，增長率約為 13.5%。我將採用 13.5%。
    *   **2028-2031 財年**：考慮到軟體行業的持續增長、ADSK 在 AI 和雲端解決方案的投資，以及其在核心市場的領導地位，但同時也考慮到市場競爭和規模效應，我預計營收增長率將逐步放緩。
        *   2028 財年：12%
        *   2029 財年：10%
        *   2030 財年：8%
        *   2031 財年：6%
*   **營業利潤率 (Operating Margin)**：ADSK Q1 FY2027 的非 GAAP 營業利潤率為 39%。公司預計 FY2027 的非 GAAP 營業利潤率約為 39%。考慮到公司持續的銷售優化和對高利潤率訂閱模式的轉型，預計未來幾年將保持穩定或略有提升。
    *   22.48% (來自基本面數據，應為 GAAP)
    *   我將採用非 GAAP 營業利潤率 39% 作為預測期內的基準，並假設其在預測期內保持穩定。
*   **稅率**：採用 ADSK 最新十二個月的有效稅率 25.7%。
*   **資本支出 (Capital Expenditure)**：根據 FY2026 數據為 -$43.00 M。預計未來將維持在營收的 0.5% 左右。
*   **營運資本變動 (Change in Working Capital)**：預計將佔營收的 -1% 至 0% 之間，反映其訂閱模式下較低的營運資本需求。

**折現率與終值**
*   **加權平均資本成本 (WACC)**：
    *   **股權成本 (Cost of Equity, Ke)**：使用資本資產定價模型 (CAPM)
        *   無風險利率 (Risk-Free Rate)：美國 10 年期國債收益率為 4.65% (截至 2026 年 8 月 7 日)。
        *   市場風險溢酬 (Market Risk Premium, MRP)：採用 GuruFocus 建議的 6%。
        *   Beta：ADSK 的 Beta 為 0.9416。
        *   Ke = 無風險利率 + Beta * MRP = 4.65% + 0.9416 * 6% = 4.65% + 5.65% = 10.30%
    *   **債務成本 (Cost of Debt, Kd)**：Alpha Spread 提供的 ADSK 債務成本為 4.83%。
    *   **稅率 (Tax Rate)**：採用 25.7%。
    *   **債務權重 (Weight of Debt, Wd)**：ADSK 的債務權益比 (Debt/Eq) 為 0.85 (來自基本面數據)。市值為 $52.56B，總債務約 $2.48B。
        *   股權價值 (E) = $52.56B
        *   債務價值 (D) = $2.48B
        *   總資本 (V) = E + D = $52.56B + $2.48B = $55.04B
        *   Wd = D / V = $2.48B / $55.04B = 4.51%
        *   We = E / V = $52.56B / $55.04B = 95.49%
    *   **WACC** = (We * Ke) + (Wd * Kd * (1 - Tax Rate))
        *   WACC = (0.9549 * 10.30%) + (0.0451 * 4.83% * (1 - 0.257))
        *   WACC = 9.835% + (0.0451 * 4.83% * 0.743)
        *   WACC = 9.835% + 0.162% = 9.997%
        *   為簡化計算並與市場數據保持一致，我將採用 Alpha Spread 提供的 WACC 8.14% 作為參考，並將我的計算結果 9.997% 作為區間上限。最終採用 9.0% 作為 DCF 模型的核心 WACC。
*   **終值增長率 (Terminal Growth Rate)**：考慮到 ADSK 作為成熟軟體公司的性質，以及全球經濟的長期增長率，我將採用 2.5%。

**估值結果**
(以下為簡化 DCF 估算，實際模型需更詳細的財務預測)

| 項目 (單位: 百萬美元) | 2027E | 2028E | 2029E | 2030E | 2031E |
| :-------------------- | :---- | :---- | :---- | :---- | :---- |
| 營收 (Revenue)        | 8,185 | 9,167 | 10,084 | 10,891 | 11,544 |
| 營收增長率            | 13.5% | 12%   | 10%   | 8%    | 6%    |

*   **終值 (Terminal Value)**：
    *   永續增長 FCF (FCF_2032) = FCF_2031 * (1 + Terminal Growth Rate) = $3,173 * (1 + 0.025) = $3,252
    *   終值 = FCF_2032 / (WACC - Terminal Growth Rate) = $3,252 / (0.09 - 0.025) = $3,252 / 0.065 = $50,031 百萬美元
    *   終值現值 = 終值 / (1 + WACC)^5 = $50,031 / (1.09)^5 = $50,031 / 1.5386 = $32,517 百萬美元

*   **企業價值 (Enterprise Value)**：
    *   預測期 FCF 現值總和 = $2,062 + $2,118 + $2,141 + $2,120 + $2,062 = $10,503 百萬美元
    *   企業價值 = 預測期 FCF 現值總和 + 終值現值 = $10,503 + $32,517 = $43,020 百萬美元

*   **股權價值 (Equity Value)**：
    *   股權價值 = 企業價值 + 現金及約當現金 - 總債務
    *   ADSK 現金及約當現金 (截至 2026 年 3 月) 約 $2.67B [cite: 37, previous search]
    *   ADSK 總債務 (截至 2026 年 3 月) 約 $2.48B [cite: 37, previous search]
    *   股權價值 = $43,020 + $2,670 - $2,480 = $43,210 百萬美元

*   **每股內在價值 (Intrinsic Value Per Share)**：
    *   流通股數：約 211 百萬股 (截至 2026 年 5 月) [cite: 32, 38, previous search]
    *   每股內在價值 = $43,210 / 211 = $204.79

*   **合理價位區間**：考慮到假設的敏感性，若 WACC 介於 8.5% 至 9.5%，終值增長率介於 2% 至 3%，則合理價位區間約為 **$190 - $220**。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**
基於同業比較，我們可以利用行業平均倍數來推算 ADSK 的目標價位。

| 指標                 | ADSK (自身) | 同業平均 (不含 ADSK) | 推算目標價 (基於 ADSK TTM 數據) |
| :------------------- | :---------- | :------------------- | :------------------------------ |
| P/E (Trailing)       | 36.39       | 26.97                | $249.08 * (26.97 / 36.39) = $184.70 |
| P/E (Forward)        | 17.57       | 18.55                | $249.08 * (18.55 / 17.57) = $263.00 |
| P/S                  | 6.99        | 6.62                 | $249.08 * (6.62 / 6.99) = $235.80 |
| EV/EBITDA            | 34.44       | 17.98                | (需計算企業價值再轉為股價) |

*   **同業平均計算 (不含 ADSK)**：
    *   P/E (Trailing): (15.17 + 21.98 + 13.73 + 55.57) / 4 = 26.61
    *   P/E (Forward): (10.23 + 15.63 + 16.86 + 31.49) / 4 = 18.55
    *   P/S: (4.16 + 4.56 + 5.20 + 12.75) / 4 = 6.67
    *   EV/EBITDA: (7.84 + 12.20 + 13.29 + 30.38) / 4 = 15.93

*   **重新計算推算目標價 (基於 ADSK TTM 數據)**：
    *   **P/E (Trailing) 法**：ADSK TTM EPS = Net Income (TTM) / Shares Outstanding = $1.5B / 211M = $7.11。
        *   目標 P/E = 26.61。目標股價 = $7.11 * 26.61 = $189.19
    *   **P/E (Forward) 法**：ADSK Forward EPS = Current EPS * (1 + EPS next Y_%) = $7.11 * (1 + 0.1266) = $8.01 (使用基本面數據中的 EPS next Y_%)
        *   目標 P/E = 18.55。目標股價 = $8.01 * 18.55 = $148.59
    *   **P/S 法**：ADSK TTM Sales Per Share = Revenue (TTM) / Shares Outstanding = $7.51B / 211M = $35.60。
        *   目標 P/S = 6.67。目標股價 = $35.60 * 6.67 = $237.45
    *   **EV/EBITDA 法**：ADSK TTM EBITDA = Operating Income (TTM) + Depreciation & Amortization (D&A)。
        *   假設 D&A 約為營收的 5% = $7.51B * 0.05 = $375.5M。
        *   Operating Income (TTM) = Revenue (TTM) * Operating Margin (TTM) = $7.51B * 0.39 = $2.929B (使用非GAAP營業利潤率)
        *   EBITDA (TTM) = $2.929B + $0.3755B = $3.3045B
        *   目標 EV/EBITDA = 15.93。目標企業價值 = $3.3045B * 15.93 = $52.64B
        *   目標股權價值 = $52.64B + $2.67B (現金) - $2.48B (債務) = $52.83B
        *   目標股價 = $52.83B / 211M = $250.38

綜合相對估值法，目標價位區間約為 **$150 - $250**。

**股息折現模型 (DDM)**
根據提供的基本面數據，ADSK 的 "Dividend %" 為 "-"，表示公司目前不支付股息。因此，股息折現模型不適用於 ADSK 的估值。

**其他方法**
對於像 Autodesk 這樣的軟體公司，資產基礎估值 (Asset-based valuation) 通常不適用，因為其價值主要來自無形資產（軟體、品牌、客戶關係）而非有形資產。SOTP (Sum-of-the-parts) 估值法可能適用於業務多元化的公司，但對於 ADSK 而言，其核心業務相對集中，因此在此次分析中不予採用。
