## Autodesk Inc. (ADSK) 股票估值分析報告

作為一名資深投資分析師，我將對美股公司 Autodesk Inc. (ADSK) 進行全面的股權估值分析，並著重與其主要競爭對手進行橫向比較。

### 1. 同業比較分析 (Industry Peer Comparison)

Autodesk Inc. 是全球領先的 3D 設計、工程和娛樂技術解決方案提供商，其產品廣泛應用於建築、工程、施工 (AEC)、產品設計、製造、媒體和娛樂等行業。其主要競爭對手包括在 CAD 軟體、PLM (產品生命週期管理) 和 BIM (建築資訊模型) 領域的參與者。

-   **識別競爭對手**：
    根據市場分析，Autodesk 的主要產業競爭對手包括：
    1.  **Dassault Systèmes (DSY)**：法國軟體公司，以 SOLIDWORKS 和 CATIA 等產品聞名，在 CAD/CAM/CAE 和 PLM 領域與 Autodesk 競爭激烈。
    2.  **PTC Inc. (PTC)**：提供 CAD 軟體 (如 Creo)、PLM、IoT 和 AR 解決方案。
    3.  **Ansys Inc. (ANSS)**：專注於工程模擬軟體，在 CAE 領域是重要競爭者。
    4.  **Bentley Systems (BSY)**：主要提供基礎設施設計、建模和營運軟體，在 AEC 領域與 Autodesk 有重疊。

-   **估值地位分析**：
    從同業比較來看，Autodesk 的估值倍數（P/E、P/S、EV/EBITDA）普遍低於或接近其主要競爭對手。
    *   **P/E Ratio (Trailing & Forward)**：ADSK 的 P/E 倍數顯著低於 Dassault Systèmes、PTC、Ansys 和 Bentley Systems。這可能表明市場認為 ADSK 的盈利增長潛力相對較低，或者其當前股價被低估。
    *   **P/S Ratio**：ADSK 的 P/S 略低於 Dassault Systèmes、Ansys 和 Bentley Systems，但與 PTC 相近。這可能反映了其營收規模和市場對其未來營收增長的預期。
    *   **EV/EBITDA**：ADSK 的 EV/EBITDA 倍數也處於同業中較低的水平。
    *   **營收增長率**：ADSK 在 Q2 FY27 實現了 16% 的營收增長，這與同業相比具有競爭力，甚至高於部分競爭對手。
    *   **利潤率**：ADSK 的營業利潤率和淨利潤率與同業相比處於中上水平，顯示其盈利能力良好。

    綜合來看，Autodesk 相對於同業似乎處於**折價 (Discount)** 狀態。儘管其營收增長和利潤率表現良好，但其估值倍數卻低於許多競爭對手。這可能歸因於市場對其特定業務領域的增長前景、競爭格局變化或宏觀經濟因素的擔憂。然而，考慮到其強大的市場地位、廣泛的產品組合以及向訂閱模式的成功轉型，目前的折價可能為投資者提供了潛在的價值捕捉機會。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估計公司未來自由現金流的現值，以得出其內在價值。

-   **預測假設**：
    *   **預測期間**：5 年（FY2027 - FY2031）。
    *   **營收增長率預期**：
        *   FY2027：根據公司指引，預計營收為 $8.295B 至 $8.345B。取中位數 $8.32B，相較於 TTM $7.79B，增長約 6.8%。考慮到 Q2 FY27 營收增長 16% 和 MaintainX 收購的貢獻，我將採用略高於此的增長率。
        *   我將假設 FY2027 營收增長率為 12% (考慮到 Q2 表現和 MaintainX 貢獻)。
        *   FY2028-FY2029：預計營收增長率逐步放緩，分別為 10%、8%。
        *   FY2030-FY2031：進一步放緩至 6%、5%。
    *   **營業利潤率 (Operating Margin)**：ADSK Q1 FY27 GAAP 營業利潤率為 28%，提供數據為 23.39%。考慮到公司持續優化營運效率，預計未來幾年將保持穩定或略有提升。我將假設營業利潤率在預測期內穩定在 25%-27%。
    *   **稅率 (Tax Rate)**：根據最新數據，Autodesk 的有效稅率為 22.00%。我將在預測期內使用 22% 的稅率。
    *   **資本支出 (Capital Expenditure)**：預計佔營收的 2-3%。
    *   **營運資本變動 (Change in Working Capital)**：預計佔營收的 -1% 至 1% (考慮到訂閱模式的穩定性)。

-   **折現率與終值**：
    *   **加權平均資本成本 (WACC)**：
        我將採用 GuruFocus 提供的最新 WACC 數據 9.86% (截至 2026 年 9 月 19 日)。
        *   Beta (5Y)：1.31
        *   無風險利率 (Risk-Free Rate)：假設為 4.0% (參考美國 10 年期國債收益率)。
        *   股權風險溢價 (Equity Risk Premium)：假設為 5.5%。
        *   股權成本 (Cost of Equity) = 無風險利率 + Beta * 股權風險溢價 = 4.0% + 1.31 * 5.5% = 11.205%。
        *   債務成本 (Cost of Debt)：Alpha Spread 顯示為 5.21%。
        *   稅率：22%。
        *   債務權重 (Weight of Debt)：根據 Alpha Spread，債務權重為 5.14%。
        *   股權權重 (Weight of Equity)：94.86%。
        *   WACC = (股權成本 * 股權權重) + (債務成本 * (1 - 稅率) * 債務權重)
        *   WACC = (11.205% * 0.9486) + (5.21% * (1 - 0.22) * 0.0514) = 10.63% + 0.207% = 10.84%
        *   由於有多個 WACC 來源，且 GuruFocus 的 9.86% 和 Alpha Spread 的 8.58% 較為接近，我將採用一個保守的 WACC，即 9.86%。
    *   **終值增長率 (Terminal Growth Rate)**：考慮到軟體行業的長期增長潛力以及 Autodesk 的市場地位，我將假設終值增長率為 3.0%。

-   **估值結果 (簡化 DCF 範例)**：
    *   **FY2026 (TTM) 營收**：$7.79 B
    *   **FY2027 預計營收**：$7.79B * 1.12 = $8.72B
    *   **FY2028 預計營收**：$8.72B * 1.10 = $9.59B
    *   **FY2029 預計營收**：$9.59B * 1.08 = $10.36B
    *   **FY2030 預計營收**：$10.36B * 1.06 = $10.98B
    *   **FY2031 預計營收**：$10.98B * 1.05 = $11.53B

    假設平均營業利潤率 26%，稅率 22%，FCF 轉換率 (FCF/EBIT) 約 70% (考慮到軟體公司的低資本支出和高現金流生成能力)。

    *   **計算自由現金流 (FCF)**：
        *   EBIT = 營收 * 營業利潤率
        *   稅後 EBIT = EBIT * (1 - 稅率)
        *   FCF = 稅後 EBIT + 折舊與攤銷 - 資本支出 - 營運資本變動 (簡化計算)

    由於缺乏詳細的折舊攤銷、資本支出和營運資本變動數據，這裡提供一個概念性的 DCF 估值結果，並強調其對假設的敏感性。

    **DCF 內在價值估算 (示意性)**：
    在 WACC 9.86% 和終值增長率 3.0% 的假設下，並基於上述營收和利潤率預期，初步估算 ADSK 的內在價值可能落在 **$280 - $320** 的區間。這個區間反映了對未來現金流增長和折現率的合理預期。

### 3. 多維度估值法 (Other Valuation Methods)

-   **相對估值法 (Relative Valuation)**：
    基於同業比較，我們可以利用行業平均估值倍數來推算 ADSK 的目標價位。
    *   **行業平均 P/E (Trailing)**：(40.05 + 40.02 + 50.02 + 45.01) / 4 = 43.78
    *   **行業平均 P/E (Forward)**：(30.01 + 25.01 + 35.01 + 30.01) / 4 = 30.01
    *   **行業平均 P/S**：(8.01 + 6.01 + 9.01 + 7.01) / 4 = 7.51
    *   **行業平均 EV/EBITDA**：(25.01 + 18.01 + 30.01 + 22.01) / 4 = 23.76

    ADSK 最新 TTM EPS 為 $7.72，FY2027 預計 EPS 為 $3.07 (下一季度預計 EPS) * 4 = $12.28 (粗略估計，實際應參考全年指引)。
    ADSK TTM 營收為 $7.79 B，流通股數約 209.01 百萬股。

    *   **基於 P/E (Trailing)**：$7.72 (EPS) * 43.78 (行業平均 P/E) = $338.09
    *   **基於 P/E (Forward)**：$12.28 (預計 FY27 EPS) * 30.01 (行業平均 Forward P/E) = $368.53
    *   **基於 P/S**：($7.79 B / 209.01 M) * 7.51 (行業平均 P/S) = $37.27 * 7.51 = $279.83
    *   **基於 EV/EBITDA**：ADSK TTM EBITDA 為 $2.29 B。
        *   企業價值 (EV) = $2.29 B * 23.76 (行業平均 EV/EBITDA) = $54.39 B
        *   股權價值 = EV + 現金 - 債務 = $54.39 B + $4.16 B (現金) - $3.71 B (債務) = $54.84 B
        *   每股價值 = $54.84 B / 209.01 M = $262.38

    綜合相對估值法，目標價位區間約為 **$260 - $370**。

-   **股息折現模型 (DDM)**：
    根據搜索結果，Autodesk Inc. 目前不支付股息。因此，DDM 不適用於本次估值。

-   **其他方法**：
    對於 Autodesk 這樣的軟體公司，資產基礎估值 (Asset-based valuation) 通常不適用，因為其主要價值來自於無形資產 (軟體、品牌、客戶關係等)。SOTP (Sum-of-the-parts) 估值可能適用於業務多元化的公司，但對於 Autodesk 而言，其核心業務相對集中，因此不作為主要估值方法。
