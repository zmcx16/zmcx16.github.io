### 1. 同業比較分析 (Industry Peer Comparison)

**識別競爭對手**：
Autodesk (ADSK) 主要在設計、工程、建築、製造和媒體娛樂等領域提供軟體解決方案。其主要競爭對手包括：
1.  **Bentley Systems (BSY)**：在建築、工程和施工 (AEC) 軟體領域的直接競爭者。
2.  **Dassault Systèmes SE (DSY)**：3D 設計軟體、產品生命週期管理 (PLM) 和模擬解決方案的全球領導者。
3.  **PTC Inc. (PTC)**：提供 CAD、PLM、物聯網 (IoT) 和擴增實境 (AR) 解決方案。
4.  **Ansys Inc (ANSS)**：專注於工程模擬軟體，常與設計軟體結合使用。
5.  **Adobe Inc (ADBE)**：雖然主要在創意軟體領域，但其訂閱制商業模式和作為大型軟體公司的地位使其成為一個重要的比較對象。

*   **股價營收比 (P/S)**：ADSK 的 P/S (6.13) 相對較低，低於 Bentley Systems (8.01)、Dassault Systèmes (8.61)、Ansys (12.01) 和 Adobe (10.00)，但高於 PTC (5.22)。這可能表明市場對 ADSK 的營收增長潛力或利潤率預期相對保守，或者其營收質量被認為略遜於部分高 P/S 的同業。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估計公司未來自由現金流的現值，以得出其內在價值。

**預測假設**：
*   **預測期間**：5 年（2027 財年 - 2031 財年），之後進入永續增長階段。
*   **營收增長率預期**：
    *   FY2027：根據公司指引，營收預計在 $8.155B - $8.215B 之間，取中位數約 $8.185B。相較於 FY2026 預計的 $7.15B - $7.165B (Q3 FY26 指引) 或 $6.13B (FY25 實際)，這代表約 14.3% 的增長。Q1 FY27 營收增長 18%，考慮到新交易模式的尾部效應將逐漸減弱，我們預計 FY27 營收增長率為 14%。
    *   FY2028-FY2029：考慮到其在 AEC 和製造領域的持續創新、雲服務的普及以及 AI 整合帶來的增長潛力，預計營收增長率逐步放緩，分別為 12%、10%。
    *   FY2030-FY2031：進一步放緩至 8%、6%。
*   **營業利潤率 (Operating Margin)**：
    *   公司 FY27 非 GAAP 營業利潤率指引約為 39%。我們將以此為基礎，預計在預測期內，隨著規模經濟和運營效率的提升，營業利潤率將逐步穩定在 39%-40% 之間。
*   **稅率**：採用公司非 GAAP 有效稅率指引 19%。
*   **資本支出 (Capital Expenditures)**：預計佔營收的 1.0% - 0.8%，隨著公司成熟而略有下降。
*   **折舊與攤銷 (Depreciation & Amortization)**：預計佔營收的 2.0% - 1.8%。
*   **營運資本變動 (Change in Working Capital)**：預計為營收的 0.5% - 0.3%，反映穩定的營運效率。

**折現率與終值**：
*   **無風險利率 (Risk-Free Rate)**：採用美國 10 年期國債收益率 4.55%。
*   **股權風險溢價 (Equity Risk Premium, ERP)**：採用 Kroll 建議的 5.0%。
*   **Beta**：採用 Finbox 提供的 1 年期 Beta 0.84。
*   **股權成本 (Cost of Equity, Ke)**：使用資本資產定價模型 (CAPM) 計算：
    *   Ke = 無風險利率 + Beta * ERP
    *   Ke = 4.55% + 0.84 * 5.0% = 4.55% + 4.20% = 8.75%
*   **債務成本 (Cost of Debt, Kd)**：採用 Alpha Spread 提供的 4.83%。
*   **稅後債務成本 (After-tax Cost of Debt)**：Kd * (1 - 稅率) = 4.83% * (1 - 0.19) = 4.83% * 0.81 = 3.91%
*   **債務權重 (Weight of Debt, Wd)**：根據 Debt/Equity (0.85)，Wd = 0.85 / (1 + 0.85) = 0.4595 ≈ 46.0%。
*   **股權權重 (Weight of Equity, We)**：We = 1 / (1 + 0.85) = 0.5405 ≈ 54.0%。
*   **加權平均資本成本 (Weighted Average Cost of Capital, WACC)**：
    *   WACC = (We * Ke) + (Wd * Kd * (1 - 稅率))
    *   WACC = (0.5405 * 8.75%) + (0.4595 * 3.91%) = 4.729% + 1.797% = 6.526%
    *   為保守起見，我們將 WACC 取整為 **6.5%**。
*   **終值增長率 (Terminal Growth Rate)**：考慮到軟體行業的長期增長潛力以及 ADSK 的市場地位，預計終值增長率為 2.5%。

**估值結果**：

*   **終值 (Terminal Value, TV)**：
    *   TV = FCF (FY2031) * (1 + 終值增長率) / (WACC - 終值增長率)
    *   TV = 3.050 * (1 + 0.025) / (0.065 - 0.025) = 3.050 * 1.025 / 0.04 = 78.156 Billion USD
*   **終值現值 (PV of TV)**：
    *   PV of TV = TV / (1 + WACC)^5 = 78.156 / (1 + 0.065)^5 = 78.156 / 1.370 = 57.048 Billion USD

    *   EV = 預測期 FCF 現值總和 + 終值現值 = 10.985 + 57.048 = 68.033 Billion USD
*   **股權價值 (Equity Value)**：
    *   Equity Value = EV + 現金及約當現金 - 總債務
    *   根據最新數據，ADSK 截至 2026 年 3 月的現金及約當現金為 $2.67B，總債務為 $2.48B。
    *   Equity Value = 68.033 + 2.67 - 2.48 = 68.223 Billion USD
*   **流通股數**：截至 2026 年 5 月 21 日，流通股數約為 211 百萬股。
*   **每股內在價值 (Intrinsic Value per Share)**：
    *   每股內在價值 = 股權價值 / 流通股數 = 68.223 Billion / 211 Million = **$323.33**

**合理價位區間**：
考慮到假設的敏感性，DCF 模型下的合理價位區間預計為 **$300 - $340**。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**：
我們將使用同業的平均估值倍數來推算 ADSK 的目標價位。

*   **P/E 倍數法**：
    *   同業預期 P/E 平均值 (不含 PTC，因其 P/E 較低)：(30.03 + 35.09 + 35.09 + 30.00) / 4 = 32.55
    *   ADSK 預期 EPS (Forward EPS)：根據提供的數據，Forward P/E 為 15.37，當前股價 $218.35。因此，Forward EPS = $218.35 / 15.37 = $14.21。
    *   目標價 = 預期 EPS * 同業平均預期 P/E = $14.21 * 32.55 = **$462.50**
    *   *此結果顯著高於當前股價，可能反映了 ADSK 預期盈利增長較快，或市場對其未來盈利的信心。*

*   **P/S 倍數法**：
    *   同業 P/S 平均值 (不含 PTC，因其 P/S 較低)：(8.01 + 8.61 + 12.01 + 10.00) / 4 = 9.66
    *   ADSK 營收 (Trailing 12 months)：根據提供的 P/S (6.13) 和市值 ($46.07B)，營收 = $46.07B / 6.13 = $7.515B。
    *   目標市值 = 營收 * 同業平均 P/S = $7.515B * 9.66 = $72.595B
    *   目標價 = 目標市值 / 流通股數 = $72.595B / 211 Million = **$343.99**

*   **EV/EBITDA 倍數法**：
    *   同業 EV/EBITDA 平均值 (不含 PTC，因其 EV/EBITDA 較低)：(25.01 + 29.87 + 35.01 + 28.00) / 4 = 29.47
    *   ADSK EBITDA (Trailing 12 months)：根據提供的 EV/EBITDA (20.30) 和企業價值 ($43.43B)，EBITDA = $43.43B / 20.30 = $2.139B。
    *   目標企業價值 = EBITDA * 同業平均 EV/EBITDA = $2.139B * 29.47 = $63.04B
    *   目標股權價值 = 目標企業價值 + 現金 - 債務 = $63.04B + $2.67B - $2.48B = $63.23B
    *   目標價 = 目標股權價值 / 流通股數 = $63.23B / 211 Million = **$299.67**

**股息折現模型 (DDM)**：
根據提供的基本面數據，ADSK 的股息率為 "-"，表明公司目前不派發股息。因此，DDM 不適用於 ADSK 的估值。

**其他方法**：
目前沒有足夠的資訊或理由採用資產基礎估值 (Asset-based) 或 SOTP (Sum-of-the-parts) 估值法，因為 ADSK 是一家以軟體和訂閱服務為主的成長型公司，其價值主要來自於未來現金流和無形資產。
