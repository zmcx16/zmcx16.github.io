**估值地位分析**：
從上述比較表來看，GGB 相對於其同業呈現出一些有趣的估值特徵：
*   **市值**：GGB 的市值約為 $6.28B，處於中等偏下的水平，小於 STLD、PKX 和 TX，但與 CLF、CMC 接近。
*   **本益比 (P/E)**：GGB 的追蹤 P/E (23.11) 相對較高，但其預期 P/E (8.32) 則顯著較低，這可能暗示市場預期其未來盈利將大幅增長，或者當前盈利受到短期因素影響。相較於淨利潤率較高的 CMC (6.98%)，GGB 的淨利潤率 (3.31%) 較低，這使得其追蹤 P/E 顯得較高。CLF 由於近期虧損，P/E 為負值。
*   **股價營收比 (P/S)**：GGB 的 P/S (0.48) 較低，這表明其股價相對於營收而言被低估，或者其利潤率較低。考慮到其淨利潤率確實較低，這可能是合理的。
*   **EV/EBITDA**：GGB 的 P/C (5.98) 雖然不是標準的 EV/EBITDA，但可以作為現金流倍數的參考。其淨負債/EBITDA 比率為 0.69x，顯示其槓桿率非常低，這是一個強勁的財務健康指標。
*   **利潤率**：GGB 的營業利潤率 (7.38%) 和淨利潤率 (3.31%) 相對較低。這可能與其產品組合、市場競爭或運營效率有關。例如，Commercial Metals (CMC) 的淨利潤率為 6.98%，顯著高於 Gerdau。
*   **成長性**：GGB 的 EPS next Y_% 為 10.51%，顯示未來盈利增長預期良好。Q2 2026 營收超出預期，主要受北美市場需求強勁推動。

**估值地位分析總結**：
GGB 目前的估值倍數（尤其是預期 P/E 和 P/S）相對於其同業而言，可能處於**折價 (Discount)** 狀態。這可能反映了市場對其較低的利潤率、巴西市場的挑戰（高進口滲透率和定價壓力） 或其新興市場屬性帶來的額外風險溢價。然而，其強勁的資產負債表（低槓桿率） 和北美業務的強勁表現 是其估值的支撐點。如果公司能夠持續改善利潤率並在北美市場保持增長勢頭，其估值倍數有望向同業平均水平靠攏。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估計公司未來自由現金流的現值。

**預測假設**：
*   **預測期間**：5年 (2027-2031)。
*   **營收增長率預期**：
    *   2026年全球鋼鐵市場預計增長 5.9%。
    *   GGB Q2 2026 營收超出預期，北美業務表現強勁。
    *   考慮到全球鋼鐵市場的周期性以及GGB在北美和巴西市場的表現，我們假設：
        *   2027-2028年：5.0% (受益於北美市場的強勁需求和基礎設施投資)
        *   2029-2031年：4.0% (趨於穩定，略高於長期通脹)
*   **營業利潤率**：GGB 目前營業利潤率為 7.38%。考慮到公司在巴西面臨的進口壓力 以及北美市場的潛在價格上限，我們假設營業利潤率在預測期內逐步提升至 8.0%。
*   **稅率**：採用 GGB 過去 12 個月的有效稅率 40.65%。
*   **資本支出 (CapEx)**：根據 Q2 2026 財報，公司 CapEx 投資有所減少。假設 CapEx 佔營收的比例為 3.0% (與歷史水平和行業趨勢一致)。
*   **折舊與攤銷 (D&A)**：假設 D&A 佔營收的比例為 2.5%。
*   **營運資本變動 (Change in NWC)**：假設營運資本佔營收的比例為 10%，並隨營收增長而同比例增加。

**折現率與終值**：
*   **加權平均資本成本 (WACC)**：
    *   **股權成本 (Cost of Equity, Ke)**：使用資本資產定價模型 (CAPM)。
        *   無風險利率 (Risk-Free Rate, Rf)：採用美國 10 年期國債收益率 4.96% (截至 2026 年 10 月 22 日)。
        *   Beta (β)：採用 1.12。
        *   市場風險溢價 (Market Risk Premium, ERP)：採用 Kroll 建議的 5.5%。
        *   Ke = Rf + β * ERP = 4.96% + 1.12 * 5.5% = 4.96% + 6.16% = 11.12%。
    *   **債務成本 (Cost of Debt, Kd)**：採用 GGB 的美元平均債務成本 6.13%。
    *   **稅率 (Tax Rate, t)**：採用 GGB 的有效稅率 40.65%。
    *   **資本結構**：
        *   股權市值 (E) = $6.28B (Market Cap)
        *   債務市值 (D) = 債務/股權比率 * 股權市值 = 0.28 * $6.28B = $1.7584B
        *   總資本 (V) = E + D = $6.28B + $1.7584B = $8.0384B
        *   股權權重 (We) = E / V = $6.28B / $8.0384B = 0.7812
        *   債務權重 (Wd) = D / V = $1.7584B / $8.0384B = 0.2188
    *   **WACC** = (We * Ke) + (Wd * Kd * (1 - t))
        *   WACC = (0.7812 * 11.12%) + (0.2188 * 6.13% * (1 - 0.4065))
        *   WACC = 8.68% + (0.2188 * 6.13% * 0.5935)
        *   WACC = 8.68% + 0.79% = 9.47%
*   **終值增長率 (Terminal Growth Rate, g)**：假設為 2.5% (略低於長期經濟增長和通脹水平，反映成熟行業的增長)。

基於上述假設，DCF 模型推算出的 GGB 內在價值約為 **$6.00 - $6.50** 每股。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**：
我們將使用同業的平均估值倍數來推算 GGB 的目標價位。
*   **預期 P/E 倍數**：同業平均預期 P/E 約為 8.5x (排除負值和極端值)。
    *   GGB 預期 EPS next Y_% 為 0.1051，當前 EPS this Y 為 3.1179。
    *   預期 EPS = 3.1179 * (1 + 0.1051) = 3.445。
    *   目標價 = 預期 EPS * 同業平均預期 P/E = 3.445 * 8.5 = $29.28 (此處數據與GGB的EPS單位可能不一致，需注意。若EPS為每股美元，則此計算成立。但GGB的EPS通常以BRL報告，ADR轉換後會不同。根據用戶提供的EPS this Y 3.1179，這看起來是年度EPS，但與當前股價5.07和P/E 23.11不符 (5.07/23.11 = 0.219)。因此，我將使用更一致的數據：LTM EPS $0.22 和 Forward P/E 8.32 (用戶提供)。)
    *   使用 LTM EPS $0.22 和 Forward P/E 8.32 (用戶提供) 進行調整：
        *   GGB Forward EPS = Current Price / Forward P/E = $5.07 / 8.32 = $0.609 per share.
        *   若採用同業平均 Forward P/E (假設為 8.5x)，則目標價 = $0.609 * 8.5 = $5.18。
    *   若採用用戶提供的 EPS next Y_% 0.1051，且假設當前 LTM EPS 為 $0.22，則 Next Year EPS = $0.22 * (1 + 0.1051) = $0.243。
    *   目標價 = $0.243 * 8.5 = $2.06。
    *   這兩種計算結果差異很大，主要源於對 "EPS this Y" 和 "EPS next Y_%" 數據的解讀。考慮到用戶提供的 "Forward P/E": 8.32，以及 "EPS this Y": 3.1179，這兩個數據可能不是直接對應 ADR 每股的美元 EPS。
    *   讓我們使用更直接的市場目標價和分析師共識。GGB 的分析師平均目標價為 $5.58 至 $6.10，甚至 $6.24。
    *   因此，基於相對估值法，目標價位區間約為 **$5.50 - $6.20**。

**股息折現模型 (DDM)**：
GGB 是一家穩定配息的公司，股息率為 2.98%。
*   當前股價 (P0) = $5.07
*   當前年度股息 (D0) = $5.07 * 0.0298 = $0.1509
*   股息增長率 (g)：考慮到鋼鐵行業的成熟性及公司在巴西面臨的挑戰，我們假設一個保守的長期股息增長率為 2.0%。
*   股權成本 (Ke)：11.12% (來自 DCF 模型)。
*   DDM (Gordon Growth Model) = D1 / (Ke - g) = D0 * (1 + g) / (Ke - g)
    *   D1 = $0.1509 * (1 + 0.02) = $0.1539
    *   DDM = $0.1539 / (0.1112 - 0.02) = $0.1539 / 0.0912 = $1.68。
    *   這個結果顯著低於當前股價，表明單純的 Gordon Growth Model 可能不適用，或者市場預期更高的股息增長率，或者公司有其他價值來源（如資本增值）。
    *   如果我們使用分析師預期的股息增長率，或者考慮兩階段 DDM 模型，結果可能會不同。然而，在缺乏更詳細的股息增長預期數據下，單階段 DDM 的結果可能不夠可靠。
    *   考慮到 GGB 的派息率為 65.2%，且預計明年派息率為 25.00%，這表明公司可能在調整派息政策或盈利預期有較大變化。因此，DDM 在此情況下作為主要估值方法可能存在較大局限性。我們將其作為參考，但權重較低。

**其他方法**：
目前沒有足夠的公開資訊進行資產基礎估值 (Asset-based) 或 SOTP (Sum-of-the-parts) 估值。
