# Matson Inc (MATX) 深度股權評價報告

#### 估值地位分析
- **溢價與折價**：相對於純國際航運商（如 ZIM），MATX 享有顯著溢價，這反映了其在夏威夷與阿拉斯加市場的護城河地位。然而，相對於美國本土資產輕型物流商（如 LSTR），MATX 的 P/E 處於折價狀態。
- **合理性**：MATX 目前 13.52 倍的遠期本益比低於其歷史五年均值（約 15-18 倍）。考量到其 **Debt/Eq 僅 0.12** 的極低槓桿率與 **ROE 17.21%** 的高效盈利能力，目前的估值倍數並未完全反映其在紅海危機導致的運價上漲背景下的獲利彈性。

### 2. 折現現金流模型 (DCF)

#### 預測假設
- **預測期間**：2025 - 2029 (5年)。
- **營收增長率**：預計 2025 年受惠於中國快航需求持續強勁，增長 8%，隨後回歸 3-4% 的常態化增長（國內航線隨通膨增長）。
- **EBITDA Margin**：維持在 20-22% 區間，考量到新船隊投入後的燃油效率提升。
- **有效稅率**：21%。
- **資本支出 (CapEx)**：考量到 Matson 正在進行的 Aloha Class 船隊更新計畫，預計未來三年 CapEx 將維持在高位。

#### 折現率與終值
- **WACC 計算**：
  - 無風險利率 (10Y Treasury): 4.3%
  - Beta: 1.15 (考量航運週期性)
  - 股權風險溢價: 5.5%
  - **計算結果 WACC ≈ 9.8%**
- **終值增長率 (g)**：2.0% (符合長期通膨預期)。

#### 估值結果
- **企業價值 (EV)**：約 $8.25 Billion
- **扣除淨負債後股權價值**：約 $8.95 Billion (因現金儲備充足)
- **每股內在價值**：**$258.40**

### 3. 多維度估值法

#### 相對估值法 (Relative Valuation)
參考同業平均 Forward P/E (排除極端值 ZIM 後約 18x) 與 MATX 自身歷史均值。
- **目標 P/E**：16.0x
- **預估 2025 EPS**：$16.91 (基於 Forward P/E 13.52 與現價推算)
- **推算價位**：16.0 * 16.91 = **$270.56**

#### 股息折現模型 (DDM)
- **當前股息**：$1.36 (年化)
- **預期增長率**：5% (公司具備強大自由現金流提升配息)
- **要求回報率**：9.8%
- **推算價位**：$1.36 * (1+0.05) / (0.098 - 0.05) = **$29.75**
- *註：由於 MATX 傾向於透過股票回購而非高額派息回饋股東，DDM 僅具參考下限價值。*

**最終結論：**

2. **目前股價位階**：**低估 (Undervalued)**
3. **投資核心論點**：MATX 目前股價（$228.64）顯著低於其內在價值。核心吸引力在於其**極低的財務槓桿 (Debt/Eq 0.12)** 與**強大的現金流產生能力**，這支撐了其持續的股票回購計畫。儘管全球航運具週期性，但 MATX 憑藉《瓊斯法案》在國內航線的壟斷地位提供了極高的安全邊際，而中國快航服務則在供應鏈緊張時期提供了巨大的獲利向上彈性。目前 13.5 倍的遠期本益比並未充分計入其優於同業的利潤率與市場領先地位。
