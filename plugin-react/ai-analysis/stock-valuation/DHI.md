# D.R. Horton Inc. (DHI) 深度估值分析報告

#### 估值地位分析
- **溢價狀態**：DHI 相對於 Lennar 和 PulteGroup 存在約 10-20% 的 **P/E 溢價**。這反映了市場對其「全美銷量第一」規模經濟的認可，以及其在入門級住房市場（Entry-level）的絕對統治力。
- **利潤率折價**：儘管規模最大，但 DHI 的利潤率低於 Toll Brothers（專注豪宅）和 NVR（輕資產模式）。這說明 DHI 的估值更多是由**周轉率**而非**利潤空間**驅動。
- **合理性**：考慮到 DHI 擁有極強的資產負債表（Debt/Eq 0.3）與穩定的市佔率擴張，目前的溢價處於合理區間。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### 預測假設
1.  **預測期間**：2025 - 2029 (5年)。
2.  **營收增長率**：預計 2025 年受降息預期帶動增長 5%，隨後穩定在 4%（考慮到美國住房缺口仍達數百萬套）。
3.  **自由現金流 (FCF) 利潤率**：假設維持在 8.5% - 9.5% 區間。DHI 近年轉向「輕土地資產」策略，有助於釋放更多現金流。
4.  **稅率**：21%。

#### 折現率與終值
- **WACC 計算**：
  - 無風險利率 (10Y Treasury): 4.2%
  - Beta: 1.55 (房地產板塊波動較大)
  - 股權風險溢價 (ERP): 5.0%
  - **權益成本 (Ke)**: 11.95%
  - **稅後債務成本**: 4.5%
  - **WACC**: 約 **10.8%**。
- **終值增長率 (g)**：2.0% (符合長期通膨與人口增長預期)。

#### 估值結果
- **企業價值 (EV)**：約 $48.5 Billion。
- **扣除淨負債後股權價值**：約 $46.2 Billion。
- **內在價值 (Intrinsic Value)**：**$168.50**。
- **合理價位區間**：**$155 - $182** (考慮 10% 安全邊際)。

### 3. 多維度估值法 (Other Valuation Methods)

#### 相對估值法 (Relative Valuation)
- **Forward P/E 法**：給予 DHI 12x - 13x 的 Forward P/E（歷史中位數偏上）。預計 2025 EPS 為 $15.20。
  - 推算目標價：$15.20 * 12.5 = **$190.00**。
- **P/B 估值法**：DHI 目前 P/B 為 1.79x。歷史區間在 1.5x - 2.2x。若回歸 2.0x 水準，目標價約為 **$170.00**。

#### 股息折現模型 (DDM)
- DHI 近期將股息提高至每季 $0.30（年化 $1.20）。
- 假設股息增長率 (g) 為 10%（過去五年複合增長極高），折現率 12%。
- DDM 結果：$1.20 * (1+10%) / (12% - 10%) = $66.00。
- **評價**：由於 DHI 仍處於資本擴張期，股息發放率低，DDM 模型會嚴重低估其價值，僅具參考意義。
