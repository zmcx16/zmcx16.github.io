*   **ICF International, Inc. (ICFI)**：一家為政府和商業客戶提供專業服務和技術解決方案的公司，在 IT 現代化、能源效率和災害恢復等領域提供諮詢服務。

從同業比較來看，Gartner 相對於其主要競爭對手展現出以下特點：
*   **盈利能力優勢**：Gartner 的營業利潤率 (17.96%) 和淨利潤率 (11.44%) 顯著高於 Forrester Research (負值) 和 ICF International (11.1% / 4.9%)。這表明 Gartner 在成本控制和營運效率方面表現更佳，能夠將更多的營收轉化為利潤。
*   **估值倍數差異**：
    *   **P/E (Forward)**：Gartner 的預期本益比 (9.22) 低於 Forrester (10.62) 和 ICF (11.5)。這暗示市場可能低估了 Gartner 未來的盈利潛力，尤其考慮到其較高的盈利能力。
    *   **P/S**：Gartner 的股價營收比 (1.47) 介於 Forrester (4.12) 和 ICF (0.8) 之間。考慮到 Gartner 較高的利潤率，其 P/S 應高於 ICF。
    *   **EV/EBITDA**：Gartner 的 EV/EBITDA (7.16x) 介於 Forrester (3.96x) 和 ICF (8.5x) 之間。儘管 Forrester 的倍數較低，但其近期營收下滑和虧損可能使其估值倍數失真。Gartner 的倍數在行業中顯得合理，但考慮其盈利能力，仍有提升空間。

總體而言，Gartner 在盈利能力方面表現卓越，但其估值倍數並未完全反映這一優勢，尤其是在預期本益比方面甚至低於盈利能力較弱的同業。這表明 Gartner 相對於同業可能處於**折價 (Discount)** 狀態，其估值倍數在考量其市場地位、技術壁壘和穩健的盈利能力後，顯得相對保守。

### 估值結果
基於上述假設，DCF 模型推算如下：

| 年度 | 營收 ($M) | 自由現金流 (FCF) ($M) | FCF 現值 ($M) |

*   **2031 年 FCF**：$1,336.46 * (1 + 0.025) = $1,369.37 百萬美元
*   **終值 (Terminal Value, TV)**：$1,369.37 / (0.0991 - 0.025) = $18,480.0 百萬美元
*   **終值現值 (PV of TV)**：$18,480.0 / (1.0991)^5 = $11,507.6 百萬美元

*   **總內在價值 (企業價值)**：$4,586.9 + $11,507.6 = $16,094.5 百萬美元

基於保守的 DCF 模型，Gartner 的每股內在價值約為 **$216.80**。考慮到假設的波動性，合理價位區間約為 **$210 - $240**。

## 3. 多維度估值法 (Other Valuation Methods)

### 相對估值法 (Relative Valuation)
我們將使用同業的預期本益比 (Forward P/E)、股價營收比 (P/S) 和企業價值倍數 (EV/EBITDA) 來推算 Gartner 的目標價位。

*   **同業平均 Forward P/E**：(Forrester 10.62 + ICF 11.5) / 2 = 11.06x
    *   Gartner 2026 年預期 EPS：$13.25
    *   目標價 (P/E) = 11.06 * $13.25 = **$146.54**

*   **同業平均 P/S**：(Forrester 4.12 + ICF 0.8) / 2 = 2.46x
    *   Gartner 過去十二個月營收每股：$6,470M / 66.95M 股 = $96.64
    *   目標價 (P/S) = 2.46 * $96.64 = **$237.73**
    *   *考量 Forrester 的 P/S 較高可能受其較小市值和特定業務影響，若給予 Gartner 較保守的 P/S 倍數 (例如 2.0x，仍高於 ICF 但低於 Forrester)，則目標價為 2.0 * $96.64 = $193.28。*

*   **同業平均 EV/EBITDA**：(Forrester 3.96 + ICF 8.5) / 2 = 6.23x
    *   Gartner 2026 年預期 EBITDA：$1,545 百萬美元
    *   隱含企業價值 = 6.23 * $1,545M = $9,627.35 百萬美元
    *   隱含股權價值 = $9,627.35M + $1,670M (現金) - $3,250M (債務) = $8,047.35 百萬美元
    *   目標價 (EV/EBITDA) = $8,047.35M / 66.95M 股 = **$120.19**
    *   *考量 Gartner 較高的盈利能力，若給予 Gartner 略高於平均的 EV/EBITDA 倍數 (例如 8.0x)，則目標價為 $161.01。*

綜合相對估值法，並考量 Gartner 的市場地位和盈利能力，其合理價位區間約為 **$150 - $180**。
