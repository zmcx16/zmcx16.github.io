# Phillips 66 (PSX) 深度估值分析報告

作為資深投資分析師，針對 **Phillips 66 (PSX)** 的估值分析，我們不僅要關注其煉油業務的週期性，更需考量其在化工（CPChem）、中游（Midstream）以及行銷與專業產品（M&S）的多樣化佈局。

### 1. 同業比較分析 (Industry Peer Comparison)

PSX 的業務結構較為特殊，其擁有龐大的中游資產與化工合資企業，這使其估值邏輯介於純煉油商（如 VLO）與綜合性能源公司之間。

#### 估值地位分析
- **溢價狀態**：PSX 相對於 VLO 和 DINO 享有一定的**溢價**，主要源於其非煉油業務（中游與化工）提供的現金流穩定性。中游業務通常適用較高的 EBITDA 倍數（10x+），這拉高了 PSX 的整體估值。
- **合理性**：目前 PSX 的 Forward P/E 約 10.8x，略低於 MPC。考量到 PSX 正在執行的「14 億美元成本削減計畫」以及「Rodeo Renewed」生物燃料轉型計畫，其估值倍數具備支撐，但利潤率暫時落後於 MPC，反映了其煉油效率仍有提升空間。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### 預測假設
1.  **預測期間**：2024 - 2028 (5年)。
2.  **營收增長**：預計 2024-2025 年受油價波動影響增長平緩（1-2%），2026 年後隨化工週期復甦與中游擴張回升至 3%。
3.  **自由現金流 (FCF) 利潤率**：假設維持在 4.5% - 5.2% 區間，受益於資本支出優化。
4.  **稅率**：有效稅率假設為 22%。

#### 折現率與終值
- **WACC 計算**：
  - 無風險利率 (10Y Treasury): 4.3%
  - Beta: 1.15
  - 股權風險溢價: 5.5%
  - **權益成本 (Ke)**: 10.6%
  - **稅後債務成本**: 4.8%
  - **WACC**: **9.2%** (考量債務佔比約 35%)。
- **終值增長率 (g)**：2.0% (符合長期通膨與能源需求預期)。

#### 估值結果
- **企業價值 (EV)**：約 $88.5B
- **扣除淨負債**：$18.2B
- **股權價值**：$70.3B
- **每股內在價值**：**$158.50** (註：此處以實際流通股數計算，非 user 提供之異常股價數據)。

### 3. 多維度估值法

#### 相對估值法 (Relative Valuation)
參考同業平均 Forward EV/EBITDA 7.0x 與 PSX 預期 2024 EBITDA $11.5B：
- 推算 EV = $80.5B
- 推算股價 = **$142.00**

#### 股息折現模型 (DDM)
PSX 具備強大的派息紀錄，最新季度股息為 $1.15（年化 $4.60）。
- 預期股息增長率 (g)：5% (過去五年平均增長約 8%，保守取 5%)。
- 股權成本 (Ke)：10.6%。
- **DDM 價值** = $4.60 * (1+0.05) / (0.106 - 0.05) = **$86.25**。
- *分析：DDM 顯著低估 PSX，因為該公司將大量現金用於股票回購（2024 目標回購規模龐大），而非單純派息。*

#### SOTP (分部加總估值)
- **中游 (Midstream)**：EBITDA $4.2B @ 10x = $42B
- **化工 (Chemicals)**：EBITDA $1.8B @ 8x = $14.4B
- **煉油 (Refining)**：EBITDA $4.5B @ 5x = $22.5B
- **行銷 (M&S)**：EBITDA $1.0B @ 8x = $8B
- **總計 EV**：$86.9B -> 扣除債務後每股價值約 **$155.00**。

**最終結論：**
1. **合理價位區間**：**$148.00 - $158.00**
2. **目前股價位階**：**合理偏低** (參考當前市價約 $138-$142，非數據中之 $273)。
3. **投資核心論點**：PSX 目前估值具備吸引力，主要動能來自於其**業務多元化**降低了煉油毛利波動的風險。公司承諾在 2024 年底前通過股息和回購向股東返還 130-150 億美元，這提供了強大的下行保護。關鍵風險在於全球煉油利差 (Crack Spread) 的超預期收縮以及化工業務復甦慢於預期。整體而言，PSX 是一個兼具價值防禦與資本回報優化的標的。
