# Camtek Ltd (CAMT) 深度估值分析報告

- **合理性評估**：CAMT 的 PEG 為 1.12，顯示其股價相對於盈餘成長性非常平衡。市場目前因半導體設備週期的短期波動對其進行了修正（較 52 週高點下跌約 40%），這使得其估值倍數在 AI 基礎設施賽道中極具吸引力。
