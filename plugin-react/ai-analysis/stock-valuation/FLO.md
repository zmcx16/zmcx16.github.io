### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**：

我們將使用同業的平均/中位數估值倍數，並應用於 FLO 的財務數據。

*   **P/E Ratio (Forward)**：
    *   同業平均 Forward P/E (Grupo Bimbo, Campbell Soup, General Mills) = (13.10 + 12.14 + 10.65) / 3 = 11.96
    *   FLO 預期 EPS (Forward EPS) = 2026 財年調整後稀釋 EPS 指引中值 ($0.75 + $0.85) / 2 = $0.80
    *   目標價 = 平均 Forward P/E * Forward EPS = 11.96 * $0.80 = **$9.57**

*   **P/S Ratio (TTM)**：
    *   同業平均 P/S (Grupo Bimbo, Campbell Soup, General Mills) = (1.0 + 0.63 + 0.97) / 3 = 0.87 (使用較保守的 Grupo Bimbo P/S 1.0x 和 Campbell Soup 0.63, General Mills 0.97)
    *   FLO TTM 營收 = $5.22B
    *   FLO 流通在外股數 = 213.5M
    *   FLO TTM 每股營收 = $5.22B / 213.5M = $24.45
    *   目標價 = 平均 P/S * 每股營收 = 0.87 * $24.45 = **$21.27**

*   **EV/EBITDA (TTM)**：
    *   同業平均 EV/EBITDA (Grupo Bimbo, Campbell Soup) = (7.0 + 6.58) / 2 = 6.79 (General Mills TTM EBITDA 為負值，不適用)
    *   FLO TTM EBITDA = $486.93M
    *   FLO 企業價值 = 平均 EV/EBITDA * TTM EBITDA = 6.79 * $486.93M = $3.306B
    *   股權價值 = 企業價值 - 淨債務 = $3.306B - $1.9572B = $1.349B
    *   目標價 = 股權價值 / 流通在外股數 = $1.349B / 213.5M = **$6.32**

相對估值法下的目標價位區間較廣，主要受不同倍數和同業選擇的影響。P/E 倍數給出的目標價為 $9.57，P/S 倍數給出的目標價為 $21.27，EV/EBITDA 倍數給出的目標價為 $6.32。考慮到 FLO 的利潤率較低，P/S 可能會高估其價值，而 EV/EBITDA 則更側重於經營層面的價值。

**股息折現模型 (Dividend Discount Model, DDM)**：

Flowers Foods 是一家穩定派息的公司，並且連續 12 年提高股息。這使得 DDM 成為一個可行的估值方法。

*   **當前股息 (Current Dividend)**：公司董事會已將年度股息重設為每股 $0.50，季度股息為每股 $0.1250。
*   **股息增長率 (Dividend Growth Rate, g)**：考慮到公司過去的股息增長歷史和當前的營收壓力，我們假設一個保守的長期股息增長率。
    *   短期 (未來 3 年)：假設股息增長率為 2.0% (考慮到公司面臨的挑戰和保守的增長預期)。
    *   長期 (永續增長)：假設為 1.5%。
*   **股權成本 (Cost of Equity, Ke)**：沿用 DCF 模型中的 6.865%。

採用兩階段 DDM 模型：

*   **第一階段 (2027-2029)：2.0% 增長**
    *   D1 (2027) = $0.50 * (1 + 0.02) = $0.51
    *   D2 (2028) = $0.51 * (1 + 0.02) = $0.5202
    *   D3 (2029) = $0.5202 * (1 + 0.02) = $0.5306

*   **第二階段 (2030 永續增長)：1.5% 增長**
    *   D4 (2030) = $0.5306 * (1 + 0.015) = $0.5385
    *   終值 (P3) = D4 / (Ke - g_long) = $0.5385 / (0.06865 - 0.015) = $0.5385 / 0.05365 = $10.037

*   **股權內在價值 (Intrinsic Value)** = D1/(1+Ke)^1 + D2/(1+Ke)^2 + D3/(1+Ke)^3 + P3/(1+Ke)^3
    *   = $0.51/(1.06865)^1 + $0.5202/(1.06865)^2 + $0.5306/(1.06865)^3 + $10.037/(1.06865)^3
    *   = $0.477 + $0.456 + $0.437 + $8.256
    *   = **$9.63**

DDM 模型下的每股內在價值約為 **$9.63**。
