## Flowers Foods, Inc. (FLO) 股權估值分析報告

作為一名資深投資分析師，我將對美股公司 Flowers Foods, Inc. (FLO) 進行全面的股權估值分析，並著重於與同業競爭對手的橫向比較。

### 1. 同業比較分析 (Industry Peer Comparison)

**識別競爭對手**
Flowers Foods, Inc. 是美國領先的包裝烘焙食品生產商和銷售商，旗下擁有 Nature's Own、Dave's Killer Bread、Wonder 和 Tastykake 等知名品牌。其主要競爭對手包括：
1.  **Bimbo Bakeries USA (Grupo Bimbo 的美國子公司)**：美國烘焙市場的領導者，市佔率約 30%。
2.  **Conagra Brands, Inc. (CAG)**：一家多元化的包裝食品公司，產品線廣泛。
3.  **Post Holdings, Inc. (POST)**：主要生產穀物、蛋白質產品和烘焙食品。
4.  **TreeHouse Foods, Inc. (THS)**：北美最大的自有品牌食品和飲料生產商之一。

**指標對照表**

**估值地位分析**
從同業比較來看，Flowers Foods (FLO) 相對於其主要競爭對手，在某些估值指標上呈現出折價狀態，但在盈利能力方面則顯得較弱。

*   **市值與規模**：FLO 的市值 ($1.62B) 遠小於 Bimbo Bakeries USA ($20.01B)、Conagra Brands ($13.78B) 和 Post Holdings ($10.01B)，與 TreeHouse Foods ($2.01B) 較為接近。這表明 FLO 在市場上的規模相對較小，可能影響其議價能力和規模經濟效益。
*   **本益比 (P/E)**：FLO 的追溯本益比 (22.37) 高於大多數同業，這可能暗示市場對其過去的盈利能力給予了較高的估值，或者其近期盈利較低導致 P/E 偏高。然而，其預期本益比 (9.24) 顯著低於同業，這強烈暗示分析師預期其未來盈利將大幅改善，使其估值更具吸引力。
*   **股價營收比 (P/S)**：FLO 的 P/S (0.31) 遠低於所有同業，這表明其股價相對於營收處於顯著折價狀態。這可能反映了市場對其利潤率或營收增長前景的擔憂。
*   **企業價值倍數 (EV/EBITDA)**：FLO 的 EV/EBITDA (7.1x) 低於同業平均水平，這也支持了其估值相對折價的觀點。EV/EBITDA 考慮了債務因素，更能反映公司的整體價值，低倍數通常意味著被低估。
*   **盈利能力**：FLO 的營業利潤率 (6.7%) 和淨利潤率 (1.38%) 均顯著低於大多數同業。這表明 FLO 在成本控制和盈利轉化方面面臨挑戰，這可能是其 P/S 和 EV/EBITDA 較低的原因之一。公司在 2025 財年因無形資產減值導致淨利潤大幅下降。
*   **營收增長率**：FLO 在 Q1 2026 的營收增長率為 1.1%，與同業的低個位數增長率相符，顯示其所處行業的成熟特性。

**總結**：FLO 目前的估值倍數（尤其是 P/S 和 EV/EBITDA）相對於同業處於折價狀態，這可能反映了市場對其較低的盈利能力和近期業績挑戰的擔憂。然而，其較低的預期本益比則暗示市場預期未來盈利將有所改善。公司正在進行品牌組合、供應鏈和財務策略的全面審查，並專注於降低成本和強化核心品牌，如 Nature's Own 和 Simple Mills，這可能為未來的盈利能力提升提供潛力。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF 模型旨在估計公司未來自由現金流的現值，以得出其內在價值。

**預測假設**
*   **預測期間**：5 年（2026 年至 2030 年）。
*   **起始自由現金流 (FCF)**：根據 2025 財年數據，FLO 支付了 $209 百萬的股息，而自由現金流為 $319 百萬。因此，我們將以 $319 百萬作為 2025 年的 FCF 基礎。
*   **營收增長率預期**：
    *   2026 年：管理層預計營收將「基本持平」或略有下降，主要受行業整體下滑和少一個會計週期的影響，但會被品牌投資和市佔率提升所抵消。考慮到 Q1 2026 營收增長 1.1%，我們假設 2026 年營收增長率為 0.5%。
    *   2027-2028 年：考慮到公司對核心品牌的重新聚焦、成本降低措施以及 Simple Mills 等高增長品牌的貢獻，預計將實現溫和增長。我們假設 2.0% 的年增長率。
    *   2029-2030 年：隨著市場趨於成熟和競爭加劇，增長率將逐漸放緩。我們假設 1.5% 的年增長率。
*   **自由現金流利潤率 (FCF Margin)**：根據 2025 年 FCF ($319M) 和營收 ($5.256B)，FCF Margin 約為 6.07%。考慮到公司專注於降低成本和提高效率，我們預計 FCF Margin 將在預測期內逐步提升至 6.5%。
*   **資本支出 (CapEx)**：管理層預計每年約 $2 百萬用於每個烘焙廠的維護性資本支出，其餘用於增長和生產力提升。FLO 擁有 44 個烘焙廠，因此維護性 CapEx 約為 $88 百萬。我們將根據營收增長和 FCF Margin 預期，將 CapEx 佔營收的比例維持在約 2.0%-2.5% 之間。

**折現率與終值**
*   **加權平均資本成本 (WACC)**：
    *   股權市值 (E)：$1.62B
    *   債務市值 (D)：$2.05B (總債務)
    *   股權成本 (Ke)：
        *   無風險利率 (Rf)：4.455% (美國 10 年期國債收益率，截至 2026 年 6 月 20 日)
        *   Beta (β)：0.41
        *   市場風險溢價 (MRP)：6.0%
        *   Ke = Rf + β * MRP = 4.455% + 0.41 * 6.0% = 4.455% + 2.46% = 6.915%
    *   債務成本 (Kd)：3.8958% (TTM 利息支出 / TTM 債務)
    *   稅率 (t)：29.87% (過去 12 個月有效稅率)
    *   WACC = (E / (E+D)) * Ke + (D / (E+D)) * Kd * (1 - t)
    *   WACC = (1.62 / (1.62 + 2.05)) * 6.915% + (2.05 / (1.62 + 2.05)) * 3.8958% * (1 - 0.2987)
    *   WACC = (1.62 / 3.67) * 6.915% + (2.05 / 3.67) * 3.8958% * 0.7013
    *   WACC = 0.4414 * 6.915% + 0.5586 * 3.8958% * 0.7013
    *   WACC = 3.05% + 1.59% = 4.64%
    *   *註：GuruFocus 報告的 WACC 為 4.57%，與我的計算結果 4.64% 非常接近，因此我們將採用 4.64% 作為 WACC。*
*   **終值增長率 (Terminal Growth Rate)**：考慮到烘焙行業的成熟性以及 FLO 作為市場領導者之一的地位，我們假設終值增長率為 1.5% (略高於長期通脹率，反映其持續經營能力)。

**估值結果**
（此處為 DCF 模型計算的簡化展示，實際計算需詳細的財務預測表）

| 年度 | 營收 (Billion USD) | FCF Margin | 自由現金流 (Million USD) | 折現因子 (WACC=4.64%) | 現值 (Million USD) |
| :--- | :----------------- | :--------- | :----------------------- | :-------------------- | :----------------- |
| 2025 | 5.256              | 6.07%      | 319                      | 1.000                 | 319.00             |
| 2026 | 5.282              | 6.10%      | 322                      | 0.956                 | 307.07             |

| 2028 | 5.496              | 6.30%      | 346                      | 0.873                 | 302.54             |

| 2030 | 5.662              | 6.50%      | 368                      | 0.797                 | 293.20             |

**終值 (Terminal Value)**
*   2030 年之後的 FCF = 368 * (1 + 1.5%) = 373.52 百萬美元
*   終值 = 373.52 / (4.64% - 1.5%) = 373.52 / 0.0314 = 11,895.54 百萬美元
*   終值現值 = 11,895.54 / (1 + 4.64%)^5 = 11,895.54 / 1.254 = 9,486.08 百萬美元

**企業價值 (Enterprise Value)**
*   企業價值 = 預測期 FCF 現值總和 + 終值現值
*   企業價值 = (307.07 + 305.36 + 302.54 + 298.04 + 293.20) + 9,486.08 = 1,506.21 + 9,486.08 = 10,992.29 百萬美元

**股權價值 (Equity Value)**
*   股權價值 = 企業價值 - 淨債務
*   淨債務 = 總債務 - 現金及約當現金 = $2.05B - $11.52M = $2.038B
*   股權價值 = $10,992.29 百萬 - $2,038 百萬 = $8,954.29 百萬

**每股內在價值 (Intrinsic Value Per Share)**
*   流通股數：211.99 百萬股
*   每股內在價值 = $8,954.29 百萬 / 211.99 百萬股 = $42.24

**合理價位區間**：考慮到假設的敏感性，我們設定合理價位區間為 **$38.00 - $46.00**。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**
我們將使用同業的平均估值倍數來推算 FLO 的目標價位。

*   **P/E Ratio (Forward)**：
    *   同業平均 Forward P/E (不含 FLO) = (11.86 + 11.90 + 10.99 + 15.87) / 4 = 12.66
    *   FLO 預期 EPS (2026 年) = $0.71 - $0.81 (管理層指引)。取中位數 $0.76。
    *   目標價 = 12.66 * $0.76 = $9.62
*   **P/S Ratio**：
    *   同業平均 P/S (不含 FLO) = (0.78 + 1.30 + 1.00 + 0.67) / 4 = 0.94
    *   FLO TTM 營收 = $5.27B
    *   FLO TTM 每股營收 = $5.27B / 211.99M 股 = $24.86
    *   目標價 = 0.94 * $24.86 = $23.37
*   **EV/EBITDA**：
    *   同業平均 EV/EBITDA (不含 FLO) = (7.80 + 9.50 + 9.10 + 10.20) / 4 = 9.15
    *   FLO TTM EBITDA = $511.53M
    *   FLO 企業價值 = 9.15 * $511.53M = $4,679.55M
    *   FLO 股權價值 = $4,679.55M - $2,038M (淨債務) = $2,641.55M
    *   目標價 = $2,641.55M / 211.99M 股 = $12.46

綜合相對估值法，考慮到 P/E (Forward) 和 EV/EBITDA 更能反映盈利能力和整體價值，我們給出相對估值法下的合理價位區間為 **$9.50 - $13.00**。P/S 估值顯著偏高，可能因為 FLO 的淨利潤率遠低於同業，導致營收雖然有一定規模但未能有效轉化為利潤。

**股息折現模型 (DDM)**
Flowers Foods 具有悠久的股息支付歷史，並連續 24 年增加股息。然而，公司近期將季度股息從 $0.2475 削減至 $0.125，以強化資產負債表。這使得傳統的 DDM 模型應用變得複雜，因為股息增長率不再穩定。

*   **最新年化股息**：$0.125 * 4 = $0.50
*   **股權成本 (Ke)**：6.915% (來自 DCF 模型)
*   **股息增長率 (g)**：由於近期股息削減，預計短期內股息增長將非常緩慢甚至停滯，直到公司財務狀況改善。長期來看，考慮到行業成熟性，我們假設一個非常低的長期股息增長率，例如 1.0%。

DDM = D1 / (Ke - g)
DDM = $0.50 * (1 + 1.0%) / (6.915% - 1.0%) = $0.505 / 0.05915 = $8.54

DDM 模型在當前股息削減的情況下，給出的估值顯著較低，反映了市場對其未來股息增長的不確定性。
