# Afya Ltd (AFYA) 深度估值分析報告

作為資深投資分析師，針對巴西領先的醫學教育集團 **Afya Ltd (AFYA)**，我結合了最新的財報數據（2024 Q3 財報）、產業競爭格局以及宏觀經濟背景進行了全面評估。Afya 目前展現出極高的獲利能力與穩健的現金流，但其估值深受巴西宏觀風險與匯率波動的壓制。

- **溢價合理性**：相較於一般高等教育，醫學教育具有極高的進入門檻（受巴西教育部監管與學額限制）與極高的學生終身價值（LTV）。Afya 相對於一般教育股應享有溢價，但目前市場因巴西利率（Selic）高企與匯率風險，給予了過度的風險折價。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

**預測假設：**
- **預測期間**：2024 - 2028 (5年)。
- **營收增長率**：預計未來 3 年保持 12-15% 的增長。動力來自於現有醫學學額的自然增長（Maturation of seats）以及數位服務部門的擴張。
- **EBITDA Margin**：假設穩定在 40% 左右，受惠於規模效應抵消通膨壓力。
- **有效稅率**：預計為 15%（受惠於巴西「Prouni」教育稅收優惠）。
- **資本支出 (CapEx)**：佔營收約 8-10%，主要用於校園維護與數位平台研發。

**折現率與終值：**
- **WACC 計算**：
  - 無風險利率 (US 10Y + Brazil Country Risk)：4.2% + 3.0% = 7.2%。
  - 股權風險溢價 (ERP)：6.0%。
  - Beta：0.95。
  - 債務成本 (Pre-tax)：11.5% (參考巴西 CDI 利率)。
  - **最終 WACC：12.8%** (反映了較高的巴西主權風險溢價)。
- **終值增長率 (g)**：3.5% (與巴西長期通膨目標一致)。

**估值結果：**
- **企業價值 (EV)**：約 18.5 億美元。
- **淨負債**：約 4.2 億美元。
- **股權價值**：14.3 億美元。
- **每股內在價值**：**$15.65**。

### 3. 多維度估值法 (Other Valuation Methods)

- **相對估值法 (Relative Valuation)**：
  若給予 Afya 歷史平均 Forward P/E 8.0x（仍低於美股教育板塊平均），以 2025 年預期 EPS $2.00 計算，目標價為 **$16.00**。
  
- **股息折現模型 (DDM)**：
  Afya 目前殖利率高達 6.06%。假設未來股息增長率為 4%，要求回報率為 12.8%，根據 Gordon Growth Model：$0.65 / (0.128 - 0.04) = **$7.38**。
  *註：DDM 估值較低，主因是公司仍處於擴張期，大量現金流用於償債與再投資，而非全額派息。*

- **P/FCF 估值**：
  目前 P/FCF 為 4.73x，遠低於其 5 年平均值 12x。若回歸至 8x 的保守水準，股價具備 70% 的上行空間。

**最終結論：**
1. **合理價位區間**：**$14.20 - $16.50**
2. **目前股價位階**：**顯著低估 (Significantly Undervalued)**
3. **投資核心論點**：Afya 擁有極強的護城河，其醫學教育業務在巴西具有壟斷性特質且抗週期。目前 5.4x 的前瞻本益比與 4.7x 的 P/FCF 顯示市場已過度反應巴西宏觀風險。隨著巴西降息預期升溫及醫學學額持續成熟，估值修復空間巨大。主要風險在於巴西雷亞爾 (BRL) 持續貶值導致美元計價回報縮水。
