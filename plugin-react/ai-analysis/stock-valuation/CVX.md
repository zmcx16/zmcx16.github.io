# Chevron Corp (CVX) 深度估值分析報告

#### 估值地位分析
- **溢價狀態**：CVX 目前相對於同業（尤其是歐洲同行）處於顯著的**溢價 (Premium)** 狀態。其 19.72 的 P/E 遠高於 XOM 的 14.85。
- **合理性分析**：此溢價主要源於其**極低的資產負債率 (Debt/Eq 0.2)** 與強大的資本回報政策。市場正對其在二疊紀盆地 (Permian Basin) 的產量增長以及收購 Hess (HES) 帶來的圭亞那資產潛力進行定價。然而，相較於 COP 的高利潤率，CVX 的營運效率仍有提升空間。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### 預測假設
- **預測期間**：2025 - 2029 (5年)。
- **營收增長率**：預計未來 3 年受惠於產量擴張，營收增長約 4-5%，隨後放緩至 2% 的永續水平。
- **自由現金流 (FCF) 利潤率**：設定在 11%-13% 區間（參考 P/FCF 14.91 與當前資本支出計劃）。
- **稅率**：有效稅率假設為 22%。

#### 折現率與終值
- **WACC 計算**：
  - 無風險利率 (10Y Treasury): 4.2%
  - Beta: 1.1 (能源股波動特性)
  - 股權風險溢價: 5.5%
  - 權益成本 (Ke): 10.25%
  - 稅後債務成本: 4.5%
  - **最終 WACC: 約 9.2%**
- **終值增長率 (g)**：2.0% (符合長期通膨與能源需求預期)。

#### 估值結果
- **企業價值 (EV)**：約 $435.0 Billion。
- **內在價值 (每股)**：**$198.50**。
- **合理價位區間**：$188 - $209。

### 3. 多維度估值法 (Other Valuation Methods)

#### 相對估值法 (Relative Valuation)
參考行業平均 Forward P/E (約 13.5x) 與 CVX 歷史溢價，給予 15.0x 的目標倍數。
- 預估 EPS (Next Year): $13.03 (基於 Forward P/E 15.79 推算)
- **目標價 = 15.0 * 13.03 = $195.45**

#### 股息折現模型 (DDM)
CVX 是著名的「股息貴族」，適用於戈登增長模型 (Gordon Growth Model)。
- 預期年度股息 (D1): $6.52 (現行 $1.63/季 * 4)
- 股息增長率 (g): 6% (過去 5 年平均)
- 股權成本 (r): 9.2%
- **估值 = 6.52 / (0.092 - 0.06) = $203.75**

#### 資產基礎估值 (SOTP)
考慮到 CVX 擁有的優質上游資產（二疊紀、哈薩克 Tengiz、澳洲 LNG），其資產淨值 (NAV) 支撐強勁。若 Hess 收購案順利完成，其資產價值將進一步提升約 15-20%。
