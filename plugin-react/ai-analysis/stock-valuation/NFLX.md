作為一名資深股權評價分析師，我將對美股公司 Netflix Inc (NFLX) 進行全面的股票估值分析，並特別加強與同業競爭對手的橫向比較。

### 1. 同業比較分析 (Industry Peer Comparison)

**識別競爭對手**
Netflix (NFLX) 在串流媒體產業的主要競爭對手包括：
*   **Walt Disney Company (DIS)**：擁有 Disney+、Hulu 和 ESPN+ 等串流服務，並在傳統媒體和主題公園領域佔據主導地位。
*   **Warner Bros. Discovery (WBD)**：旗下擁有 HBO Max (現為 Max) 和 Discovery+ 等串流平台，以及龐大的電影和電視內容庫。
*   **Paramount Global (PARA)**：營運 Paramount+ 串流服務，並擁有 CBS、MTV 等電視網絡及派拉蒙影業。

**估值地位分析**
從同業比較來看，Netflix 相對於其主要競爭對手，在多個估值指標上呈現出溢價狀態，但其盈利能力和成長性也更為突出：

*   **P/E Ratio (本益比)**：Netflix 的TTM P/E為17.17，低於DIS的21.0x，但WBD和PARA的P/E因盈利問題而失真（WBD為負，PARA極高）。然而，Netflix的Forward P/E為15.81，顯示市場預期其未來盈利增長將使其估值更具吸引力，且低於WBD的143.54x，但略高於DIS的13.8x和PARA的12.08x。
*   **P/S Ratio (股價營收比)**：Netflix 的P/S為4.88，顯著高於DIS (2.04x)、WBD (1.93x) 和PARA (0.24x)。這表明市場願意為Netflix的每一美元營收支付更高的價格，反映了其更高的利潤率和成長預期。
*   **EV/EBITDA (企業價值倍數)**：Netflix 的EV/EBITDA為15.87x，高於DIS的11.6x和PARA的8.10x。WBD的30.28x則因其EBITDA較低而顯得異常高。Netflix的較高倍數反映了其在串流媒體市場的領先地位、強勁的盈利能力和持續的內容投資所帶來的競爭優勢。
*   **成長性與盈利能力**：Netflix 在Q3 2026實現了11.8%的營收年增長率，遠超WBD (-6.05%) 和PARA (-1.56%) 的負增長，也高於DIS (3.35%)。此外，Netflix 的營業利潤率 (34.6%) 和淨利潤率 (28.46%) 均顯著優於WBD (營業利潤率7.53%，淨利潤率-8.77%) 和PARA (營業利潤率10.26%，淨利潤率-0.05%)。這表明Netflix在規模擴張的同時，其盈利效率也保持領先。

**結論**：Netflix 相對於同業處於溢價狀態，這主要是由於其在串流媒體市場的領導地位、持續的用戶增長、強勁的盈利能力以及相對較高的營收增長率所支撐。儘管其估值倍數較高，但考慮到其市場地位和盈利效率，這種溢價在一定程度上是合理的。然而，投資者仍需關注其未來增長的可持續性以及內容成本的控制。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

DCF模型旨在估算公司未來自由現金流的現值，以得出其內在價值。

**預測假設**

*   **預測期間**：5年詳細預測期 (2027-2031)，之後進入永續增長階段。
*   **營收增長率預期**：
    *   Netflix Q3 2026營收年增長11.8%，並預計2027年將實現雙位數營收增長。
    *   考慮到其廣告業務的快速增長（2026年預計超過80%） 和全球用戶擴張潛力，但同時面臨市場飽和和競爭加劇，我們假設：
        *   2027年：11.0% (略低於Q3 2026，考慮到基數效應和宏觀經濟不確定性)
        *   2028年：10.0%
        *   2029年：9.0%
        *   2030年：8.0%
        *   2031年：7.0%
*   **自由現金流利潤率 (FCF Margin)**：
    *   Netflix TTM (截至2026年9月) 的自由現金流為$11.38B，營收為$49.73B，FCF Margin約為22.88%。
    *   考慮到Netflix對內容投資的持續承諾以及規模經濟效應，我們預計其FCF Margin將保持穩定並略有提升：
        *   2027-2028年：23.0%
        *   2029-2031年：24.0%

**折現率與終值**

*   **加權平均資本成本 (WACC)**：
    *   股權成本 (Cost of Equity, Ke) = 無風險利率 + Beta * 市場風險溢酬
        *   無風險利率 (Risk-Free Rate)：採用4.93% (基於當前市場環境)
        *   Beta：0.8674
        *   市場風險溢酬 (Market Risk Premium, ERP)：4.3%
        *   Ke = 4.93% + 0.8674 * 4.3% = 4.93% + 3.73% = 8.66%
    *   債務成本 (Cost of Debt, Kd)：5.79%
    *   有效稅率 (Effective Tax Rate)：25.5% (聯邦與州平均)
    *   稅後債務成本 (Kd_at) = 5.79% * (1 - 0.255) = 4.31%
    *   股權權重 (We) = 1 / (1 + 債務/股權比) = 1 / (1 + 0.59) = 0.6289
    *   債務權重 (Wd) = 0.59 / (1 + 0.59) = 0.3711
    *   **WACC = (0.6289 * 8.66%) + (0.3711 * 4.31%) = 5.44% + 1.60% = 7.04%**

*   **終值增長率 (Terminal Growth Rate, g)**：
    *   考慮到Netflix作為成熟行業領導者的地位，以及全球經濟的長期增長潛力，我們假設永續增長率為 **2.5%**。

**估值結果 (DCF 模型)**

為簡化計算，我們將使用上述假設進行估算。
*   **基期營收 (TTM Sep 2026)**: $49.73B
*   **基期自由現金流 (TTM Sep 2026)**: $11.38B

| 年度 | 營收增長率 | 預測營收 (Billion USD) | FCF Margin | 預測自由現金流 (Billion USD) | 折現因子 (WACC=7.04%) | 自由現金流現值 (Billion USD) |
| :--- | :--------- | :--------------------- | :--------- | :----------------------------- | :--------------------- | :----------------------------- |
| 2026 (TTM) | -          | 49.73                  | 22.88%     | 11.38                          | -                      | -                              |
| 2027 | 11.0%      | 55.20                  | 23.0%      | 12.69                          | 0.9342                 | 11.85                          |
| 2028 | 10.0%      | 60.72                  | 23.0%      | 13.97                          | 0.8728                 | 12.20                          |
| 2029 | 9.0%       | 66.18                  | 24.0%      | 15.88                          | 0.8154                 | 12.97                          |
| 2030 | 8.0%       | 71.47                  | 24.0%      | 17.15                          | 0.7618                 | 13.07                          |
| 2031 | 7.0%       | 76.47                  | 24.0%      | 18.35                          | 0.7117                 | 13.06                          |
| **預測期自由現金流現值總和** | | | | | | **63.15** |

*   **終值 (Terminal Value)**：
    *   永續增長自由現金流 (FCF_2032) = FCF_2031 * (1 + g) = 18.35 * (1 + 0.025) = 18.81B USD
    *   終值 = FCF_2032 / (WACC - g) = 18.81B / (0.0704 - 0.025) = 18.81B / 0.0454 = 414.32B USD
    *   終值現值 = 終值 / (1 + WACC)^5 = 414.32B / (1 + 0.0704)^5 = 414.32B / 1.4036 = 295.19B USD

*   **企業價值 (Enterprise Value)** = 預測期自由現金流現值總和 + 終值現值
    *   企業價值 = 63.15B + 295.19B = 358.34B USD

*   **股權價值 (Equity Value)** = 企業價值 + 現金及約當現金 - 總債務
    *   Netflix 總債務約為$15.3B，現金及約當現金約為$8.23B。
    *   股權價值 = 358.34B + 8.23B - 15.3B = 351.27B USD

*   **每股內在價值 (Intrinsic Value Per Share)** = 股權價值 / 流通股數
    *   流通股數 (Q3 2026稀釋後) 約為4.195B股。
    *   每股內在價值 = 351.27B / 4.195B = **$83.74**

*   **合理價位區間**：考慮到假設的敏感性，我們可以設定一個區間。若WACC在6.5%至7.5%之間，永續增長率在2.0%至3.0%之間，每股內在價值可能落在 **$75 - $95** 之間。

### 3. 多維度估值法 (Other Valuation Methods)

**相對估值法 (Relative Valuation)**

我們將使用同業的平均估值倍數來推算Netflix的目標價位。由於WBD和PARA的盈利能力不穩定，其P/E倍數參考價值較低。我們主要參考DIS和NFLX自身的歷史倍數。

*   **P/E Ratio (本益比)**：
    *   NFLX TTM P/E: 17.17
    *   DIS TTM P/E: 21.0x
    *   行業平均 (剔除異常值)：約19.0x (取NFLX和DIS的平均)
    *   NFLX TTM EPS (基於$3.7B淨利潤和4.195B股數): $0.88/股 (Q3 2026淨利潤為$3.7B，但這是季度數據，TTM EPS為$3.45)。使用TTM EPS $3.45。
    *   基於行業平均P/E的目標價 = $3.45 * 19.0 = **$65.55**

*   **P/S Ratio (股價營收比)**：
    *   NFLX TTM P/S: 4.88
    *   DIS TTM P/S: 2.04x
    *   WBD TTM P/S: 1.93x
    *   PARA TTM P/S: 0.24x
    *   行業平均 (剔除PARA的極低值)：約2.95x (取NFLX, DIS, WBD的平均)
    *   NFLX TTM Revenue Per Share (基於$49.73B營收和4.195B股數): $11.85/股
    *   基於行業平均P/S的目標價 = $11.85 * 2.95 = **$34.96** (此方法對NFLX可能低估，因其利潤率遠高於同業)

*   **EV/EBITDA (企業價值倍數)**：
    *   NFLX EV/EBITDA: 15.87x
    *   DIS EV/EBITDA: 11.6x
    *   WBD EV/EBITDA: 30.28x
    *   PARA EV/EBITDA: 8.10x
    *   行業平均 (剔除WBD的極高值)：約11.86x (取NFLX, DIS, PARA的平均)
    *   NFLX TTM EBITDA Per Share (基於$15.96B EBITDA和4.195B股數): $3.80/股
    *   基於行業平均EV/EBITDA的目標價 = $3.80 * 11.86 = **$45.00** (此方法也可能低估NFLX，因其成長性更優)

考慮到Netflix的獨特市場地位和盈利能力，簡單的行業平均可能無法完全捕捉其價值。若我們僅考慮Netflix自身的歷史估值區間，並結合其成長性，P/E和EV/EBITDA倍數可能更具參考價值。

**股息折現模型 (DDM)**
根據提供的基本面數據，Netflix 的 "Dividend %" 為 "-"，表示公司目前不派發股息。因此，股息折現模型不適用於本次估值。

**其他方法**
資產基礎估值 (Asset-based) 或 SOTP (Sum-of-the-parts) 對於Netflix這類以無形資產（內容庫、品牌、技術平台）為核心價值的公司而言，通常不適用或難以精確量化。因此，本次分析不採用這些方法。
