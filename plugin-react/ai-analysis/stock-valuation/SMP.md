# Standard Motor Products, Inc. (SMP) 深度估值分析報告

作為資深投資分析師，針對 Standard Motor Products (SMP) 的估值分析將結合其在汽車售後市場（Aftermarket）的穩健地位、近期收購案（如 Nissens Automotive）的影響，以及當前市場對其價值股的定價邏輯進行深度剖析。

- **資產效率**：SMP 的 P/S 比率 (0.46) 顯示其營收規模相對於市值極大，若利潤率能因收購整合而提升，股價具備極強的彈性。
- **結論**：相對於 DORM 的溢價，SMP 目前處於「價值窪地」，市場尚未完全反映其在溫度控制領域的市場份額優勢。

### 2. 折現現金流模型 (Discounted Cash Flow, DCF)

#### **預測假設**
1.  **預測期間**：5 年 (2025-2029)。
2.  **營收增長率**：預計未來 3 年為 3.5% - 4.5%（考慮到 Nissens 收購帶來的歐洲市場擴張與電動車熱管理零件的增長），隨後回歸 2% 的永續增長。
3.  **自由現金流 (FCF) 利潤率**：假設維持在 5.5% - 6.2% 區間。SMP 具備穩定的現金產生能力，P/FCF 為 9.68 顯示其現金流品質良好。
4.  **稅率**：25%。

#### **折現率與終值**
- **WACC 計算**：
    - 無風險利率 (10Y Treasury): 4.3%
    - Beta: 1.1 (反映汽車產業週期性)
    - 股權風險溢價 (ERP): 5.5%
    - 權益成本 (Ke): 4.3% + 1.1 * 5.5% = 10.35%
    - 稅後債務成本: ~5.2%
    - **WACC 最終設定：8.8%** (考慮到中小市值風險溢價)。
- **終值增長率 (g)**：2.0%。

#### **估值結果**
- **企業價值 (EV)**：約 $13.8 億。
- **扣除淨負債**：約 $3.2 億。
- **股權價值**：約 $10.6 億。
- **DCF 每股內在價值**：**$47.50**。

### 3. 多維度估值法 (Other Valuation Methods)

#### **相對估值法 (Relative Valuation)**
- **Forward P/E 乘數法**：參考同業平均 Forward P/E 約 11x。
- 計算：預估 EPS ($4.89) × 10x (保守給予折價) = **$48.90**。
- **P/S 乘數法**：給予 0.55x P/S（歷史中位數）。
- 計算：(14.6 億營收 × 0.55) / 22.3M 股 = **$36.00**。

#### **股息折現模型 (DDM)**
- **參數**：現年股息 $1.24，預期增長率 3%，要求回報率 (Ke) 10.35%。
- **計算**：$1.24 * 1.03 / (0.1035 - 0.03) = **$17.37**。
- *註：由於 SMP 傾向於將資金用於收購而非全額派息，DDM 僅供參考，權重較低。*
